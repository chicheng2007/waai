# 第 9 关 · 堆布局自动化：让脚本帮你摆柜子

## 🎬 游戏开场

House of Apple 这种现代连招,你要精确控制十几个 chunk 的位置、大小、释放顺序——手动算一遍脑子就炸了,改一个参数全部重来。

聪明的玩家不手动摆柜子,而是写**布局脚本**:用代码描述"先申请几个什么大小的 chunk、再释放谁、再写什么",让脚本自动生成布局并验证。

这一关我们学怎么把堆布局"代码化",这是打复杂堆题的工程能力。

---

## 🧠 核心概念（游戏版）

### 1. 为什么要自动化?

- **可复现**:脚本每次跑出一样的布局,方便调试。
- **可调参**:改一个数字,重新生成,不用手动重摆。
- **可验证**:脚本能自动检查"目标 chunk 是否在预期地址"。

游戏翻译:与其每次手工摆柜子,不如写一个"摆柜机器人",你说参数它摆好,还帮你检查摆得对不对。

### 2. 用 pwntools 封装堆操作

把菜单式交互封装成函数:

```python
def add(idx, size, data):
    p.recvuntil(b'choice:')
    p.sendline(b'1')
    p.recvuntil(b'index:')
    p.sendline(str(idx).encode())
    p.recvuntil(b'size:')
    p.sendline(str(size).encode())
    p.recvuntil(b'data:')
    p.sendline(data)

def delete(idx):
    p.recvuntil(b'choice:')
    p.sendline(b'2')
    p.recvuntil(b'index:')
    p.sendline(str(idx).encode())

def edit(idx, data):
    ...
def show(idx):
    ...
```

有了这些积木函数,布局就是调用序列:

```python
# 布置两个large chunk + 一个guard
add(0, 0x500, b'A'*0x500)
add(1, 0x30, b'guard')
add(2, 0x520, b'B'*0x520)
add(3, 0x30, b'guard2')
delete(0)     # 制造unsorted bin
```

### 3. 布局的"参数化"

把关键地址和大小写成常量,集中管理:

```python
CHUNK_A_SIZE = 0x500
CHUNK_B_SIZE = 0x520
TARGET = libc_base + 0x...   # 目标地址
```

这样版本换了只要改常量,不用重写整个 exp。

### 4. 用 pwndbg 脚本辅助验证

gdb 的 pwndbg 支持脚本化:

```bash
(gdb) source layout.gdb
```

写一个 gdb 脚本,在关键断点自动打印堆布局:

```gdb
break malloc
commands
    silent
    heap
    continue
end
```

让调试过程自动化,一眼看出布局偏在哪。

### 5. 布局模板化

把常见的布局套路存成模板,下次直接套:

```python
# 模板:制造UAF + 泄露libc
def leak_libc_via_unsorted():
    add(0, 0x500, b'A')
    add(1, 0x20, b'guard')
    delete(0)
    show(0)
    return parse_leak(...)
```

游戏翻译:把常用的"摆柜套路"存成 macros(宏),一键调用。
