# 第 14 关 · angr：请个 AI 帮你代打

## 🎬 游戏开场

有些题目是一道"迷宫":程序检查你的输入,只有当输入满足一堆复杂条件时才给你 flag。人肉逆向下条件,可能要啃几百行汇编。

**angr** 是个"AI 代练"——它用**符号执行**技术,把程序当成数学问题,自动推导出"什么输入能走到正确分支"。你只要告诉它"我要到这个地址(成功)""避开那个地址(失败)",它就自己算出答案。

游戏比喻:你不用自己走迷宫,而是派一个机器人进去,它把每条路都"符号化"地走一遍,最后告诉你"走左边、左边、右边就能到终点"。

---

## 🧠 核心概念（游戏版）

### 1. 符号执行是什么?

普通执行:输入 `abc`,程序算出结果。

符号执行:把输入当成**符号变量**(比如叫 x,它可以是任意值),程序每走一个判断分支,就记下"走这条路需要 x 满足什么条件"。最后把所有条件收集起来,用约束求解器(SMT)解出满足条件的 x。

游戏比喻:机器人不实际走,而是记下"要过这关需要钥匙A""过下一关需要密码是1234",最后汇总成一张"通关条件清单",求解器一算就得出答案。

### 2. angr 基本用法

```python
import angr

p = angr.Project('./maze', auto_load_libs=False)

# 从main开始,把输入符号化
state = p.factory.entry_state()

# 创建模拟管理器,开始探索
simgr = p.factory.simgr(state)

# 探索:目标是good地址,避开bad地址
simgr.explore(
    find=0x400a00,      # 成功分支地址
    avoid=0x400b00      # 失败分支地址
)

# 找到解,打印输入
if simgr.found:
    print(simgr.found[0].posix.dumps(0))
```

### 3. 典型场景

- **迷宫/验证题**:输入满足复杂条件 → angr 求解。
- **绕过检查**:找到"能走到解密函数"的输入。
- **ctf 的 "re" 题**:angr 是逆向神器(虽然本教程讲 PWN,但 angr 跨领域)。

### 4. 局限性

- **路径爆炸**:分支太多,符号执行会指数爆炸(游戏迷宫太大,机器人跑不过来)。
- **系统调用/复杂逻辑**:真实 PWN 程序有栈溢出、指针操作,angr 处理起来困难。
- **需要合理设置 find/avoid**:地址要对,否则探索无果。

游戏比喻:angr 走迷宫很强,但迷宫太大它会累;遇到需要真实交互(如网络)的关卡,它就不擅长了。

### 5. 和其他工具的关系

- **angr**:符号执行,适合求解输入条件。
- **AFL**(第 15 关):模糊测试,适合暴力找崩溃。
- 两者都是"自动化挖洞/解题"的利器,互补。
