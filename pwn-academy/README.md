## 🧭 你该从哪套开始？

```
你是完全零基础?
  ├─ 是 → 从 03-core-game(基础·游戏版)第1关开始
  │         看不懂某个概念? → 翻 01-core(基础·硬核版)对应章节
  └─ 否 → 你能独立做中低难度栈题吗?
       ├─ 否 → 01-core(基础·硬核版)系统学习
       └─ 是 → 04-deep-game(进阶·游戏版)看现代招式
                 想深挖源码 → 02-deep(进阶·硬核版)
```

**推荐组合读法**:

- **零基础路线**:03-core-game（游戏版入门）→ 01-core（硬核版补细节）→ 04-deep-game（游戏版进阶）→ 02-deep（硬核版深挖）
- **速成路线**:03-core-game → 04-deep-game（纯游戏版，快速建立全局观）
- **查阅路线**:把 01-core / 02-deep 当工具书，遇到问题再翻

## 🎮 游戏版的世界观速览

游戏版（03、04）把整个 PWN 世界包装成一款叫**《内存城》**的闯关游戏。所有概念都有游戏对应:

| 游戏说法 | 真实术语 |
| --- | --- |
| 内存城市、门牌号 | 内存、地址 |
| 藏宝图坐标 | 指针 |
| 叠盘子、回城卷轴 | 栈、返回地址 |
| 往盘子堆太多菜 | 栈溢出 |
| 乐高积木 | ROP gadget |
| 餐桌警报器 | Canary |
| 储物柜租赁系统 | 堆（malloc/free） |
| 退租偷留钥匙 | UAF |
| 快速回收筐的防伪章/打码 | tcache key / safe-linking |
| 假存档卡、官方技能表按钮 | fake FILE / House of Apple |
| AI 代打、试错机器人 | angr / AFL |

详细对照表见 [03-core-game/appendix/glossary-game.md](03-core-game/appendix/glossary-game.md)。
