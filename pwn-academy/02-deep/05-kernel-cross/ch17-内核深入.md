# 第 17 章 内核 PWN 深入

> 基础版介绍了内核 PWN 的基本概念，这一章深入内核堆（slab/slub）和常用的利用辅助技术。

---

## 17.1 内核堆：slab/slub 分配器

内核中的小对象通过 **slab** 或 **slub** 分配器管理（现代内核默认是 slub）。

```text
kmalloc(size) → slub 分配器 → 从 kmem_cache 中取一个 object
```

每个 `kmem_cache` 管理一种固定大小的对象。同大小的对象来自同一个 slab 页。

```bash
# 查看内核的 slab 缓存
cat /proc/slabinfo
```

---

## 17.2 内核态 UAF

内核模块中的 UAF 和用户态类似，但目标不同：

- 用户态 UAF → 劫持函数指针 → getshell
- 内核态 UAF → 修改 cred 结构 → 提权

### 17.2.1 常见目标对象

- `struct cred`：进程权限
- `tty_struct`：终端设备（含函数指针）
- `seq_operations`：包含函数指针
- `sk_buff`：网络数据包

---

## 17.3 userfaultfd 与堆喷

**userfaultfd** 允许在用户态处理缺页异常。利用它可以**精确控制内核访问某块内存的时间**——这对堆利用中的竞态条件非常有用。

```c
// 创建 userfaultfd
int ufd = syscall(__NR_userfaultfd, O_CLOEXEC | O_NONBLOCK);
// 注册一个地址范围
ioctl(ufd, UFFDIO_REGISTER, &range);
// 当内核访问这个范围时会阻塞，等待用户态处理
```

**堆喷（Heap Spray）**：大量分配相同大小的对象，提高命中率。

---

## 17.4 内核利用的一般流程

```text
1. 逆向漏洞模块，找到漏洞（UAF、溢出等）
2. 构造原语：任意读/任意写
3. 泄露内核地址（绕过 KASLR）
4. 修改 cred 提权，或劫持控制流执行 commit_creds
5. 返回用户态，获得 root shell
```
