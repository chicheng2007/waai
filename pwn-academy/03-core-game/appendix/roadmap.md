- [ ] 栈溢出为什么能覆盖返回地址?偏移怎么测?
- [ ] NX 开着为什么 ret2shellcode 失效?ROP 为什么能绕过?
- [ ] ret2libc 为什么要泄露 libc 基址?怎么泄露?
- [ ] Canary 怎么泄露?为什么能原样填回?
- [ ] UAF 和 Double Free 的区别是什么?
- [ ] tcache poisoning 的原理是什么?safe-linking 怎么破?
- [ ] 堆风水为什么重要?

## 🚀 毕业之后:进阶版地图

《进阶版游戏化简单易懂版》将带你:

- **走进后台**:malloc/free/tcache 源码级理解
- **现代连招**:House of Apple、FSOP、largebin attack
- **存档系统**:IO_FILE vtable 演化史
- **自动闯关**:angr 符号执行、AFL 模糊测试
- **新地图**:内核深入、Windows、ARM

从"会用招式"到"理解招式从哪来",再到"让机器帮你找漏洞"。
