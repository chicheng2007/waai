## 🧠 核心概念（游戏版）

### 1. 什么是 PWN？

在游戏里，"PWN" 这个词最早是玩家对别人的调侃："你被 PWN 了" 意思是 "你被打败了"。

在 CTF（夺旗赛）里，**PWN 题**就是：给你一个程序（一个游戏关卡），你要找到它的 Bug，让它按你的意愿运行，最后拿到服务器上藏着的**旗子（flag）**。

一句话：

> **PWN = 找到程序的 Bug → 利用 Bug 控制程序 → 拿到 flag。**

### 2. 你的"武器"是什么？

普通玩家玩游戏用键盘鼠标。你用的是：

| 装备 | 游戏里的作用 | 真实名字 |
| --- | --- | --- |
| 藏宝图 | 看清城市布局 | 二进制文件（ELF） |
| 透视挂 | 看到内存里每一格的值 | gdb 调试器 |
| 游戏手柄 | 自动跟 NPC 对话 | pwntools |
| 作弊码本 | 各种现成套路 | exp 脚本模板 |

别怕，这些装备第 26、27 关会手把手教你用。现在你只要知道它们存在就行。

### 3. 内存是一座城市

这是全书最重要比喻，务必记住：

想象内存是一座**巨大的城市**：

- **每一格内存 = 城里的一间小屋**，能住一个字节（8 位，范围 0~255）。
- **每个字节 = 一个房间号 + 房间里的东西**。房间号就是**地址**（address）。
- **地址是连续的**：0x1000、0x1001、0x1002……就像门牌号一条街排过去。
- **CPU = 城市的管理员**，它拿着一张指令清单，按顺序走到每个房间，检查里面的东西，做相应的操作。

```
内存城市的一条街：

地址:   0x1000   0x1001   0x1002   0x1003   0x1004  ...
       ┌───────┬───────┬───────┬───────┬───────┐
内容:  │  0x48 │  0x65 │  0x6c │  0x6c │  0x6f │ ...
       │  'H'  │  'e'  │  'l'  │  'l'  │  'o'  │
       └───────┴───────┴───────┴───────┴───────┘
```

看，字符串 "Hello" 就这样住在内存的连续房间里。

**关键认知**：程序的一切——你的输入、变量、代码、返回地址——全都住在这座城市里，没有魔法，只有门牌号和房间里的数据。你后面所有的"攻击"，本质上都是：**想办法改掉某些房间里的值，让管理员（CPU）按你的意思办事。**

### 4. 字节的"读法"：小端序

游戏里有个奇怪的设定：有些东西的写法和你想的不一样。

比如数字 `0x12345678`（这是一个 4 字节的整数），你在城市里看到它的房间是这样排的：

```
正常想法（大端）： 12 34 56 78
城市实际（小端）： 78 56 34 12   ← 低位字节住小门牌号
```

这叫**小端序（little-endian）**：**低位的数字，住在低地址**。就像这座城市规定"尾巴朝前放"。

> 游戏提示：x86、x86-64 的电脑都是小端序。你以后写 payload 时会反复遇到它，现在先记住"反过来写"就行。

## 🔧 真实世界对照

上面讲的全是比喻，现在把它翻译成真实术语：

| 游戏说法 | 真实术语 | 说明 |
| --- | --- | --- |
| 城市 | 内存空间（虚拟地址空间） | 一个进程独占的"地盘" |
| 门牌号 | 地址（address） | 通常用十六进制表示，如 `0x7ffffffe1234` |
| 小屋 | 字节（byte） | 内存的最小寻址单位，8 bit |
| 城市管理员 | CPU | 取指、译码、执行 |
| 指令清单 | 代码段（.text） | 编译后的机器指令 |
| 旗子 | flag | 比赛要拿的字符串，形如 `flag{...}` |
| 关卡 | 一个有漏洞的二进制程序 | 通常运行在远程服务器 |

**你在这个游戏里到底要做什么？**

典型流程是这样的：

1. 主办方给你一个程序（比如一个"猜数字游戏"）。
2. 你运行它，发现它有个 Bug——比如你输入超长字符串会让它崩溃。
3. 你利用这个 Bug，让程序执行一段你准备好的代码。
4. 这段代码帮你打开一个"远程终端"（shell），你输入 `cat flag`，旗子到手。

这道题的解法脚本（exp）长这样，先混个脸熟：

```python
from pwn import *

p = remote("比赛服务器", 10001)      # 连接游戏关卡
payload = b"A" * 64 + p64(0xdeadbeef) # 作弊码：填充满 + 改返回地址
p.sendline(payload)                   # 发送作弊码
p.interactive()                       # 进入游戏控制台，拿 flag
```

看不懂？没关系。等你打完新手村，这些都会变成你的肌肉记忆。

## 🎯 闯关任务：装配你的第一套装备

光说不练假把式。现在我们就把游戏环境装好（这一步是整个教程唯一需要"动手配置"的地方，之后全是闯关）。

**目标**：装好一个 64 位 Ubuntu 虚拟机 + 三件套工具。

> 如果你已经装好了，跳过这段，直接看"本关小结"。

### 第一步：装系统

推荐用 **Ubuntu 22.04 64 位**（虚拟机或 WSL 都行）。原因：这是 CTF 圈子的"标准游戏机"，资料最多，坑最少。

### 第二步：一句话装工具

打开终端，执行：

```bash
sudo apt update && sudo apt install -y \
    gdb python3 python3-pip git wget \
    gcc multilib gcc-multilib binutils \
    oneaccord || true
```

然后装 pwntools（你的游戏手柄）：

```bash
sudo pip3 install pwntools
```

再装一个辅助查看工具：

```bash
sudo apt install -y checksec
```

### 第三步：验证装备

```bash
python3 -c "from pwn import *; print('pwntools OK')"
gdb --version | head -1
```

看到版本号，就说明你的"新手礼包"领到手了。

### 第四步：领你的第一个关卡

我们写一个最简单的程序来观察内存：

```c
// hello.c
#include <stdio.h>
int main() {
    char name[16];
    printf("你的名字是？");
    gets(name);
    printf("你好，%s！\n", name);
    return 0;
}
```

编译它（关掉保护，方便新手村练习）：

```bash
gcc -g -O0 -fno-stack-protector -no-pie hello.c -o hello
```

运行，输入你的名字。你会发现它"听话"——目前为止还没漏洞可利用。

但注意：`gets(name)` 是个**危险函数**——它不检查你输入多长。如果你输入 100 个字符会发生什么？这就是第 7 关「栈溢出」要讲的事。
