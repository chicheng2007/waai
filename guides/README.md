# guides · 语法学习区

> 一看代码就懵？从这里开始。这个目录只做一件事：**把读代码必备的语法讲到你够用**，不贪多、不死磕。

## 这里有什么

| 文档 | 给谁 | 什么时候看 | 怎么用 |
|---|---|---|---|
| [3 天语法急救包](SYNTAX-BOOTCAMP.md) | 只会 `print`、变量赋值，一看 `for` / `.split()` 就懵的人 | **完全零基础，马上要读代码时** | 按顺序 3 天读完，只讲 5 个零件：for、列表、split/strip、字典、函数 |
| [语法库大全](SYNTAX-REFERENCE.md) | 会一点基础，写代码卡住、某语法忘了怎么写的人 | **随查随用，不用从头读** | 按目录定位：Python 全套语法 + 网安代码片段 + C/C++/Rust/Go 对照 + 报错速查 |

## 两者怎么配合

- **先急救，后速查**：完全零基础 → 先花 3 天读急救包建立"能读懂代码"的最低基础；之后写代码遇到忘了的语法 → 翻语法库大全。
- **急救包是"线"**（3 天一条路径读完），**语法库是"点"**（字典式随查）。
- 两份文档都用"发牌 / 切香肠"这类生活比喻，配合你反馈过的"这种语法不懂"问题写的。
