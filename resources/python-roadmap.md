# Python 学习路线（网安 + AI 方向专用）

> 目标：从"只会基础语法"到"能用 Python 解决网安和 AI 的实际问题"。
> 定位：Python 是软考之外**三条线的共同底座**——AI 全靠它，CTF 脚本、取证分析、日志处理也都靠它。这门语言练熟了，后面三条线都会顺。

## 一、你在哪一格？目标在哪？

```
你现在：会 Python / C++ 基础语法（变量、循环、函数、if）
目标：  能独立写脚本处理数据、分析日志、跑机器学习模型
差距：  不是"学语法"，而是"用 Python 做事"——标准库、数据处理、工程习惯
```

**一句话**：别再从 `print("hello world")` 开始，你的重点是**标准库 + 数据处理 + 实战**。语法不懂的地方边用边查。

**核心原则**：
1. **不啃语法书**：语法你已经会了，缺的是"用"。书当字典查，别从头读到尾。
2. **每天敲代码**：看懂 ≠ 会写。哪怕 20 分钟，手不能停。
3. **结合网安场景练**：学一个知识点，立刻配一个网安/AI 小练习，记忆最深。
4. **用 AI 加速**：报错直接问大模型，让它解释、改代码，但**每行都要看懂**。
5. **一次深入，别贪多**：一个库练到能写小项目，再开下一个。

## 三、台阶 1：语法查漏 + Python 思维

**别重学语法，只补这几处高频坑**（你会 C++，注意 Python 的不同）：

| 知识点 | C++ 思维要转换的地方 | 练习 |
|---|---|---|
| 列表 / 字典 / 集合 | 动态类型、引用语义 | 用 dict 统计一段文本的词频 |
| 列表推导式 | C++ 没有，Python 核心写法 | `[x*2 for x in range(10) if x%2==0]` |
| 切片 `s[1:5]` | 字符串 / 列表通用 | 截取日志里的固定字段 |
| `for ... in` | 迭代的是对象不是下标 | 遍历文件内容逐行处理 |
| 可变 / 不可变 |  list 能改、tuple / str 不能 | 理解为什么函数里改 list 会影响外部 |
| 缩进与作用域 | 靠缩进，不用大括号 | 写个嵌套判断的小函数 |

**网安小练习**：
- 写一个脚本，输入一段字符串，统计每个字符出现次数（用 dict）
- 写一个"密码强度检查器"：判断长度、是否含数字/大小写/符号

**自测**：能在 20 分钟内写出一个 50 行以内、逻辑完整的小脚本。

## 四、台阶 2：核心数据结构与文件处理

这是"能处理真实数据"的分水岭。学这些：

| 内容 | 用法 | 网安/取证场景 |
|---|---|---|
| `open()` / `with` | 读写文本、指定 `encoding='utf-8'` | 读取日志文件、火眼导出的报告 |
| `csv` 模块 | `csv.reader` / `csv.writer` | 处理流量表、资产清单 |
| `json` 模块 | `json.loads` / `json.dumps` | 解析 API 返回、配置文件 |
| `os` / `pathlib` | 路径、遍历目录、批量改名 | 批量处理镜像文件、证据文件 |
| 异常处理 `try/except` | 别让脚本一报错就崩 | 处理格式不规范的数据 |

**代码示例：读日志统计每个 IP 出现次数**
```python
from collections import Counter

counts = Counter()
with open("access.log", encoding="utf-8") as f:
    for line in f:
        parts = line.split()
        if parts:
            counts[parts[0]] += 1

for ip, n in counts.most_common(10):
    print(ip, n)
```

**自测**：能独立写一个脚本，读入一个 CSV，统计出某个字段的分布并打印。

## 五、台阶 3：正则表达式（网安必备）

**这是网安和取证最高频的技能**——从海量文本里捞关键线索全靠它。认真学。

| 语法 | 作用 | 例子 |
|---|---|---|
| `\d` `\w` `\s` | 数字 / 单词字符 / 空白 | 匹配日志字段 |
| `.` `*` `+` `?` | 通配与数量 | 模糊匹配 |
| `[abc]` `[^abc]` | 字符集 | 匹配特定字符范围 |
| `^` `$` | 行首行尾 | 精确锚定 |
| `(...)` 分组 | 提取子串 | 抓取 IP、时间、URL |
| `re.findall` / `re.search` | 查找 / 匹配 | 批量提取 |

**代码示例：从日志里提取 IP 和时间**
```python
import re

text = "2026-11-23 10:30:01 192.168.1.10 GET /index.html"
pattern = r"(\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2})\s+(\d+\.\d+\.\d+\.\d+)"
m = re.search(pattern, text)
if m:
    print("时间:", m.group(1), "IP:", m.group(2))
```

**网安小练习**：
- 从一段文本里提取所有 IP 地址、邮箱、URL（正则在线测试用 regex101.com）
- 写一个"日志清洗器"：用正则把非结构化日志转成 CSV

**自测**：能不看文档，写出正则从访问日志里提取 IP、时间、请求路径。

## 六、台阶 4：数据处理三件套

AI 和数据分析的地基。软考期每天 30 分钟就能慢慢啃。

| 库 | 学什么 | 重点 |
|---|---|---|
| **numpy** | 数组、矩阵运算、广播 | 理解"矩阵"在代码里怎么表示 |
| **pandas** | DataFrame、筛选、分组、合并 | 数据清洗主力，`read_csv` 必会 |
| **matplotlib** | 折线图、柱状图、散点图 | 把统计结果画出来 |

**代码示例：pandas 分组统计**
```python
import pandas as pd

df = pd.read_csv("traffic.csv")
print(df.head())                       # 看前 5 行
print(df.groupby("label").size())      # 按标签分组计数
print(df["duration"].describe())       # 数值列统计
```

**网安结合**：拿 KDD99 / CIC-IDS2017 数据集（见[链接速查表](links.md#四数据集)），用 pandas 读进来，看看每条连接记录有哪些字段、正常和攻击各多少。

**自测**：能用 pandas 读入一个数据集，做分组统计并画出一张柱状图。

## 七、台阶 5：网络与系统编程（软考后重点）

> ⚠️ **法律红线**：本章所有探测、扫描类脚本，**只能对自己的靶场或书面授权的环境使用**。未授权碰真实系统违法。

| 内容 | 用途 | 场景 |
|---|---|---|
| `requests` | 发 HTTP 请求、调 API | 抓网页、调威胁情报 API、爬 Writeup |
| `socket` | TCP / UDP 通信 | 理解网络协议（和软考知识直接对应） |
| `subprocess` | 调用系统命令 | 批量调用工具、自动化 |
| `threading` | 多线程 | 并发扫描（授权环境） |

**代码示例：用 requests 请求一个网页**
```python
import requests

r = requests.get("https://www.example.com", timeout=10)
print(r.status_code)
print(r.text[:200])
```

**网安小练习**（授权环境）：
- 写一个端口探测脚本（socket 连本机某个端口，判断是否开放）
- 写一个批量查询域名信息的脚本（requests 调公开 API）

**自测**：能写一个脚本，调用一个公开 API 拿到数据并解析出想要字段。

## 八、台阶 6：工程化（全程穿插）

从"能跑"到"能维护、能展示"，这是把项目写进简历的关键：

| 习惯 | 怎么做 | 为什么重要 |
|---|---|---|
| **虚拟环境** | `python -m venv venv`，装依赖前先激活 | 不同项目依赖不冲突 |
| **requirements.txt** | `pip freeze > requirements.txt` | 别人能复现你的环境 |
| **模块化** | 别把所有代码堆一个文件，拆成多个 `.py` | 代码清晰、能复用 |
| **Git** | 每个项目建仓库，勤 commit | 记录进度、展示作品 |
| **注释与命名** | 变量名说清含义，关键逻辑写注释 | 三个月后你还看得懂 |

> 这些不用专门学很久，从第一个小项目就开始用，慢慢成习惯。

## 十一、常见坑（帮你少走弯路）

1. **只看不敲**：视频看了很多，代码一行没写 → 等于没学。每个例子都亲手敲一遍。
2. **死磕语法**：语法会了就往前走，遇到不懂的边用边查，别在语法书上耗。
3. **不装虚拟环境**：依赖装乱了以后很难收拾，从第一个项目就用 venv。
4. **抄代码不理解**：用 AI 生成的代码，逐行看懂再留，否则换道题还是不会。
5. **贪多求快**：同时学 numpy、pandas、requests → 都不精。一个练透再开下一个。
6. **不看报错**：报错信息是提示不是阻碍，读懂它（或问 AI）是基本功。
