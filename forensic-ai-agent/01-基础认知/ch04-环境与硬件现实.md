## 4.1 先算一笔账：8GB 显存能做什么

显卡显存是 AI 开发最硬的限制。先把它算清楚，你就知道哪些事能做、哪些要上云。

一个模型需要多少显存？粗略公式：

```
显存需求 ≈ 参数量 × 每参数字节数 + 运行时开销
```

以 9B（90 亿）模型为例：

| 精度 | 每参数字节 | 9B 模型显存 | 你的 8GB 能跑吗 |
|---|---|---|---|
| FP16（16bit） | 2 字节 | 约 18GB | ❌ 装不下 |
| INT8（8bit 量化） | 1 字节 | 约 9GB | ❌ 勉强不够 |
| INT4（4bit 量化） | 0.5 字节 | 约 4.5GB | ✅ 可以，还有余量 |

**结论**：你的 8GB 显卡，用 4bit 量化能流畅跑 9B 模型；跑 7B 更轻松。

那微调呢？微调需要额外显存存梯度、优化器状态，即使 LoRA 也要多一些。

| 任务 | 9B 模型 4bit 下显存 | 8GB 能行吗 |
|---|---|---|
| 推理（对话） | 约 5-6GB | ✅ 可以 |
| LoRA 微调 | 约 6-7GB（小 batch） | ✅ 勉强可以 |
| 全参数微调 | 30GB+ | ❌ 必须上云 |

**这本书的策略**：

- **推理、数据处理、写 Prompt**：全部本地做；
- **LoRA 微调小模型（7B）**：本地可以试；
- **更大的微调任务**：上云租卡（后面讲怎么租）。

记住一句话：**本地够用，重活上云，不浪费钱也不硬撑。**

## 4.2 软件栈全景

你要装的东西分四层，从下到上：

```
┌─────────────────────────────────┐
│ 应用层：LM Studio / 你的 Agent 代码 │
├─────────────────────────────────┤
│ 微调框架：LLaMA-Factory / unsloth  │
├─────────────────────────────────┤
│ 深度学习：PyTorch + CUDA           │
├─────────────────────────────────┤
│ 底层：NVIDIA 驱动                  │
└─────────────────────────────────┘
```

### 第一层：NVIDIA 驱动

去 NVIDIA 官网下载对应你显卡的驱动（GeForce Experience 或手动装）。装完在命令行输入：

```bash
nvidia-smi
```

能看到显卡信息和 CUDA 版本就成功了。**这一步是所有 GPU 开发的前提。**

### 第二层：CUDA + PyTorch

CUDA 是 NVIDIA 的并行计算平台，PyTorch 是深度学习框架。装 PyTorch 时会自动带 CUDA 运行时，不用单独装完整 CUDA Toolkit。

```bash
# 创建虚拟环境（推荐 conda）
conda create -n forensic-ai python=3.11
conda activate forensic-ai

# 安装 PyTorch（CUDA 12.1 版本，按你的显卡选）
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
```

验证：

```bash
python -c "import torch; print(torch.cuda.is_available())"
```

输出 `True` 就对了。

### 第三层：微调框架

两个选择：

- **LLaMA-Factory**：功能全、有 Web 界面，适合新手；
- **unsloth**：速度快、省显存，适合进阶。

本书 ch11 会详细讲安装和使用，这里先不展开。

### 第四层：应用层

- **LM Studio**：你已装好，用来本地跑模型、当助教；
- **Python 开发环境**：PyCharm 或 VS Code；
- **Jupyter**：做数据分析方便。

## 4.3 本地模型部署实操（LM Studio）

你已经装了 LM Studio + Qwen3.5-9B，这里把关键设置说清楚，因为你后面要反复用。

### 下载模型

LM Studio 里搜索 "Qwen3.5" 或 "Qwen2.5"，选择 **GGUF 格式**、**Q4 量化**（4bit）的版本。文件名类似 `qwen3.5-9b-q4_k_m.gguf`，约 5-6GB。

> **为什么选 Q4_K_M？** Q4 是 4bit 量化，省显存；K_M 是其中质量较好的一档。太小（Q2/Q3）质量差，太大（Q5/Q6）显存吃紧。Q4_K_M 是 8GB 显卡的甜点。

### 关键参数设置

| 参数 | 推荐值 | 说明 |
|---|---|---|
| GPU Offload | 全部（max） | 把所有层放到 GPU 上 |
| Context Length | 8192 或 16384 | 上下文长度，越大越吃显存 |
| Temperature | 0.3（分析）/ 0.7（创作） | 越低越稳定 |

**取证场景建议 Temperature 设低一点（0.1-0.3）**，因为你要的是稳定、可复现的分析，不是天马行空的创作。

### 验证跑起来了

问它一句："用一句话介绍数字取证。"能正常回答，且速度可接受（每秒几十个 token），就算成功。

## 4.4 命令行模型运行（进阶）

LM Studio 适合交互，但做 Agent 开发时需要用代码调用模型。有两种方式：

### 方式一：LM Studio 本地服务器

LM Studio 可以开一个兼容 OpenAI 格式的本地 API 服务。在设置里开启 "Local Server"，然后用 Python 调用：

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:1234/v1",
    api_key="not-needed"  # 本地服务不需要真正 key
)

resp = client.chat.completions.create(
    model="local-model",
    messages=[{"role": "user", "content": "分析这段日志：..."}]
)
print(resp.choices[0].message.content)
```

这样你的 Python 代码就能调用本地模型了，而且**格式和调用 OpenAI 一样**，以后换模型很方便。

### 方式二：Ollama

Ollama 是另一个本地模型管理工具，命令行更简洁：

```bash
ollama pull qwen2.5:7b
ollama run qwen2.5:7b
```

它同样提供本地 API。二选一即可，本书以 LM Studio 为主。

## 4.5 什么时候该上云

本地做不了的事，就上云租卡。国内常用平台：AutoDL、恒源云、阿里云 PAI。

**租卡参考**（价格会变，仅作量级参考）：

| 任务 | 需要的卡 | 大致成本 |
|---|---|---|
| LoRA 微调 7B | RTX 3090 (24GB) | 约 1-2 元/小时 |
| LoRA 微调 9B/14B | RTX 4090 (24GB) | 约 2-3 元/小时 |
| 全参数微调 | A100 (40/80GB) | 约 10 元+/小时 |

**省钱技巧**：

1. 先用小数据、小模型在本地跑通流程，确认代码没问题，再上云跑完整训练——**别拿租的卡调试代码**；
2. 用按量付费，跑完立刻关机；
3. 很多平台有学生优惠或新用户券。

本书 ch11-ch15 会给你一套"本地调试 → 上云训练"的标准流程。

## 4.6 数据处理环境

AI 取证大量时间花在数据处理上。除了 GPU 环境，你还要装数据处理工具：

```bash
# 数据分析三件套
pip install pandas numpy

# 日志解析
pip install python-dateutil

# 大模型调用
pip install openai

# 后面微调会用到
pip install transformers datasets peft accelerate
```

不用一次装全，用到时再装。**装在同一个 conda 环境 `forensic-ai` 里，保持环境干净。**

## 4.7 动手任务

1. **跑通 nvidia-smi**：确认驱动正常，记录你的显存大小。
2. **验证 PyTorch CUDA**：执行 `torch.cuda.is_available()`，确保是 `True`。
3. **本地模型对话**：用 LM Studio 跑 Qwen，问一个取证相关问题，记录响应速度和质量。
4. **开启本地 API**：在 LM Studio 里开启 Local Server，用上面的 Python 代码调用一次，确认能通。
5. **注册一个云平台账号**（AutoDL 或类似），先不充钱，熟悉界面即可。

完成这五步，你的开发环境就齐了。

## 4.8 小结

- 8GB 显存能跑 4bit 量化的 9B 模型推理和小规模 LoRA 微调；全参数微调必须上云；
- 软件栈四层：驱动 → CUDA/PyTorch → 微调框架 → 应用层；
- LM Studio 设 Q4_K_M 量化、GPU 全offload、Temperature 调低；
- 本地服务器让 Python 代码能调用模型，格式兼容 OpenAI；
- 上云原则：本地调通流程再去租卡，按量付费；
- **策略：本地够用，重活上云，不浪费钱也不硬撑。**
