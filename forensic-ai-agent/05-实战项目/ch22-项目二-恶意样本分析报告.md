## 22.1 项目概览

**要做的东西**：输入一个可疑的可执行文件（样本），自动提取特征、分析行为、生成分析报告。

**和项目一的区别**：

| 对比 | 项目一（日志研判） | 项目二（样本分析） |
|---|---|---|
| 输入 | 文本日志 | 二进制文件 |
| 分析对象 | 结构化文本 | 程序行为 |
| 工具 | grep、正则 | file、strings、objdump |
| 难度 | 中等 | 较高 |

**核心思路**：二进制分析工具提取特征 → 大模型理解特征并生成报告。**AI 不做逆向本身，而是理解逆向的结果**。

**法律红线**：只用自己编写的"无害测试样本"或公开的恶意样本数据集，**绝不分析真实未知样本**。样本分析要在隔离环境（虚拟机）做。

## 22.2 静态分析工具链

静态分析 = 不运行程序，只看文件本身。工具：

| 工具 | 用途 | 命令示例 |
|---|---|---|
| `file` | 识别文件类型 | `file sample.exe` |
| `sha256sum` | 计算哈希 | `sha256sum sample.exe` |
| `strings` | 提取可打印字符串 | `strings sample.exe` |
| `objdump` | 反汇编 | `objdump -d sample.exe` |
| `exiftool` | 查看元数据 | `exiftool sample.exe` |
| `readelf` | ELF 文件结构 | `readelf -h sample` |

写一个特征提取函数：

```python
# static_analysis.py
import subprocess
import hashlib

def sha256(file):
    with open(file, "rb") as f:
        return hashlib.sha256(f.read()).hexdigest()

def run_cmd(cmd):
    try:
        return subprocess.run(cmd, capture_output=True, text=True, timeout=30).stdout[:5000]
    except Exception as e:
        return f"错误：{e}"

def extract_features(file):
    """提取样本的静态特征"""
    return {
        "file_type": run_cmd(["file", file]),
        "sha256": sha256(file),
        "size": __import__("os").path.getsize(file),
        "strings": run_cmd(["strings", "-n", "6", file])[:3000],
        "imports": run_cmd(["objdump", "-p", file])[:2000] if file.endswith(".exe") else "",
    }
```

## 22.3 让大模型理解特征

提取的特征是原始文本（strings 输出一大堆乱码般的函数名、URL、路径）。让大模型来"读懂"它：

```python
from openai import OpenAI
client = OpenAI(base_url="http://localhost:1234/v1", api_key="not-needed")

ANALYSIS_PROMPT = """你是恶意软件分析师。根据下面的静态特征，分析这个样本。

特征：
文件类型：{file_type}
SHA256：{sha256}
大小：{size} 字节
可疑字符串：{strings}
导入函数：{imports}

请分析：
1. 样本类型（木马/挖矿/勒索/广告软件/未知）
2. 可疑行为（网络连接、文件操作、注册表修改等）
3. 关键证据（引用上面的字符串）
4. 风险等级（高/中/低）
5. 处置建议

只基于给出的特征分析，不要编造。"""

def analyze_sample(features):
    prompt = ANALYSIS_PROMPT.format(**features)
    resp = client.chat.completions.create(
        model="local-model",
        messages=[{"role": "user", "content": prompt}],
        temperature=0.1, max_tokens=1000
    )
    return resp.choices[0].message.content
```

**关键点**：

1. **给足特征**：把工具输出完整给模型，它才能基于事实分析；
2. **要求引用证据**：提示里要求"引用上面的字符串"，减少幻觉；
3. **明确结构**：要求分 5 点回答，输出稳定。

## 22.4 用 Agent 编排

用 LangChain 把"提取特征 → 分析 → 生成报告"串成 Agent：

```python
from langchain.tools import tool
from langchain_openai import ChatOpenAI
from langchain.agents import initialize_agent, AgentType

@tool
def extract_features(file: str) -> str:
    """提取样本静态特征。file是样本文件路径。"""
    import json
    return json.dumps(extract_static(file), ensure_ascii=False)

@tool
def analyze_features(features: str) -> str:
    """分析样本特征，返回分析报告。"""
    return analyze_sample(json.loads(features))

llm = ChatOpenAI(base_url="http://localhost:1234/v1", api_key="not-needed",
                 model="local-model", temperature=0.1)
agent = initialize_agent(
    [extract_features, analyze_features], llm,
    agent=AgentType.ZERO_SHOT_REACT_DESCRIPTION,
    verbose=True, max_iterations=5
)

result = agent.run("分析 samples/test_sample.exe，生成恶意样本分析报告")
```

Agent 自动决定：先提取特征 → 再分析 → 生成报告。

## 22.5 动态分析（进阶，可选）

静态分析看不到程序运行时行为。动态分析 = 在隔离环境运行样本，观察行为：

- **沙箱**：用 Cuckoo Sandbox 或任何沙箱（在虚拟机里）；
- **监控**：记录文件操作、网络连接、进程创建；
- **注意**：必须在隔离环境！绝不能在主机上直接运行可疑样本。

动态分析结果也可以喂给大模型分析：

```python
def analyze_dynamic(behavior_log):
    prompt = f"""根据下面的运行时行为记录，分析样本行为：
{behavior_log}
总结：网络活动、文件操作、进程行为、风险等级。"""
    return client.chat.completions.create(...).choices[0].message.content
```

**新手建议**：先做静态分析版本，动态分析作为进阶。动态分析环境搭建复杂，且有风险。

## 22.6 测试数据从哪来

**绝不能随便找真实恶意样本分析**——风险高、可能违法。安全的做法：

1. **自己写测试样本**：写一个"模拟恶意行为"的无害程序（如打印一段可疑字符串、创建临时文件），用它测试流程；
2. **公开教学样本**：一些安全课程提供无害化的教学样本；
3. **合成样本**：自己构造一个有可疑字符串的文件（文本文件也行），测试分析流程。

本书用方法 1 和 3：

```python
# 生成一个测试用"样本"（其实是无害文本文件）
with open("samples/test_sample.exe", "w") as f:
    f.write("MZ\x90\x00")  # 假的 PE 头
    f.write("\n".join([
        "http://malicious-example.test/beacon",
        "CreateFileA", "RegSetValueEx", "socket", "connect",
        "C:\\Windows\\System32\\svchost.exe",
    ]))
```

这样 `strings` 能提取出"可疑"字符串，大模型能分析，但没有真实危害。**测试流程完全安全。**
