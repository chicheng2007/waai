> **本章目标**：装好微调框架 LLaMA-Factory，配置好 QLoRA 训练环境，把整套流水线跑通。这一章全是实操，跟着命令一步步做，最后你会拥有一个能开始训练的环境。

## 11.1 选哪个框架

微调框架有几个选择：

| 框架 | 优点 | 缺点 | 适合谁 |
|---|---|---|---|
| **LLaMA-Factory** | 功能全、有 Web 界面、支持多种模型、文档全 | 稍重 | 新手首选 |
| unsloth | 速度快、省显存 | 配置略麻烦 | 进阶用户 |
| Axolotl | 配置灵活 | 学习曲线陡 | 老手 |
| 手写 Trainer | 最灵活 | 工作量大 | 研究者 |

本书选 **LLaMA-Factory**。原因：

1. 对 Qwen 支持好；
2. 支持 QLoRA，配置简单；
3. 有 WebUI，可视化操作，新手友好；
4. 社区活跃，遇到问题容易搜到答案。

## 11.2 安装 LLaMA-Factory

### 本地安装（用于调试）

```bash
# 进入之前建的 conda 环境
conda activate forensic-ai

# 克隆仓库
git clone https://github.com/hiyouga/LLaMA-Factory.git
cd LLaMA-Factory

# 安装（含 torch 和量化依赖）
pip install -e ".[torch,metrics]"

# 验证安装
llamafactory-cli version
```

如果能显示版本号，安装成功。

### 常见问题

**问题 1：bitsandbytes 报错**

QLoRA 需要 bitsandbytes 做量化。如果报错，重装：

```bash
pip install bitsandbytes --upgrade
```

Windows 用户注意：bitsandbytes 对 Windows 支持有限，建议用 WSL2 或直接上云（Linux 环境）。

**问题 2：CUDA 版本不匹配**

确认 PyTorch 的 CUDA 版本和驱动兼容：

```bash
python -c "import torch; print(torch.version.cuda)"
```

## 11.3 准备模型和数据

### 下载模型

LLaMA-Factory 会从 Hugging Face 自动下载模型，但国内可能慢。可以先手动下载（用 modelscope 或 huggingface-cli）：

```bash
# 用 modelscope（国内快）
pip install modelscope
modelscope download --model Qwen/Qwen2.5-7B-Instruct
```

下载后记下本地路径，如 `~/.cache/modelscope/hub/Qwen/Qwen2.5-7B-Instruct`。

> **选 7B 还是 9B？** 本地 8GB 显卡，7B 更稳。9B 也可以，但要小心 batch size。本书先用 7B 跑通，再试 9B。

### 放数据

把 ch09 生成的数据放到 LLaMA-Factory 的 `data/` 目录：

```bash
cp /path/to/starsea_sft.jsonl LLaMA-Factory/data/
cp /path/to/starsea_val.jsonl LLaMA-Factory/data/
```

然后在 `data/dataset_info.json` 里注册数据集：

```json
{
  "starsea": {
    "file_name": "starsea_sft.jsonl",
    "formatting": "sharegpt",
    "columns": {
      "messages": "messages"
    },
    "tags": {
      "role_tag": "role",
      "content_tag": "content",
      "user_tag": "user",
      "assistant_tag": "assistant",
      "system_tag": "system"
    }
  }
}
```

这段配置告诉框架：数据文件叫什么、是什么格式、字段怎么对应。我们的 messages 格式（OpenAI 风格）就是 sharegpt 格式。

## 11.4 写训练配置

LLaMA-Factory 用 YAML 配置文件。创建一个 `starsea_lora.yaml`：

```yaml
### model
model_name_or_path: /path/to/Qwen2.5-7B-Instruct
quantization_bit: 4              # QLoRA：4bit 量化
quantization_method: bitsandbytes

### method
stage: sft                        # 监督微调
do_train: true
finetuning_type: lora             # LoRA
lora_rank: 16                     # r
lora_alpha: 32                    # alpha
lora_target: q_proj,v_proj,k_proj,o_proj,gate_proj,up_proj,down_proj

### dataset
dataset: starsea
template: qwen
cutoff_len: 1024                  # 单条最大长度
max_samples: 1000                 # 先小规模测试
overwrite_cache: true
preprocessing_num_workers: 4

### output
output_dir: saves/starsea_lora
logging_steps: 10
save_steps: 100
plot_loss: true

### train
per_device_train_batch_size: 1    # 显存小，batch 设 1
gradient_accumulation_steps: 8    # 累积 8 步等效 batch 8
learning_rate: 2e-4
num_train_epochs: 2.0
lr_scheduler_type: cosine
warmup_ratio: 0.1
bf16: true                        # 混合精度（显卡支持的话）

### eval
val_size: 0.1
per_device_eval_batch_size: 1
eval_strategy: steps
eval_steps: 100
```

关键配置解释：

- `quantization_bit: 4` + `finetuning_type: lora` = QLoRA；
- `per_device_train_batch_size: 1` + `gradient_accumulation_steps: 8`：显存不够放大 batch，用小 batch + 梯度累积模拟；
- `cutoff_len: 1024`：我们的日志样本较短，1024 够用，省显存；
- `max_samples: 1000`：先拿 1000 条测试流程，跑通再放开。

## 11.5 本地试跑（调试）

先用少量数据跑通流程：

```bash
llamafactory-cli train starsea_lora.yaml
```

观察输出：

- 如果显存溢出（OOM），把 `cutoff_len` 降到 512，`lora_rank` 降到 8；
- 如果能看到 loss 在下降，说明流程通了。

**这一步的目的不是训练出好模型，而是验证环境没问题。** 跑几十步就可以 Ctrl+C 停掉。

---

## 11.6 上云训练

本地跑通后，上云跑完整训练。流程：

1. **租卡**：AutoDL 租一张 RTX 3090/4090（24GB），选 PyTorch 镜像；
2. **传代码和数据**：用 FileZilla 或 scp 上传 LLaMA-Factory 和数据；
3. **装环境**：云机器上重复 11.2 的安装；
4. **改配置**：显存大了，可以放大 batch（如 4）、放长 cutoff_len（如 2048）、放开 max_samples；
5. **开训**：`llamafactory-cli train starsea_lora.yaml`；
6. **下模型**：训练完把 `saves/starsea_lora` 下载回本地。

### 省钱要点

- **本地调试，云端训练**——别用租的卡调代码；
- 用按量付费，训练完立即关机；
- 先小规模跑通，再全力训练。

## 11.7 用 WebUI（可选）

LLaMA-Factory 提供图形界面，不想写 YAML 可以用它：

```bash
llamafactory-cli webui
```

浏览器打开提示的地址（默认 `http://localhost:7860`），在里面选模型、选数据集、调参数、点"开始"。适合对命令行不熟的人。

但本书建议**先用命令行跑通**，因为：
1. 命令行配置可保存、可复现；
2. 上云时通常只有命令行；
3. 命令行报错信息更清楚。

## 11.8 动手任务

1. **装好 LLaMA-Factory**：执行 11.2 的命令，`llamafactory-cli version` 能显示版本号。
2. **下载模型**：下载 Qwen2.5-7B-Instruct，记下路径。
3. **注册数据**：把 ch09 的数据放进去，写好 `dataset_info.json`。
4. **本地试跑**：用 1000 条数据跑几十步，确认 loss 下降、不 OOM。
5. **记录环境**：把你的配置写到笔记里，包括版本号、路径、参数。

环境跑通了，下一章正式训练：用全部数据微调出一个取证问答模型。

---

## 11.9 小结

- LLaMA-Factory 是新手友好的微调框架，支持 Qwen + QLoRA + WebUI；
- 安装：clone → pip install -e；注意 bitsandbytes 和 CUDA 版本；
- 数据要放在 `data/` 并在 `dataset_info.json` 注册；
- YAML 配置关键项：量化位数、LoRA 秩、batch size、梯度累积、学习率；
- **本地小数据调试 → 云端全量训练**，省钱又高效；
- 本地试跑目的是验证环境，不是出好模型。
