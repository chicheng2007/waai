## 学习建议

- **Python 是底座**：软考之外的三条线（网安 / AI / 取证）都靠它，优先练熟。详细台阶见 [python-roadmap.md](python-roadmap.md)。
- **Git 边用边学**：不用先系统学完再动手。维护 waai 仓库的过程本身就是练习，卡住再查 [git-tutorial.md](git-tutorial.md) 的"报错急救"章节。
- **命令行要有手感**：你用 Windows，至少把 [CMD/PowerShell](cmd-powershell-tutorial.md) 的"常用命令"和"环境变量"两节过一遍，避免 `python` 无法识别这类卡壳。
