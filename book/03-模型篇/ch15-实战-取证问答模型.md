## 15.1 项目目标

我们要做一个**取证问答模型**：给它一段日志，它能按"结论/依据/建议"三段式给出专业分析。

验收标准：

| 指标 | 目标 |
|---|---|
| 结论准确率 | ≥ 85% |
| 异常召回率 | ≥ 80% |
| 格式合规率 | ≥ 95% |
| 推理速度 | 本地 7B 模型每秒 ≥ 20 token |

达到这些标准，模型就算可用了。

## 15.4 训练脚本封装

把训练命令封装成脚本，方便复现：

```bash
#!/bin/bash
# scripts/train.sh
set -e

MODEL_PATH="/path/to/Qwen2.5-7B-Instruct"
CONFIG="configs/train_v2.yaml"
OUTPUT="outputs/v2"

echo "开始训练..."
llamafactory-cli train \
  --model_name_or_path "$MODEL_PATH" \
  --config "$CONFIG" \
  --output_dir "$OUTPUT"

echo "训练完成，开始评估..."
python scripts/eval.py --model "$OUTPUT" --data data/starsea_val.jsonl
```

这样一条命令完成"训练 + 评估"，可复现、可自动化。

## 15.5 推理封装

把模型封装成一个易用的函数，供上层 Agent 调用（ch16 之后会用到）：

```python
# scripts/inference.py
from transformers import AutoModelForCausalLM, AutoTokenizer
from peft import PeftModel

class ForensicQA:
    def __init__(self, base_path, adapter_path):
        self.tokenizer = AutoTokenizer.from_pretrained(base_path)
        model = AutoModelForCausalLM.from_pretrained(
            base_path, device_map="auto", torch_dtype="auto"
        )
        self.model = PeftModel.from_pretrained(model, adapter_path)

    def analyze(self, log_line):
        messages = [
            {"role": "system", "content": "你是专业的电子取证分析助手。请按结论/依据/建议三段式回答。"},
            {"role": "user", "content": f"分析这段日志：\n{log_line}"}
        ]
        text = self.tokenizer.apply_chat_template(
            messages, tokenize=False, add_generation_prompt=True
        )
        inputs = self.tokenizer([text], return_tensors="pt").to(self.model.device)
        outputs = self.model.generate(
            **inputs, max_new_tokens=200, temperature=0.1, do_sample=True
        )
        return self.tokenizer.decode(
            outputs[0][inputs.input_ids.shape[1]:], skip_special_tokens=True
        )

# 使用
qa = ForensicQA("/path/to/Qwen2.5-7B-Instruct", "outputs/v2")
print(qa.analyze("2026-10-15 02:03:11 DENY 203.0.113.5->10.0.2.10:23 size=60"))
```

这个 `ForensicQA` 类就是后面 Agent 的一个"工具"——Agent 调用它来分析日志。

## 15.6 最终评估与迭代

用 ch13 的方法做完整评估，达成验收标准后，写一份评估报告：

```markdown
# 取证问答模型评估报告

## 模型信息
- 基座：Qwen2.5-7B-Instruct
- 方法：QLoRA（rank=16, alpha=32）
- 数据：星海案数据集 v1.0（1.8 万条）
- 训练：3 epoch, lr=2e-4, 等效 batch=16

## 评估结果
| 指标 | 原模型 | 微调后 | 提升 |
|---|---|---|---|
| 结论准确率 | 0.62 | 0.88 | +0.26 |
| 异常召回率 | 0.45 | 0.82 | +0.37 |
| 格式合规率 | 0.20 | 0.96 | +0.76 |
| 裁判平均分 | 2.8 | 4.3 | +1.5 |

## 结论
微调显著提升取证分析能力，达到验收标准。召回率提升最大，
说明模型对异常事件的识别能力增强明显。

## 局限
- 对训练中未见过的日志格式泛化能力有限
- 仍存在少量幻觉，需人工审核
- 长日志（超过 cutoff_len）会被截断
```

**诚实写出局限**，这是专业素养的体现，也是面试官看重的地方。
