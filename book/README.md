## 这本书是给谁写的

如果你符合下面几条，这本书就是为你准备的：

- 网安 / 计算机专业学生，**会 Python 基础语法**，但没系统学过 AI；
- 手里有一张 **8GB 显存的消费级显卡**（如 RTX 5060 / 4060 / 3060），本地跑得动量化模型，但训练大模型不现实；
- 想搞懂「AI 到底怎么用到数字取证上」，而不是只调用别人的 API；
- 希望最后能拿出一个**能写进简历的完整项目**。

**不需要**你先学完机器学习再来看这本书。数学和原理会在用到的地方讲，够用就行。

---

## 我能用什么硬件（先说清楚现实）

这本书的所有实操都基于这套配置，也是作者的真实环境：

| 部件 | 配置 | 对 AI 的意义 |
|---|---|---|
| GPU | RTX 5060 Laptop 8GB | 能跑 4bit 量化的 7B~9B 模型；能 LoRA 微调小模型；**不能**全参数微调大模型 |
| 内存 | 32GB DDR5 | 数据处理、加载数据集够用 |
| 本地模型 | LM Studio + Qwen3.5-9B（量化） | 当「免费助教」和验证环境 |
| 云资源 | 按需租用（如 AutoDL） | 需要更大显存时临时租，按小时付费 |

**核心策略**：本地做数据处理、推理验证、小模型微调；重活儿上云。这本书会明确告诉你每一步该在哪儿做。

## 三条阅读路线

- **速成路线（1 周）**：ch01 → ch04 → ch16 → ch20 → ch21。先做出一个能跑的 Agent，再回头补原理。
- **系统路线（2–3 个月）**：按 01→24 顺序读，每章配一个动手任务。适合想真正吃透的人。
- **项目驱动路线**：直接看第五部分的三个项目，卡住时按链接回查对应章节。适合有明确作品目标的人。

## 怎么使用这本书

1. **每章独立**：每章有「本章目标 / 核心内容 / 动手任务 / 小结」，可以单独查。
2. **相对链接串联**：所有章节通过相对链接互连，clone 整个目录即可离线阅读。
3. **代码可运行**：示例代码都给出完整文件和运行命令，不写「此处省略」。
4. **硬件双路径**：标注「本地」和「上云」两种做法，按需选择。
