# Wireshark 从入门到精通

> 一份系统、完整、可实践的 Wireshark 中文教程。从网络协议基础讲起，覆盖抓包、过滤、协议深度解析、高级分析、实战排障、安全分析以及插件开发，共 43 章。
>
> **篇幅说明**：中文正文约 4.5 万字；若计入命令行示例、协议字段表、过滤器表达式、代码块与技术术语，全部内容约 12.4 万字符。

## 关于本教程

Wireshark 是世界上最流行的网络协议分析器（网络抓包工具）。无论是网络工程师排查故障、安全分析师溯源攻击、开发人员调试协议，还是学习者理解网络原理，Wireshark 都是不可或缺的利器。

本教程的目标是：**让零基础读者系统掌握 Wireshark，并能把它用到真实工作场景中。**

教程特点：

- **体系完整**：从 OSI 模型到协议解析，从基础操作到高级实战，循序渐进。
- **注重实践**：每章都配有价值的操作说明、过滤器表达式和真实场景分析。
- **中文原创**：结合中文读者的学习习惯，讲透原理，而非简单翻译官方文档。
- **持续更新**：欢迎 Issue 指正、Pull Request 贡献。

## 如何阅读

1. **零基础读者**：建议按章节顺序阅读，先掌握第一部分和第二部分。
2. **有网络基础的读者**：可直接跳到第三部分（过滤器）和第四部分（协议解析）。
3. **实战导向读者**：重点阅读第六部分，遇到问题再回查前面的章节。
4. **开发者**：关注第七部分，了解如何扩展 Wireshark。
