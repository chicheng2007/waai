# 第十二章 显示过滤器基础

显示过滤器（Display Filter）是 Wireshark 最核心、最强大的功能。它在抓包**之后**生效，从已捕获的数据中精确筛选出你关心的包。与捕获过滤器不同，被过滤掉的包并没有消失，随时可以取消过滤恢复显示。

## 12.1 显示过滤器输入框

输入框位于工具栏下方。输入表达式后：

- 按 `Enter` 或点击右侧的箭头按钮应用过滤。
- 背景变为**绿色**：表达式语法正确。
- 背景变为**红色**：表达式有语法错误，无法应用。
- 背景变为**黄色**：表达式有效但可能有歧义或警告。
- 点击右侧的 `×`（或按 `Ctrl + Shift + L`）清除过滤，恢复显示所有包。
- 点击下拉箭头可选择最近使用过的或保存的过滤表达式。

## 12.2 基本语法

显示过滤器的核心结构是：

```
字段名 比较运算符 值
```

例如：

```
ip.addr == 192.168.1.1
```

含义：源地址或目的地址等于 192.168.1.1 的包。

### 12.2.1 协议过滤器

最简单的过滤器是**协议名**，直接输入协议名即显示该协议的所有包：

```
tcp          # 所有 TCP 包（包括其上层协议）
udp          # 所有 UDP 包
arp          # 所有 ARP 包
dns          # 所有 DNS 包
http         # 所有 HTTP 包
icmp         # 所有 ICMP 包
ip           # 所有 IPv4 包
ipv6         # 所有 IPv6 包
```

注意：`tcp` 会显示所有基于 TCP 的包（包括 HTTP、TLS 等），而 `http` 只显示被识别为 HTTP 的包。

### 12.2.2 比较运算符

| 运算符 | 含义 | 示例 |
| --- | --- | --- |
| `==` | 等于 | `ip.addr == 10.0.0.1` |
| `!=` | 不等于 | `tcp.port != 80` |
| `>` | 大于 | `frame.len > 1000` |
| `<` | 小于 | `frame.len < 100` |
| `>=` | 大于等于 | `tcp.window_size >= 1000` |
| `<=` | 小于等于 | `ip.ttl <= 16` |

### 12.2.3 逻辑运算符

| 运算符 | 别名 | 含义 | 示例 |
| --- | --- | --- | --- |
| `&&` | `and` | 与（两者都满足） | `ip.addr == 10.0.0.1 && tcp.port == 80` |
| `\|\|` | `or` | 或（满足其一） | `arp \|\| icmp` |
| `!` | `not` | 非（取反） | `!dns` |
| `()` | — | 括号，改变优先级 | `tcp && (port 80 \|\| port 443)` |

> **重要陷阱**：`ip.addr != 10.0.0.1` 的含义是「源地址不等于 10.0.0.1 **或** 目的地址不等于 10.0.0.1」。因为 `ip.addr` 同时匹配源和目的两个字段，只要其中一个不等于就满足。所以这个表达式几乎匹配所有包！正确的写法是 `!ip.addr == 10.0.0.1`（对整体取反）或 `ip.src != 10.0.0.1 && ip.dst != 10.0.0.1`。这是新手最常踩的坑之一。

## 12.3 常用字段

### 12.3.1 IP 相关字段

```
ip.addr == 192.168.1.1           # 源或目的 IP
ip.src == 192.168.1.1            # 源 IP
ip.dst == 192.168.1.1            # 目的 IP
ip.ttl == 64                     # TTL 为 64
ip.version == 4                  # IPv4
ip.flags.df == 1                 # DF 标志（不分片）
ip.fragment                      # 分片包
ipv6.addr == 2001:db8::1         # IPv6 地址
```

### 12.3.2 TCP / UDP 端口字段

```
tcp.port == 80                   # TCP 源或目的端口
tcp.srcport == 80                # TCP 源端口
tcp.dstport == 443               # TCP 目的端口
udp.port == 53                   # UDP 端口
tcp.flags.syn == 1               # SYN 标志置位
tcp.flags.reset == 1             # RST 标志置位
tcp.flags.fin == 1               # FIN 标志置位
tcp.flags.ack == 1               # ACK 标志置位
tcp.len > 0                      # 有数据的 TCP 段
```

### 12.3.3 以太网字段

```
eth.addr == 00:11:22:33:44:55    # MAC 地址
eth.src == 00:11:22:33:44:55     # 源 MAC
eth.dst == ff:ff:ff:ff:ff:ff     # 广播
eth.type == 0x0806               # 以太网类型为 ARP
```

### 12.3.4 帧相关字段

```
frame.len > 1000                 # 帧长大于 1000 字节
frame.number == 100              # 第 100 个包
frame.time >= "2024-01-01"       # 指定时间之后
```

## 12.4 按值匹配的技巧

### 12.4.1 包含匹配

```
http.request.uri contains "admin"     # URI 中包含 "admin"
http.user_agent contains "Firefox"    # UA 包含 Firefox
dns.qry.name contains "example"       # DNS 查询名包含 example
```

### 12.4.2 精确匹配协议子树

```
http.request.method == "GET"          # HTTP GET 请求
http.response.code == 404             # 404 响应
dns.qry.name == "www.example.com"     # 查询特定域名
```

### 12.4.3 存在性检查

直接写字段名，表示「该字段存在」：

```
tcp.flags.syn                    # 有 SYN 标志的包
http.request                     # HTTP 请求包
dns.resp                         # DNS 响应包
```

## 12.5 从界面自动生成过滤器

你不必记住所有字段名。以下方法可以快速生成过滤器：

1. **右键菜单**：在协议详情窗格中右键点击某个字段 → `Prepare as Filter` → 选择 `Selected`、`with Value` 等，Wireshark 会自动生成对应的过滤表达式并填入输入框。
2. **过滤器下拉箭头**：点击输入框右侧的下拉箭头，显示最近使用和保存的过滤器。
3. **显示过滤器参考**：菜单 `Help → Display Filter Reference` 打开在线/本地的字段参考文档，可搜索所有字段名。

> **强烈建议**：多用右键 `Prepare as Filter`。这是学习字段名的最快途径——你看到什么字段，想过滤它，直接右键生成，几次之后自然就记住了。

## 12.6 过滤器的应用范围

- 显示过滤器只影响**显示**，不影响捕获文件本身。
- 被过滤掉的包在统计工具中默认也被排除（可在统计设置中调整）。
- 保存文件时可以选择「只保存显示的包」（见第十五章）。

## 12.7 小结

- 显示过滤器在抓包后生效，语法为「字段 运算符 值」。
- 协议名可直接作为过滤器；比较运算符包括 `==`、`!=`、`>`、`<` 等。
- 逻辑运算符 `&&`、`or`、`not` 可组合复杂条件。
- 警惕 `ip.addr != x` 的陷阱，用 `!ip.addr == x` 代替。
- 常用字段：ip.addr/src/dst、tcp.port/srcport/dstport、tcp.flags.*、eth.addr、frame.len。
- 右键 `Prepare as Filter` 是快速生成和学习过滤器的最佳途径。
