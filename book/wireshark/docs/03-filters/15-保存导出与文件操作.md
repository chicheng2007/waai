# 第十五章 保存、导出与文件操作

抓包之后，如何妥善保存、导出有用的信息、处理抓包文件，是日常工作的必备技能。本章覆盖文件保存格式、对象导出、命令行文件处理工具等内容。

## 15.1 保存抓包文件

### 15.1.1 Save 与 Save As

- **Save（`Ctrl + S`）**：保存到当前文件。如果是新捕获还未保存过，等同于 Save As。
- **Save As（`Ctrl + Shift + S`）**：另存为新文件，可以选择格式、范围等选项。

Save As 对话框中几个关键选项：

- **File name**：文件名。
- **File type**：文件格式（pcapng 或 pcap）。
- **Packet Range**：保存范围——全部包、显示的包（应用过滤器后）、标记的包、指定序号范围。

> **实用技巧**：先用显示过滤器筛出关注的包，再 `Save As` 并选择「Displayed」范围，就能得到一个只含目标流量的精简文件，便于分享或存档。

### 15.1.2 pcapng 与 pcap

| 特性 | pcapng | pcap（经典） |
| --- | --- | --- |
| 多接口支持 | 支持 | 不支持 |
| 注释/包注释 | 支持 | 不支持 |
| 增强时间戳精度 | 支持 | 有限 |
| 兼容性 | Wireshark 及较新工具 | 几乎所有网络工具 |
| 默认格式 | Wireshark 4.x | 早期版本 |

**建议**：日常分析用 pcapng（功能全）；需要和旧工具（某些 IDS、嵌入式设备）交互时，另存为 pcap。

## 15.2 导出对象（Export Objects）

Wireshark 能从应用协议中提取传输的文件/对象，这是非常实用的功能。

菜单 `File → Export Objects`，支持的协议包括：

- **HTTP**：网页、图片、脚本、下载的文件。
- **TCP**：TCP 流重组的数据。
- **UDP**：UDP 载荷。
- **DICOM、IMF、SMB、TFTP** 等。

以 HTTP 为例：

1. 抓包中访问一个网站。
2. `File → Export Objects → HTTP`。
3. 对话框中列出所有 HTTP 传输的对象（文件名、内容类型、大小、来源）。
4. 选中需要的文件，点击 `Save` 或 `Save All`。

**应用场景**：

- 取证分析：提取攻击者下载的恶意文件。
- 内容审计：还原用户访问的网页内容。
- CTF 题目：从流量中提取隐藏的文件（flag 常藏在这里）。

> **注意**：只能导出未被压缩/加密的原始内容。如果 HTTP 启用了压缩（gzip）或走 HTTPS（TLS 加密），需要先解密 TLS（见第二十九章）或处理压缩数据。

## 15.3 导出包数据

### 15.3.1 导出选定字节

在协议详情窗格中选中某个字段，或右键数据包 → `Export Selected Packet Bytes...`，可把选中的字节保存为二进制文件。适用于提取特定载荷。

### 15.3.2 导出为文本/CSV

菜单 `File → Export Packet Dissections`：

- **As Plain Text**：把包的解析结果导出为文本（含协议树）。
- **As CSV**：导出为 CSV，方便用 Excel 分析。可勾选只导出某些列。
- **As XML / PostScript**：其他格式。

导出时同样可以选择范围（全部/显示/标记/指定区间），以及是否包含详情树。

## 15.4 命令行文件处理工具

Wireshark 安装附带几个命令行工具，适合批量处理抓包文件。

### 15.4.1 capinfos：查看文件信息

```bash
capinfos capture.pcapng
```

输出包含：文件类型、包数、捕获时长、文件大小、平均速率、时间范围、接口信息等。快速了解一个抓包文件的基本情况时非常有用。

### 15.4.2 editcap：编辑抓包文件

```bash
# 分割文件：每 10000 个包一个文件
editcap -c 10000 big.pcapng part.pcapng

# 按时间分割：每 60 秒一个文件
editcap -i 60 big.pcapng part.pcapng

# 提取指定范围的包
editcap -r big.pcapng selected.pcapng 100-200

# 删除指定包
editcap big.pcapng out.pcapng 5 10 15

# 调整时间戳（+2 秒）
editcap -t 2.0 in.pcapng out.pcapng
```

### 15.4.3 mergecap：合并文件

```bash
mergecap -w combined.pcapng a.pcapng b.pcapng
```

按时间戳顺序合并多个抓包文件。多人同时抓包后合并分析时很有用。

### 15.4.4 text2pcap：文本转抓包

把十六进制文本转换为 pcap 文件，适合从日志、代码中的十六进制数据生成可分析的抓包文件：

```bash
text2pcap input.txt output.pcapng
```

## 15.5 文件处理实战流程

假设你拿到了一个 2GB 的抓包文件，想分析其中的 HTTP 流量：

1. `capinfos big.pcapng` 了解概况。
2. 用 Wireshark 打开，设置显示过滤器 `http` 观察。
3. 若文件太大卡顿，用 `editcap` 按时间或包数分割成小文件。
4. 用 `tshark -r big.pcapng -Y "http" -w http-only.pcapng` 提取 HTTP 流量到新文件（tshark 见第三十章）。
5. 对新文件做深入分析、导出对象。

## 15.6 小结

- Save As 可选择保存范围（全部/显示/标记/指定区间），先过滤再保存能精简文件。
- pcapng 功能强（多接口、注释），pcap 兼容性好，按需选择。
- Export Objects 可从 HTTP 等协议提取传输的文件，是取证和 CTF 的利器。
- 可导出包解析结果为文本或 CSV。
- 命令行工具：capinfos（信息）、editcap（分割/提取）、mergecap（合并）、text2pcap（文本转包）。
