# 第二十六章 统计工具集

Wireshark 的 Statistics（统计）菜单提供了一系列宏观分析工具。当你面对成千上万个数据包时，统计工具能帮你从「只见树木」上升到「看见森林」，快速把握整体流量特征，发现异常。本章逐一介绍这些工具。

## 26.1 Protocol Hierarchy（协议分层统计）

菜单 `Statistics → Protocol Hierarchy`。

它按协议层次树状展示各类协议的数据包数量和占比：

```
Frame                    100%  10000 packets
 Ethernet                100%  10000
  IPv4                    95%   9500
   TCP                    70%   7000
    HTTP                  40%   4000
    TLS                   25%   2500
    SSH                   5%    500
   UDP                    25%   2500
    DNS                   15%   1500
    DHCP                  5%    500
  ARP                     5%    500
```

**用途**：

- 快速了解抓包中有哪些协议、各占多少。
- 发现异常协议（如内网出现大量不常见的协议）。
- 判断是否需要进一步过滤分析。

右键某一行可以选择「作为过滤器应用」（Apply as Filter），直接筛选出该协议的流量。

## 26.2 Conversations（会话统计）

菜单 `Statistics → Conversations`。

会话（Conversation）是指两个通信端点之间的双向流量。工具列出所有会话及其包数、字节数、持续时间：

| 端点 A | 端点 B | 包数 | 字节 | 持续时间 |
| --- | --- | --- | --- | --- |
| 192.168.1.10:54321 | 93.184.216.34:80 | 45 | 32000 | 2.3s |
| 192.168.1.10:53124 | 8.8.8.8:53 | 2 | 150 | 0.05s |

支持按 Ethernet、IPv4、IPv6、TCP、UDP 等类型查看。

**用途**：

- 找出流量最大的会话（按 Bytes 排序）。
- 发现异常连接（如内网主机连接陌生公网 IP）。
- 右键会话可应用过滤器或追踪流。

## 26.3 Endpoints（端点统计）

菜单 `Statistics → Endpoints`。

端点是通信的一端（IP 地址或 MAC 地址 + 端口）。工具列出每个端点的发送/接收包数和字节数。

**用途**：

- 找出流量最大的主机（可能是文件服务器、下载机器或攻击源）。
- 发现发送异常大量数据的主机（数据泄露迹象）。
- 按名称排序时需开启名称解析。

## 26.4 HTTP 统计

菜单 `Statistics → HTTP`，包含：

- **Requests by URI**：按请求路径统计次数，找出最常访问的资源。
- **Responses by Status Code**：按状态码统计，快速看到 404、500 等错误数量。

**用途**：Web 性能分析、发现异常请求（如大量扫描某个路径）。

## 26.5 DNS 统计

菜单 `Statistics → DNS`：

- 统计查询/响应数量、响应码分布。
- 按查询类型（A、AAAA、MX 等）统计。

**用途**：发现 DNS 异常（大量 NXDOMAIN 可能意味着域名扫描或 DNS 隧道）。

## 26.6 Flow Graph（流量图）

菜单 `Statistics → Flow Graph`。

以图形化方式展示包在时间轴上的交互，横轴是参与者（IP 或端口），线表示包的方向：

```
192.168.1.10          93.184.216.34
     |---- SYN ------->|
     |<--- SYN+ACK ----|
     |---- ACK ------->|
     |---- GET ------->|
     |<--- 200 OK -----|
```

**用途**：直观展示通信流程，特别适合分析握手、协议交互顺序。

## 26.7 I/O Graph（吞吐量图表）

菜单 `Statistics → I/O Graph`。

展示单位时间内的包数或字节数随时间变化的曲线，类似网络流量监控图。可添加多条曲线（用不同的显示过滤器），对比不同协议的流量。

**用途**：

- 观察流量趋势（何时出现峰值）。
- 定位流量突增的时间点，然后回到列表分析该时段。
- 带宽规划与容量分析。

## 26.8 其他统计工具

- **Service Response Time**：统计服务响应时间（如 DNS、LDAP、MySQL 的响应延迟）。
- **TCP Stream Graphs**：TCP 流的详细图表（见第二十七章）。
- **VoIP Calls**：VoIP 通话统计与质量分析。
- **WLAN Traffic**：无线流量统计（按信道、信号强度等）。
- **Compare**：比较两个抓包文件的差异。

## 26.9 统计工具实战思路

分析一个陌生抓包文件的标准流程：

1. `capinfos` 或状态栏了解文件概况（时长、包数）。
2. `Protocol Hierarchy` 看协议分布。
3. `Conversations` 找流量最大的会话。
4. `Endpoints` 找最活跃的主机。
5. 针对重点用显示过滤器深入分析。
6. `I/O Graph` 看流量趋势，定位异常时间点。

## 26.10 小结

- Protocol Hierarchy：协议分层统计，把握整体构成。
- Conversations：会话统计，找出流量最大的连接。
- Endpoints：端点统计，找出最活跃的主机。
- HTTP/DNS 统计：应用层专项统计。
- Flow Graph：图形化展示通信流程。
- I/O Graph：流量随时间变化的曲线。
- 统计工具是「宏观定位、微观分析」工作流的起点。
