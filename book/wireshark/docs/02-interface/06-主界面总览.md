# 第六章 主界面总览

熟悉 Wireshark 的主界面，是高效分析的前提。本章带你认识窗口的各个组成部分以及推荐的工作流。

## 6.1 窗口组成

Wireshark 主窗口从上到下分为以下几个区域：

```
┌─────────────────────────────────────────────┐
│ 标题栏                                       │
├─────────────────────────────────────────────┤
│ 菜单栏 (File Edit View Capture Analyze ...)  │
├─────────────────────────────────────────────┤
│ 工具栏 (开始/停止、打开、保存、过滤等)         │
├─────────────────────────────────────────────┤
│ 显示过滤器输入框                              │
├─────────────────────────────────────────────┤
│ 数据包列表窗格 (Packet List)                  │
├─────────────────────────────────────────────┤
│ 协议详情窗格 (Packet Details)                 │
├─────────────────────────────────────────────┤
│ 字节窗格 (Packet Bytes)                      │
├─────────────────────────────────────────────┤
│ 状态栏 (包数、过滤状态、配置文件等)            │
└─────────────────────────────────────────────┘
```

### 6.1.1 标题栏

显示当前抓包文件名和 Wireshark 版本。如果是实时捕获，会显示「Live capture」。

### 6.1.2 菜单栏

包含所有功能的入口，常用的有：

- **File**：打开、保存、导出、关闭。
- **Edit**：首选项、查找、时间格式。
- **View**：显示选项、列、着色、折叠/展开。
- **Capture**：捕获选项、开始/停止、捕获过滤器。
- **Analyze**：显示过滤器、专家信息、协议启用、解码为（Decode As）。
- **Statistics**：各类统计工具。
- **Telephony**：VoIP 分析相关工具。
- **Wireless**：无线相关工具。
- **Help**：帮助文档、关于。

### 6.1.3 工具栏

常用操作的快捷按钮，从左到右大致为：

- 新建捕获、打开、保存、关闭文件
- 开始/停止捕获（鲨鱼鳍/方块）
- 重新开始捕获
- 捕获选项、显示过滤器相关
- 放大/缩小、重置缩放
- 查找、跳转

把鼠标悬停在按钮上会显示提示文字，很快就能熟悉。

### 6.1.4 显示过滤器输入框

位于工具栏下方，是 Wireshark 最核心的交互区域之一。输入过滤表达式并按回车，列表就只显示符合条件的包。绿色背景表示表达式有效，红色表示无效，黄色表示可能有警告（详见第十二章）。

### 6.1.5 三个核心窗格

这是分析的主战场：

1. **数据包列表窗格**（上）：所有数据包的摘要，一行一个包。
2. **协议详情窗格**（中）：当前选中包的协议树，逐层展开。
3. **字节窗格**（下）：当前选中包的原始十六进制和 ASCII 内容。

三个窗格联动：在列表选中包 → 详情和字节窗格更新；在详情树选中字段 → 字节窗格高亮对应字节。

### 6.1.6 状态栏

最底部显示：

- 当前显示的包数 / 总包数
- 是否处于过滤状态
- 当前配置文件（Profile）名称
- 数据包标记数量

## 6.2 推荐的工作流

高效的分析通常遵循这样的流程：

1. **明确目标**：你要找什么？是某个 IP 的流量，还是某种协议，还是某个时间段的数据？
2. **先过滤后分析**：用显示过滤器缩小范围，避免被无关流量淹没。
3. **看列表找异常**：关注时间间隙、包长度、重复的包、异常协议。
4. **看详情读字段**：展开协议树，检查关键字段（IP、端口、标志位、状态码）。
5. **看字节验证**：必要时对照原始字节确认。
6. **用统计工具验证**：用 Statistics 菜单的工具从宏观角度确认判断。
7. **跟着流走**：右键 → `Follow`（追踪 TCP/UDP/HTTP 流），还原完整会话。

## 6.3 界面布局调整

Wireshark 的窗格布局可以灵活调整：

- **拖动分隔条**：三个窗格之间可以拖动分隔线改变高度。
- **隐藏窗格**：`View → Packet Bytes` 可切换字节窗格显示。
- **分离窗口**：`Edit → Preferences → Layout` 可设置窗格排列方式（上/下、左/右等）。
- **多窗口**：同一个包可以在多个独立窗口查看，适合对照分析。

## 6.4 配色方案

默认的配色方案用不同背景色区分协议类型，便于快速识别。例如：

- 浅紫色：TCP
- 浅蓝色：UDP
- 浅绿色：HTTP
- 浅黄色：DNS
- 黑色背景红色字：错误/异常包

可以在 `View → Coloring Rules` 中自定义（见第十四章）。

## 6.5 小结

- 主界面由菜单栏、工具栏、过滤器框、三个核心窗格和状态栏组成。
- 三个窗格（列表 / 详情 / 字节）联动是分析的核心。
- 推荐工作流：过滤 → 看列表 → 看详情 → 看字节 → 用统计验证 → 跟踪流。
- 布局、配色都可以根据个人习惯调整。
