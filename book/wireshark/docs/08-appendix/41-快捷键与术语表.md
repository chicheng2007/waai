# 附录 B：快捷键与术语表

## B.1 常用快捷键

### 文件操作

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + O` | 打开文件 |
| `Ctrl + S` | 保存 |
| `Ctrl + Shift + S` | 另存为 |
| `Ctrl + W` | 关闭文件 |

### 捕获操作

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + E` | 开始/停止捕获 |
| `Ctrl + Shift + E` | 重新开始捕获 |
| `Ctrl + K` | 打开捕获选项 |

### 显示与导航

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + F` | 查找包 |
| `Ctrl + G` | 跳转到指定包 |
| `Ctrl + Home` | 跳到第一个包 |
| `Ctrl + End` | 跳到最后一个包 |
| `Ctrl + M` | 标记/取消标记 |
| `Ctrl + Shift + M` | 跳到下一个标记 |
| `Ctrl + L` | 清除过滤器（焦点在过滤框时） |
| `Ctrl + Shift + L` | 重新加载 Lua 插件 |

### 视图操作

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + Shift + P` | 打开首选项 |
| `Ctrl + Shift + C` | 切换包列表着色 |
| `+` / `-` | 放大/缩小字体 |
| `Ctrl + 0` | 重置缩放 |
| `Tab` | 在窗格间切换焦点 |
| `↓` / `↑` | 移动选中包 |
| `Enter` / `Space` | 展开/折叠协议树节点 |

### 复制与导出

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + C` | 复制选中内容 |
| `Ctrl + Shift + C` | 复制字段（视上下文） |

> **提示**：快捷键可能因版本和平台略有差异。完整列表见 `Edit → Preferences → Shortcuts`。

## B.2 术语表

| 术语 | 英文 | 解释 |
| --- | --- | --- |
| 抓包 | Capture | 捕获网络接口上的数据包 |
| 数据包 | Packet | 网络传输的基本单位 |
| 帧 | Frame | 数据链路层的传输单元 |
| 段 | Segment | TCP 的传输单元 |
| 数据报 | Datagram | UDP 或 IP 的传输单元 |
| 协议分析器 | Protocol Analyzer | 解析网络协议的工具 |
| 混杂模式 | Promiscuous Mode | 网卡接收所有帧的模式 |
| 监听模式 | Monitor Mode | 无线网卡捕获 802.11 帧的模式 |
| 显示过滤器 | Display Filter | 抓包后筛选显示的表达式 |
| 捕获过滤器 | Capture Filter | 抓包前决定抓什么的工具（BPF） |
| BPF | Berkeley Packet Filter | 捕获过滤器的语法体系 |
| Dissector | Dissector | Wireshark 中解析特定协议的模块 |
| pcap | Packet Capture | 经典的抓包文件格式 |
| pcapng | PCAP Next Generation | 新一代抓包文件格式 |
| 握手 | Handshake | 建立连接时的控制消息交换 |
| 三次握手 | Three-way Handshake | TCP 建立连接的 SYN/SYN-ACK/ACK 过程 |
| 四次挥手 | Four-way Handshake | TCP 关闭连接的 FIN/ACK 交换 |
| 序列号 | Sequence Number | TCP 标识字节顺序的编号 |
| 确认号 | Acknowledgment Number | TCP 期望收到的下一字节序号 |
| 重传 | Retransmission | 重新发送未被确认的数据 |
| 滑动窗口 | Sliding Window | TCP 流量控制机制 |
| 零窗口 | Zero Window | 接收方缓冲区满，窗口为 0 |
| RTT | Round-Trip Time | 往返时间 |
| MTU | Maximum Transmission Unit | 最大传输单元 |
| MSS | Maximum Segment Size | TCP 最大报文段长度 |
| TTL | Time To Live | IP 包的生存时间 |
| MAC 地址 | MAC Address | 数据链路层的物理地址 |
| IP 地址 | IP Address | 网络层的逻辑地址 |
| 端口 | Port | 传输层区分应用的编号 |
| ARP | Address Resolution Protocol | IP 解析为 MAC 的协议 |
| DNS | Domain Name System | 域名解析系统 |
| DHCP | Dynamic Host Configuration Protocol | 动态主机配置协议 |
| TLS | Transport Layer Security | 传输层安全协议 |
| HTTPS | HTTP over TLS | 加密的 HTTP |
| SNI | Server Name Indication | TLS 中明文的域名指示 |
| 会话 | Conversation | 两个端点间的双向通信 |
| 流 | Stream | 一条连接的完整数据 |
| 专家信息 | Expert Information | Wireshark 的异常包诊断系统 |
| 端口镜像 | SPAN / Port Mirroring | 交换机把流量复制到监控端口 |
| TAP | Test Access Point | 网络分流器 |
| C2 | Command and Control | 恶意软件的命令控制服务器 |
| IoC | Indicator of Compromise | 入侵指标 |
| DDoS | Distributed DoS | 分布式拒绝服务攻击 |
