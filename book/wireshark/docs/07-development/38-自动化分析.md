# 第三十八章 自动化分析

当需要对大量抓包文件做重复分析时，手动操作效率低下。本章介绍如何把 tshark 与 Python 结合，构建自动化分析流水线。

## 38.1 为什么需要自动化

- **批量处理**：每天分析几十个抓包文件。
- **重复任务**：定期提取特定指标（如 HTTP 错误率、DNS 查询量）。
- **告警集成**：从流量中自动发现异常并触发告警。
- **报告生成**：自动生成分析报告。

## 38.2 用 Python 调用 tshark

### 38.2.1 基本封装

```python
import subprocess

def run_tshark(args):
    """调用 tshark 并返回输出"""
    cmd = ["tshark"] + args
    result = subprocess.run(cmd, capture_output=True, text=True)
    if result.returncode != 0:
        raise RuntimeError(f"tshark failed: {result.stderr}")
    return result.stdout

# 提取 HTTP 请求
output = run_tshark([
    "-r", "capture.pcapng",
    "-Y", "http.request",
    "-T", "fields",
    "-e", "frame.time",
    "-e", "ip.src",
    "-e", "http.request.method",
    "-e", "http.host",
    "-e", "http.request.uri",
    "-E", "separator=|"
])
```

### 38.2.2 解析为结构化数据

```python
def parse_fields(output, separator="|"):
    records = []
    for line in output.strip().split("\n"):
        if line:
            records.append(line.split(separator))
    return records
```

## 38.3 实战脚本示例

### 38.3.1 HTTP 错误统计

```python
import subprocess
from collections import Counter

def http_error_stats(pcap_file):
    out = subprocess.run([
        "tshark", "-r", pcap_file,
        "-Y", "http.response.code >= 400",
        "-T", "fields", "-e", "http.response.code"
    ], capture_output=True, text=True).stdout

    codes = [line for line in out.split("\n") if line]
    return Counter(codes)

stats = http_error_stats("capture.pcapng")
for code, count in stats.most_common():
    print(f"HTTP {code}: {count} 次")
```

### 38.3.2 提取所有 DNS 查询域名

```python
def extract_dns_names(pcap_file):
    out = subprocess.run([
        "tshark", "-r", pcap_file,
        "-Y", "dns.qry.name",
        "-T", "fields", "-e", "dns.qry.name"
    ], capture_output=True, text=True).stdout
    return sorted(set(line for line in out.split("\n") if line))

domains = extract_dns_names("capture.pcapng")
print(f"共查询 {len(domains)} 个域名")
for d in domains[:20]:
    print(d)
```

### 38.3.3 检测重传异常

```python
def retransmission_analysis(pcap_file):
    out = subprocess.run([
        "tshark", "-r", pcap_file,
        "-Y", "tcp.analysis.retransmission",
        "-T", "fields", "-e", "tcp.stream",
        "-E", "separator=|"
    ], capture_output=True, text=True).stdout
    streams = Counter(line for line in out.split("\n") if line)

    total = subprocess.run([
        "tshark", "-r", pcap_file, "-Y", "tcp",
        "-T", "fields", "-e", "frame.number"
    ], capture_output=True, text=True).stdout.count("\n")

    return streams, total
```

## 38.4 使用 tshark 的 JSON 输出

对于复杂分析，JSON 输出更容易处理：

```python
import json

out = subprocess.run([
    "tshark", "-r", "capture.pcapng",
    "-Y", "http", "-T", "json"
], capture_output=True, text=True).stdout

packets = json.loads(out)
for pkt in packets:
    layers = pkt["_source"]["layers"]
    if "http" in layers:
        http = layers["http"]
        print(http.get("http.request.method"), http.get("http.host"))
```

## 38.5 替代方案：Python 直接解析 pcap

除了调用 tshark，也可以用 Python 库直接解析：

- **scapy**：功能强大，能解析和构造包。
- **dpkt**：轻量，解析速度快。
- **pyshark**：tshark 的 Python 封装。

```python
# scapy 示例
from scapy.all import rdpcap, IP, TCP

packets = rdpcap("capture.pcapng")
syn_count = 0
for pkt in packets:
    if IP in pkt and TCP in pkt:
        if pkt[TCP].flags & 0x02 and not (pkt[TCP].flags & 0x10):
            syn_count += 1
print(f"SYN 包数量: {syn_count}")
```

直接解析的优点是不依赖外部进程，速度快；缺点是需要自己处理协议细节，且解析能力不如 Wireshark 全面。

## 38.6 构建分析流水线

一个完整的自动化分析系统可能包括：

1. **采集**：定时抓包或用 tcpdump/dumpcap 持续捕获。
2. **存储**：按时间分文件存储，压缩归档。
3. **分析**：定时脚本调用 tshark 提取关键指标。
4. **检测**：规则引擎判断异常（如错误率超阈值）。
5. **告警**：邮件/消息通知。
6. **报告**：生成可视化报告（matplotlib、HTML）。

## 38.7 小结

- 自动化适合批量、重复、定时的分析任务。
- Python 调用 tshark 是最简单的方式：subprocess + `-T fields` 提取字段。
- JSON 输出适合复杂结构的处理。
- scapy/dpkt/pyshark 可直接解析 pcap，速度快但需自己处理协议细节。
- 完整流水线：采集 → 存储 → 分析 → 检测 → 告警 → 报告。
