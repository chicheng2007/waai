# 第一部分 · 认识你自己：来不来得及

## 1.1 先回答那个你最纠结的问题

你打开这份文档之前，脑子里盘旋的大概是这几个念头："我大二了，攻防取证 AI 全都不会，是不是晚了？""别人好像早就开始了，我是不是没救了？""三线一起学会不会把自己搞崩？"

**直截了当的回答：来得及，而且你现在这个状态，比你以为的要好得多。**

不是安慰你。我们把你担心的每一条拆开看：

| 你的顾虑 | 真实情况 |
|---|---|
| "我攻防零基础" | 网安专业大一大二本来就不系统教攻防，多数学校大三才开渗透课程。你现在起步不是落后，是刚好卡在最好的起点上。 |
| "我取证刚开始" | 大二就能接触火眼证据分析，已经领先大部分同学——很多人到毕业都没摸过专业取证平台。取证是练出来的，不是提前学会的。 |
| "我 AI 也零基础" | AI 入门真正需要的只有两样：会一点 Python、懂一点基础数学。这两样你都在补，而且学校课程本来就会覆盖。 |
| "三线一起会不会太乱" | 会不会乱，取决于有没有清晰的主次和时间分配。这份文档的核心就是帮你把"三线"排出优先级——见第二部分。 |
| "我只会 Python / C++ 基础语法" | 这就够了。AI 和网安脚本用的是同一套 Python，语法之外的东西（库、思维、工程习惯）都是边做边长的，没人指望你现在就会。 |

一句话：**你现在不是"落后"，而是站在三条线的起点上。别人大四才后悔没早点规划，你大二就开始布局，这本身就是优势。**

## 1.2 请重新记住你的定位

很多同学低估自己，是因为拿"攻防取证也零基础"给自己贴了个"啥也不会"的标签。但定位应该是这样：

```
起点：网安专业在读（有课程 / 实验室 / 老师资源）
      + 正在考软考（网络地基正在打）
      + 三线都刚起步（可塑性最强的时候）
目标：网安基础 + AI 能力双修的复合型人才
优势：年轻、时间多、有专业环境、知道要学什么
```

注意最后一条——**"知道要学什么"本身就是巨大优势**。很多上了研究生的人还在纠结方向，你已经有了清晰的三线框架。剩下的只是执行。

## 1.3 最重要的一条认知：AI 是加速器，不是额外的负担

这是整份文档的灵魂，值得单独拎出来讲透。

大多数同学的默认想法是："我得先把网安学好，再去碰 AI。" 于是他们把 AI 排在很后面，等到大三大四才匆匆起步，结果发现既要准备实习/考研，又要补 AI，顾此失彼。

**更聪明的做法反过来：从第一天起，就把 AI 当成你学网安的工具。**

具体怎么用：

- **学攻防时**：遇到"SQL 注入到底怎么回事""攻击链每一步在干嘛""这个 Writeup 写的是什么鬼"，直接问大模型，让它用打游戏、盖房子这种生活比喻讲给你听。门槛瞬间降下来。
- **写脚本时**：让 AI 帮你写代码、改报错、解释正则。你负责判断对错、负责理解逻辑——这是你真正要练的能力。
- **做取证时**：让 AI 帮你写批量分析脚本、解读火眼导出的报告、从海量日志里捞关键线索。这是只会点鼠标的人不会的。
- **学软考时**：让 AI 用大白话解释"子网划分""OSPF 邻居建立过程"，比啃教材快得多。

这样一来，你学网安的速度会比纯手工的同学快，而且**在过程中自然就积累出了"AI + 网安"的实战感觉**——这恰恰是最难靠课堂学到的东西。

> **核心洞察**：三条线不是竞争关系，是互相加速的关系。软考打网络地基 → 网安基础给 AI 提供真实场景 → AI 反过来加速你学网安。三者形成正循环，越往后越省力。

## 1.4 AI Agent 的两个身份：现在用，以后做

关于 Agent（智能体），你要建立"双重身份"的认知，这会让你既不错过当下的红利，也不错过未来的方向。

**身份 ①：现在就是你的学习工具（不用学，直接用）**

| 工具 | 帮你做什么 |
|---|---|
| Cursor / Claude Code | 帮你写 Python、改报错、解释代码、写 CTF 解题脚本、写取证分析脚本 |
| Copilot / 通义灵码 | 代码自动补全，敲代码快一倍 |
| 各类 AI 助手 | 用大白话讲"SQL 注入原理"、帮你读 Writeup、解释日志字段 |
| 你本地的 Qwen3.5-9B | 24 小时在线、不要钱、数据不出本机的私人助教 |

> **用法铁律**：让 AI 帮你写代码，但你**必须看懂每一行**。看懂 ≠ 抄，抄了不理解等于没学。从大二第一天就用，这是你比同学快的根本原因。

**身份 ②：大三以后深入的方向（AI + 网安最有前景的赛道）**

网安行业正在把 Agent 用在：自动化渗透测试（给授权范围，自动探测、扫描、出报告）、威胁情报分析（自动汇总多源情报、总结 IoC）、SOC 告警降噪（海量告警里自动甄别真威胁）、取证辅助（自动从镜像/日志提取关键证据）。

这条路怎么走，见 [第六部分 Agent 章节](#63-阶段-3大模型--ai-agent学有余力再碰) 和 [04 大模型/Agent](roadmap/04-llm-agent.md)。现在你只需要知道：Agent 开发大三下再系统深入完全来得及，但 Agent 工具从今天就能用起来。

## 1.5 给自己一个现实的预期

最后浇一点冷静的水，避免你三天热血上头、第四天放弃。

- **这不是三个月速成的故事**。软考、CTF、取证、机器学习、深度学习、大模型——每一块都需要时间沉淀。合理预期是：大二打地基 + 出第一个项目，大三出 2~3 个像样作品，大四成型。
- **你会频繁卡住**，这很正常。卡住 15 分钟就求助（问 AI 或问人），别死磕到怀疑人生。
- **前两周最难受**，因为全是新东西。撑过去，后面会越来越顺——这是所有过来人的共同体验。
- **进度因人而异**，别和别人比。你只需要比昨天的自己强一点。

准备好了，就往下走。第二部分给你全局地图。
# 第二部分 · 全局路线图：三线并进

## 2.1 三线是哪三线

整条路线按"三线并进"设计，每条线有自己的节奏和终点：

| 学习线 | 内容 | 当前定位 | 结束标志 |
|---|---|---|---|
| **主线 · 软考** | 网络工程师（网络地基） | 现在是绝对优先 | 一次通过 |
| **网安线** | CTF 驱动攻防 + 火眼取证 | 贯穿始终，从零起步 | 能独立打 CTF、做取证分析 |
| **AI 线** | 传统 ML → 深度学习 → 网安项目 → 大模型 / Agent | 软考后正式发力 | 有 1~2 个能写进简历的项目 |

这里的"并进"不是说三条线同时用 equally 的精力，而是**都保持连续性、不中断**——软考期以软考为主，但网安和 AI 每天都有最低限度的投入，保持手感和连续性。这样软考一结束，AI 线可以立刻提速，而不是从零重启。

## 2.3 时间分配原则（最关键的一张表）

很多计划失败，不是因为内容不对，而是因为精力分配错了。这张表告诉你每个阶段该把时间花在哪：

| 阶段 | 软考 | 网安基础 | AI | 专业课 / 其他 |
|---|---|---|---|---|
| **软考期** | 60% | 25% | 15% | 按当期课业 |
| **软考后** | — | 40% | 50% | 10% |

**软考期为什么软考占 60%**？因为软考有明确 deadline，且是这几件事里唯一"一次考过最省事"的——拖着不过会一直占用心理带宽。集中精力一次性拿下，反而释放了后面的时间。

**软考后为什么 AI 反超到 50%**？因为网安基础可以继续靠 CTF 和课程"细水长流"，但 AI 是需要连续投入才能形成能力的——断断续续学机器学习，每次都要重新捡起来，效率极低。软考后是你集中火力建 AI 能力的最佳窗口。

> ⚠️ 这两张表是**原则不是教条**。考试周、课程大作业多的时候，当期课业优先。灵活调整，但大方向别变。

## 2.4 完整的大学时间线（三线版）

把视野拉长到整个大学，你会更清楚每一步的意义：

| 时间 | 软考/网络 | 网安基础 | AI 进度 | 里程碑 |
|---|---|---|---|---|
| **大二上（现在）** | 备考软考 | CTF 入门 + DVWA 靶场 | 每天 30min Python/数学 | 软考通过 + 10 道 CTF |
| **大二寒假** | 网络知识巩固 | 深入火眼 + 补取证原理 + 更多 CTF | 吴恩达 ML 前半 | sklearn 跑通第一个模型 |
| **大二下** | 专业课 | Web 安全深入 + 团队 CTF 比赛 | 李沐 DL + 第 1 个项目 | 1 个网安 AI 项目 |
| **大三上** | 专业课 | 逆向 / 内存取证入门 | NLP/流量分析 + 第 2 个项目 | 2~3 个项目，GitHub 有作品 |
| **大三下** | — | 找实习 / 参加护网演练 | 大模型入门 + 补算法 | 简历成型 / 考研规划清晰 |
| **大四上** | — | 实习或考研冲刺 | 项目打磨 | 拿到 offer 或上岸 |
| **大四下** | — | 毕业设计 | 做 AI+网安相关的毕设（可选 Agent 方向） | 毕业 |

**这张表怎么用**：不必焦虑整张表，你只需要做好"当前格子"的事。大一格子里的事做完， naturally 就进入下一格。真正拉开差距的不是谁看得远，而是谁把每一格都踏实走完了。

## 2.5 里程碑体系：用"结束标志"驱动，不用"学了多久"驱动

很多人打卡"今天学了 3 小时"，一个月后发现什么都没做成。问题在于**用时间当进度指标**——时间投入了，但可能全在低效重复。

更靠谱的是用**里程碑（结束标志）**驱动。每条线的每个阶段都有一个明确的、可验证的完成标准：

- 软考线：✅ 一次通过 → 这是硬指标，过了就过，没过就再来。
- 网防线：✅ 完成 10 道 CTF 签到题 / ✅ 独立做一次完整取证分析 → 做了就是做了。
- AI 线阶段 1：✅ sklearn 跑通 KDD99 入侵检测 → 有代码、有结果。
- AI 线阶段 2：✅ 1~2 个项目上 GitHub → 有链接可展示。

每达成一个里程碑，就在 [每日打卡](checkin-log.md) 里记一笔。这种"可验证的完成感"比"我今天很努力"更能支撑你走下去。

## 2.6 三条线怎么互相加速：几个真实例子

理论说完了，看几个具体场景，你就明白"三线并进"不是空话：

**场景 1：学子网划分（软考）→ 理解日志里的 IP（网安 + Python）**
软考教你 IP 地址、子网划分。当你写日志分析脚本、看到 `192.168.1.100` 这样的 IP 时，你能立刻判断它是内网地址、属于哪个网段——这就是软考知识在网安场景里的直接复用。

**场景 2：CTF Web 题（网安）→ 学会用正则提取数据（Python）→ 分析日志（AI 项目）**
打 CTF 时你会接触大量 HTTP 请求，慢慢你会看懂请求结构。这个能力迁移到日志分析：用正则从访问日志里提取 IP、时间、请求、状态码——这正是 [14 天实战](START-HERE.md) 第 2 天干的事。

**场景 3：取证报告（网安）→ 喂给本地大模型总结（AI）**
火眼导出一份报告，你让 Qwen3.5-9B 帮你提取里面的关键时间点和 IP，这就是最朴素的"AI + 取证"实践。你会开始理解大模型在安全工作流里到底能干什么。

**场景 4：深度学习学 LSTM（AI）→ 做日志异常检测（网安项目）**
学了 LSTM 之后，你自然会想"能不能用它检测日志里的异常序列"——这就是阶段 2 的网安 AI 项目。你的网安背景帮你设计特征，AI 能力帮你建模型，两者缺一不可。

看懂了吗？**三线不是三份独立的作业，而是同一个能力的不同侧面。** 这就是这份路线最核心的设计。
# 第三部分 · 阶段 0：软考主线

> 完整版见 [01 · 软考期](roadmap/01-soft-exam.md)。这里是浓缩版，帮你快速抓住重点。

## 3.1 为什么软考是现在唯一的硬主线

三条线里，只有软考有明确的、不可回避的 deadline，而且它的知识价值极高——**软考网络工程师考的就是网络地基**，而你后面做的每一件事都踩在这个地基上：

- 做异常流量检测 → 要懂 TCP/IP 协议、端口、三次握手
- 做渗透测试 → 要懂网络拓扑、路由交换、防火墙规则
- 做电子取证 → 要懂数据包结构、协议分析
- 写安全脚本 → 要懂 socket 通信、IP 地址

所以软考不是"耽误你学网安和 AI 的杂事"，它**本身就是在打这三件事的地基**。把它一次性拿下，后面会省大量力气。

## 3.2 你的现成资料够不够：够

你手上的组合是：**Summer 的课（去年录播）+ 官方《网络工程师教程》**。这个组合完全够用，但要注意补上最关键的一环——真题。

| 资料 | 怎么用 | 注意点 |
|---|---|---|

## 3.3 高效复习四步法

不要盲目地从头看到尾。按这个流程走，效率最高：

1. **看 Summer 的课建立框架、理解难点**——视频比教材更容易建立直觉，先听懂大概念。

4. **用 Anki / 备忘录记易忘的协议端口号、命令**——像 `80=HTTP`、`443=HTTPS`、`3389=RDP` 这种，靠重复记忆。

**下午案例题特别提醒**：组网配置、故障分析这类题，必须**动手写**，不能只看答案。这是绝大多数人挂科的地方——看懂答案和实际能写出来，是两码事。找个本子，把配置命令亲手敲一遍、把故障分析步骤亲手列一遍。

# 第四部分 · 网安基础线：攻防与取证

> 完整版见 [01 软考期 · 网安基础](roadmap/01-soft-exam.md#43-网安基础从零补重点)。网安线贯穿整个大学，这里是起步阶段的方法。

## 4.1 网络攻防：用 CTF 驱动，不要先啃大部头

攻防这块最容易犯的错，就是想"先把书看完再实战"。网安是实操性极强的领域，正确路径是**边做题边补**——CTF 是最好的老师。

### 学习顺序（由易到难，别一上来碰二进制）

| 顺序 | 内容 | 怎么学 | 预计时间 |
|---|---|---|---|
| ① 建立直觉 | 渗透测试、CTF、漏洞、攻击链是什么 | B站搜"网络安全入门科普"，看 5~10 个视频 | 1 周 |
| ② Web 安全入门 | SQL 注入、XSS、CSRF、文件上传 | 本地搭 DVWA 靶场（DVWA + PHPstudy），照着教程复现 | 3~4 周 |
| ③ 工具上手 | Burp Suite、Wireshark、Kali Linux | B站"Burp Suite 入门"、"Wireshark 抓包"教程 | 2~3 周 |
| ④ 打 CTF | Misc（杂项）、Web 签到题 | 平台：攻防世界（XCTF）、NSSCTF、CTFtime | 持续 |
| ⑤ 进阶（大三再说） | 逆向、PWN、二进制漏洞 | 《逆向工程核心原理》、PWN 入门 | 大三 |

### 关键建议

- **CTF 是最好的老师**：从最简单的 Misc 和 Web 题开始，做不出来就看 Writeup（题解），看懂了**再自己敲一遍**。看题解不丢人，看完不复盘才丢人。想要系统路线，仓库里有 [CTF 从零到实战（Web + Misc，6 卷 33 章）](tutorial/06-CTF-Web与Misc/README.md)，零基础友好、每章可复现。
- **用 AI 加速**：遇到不懂的概念直接问大模型，比如"用打游戏的方式解释 SQL 注入"，比看书的门槛低很多。该教程第 26 章专门讲 AI 辅助解题。
- **靶场推荐**：DVWA（本地）、攻防世界（在线）、Hack The Box（进阶）。新手强烈推荐 TryHackMe 的游戏化引导。
- **C++ 在这里有用**：大三学逆向、二进制漏洞时，你的 C++ 基础会派上用场。现在保持手感即可，不用猛练。

## 4.2 电子取证：以你正在用的「火眼证据分析」为主线

> **重要**：你已经在用火眼证据分析，这是国内执法与司法领域的主流取证平台，比 Autopsy 更贴近实战。**别本末倒置去从头学一堆工具**——工具只是载体，思维和原理才是核心。

### 工具取舍（不要全学）

| 工具 | 要不要学 | 理由 |
|---|---|---|
| **火眼证据分析**（你正在用） | **主线，继续深入** | 学校有环境、贴近国内实战，把它用熟比啥都强 |
| FTK Imager | **只学"做镜像"一个功能** | 镜像格式是通用概念，理解原理即可，不用深挖 |
| Autopsy | **可不学** | 开源免费，只适合没有火眼环境时在家练习；你有火眼就不用花时间 |
| Volatility（内存取证） | **大三再了解** | 现在不碰 |

### 真正该补的三样（比学新工具重要得多）

1. **取证思维**：证据链完整性、操作全程留痕、哈希校验（MD5/SHA）、时间线分析。工具会换代，规范不变。火眼用得再熟，不懂这些也做不好案子。
2. **底层原理**：文件系统（NTFS/FAT）、注册表关键项、浏览器痕迹、日志结构。火眼分析出结果，你要能解释"为什么"——这才是从"操作员"变成"分析师"的关键。
3. **AI 辅助取证（你的差异化）**：让大模型帮你写批量分析脚本、解读火眼导出的报告、从海量日志里捞关键线索。这是只会用火眼的人不会的。

### 学习顺序

| 顺序 | 内容 | 资源 | 预计时间 |
|---|---|---|---|
| ① 建立直觉 | 取证流程（保护→获取→分析→呈现）、证据链概念 | B站搜"电子数据取证入门" | 1 周 |
| ② 深入火眼 | 把手头火眼案例做透，理解每个功能在分析什么 | 学校教程 + 实际案例 | 持续 |
| ③ 补原理 | 文件系统、注册表、浏览器痕迹、日志结构 | 教材 + B站，边用火眼边对照 | 持续 |
| ④ 镜像原理（了解） | 用 FTK Imager 做一次镜像，理解"为什么必须先镜像再分析" | 官网 + 自己的 U 盘 | 1 次即可 |
| ⑤ AI 辅助 | 让大模型帮你解读报告、写分析脚本 | 你正在用的 AI 助手 | 持续 |

> **取证是流程 + 思维 + 经验**，不需要很深的数学，你完全能上手。尽量蹭学校的真实案例数据——真实案子比模拟数据有价值得多。把你手头的火眼用到极致，比多学三个工具都有价值。

## 5.3 台阶 1：语法查漏 + Python 思维

## 5.4 台阶 2：核心数据结构与文件处理

这是"能处理真实数据"的分水岭。

| 内容 | 用法 | 网安/取证场景 |
|---|---|---|
| `open()` / `with` | 读写文本、指定 `encoding='utf-8'` | 读取日志文件、火眼导出的报告 |
| `csv` 模块 | `csv.reader` / `csv.writer` | 处理流量表、资产清单 |
| `json` 模块 | `json.loads` / `json.dumps` | 解析 API 返回、配置文件 |
| `os` / `pathlib` | 路径、遍历目录、批量改名 | 批量处理镜像文件、证据文件 |
| 异常处理 `try/except` | 别让脚本一报错就崩 | 处理格式不规范的数据 |

**代码示例：读日志统计每个 IP 出现次数**

```python
from collections import Counter

counts = Counter()
with open("access.log", encoding="utf-8") as f:
    for line in f:
        parts = line.split()
        if parts:
            counts[parts[0]] += 1

for ip, n in counts.most_common(10):
    print(ip, n)
```

**自测**：能独立写一个脚本，读入一个 CSV，统计出某个字段的分布并打印。

## 5.5 台阶 3：正则表达式（网安必备）

**这是网安和取证最高频的技能**——从海量文本里捞关键线索全靠它。认真学。

| 语法 | 作用 | 例子 |
|---|---|---|
| `\d` `\w` `\s` | 数字 / 单词字符 / 空白 | 匹配日志字段 |
| `.` `*` `+` `?` | 通配与数量 | 模糊匹配 |
| `[abc]` `[^abc]` | 字符集 | 匹配特定字符范围 |
| `^` `$` | 行首行尾 | 精确锚定 |
| `(...)` 分组 | 提取子串 | 抓取 IP、时间、URL |
| `re.findall` / `re.search` | 查找 / 匹配 | 批量提取 |

**代码示例：从日志里提取 IP 和时间**

```python
import re

text = "2026-11-23 10:30:01 192.168.1.10 GET /index.html"
pattern = r"(\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2})\s+(\d+\.\d+\.\d+\.\d+)"
m = re.search(pattern, text)
if m:
    print("时间:", m.group(1), "IP:", m.group(2))
```

**网安小练习**：
- 从一段文本里提取所有 IP 地址、邮箱、URL（正则在线调试用 regex101.com）。
- 写一个"日志清洗器"：用正则把非结构化日志转成 CSV。

**自测**：能不看文档，写出正则从访问日志里提取 IP、时间、请求路径。

> 看不懂 `for line in LOG_SAMPLE.strip().split("\n")` 这类语法？先花 3 天看 [SYNTAX-BOOTCAMP.md（3 天语法急救包）](guides/SYNTAX-BOOTCAMP.md)——用"发牌/切香肠"的生活比喻讲懂读代码必备的 5 个零件。忘了某个语法怎么写？查 [SYNTAX-REFERENCE.md（语法库大全）](guides/SYNTAX-REFERENCE.md)。

## 5.11 Python 常见坑

1. **只看不敲**：视频看了很多，代码一行没写 → 等于没学。
2. **死磕语法**：语法会了就往前走，遇到不懂的边用边查。
3. **不装虚拟环境**：依赖装乱了以后很难收拾，从第一个项目就用 venv。
4. **抄代码不理解**：用 AI 生成的代码，逐行看懂再留。
5. **贪多求快**：同时学 numpy、pandas、requests → 都不精。一个练透再开下一个。
6. **不看报错**：报错信息是提示不是阻碍，读懂它（或问 AI）是基本功。

## 6.1 阶段 1：传统机器学习（软考后 1~2 个月）

**为什么先学传统 ML，不直接上深度学习？**
- 原理简单、训练快、可解释性强
- 在网安领域**大量使用**（恶意代码检测、流量分类主要用它）
- 打好这个概念基础，学深度学习会顺很多

### 学习步骤

**第 1 步：看课建立框架（2~3 周）**
- 吴恩达《Machine Learning》（Coursera，B站有搬运）
- 先只看前 5 周：线性回归、逻辑回归、代价函数、梯度下降、决策树、SVM
- 目标：理解"模型 = 从数据里学规律"

**第 2 步：sklearn 动手（2~3 周）**
- 安装：`pip install scikit-learn`
- 跟着官方文档 Getting Started 敲一遍鸢尾花分类
- 掌握标准流程：**加载数据 → 划分训练/测试集 → 选模型 → 训练 → 评估**

```python
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score

data = load_iris()
X_train, X_test, y_train, y_test = train_test_split(
    data.data, data.target, test_size=0.2, random_state=42
)
model = RandomForestClassifier()
model.fit(X_train, y_train)
print("准确率:", accuracy_score(y_test, model.predict(X_test)))
```

**第 3 步：网安小项目（2~3 周）**
- 数据集：Kaggle 搜 `KDD Cup 1999`（经典网络入侵检测数据集）
- 任务：用随机森林 / 决策树判断一条网络连接是不是攻击
- 目标：跑通全流程，写出一个简单的分析报告
- 注意：这时候你的软考网络知识就派上用场了——理解每条连接记录的特征含义

**自测清单**：能解释训练集/测试集为何分开；能解释过拟合及避免方法；能独立用 sklearn 跑通一个分类任务；完成 KDD99 入侵检测小项目。

- **框架**：PyTorch（你的 RTX 5060 有 8GB 显存，直接装 CUDA 版用 GPU 训练，比 CPU 快一个数量级，安装见 [硬件与本地环境](reference/hardware-setup.md)）

## 6.3 阶段 3：大模型 + AI Agent（学有余力再碰）

前面走通了再进这一阶段。Agent 对你有双重身份：现在当工具用，大三以后当发展方向。

### 大模型基础

- 了解 Transformer 架构、BERT、GPT 的原理
- 工具：Hugging Face `transformers` 库，直接调用开源模型（如 `bert-base-chinese`）
- 实战方向：
  - 用大模型做**威胁情报问答**：把攻击报告喂给 LLM，自动总结 IoC（攻击指标）
  - 用大模型辅助**钓鱼文本识别**、**告警降噪**
  - 了解 RAG（检索增强生成）：把安全知识库接进大模型

> 你的 RTX 5060（8GB）可以用 Ollama / LM Studio 本地跑 7B~9B 量化模型做这些实验（你已实测 Qwen3.5-9B），见 [第九部分](#第九部分--硬件与本地大模型环境)。

### AI Agent：现在当工具，以后当方向

**是什么**：普通大模型是你问一句它答一句；Agent 是你给它一个**目标**，它自己拆解任务、调用工具、多步执行直到完成——相当于一个"数字助手"。

**学习路径**（大三下 ~ 大四再碰）：
1. 先走通 Python → 传统 ML → 深度学习基础
2. 学 Prompt 工程、Function Calling（让模型调用工具）
3. 学一个 Agent 框架：LangChain（最主流）或 CrewAI（多智能体）
4. 做一个网安场景的 Agent 小项目（比如"给定域名自动查情报并总结"）

> **红线提醒**：任何渗透、扫描类操作**必须在自己的靶场或有书面授权的环境**进行。技术再强，越界就是毁前程。

# 第九部分 · 硬件与本地大模型环境

## 9.1 你不需要为硬件焦虑

你的设备：**联想拯救者 R9000P 2025 · RTX 5060（8GB 显存）+ R9 9955HX（16 核 32 线程）+ 32GB DDR5 + 1TB SSD**。

结论先说：**这是一台很能打的 AI 学习本**，不是"够不够用"，而是"用得很好"。别再觉得需要加钱换设备。

| 部件 | 规格 | 对 AI 的意义 |
|---|---|---|
| **GPU** | RTX 5060 Laptop，8GB 显存，Blackwell 架构 | 能用 GPU 训练/推理，8GB 是本地跑模型的实用门槛 |
| **CPU** | AMD R9 9955HX，16 核 32 线程 | 数据处理、编译、跑传统 ML 绰绰有余 |
| **内存** | 32GB DDR5 | 大数据集、多任务、开虚拟机都不慌 |
| **硬盘** | 1TB SSD | 放数据集、模型权重、多个虚拟环境 |

对比一下：很多 AI 初学者用的是无独显轻薄本或老旧机器，只能 CPU 慢跑或用免费云环境。你的配置可以直接本地 GPU 训练，起步就领先一大截。

## 9.2 8GB 显存能做什么、不能做什么

**能做（你的主战场）**：
- ✅ 传统机器学习（sklearn / XGBoost）——跟显存没关系，CPU 就够快
- ✅ 深度学习入门：MLP / CNN / LSTM / 小型 Transformer，本地训练
- ✅ 网安实战项目：流量分类、日志异常检测、钓鱼文本识别、恶意代码分类（都是小模型）
- ✅ 本地跑小模型推理：BERT 类、9B 级 LLM（Q4 量化后能完整放进显存，**你已实测跑通 Qwen3.5-9B**）
- ✅ Stable Diffusion 画图、用 Ollama / LM Studio 本地跑量化大模型

**别硬做（要云算力）**：
- ❌ 从头预训练大模型（那是 A100/H100 集群的活）
- ❌ 全参数微调 7B 以上大模型（显存不够，但可用 LoRA / QLoRA 轻量微调）
- ❌ 超大图像 / 视频生成模型

> 关键点：**你整个学习路线里的项目，8GB 显存全部够用**。等真需要更强算力（比如大三做毕设微调大模型），再考虑云服务器（AutoDL 等，按小时租），不用现在升级硬件。

## 9.3 软件环境：GPU 版 PyTorch

1. **确认驱动**：终端运行 `nvidia-smi`，能看到 GPU 信息和 CUDA 版本就正常。RTX 5060 较新，建议装最新版 NVIDIA 驱动。
2. **装 CUDA 版 PyTorch**：去 [PyTorch 官网](https://pytorch.org/get-started/locally/) 选 Stable → Windows → Pip → Python → CUDA 12.x，复制生成的命令执行：
   ```bash
   pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
   ```
3. **验证 GPU**：
   ```python
   import torch
   print(torch.cuda.is_available())        # 应输出 True
   print(torch.cuda.get_device_name(0))    # 应显示 RTX 5060
   ```
4. **用 conda 管理环境**（推荐）：`conda create -n ai python=3.11` → `conda activate ai`，每个项目一个环境。

> ⚠️ 常见坑：PyTorch 的 CPU 版和 CUDA 版不能混装。装过 CPU 版先 `pip uninstall torch torchvision torchaudio` 卸载干净再装。

## 9.4 本地跑大模型：LM Studio + Qwen3.5-9B

> **你的实战记录**：你已经在 LM Studio 部署了 **Qwen3.5-9B**——这不是"能不能跑"的问题，而是 8GB 显存公认的甜点配置。

### 你的配置为什么合理

| 项目 | 说明 |
|---|---|
| **模型** | Qwen3.5-9B —— 社区公认 8GB 显存的最佳本地助手 |
| **量化** | Q4_K_M 是甜点：9B 压到约 5GB，保留约 95% 能力，完整放进 8GB 显存 |
| **格式** | LM Studio 只认 **GGUF** 格式，下载认准 GGUF 后缀 |
| **上下文** | 原生支持 32K；8GB 显存下 4K~8K 最稳，长文本再往上调 |
| **速度** | 完整 GPU 加载可达 40~55 token/s（流畅对话级） |

### 部署要点

1. **GPU offload 拉满**：模型能完整放进显存时，把 GPU 层数滑到最大（约 32 层全 offload），速度最快。
2. **上下文别贪大**：4K~8K 够日常；调太高吃 KV Cache 显存，可能 OOM。
3. **量化选择**：Q4_K_M 默认最佳；显存有余量再上 Q5_K_M / Q6_K 提升质量。
4. **国内下载**：Hugging Face 直连慢用 `hf-mirror.com` 镜像；LM Studio 的 Discover 里也能直接搜。
5. **当 API 用**：LM Studio 的 Developer 标签开一个 OpenAI 兼容的本地服务（`localhost:1234`），让 Python 脚本 / Agent 直接调用——这是接 Agent 项目的关键，也是 [14 天实战](START-HERE.md) 第 9~10 天做的事。

### 网安玩法（授权范围内）

- **安全知识问答**：把 CTF Writeup、取证笔记喂给它，做个人知识助手
- **威胁情报总结**：把攻击报告贴给它，提取 IoC（IP / 域名 / hash）
- **日志解读**：让它解释日志字段、分析可疑记录（辅助学取证）
- **RAG 实验**：本地模型 + 安全知识库，做检索增强问答

> 本地 9B 模型推理能力有限，复杂任务比不上云端大模型。但**用来学原理、写代码、做实验完全够**，而且数据不出本机——对网安场景反而是优势。

## 9.5 设备使用建议

1. 训练时插电源、开性能模式，让显卡满血释放。
2. 注意散热：垫高底部、保持通风，别堵出风口。
3. AI 学习基本都要插电，别指望电池续航（游戏本通病）。
4. 1TB SSD 给数据集和模型单独建文件夹，模型权重动辄几个 GB。
5. 别折腾双系统，Windows + WSL2 足够学 AI。

**一句话**：这台机器陪你走完从 Python 入门到大模型实验的全程都没问题。真正稀缺的是时间和动手——把机器用起来，比纠结配置重要一万倍。

4. **每天敲代码**：哪怕只有 20 分钟，手不能停。看懂 ≠ 会写。
5. **一个项目做透**：贪多做一堆半吊子项目，不如把一个做到能讲清楚。
6. **用输出倒逼输入**：写博客、传 GitHub、给同学讲，教别人是最好的学习。
7. **语言先专精 Python**：Go / Rust 大三后按方向再学；C++ 保持手感即可。
8. **从第一天就用编码 Agent**：Cursor / Copilot 帮你写代码，但每一行你都要看懂。
9. **守住法律底线**：渗透、扫描只在靶场或书面授权环境进行。
10. **别和别人比进度**：每个人节奏不同，你只需要比昨天的自己强。

## 11.3 如何真正读懂一段代码

你之前反馈过"这种语法不懂，只会最简单的"——这非常正常，关键是掌握一套拆解方法。以这行为例：

```python
for line in LOG_SAMPLE.strip().split("\n"):
```

**拆解法（四步）**：
1. **找主干**：这是一个 `for ... in ...:` 循环——"挨个处理一堆东西"。
2. **看右边**：`LOG_SAMPLE.strip().split("\n")` 是在造"那堆东西"。`strip()` 去掉首尾空白，`split("\n")` 按换行切成多行——想象把一根香肠切成一片片。
3. **看循环变量**：`line` 每一次代表其中一行——像发牌，一次发一张。
4. **看循环体**：冒号下面缩进的代码，对每一张"牌"（每一行）执行一次。

**通用口诀**：遇到看不懂的代码，先问 AI"用生活比喻解释这一行"，再让它"逐段拆解"，最后自己把它改写一遍。看不懂 → 问 → 改写，循环三次，没有看不懂的代码。

> 语法急救见 [SYNTAX-BOOTCAMP.md](guides/SYNTAX-BOOTCAMP.md)（3 天 5 个零件），速查见 [SYNTAX-REFERENCE.md](guides/SYNTAX-REFERENCE.md)（字典式大全，含 C/C++/Rust/Go 对照）。

## 11.4 如何正确用 AI 辅助学习

AI 是这份路线里反复出现的关键词，但用错方式会让你"看起来效率高，实际没长本事"。正确的姿势：

**该用的地方**：
- 解释概念（用比喻、用生活例子）
- 改报错（贴完整报错，让它解释原因 + 给改好的代码）
- 解释陌生代码（逐段拆解）
- 生成样板代码（然后逐行看懂再留）
- 当陪练（让它出练习题、帮你 review）

**不该用的地方**：
- 直接抄它给的代码不理解——换道题你还是不会
- 让它替你思考"该学什么"——方向问题这份文档已经给了
- 全盘相信它的输出——本地 9B 模型会出错，**你要练的就是判断它对不对**

**黄金习惯**：每用 AI 解决一个问题，追问一句"为什么这么做"，并尝试不看答案自己重写一遍。这一句追问，是真学和假学的分界线。

## 11.5 打卡系统：让坚持看得见

[每日打卡表](checkin-log.md) 不只是记录，它是你的"进度可视化"。每天学完追加一行：

```
| 日期 | 学习线 | 今日任务 | 时长 | 状态 |
```

**为什么打卡有用**：
- 看得见的积累会带来正反馈，越打越想打
- 断更时你会心虚，这种轻微压力帮你续上节奏
- 回头看时，几十行记录就是你的成长轨迹

**里程碑清单**也记在同一个文件里：软考通过、10 道 CTF、第一个 AI 项目上 GitHub……每达成一个就打勾。

## 11.6 如何做能写进简历的项目

项目是网安 + AI 领域最硬的作品证明。做项目时记住：

1. ** From a real problem**：明确要解决网安里的什么痛点（如"从海量日志里快速找可疑 IP"）。
2. **数据要有出处**：说明数据来源、规模、预处理方法。
3. **方法要有理由**：为什么选这个模型/方案，而不是别的。
4. **评估要诚实**：不只看准确率，网安场景更关注召回率（漏报代价高）。
5. **展示要专业**：GitHub README 写清楚项目简介、功能、使用方法、技术栈；配一张效果图。
6. **合规要声明**：注明数据为模拟/授权环境，守住法律底线。

一个做透的项目 + 一篇讲清楚的博客 > 十个半吊子项目。

## 11.7 常见的时间管理问题

- **"课业太忙没时间"**：软考期每天 30 分钟 Python 就够；真忙的一周可以只保软考 + 打卡不断。
- **"总想等准备好再开始"**：永远准备不好。今天就开始 [14 天实战](START-HERE.md) 第 0 天。
- **"学不进去"**：换个小任务，比如只做一道 CTF 签到题、只敲一遍示例代码。行动会带动状态。
- **"坚持不下来"**：把目标降到"不可能失败"的程度（比如每天只敲 5 行代码），先养成习惯再提速。

## 方向与心态

**Q1：我现在大二，攻防、取证、AI 全都零基础，还来得及吗？**
来得及。网安专业大一大二本来就不系统教攻防，多数学校大三才开课；取证你能接触火眼已经领先；AI 入门只需要 Python + 基础数学。你不是落后，是站在三条线的起点上。详见 [第一部分](#第一部分--认识你自己来不来得及)。

不会，前提是有主次。软考期软考占 60%、网安 25%、AI 15%；软考后 AI 反超到 50%。三条线共享底层（协议、Python、日志分析），实际是互相加速，不是三份独立作业。

**Q3：我是网安专业的，但攻防毫无基础，从哪开始？**

**Q4：我看到同学已经会很多了，很焦虑。**
别横向比，纵向比。每个人起点和节奏不同，你只需要比昨天的自己强。而且"知道自己要学什么"已经是巨大优势——很多人到毕业还在纠结方向。

## 语言与工具

**Q5：我现在应该学 Python 吗？我 Python 基础不强。**
应该，而且 Python 是绝对主力。你不需要从零重学语法——你的重点是"用 Python 做事"：标准库、数据处理、正则、工程习惯。按 [七个台阶](#第五部分--python-底座七个台阶) 走，软考期每天 30 分钟即可。

保持手感即可，不用猛练。AI 里 C++ 用于模型部署/性能优化，网安里用于逆向/PWN——这些是大三的方向。现在别投入过多精力。

**Q10：AI Agent 是什么，我要现在学吗？**
Agent 是你给它目标、它自己拆任务调工具多步执行完成的东西。它有双重身份：现在当**工具**用（Cursor / Copilot 帮你写代码、改报错，不用学直接用），大三下以后当**方向**深入（自动化渗透、威胁情报、SOC 告警降噪）。详见 [1.4](#14-ai-agent-的两个身份现在用以后做) 和 [6.3](#63-阶段-3大模型--ai-agent学有余力再碰)。

## 12A.2 机器学习 / AI 术语速查

| 术语 | 含义 |
|---|---|
| **模型** | 从数据里学到的规律，本质是一个能预测的函数 |
| **特征** | 用来描述样本的属性，比如日志里的 IP、状态码 |
| **标签** | 样本的答案，比如"这条连接是不是攻击" |
| **训练集 / 测试集** | 用来训练模型的数据 / 用来检验模型的数据，必须分开 |
| **过拟合** | 模型死记硬背训练数据、遇到新数据就废 |
| **召回率** | 真正该找出的样本里，被模型找出来的比例——网安场景最关键（漏报代价高） |
| **精确率** | 模型找出来的里面，真正对的比例 |
| **sklearn** | Python 传统机器学习库，封装了大量算法 |
| **PyTorch** | 主流深度学习框架，你的 RTX 5060 能 GPU 加速 |
| **LSTM** | 长短时记忆网络，擅长处理序列数据（日志、流量） |
| **Transformer** | 当前大模型的核心架构，基于注意力机制 |
| **LLM** | 大语言模型，如 GPT、Qwen |
| **RAG** | 检索增强生成，把外部知识库接进大模型再回答 |
| **Prompt** | 提示词，你给大模型的指令 |
| **Agent** | 智能体，能自己拆任务、调工具、多步执行完成目标 |
| **Function Calling** | 让大模型调用外部函数/工具的能力 |
| **量化** | 降低模型数值精度（如 FP16→Q4）以减小体积、加速推理 |
| **GGUF** | LM Studio / llama.cpp 用的模型格式 |
| **微调（Fine-tuning）** | 在预训练模型基础上用你的数据继续训练 |
