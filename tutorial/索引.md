# 完整系统教程索引

> 本仓库收录三套由用户整理的完整教程，按目录编号分套存放，**打开文件夹即可按 01→09 顺序阅读**：
>
> 1. **[01-Python主线](README.md)** · 主教程（9 卷 30 章）：从零到 AI+网安，卷目录按 01→09 编号（目录说明见 [README.md](README.md)）
> 2. **[02-系统语言](02-系统语言/README.md)** · 进阶（C/C++ · Rust · Go 各 12 章）：底层 / 性能 / 系统安全
> 3. **[03-混合编程](03-混合编程/README.md)** · 高级（5 卷 20 章）：Python 与 C/C++ · Rust · Go 互调，卷目录按 01→05 编号
>
> 三套都是零基础友好、代码驱动、每章有可运行代码 + 逐行解释 + 配套练习。三套合计 **86 章、约 60 万字**。

```
tutorial/
├── 01-Python主线/    ← 大二主线，9 卷按 01→09 编号
├── 02-系统语言/      ← 进阶，C/C++ · Rust · Go
├── 03-混合编程/      ← 高级，5 卷按 01→05 编号
├── README.md         ← 主教程目录
└── 索引.md           ← 本文件
```

> ⚠️ **学习顺序提醒**：大二阶段请**先以 Python 主教程为绝对主线**。系统语言（C/C++/Rust/Go）是进阶内容——C++ 保持手感即可，Rust/Go 大三后按方向再碰。混合编程是**三套里最靠后的一套**，需要前两套打底，建议大三下或大四再系统学。别同时开多门语言，会分散精力。详见仓库 README 的"语言与工具取舍"。
