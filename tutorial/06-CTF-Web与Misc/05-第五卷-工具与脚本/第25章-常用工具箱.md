# 第 25 章 CTF 常用工具箱与速查

## 本章目标

读完这一章，你将能够：

- 掌握 sqlmap、nmap、hydra 等核心工具的基本用法
- 知道各类字典资源在哪、怎么用
- 建立一份"什么场景用什么工具"的速查表
- 了解 dirsearch/ffuf/whatweb 等辅助工具
- 学会整理自己的 CTF 工具箱和速查笔记

> CTF 比的不只是知识，还有工具熟练度。同样一道注入题，手工要半小时，sqlmap 两分钟——前提是你知道 sqlmap 怎么用、输出怎么看。这一章把常用工具系统梳理一遍，作为你的"工具手册"。

## 25.1 sqlmap：SQL 注入自动化

第 6 章介绍过基本用法，这里系统梳理。

### 25.1.1 核心命令

```bash
# 探测注入点
sqlmap -u "http://target.com/news?id=1"

# 爆所有数据库
sqlmap -u "http://target.com/news?id=1" --dbs

# 爆表 / 列 / 数据
sqlmap -u "http://target.com/news?id=1" -D dbname --tables
sqlmap -u "http://target.com/news?id=1" -D dbname -T tablename --columns
sqlmap -u "http://target.com/news?id=1" -D dbname -T tablename --dump

# 一键拿所有数据（省事但有风险，可能被发现）
sqlmap -u "http://target.com/news?id=1" --dump-all

# POST 请求（先把 Burp 抓的请求保存到 request.txt）
sqlmap -r request.txt

# 指定注入参数和 DBMS
sqlmap -u "..." -p id --dbms=mysql

# 拖库速度控制（--delay 避免打挂靶场）
sqlmap -u "..." --delay=1
```

### 25.1.2 看懂输出

sqlmap 运行时会告诉你：
- 参数是否可注入（`id` is vulnerable）
- 注入类型（boolean-based / time-based / UNION query）
- 数据库类型（MySQL/PostgreSQL/...）
- 用了什么 payload

**这些输出正是学习材料**——新手应该用 sqlmap 输出反推手工 payload，加深理解。

## 25.2 nmap：网络扫描

```bash
# 扫描端口
nmap target.com

# 扫常见端口 + 服务版本
nmap -sV target.com

# 全端口扫描
nmap -p- target.com

# 服务/版本/OS 探测（激进）
nmap -A target.com

# 只做主机发现（ping sweep）
nmap -sn 192.168.1.0/24

# 脚本扫描（如 HTTP 常见漏洞）
nmap -sC -sV target.com
```

**CTF 用途**：信息收集阶段探测目标开了哪些端口、什么服务——呼应第 5 章。

## 25.3 hydra：密码爆破

```bash
# SSH 爆破
hydra -l root -P passwords.txt ssh://target.com

# HTTP POST 表单爆破
hydra -l admin -P passwords.txt target.com http-post-form "/login:user=^USER^&pass=^PASS^:登录失败"

# FTP 爆破
hydra -L users.txt -P passwords.txt ftp://target.com

# HTTP Basic 认证
hydra -l admin -P passwords.txt target.com http-get
```

**参数说明**：`-l` 单用户、`-L` 用户字典、`-P` 密码字典。`http-post-form` 的格式是 `路径:参数:失败特征`。

## 25.4 目录/文件扫描工具

```bash
# dirsearch
dirsearch -u http://target.com -e php,bak,zip,txt -t 20

# ffuf（更快，语法不同）
ffuf -u http://target.com/FUZZ -w wordlist.txt -mc 200,301,302,403

# gobuster
gobuster dir -u http://target.com -w wordlist.txt
```

**字典**：Kali 自带 `/usr/share/wordlists/`，常用 `dirb/common.txt`、`dirb/big.txt`。

## 25.6 Misc 工具速查

| 场景 | 工具 | 命令示例 |
|------|------|---------|
| 文件类型 | file | `file xxx` |
| 元数据 | exiftool | `exiftool xxx` |
| 文件分析/分离 | binwalk | `binwalk -e xxx` |
| 文件提取 | foremost | `foremost xxx -o out/` |
| 图片隐写 | zsteg / Stegsolve | `zsteg image.png` |
| JPG 隐写 | steghide | `steghide extract -sf xxx.jpg` |
| 流量分析 | Wireshark / tshark | `tshark -r x.pcap -Y "http"` |
| 哈希破解 | hashcat | `hashcat -m 0 hash.txt dict.txt` |
| 内存取证 | Volatility | `volatility -f mem.raw imageinfo` |
| 编码解码 | CyberChef | 网页工具，Magic 功能 |

## 25.7 字典资源

| 字典 | 用途 | 位置 |
|------|------|------|
| rockyou.txt | 密码爆破（经典） | `/usr/share/wordlists/`（可能需解压） |
| dirb/common.txt | 目录扫描 | `/usr/share/wordlists/dirb/` |
| fuzzDicts | 综合 fuzz 字典 | GitHub 搜 fuzzDicts |
| SecLists | 全能字典集合 | GitHub 搜 SecLists |

**字典选择**：先用小字典（common）快速扫，不够再上大字典。字典越大越慢，别一上来用最大的。

## 25.8 建立你的速查表

工具太多记不住？**自己整理一份速查表**（Cheat Sheet），需要时直接查。推荐格式：

```markdown
# 我的 CTF 速查表

## SQL 注入
- 探测：' and 1=1 / '
- 联合：ORDER BY 判列 → UNION SELECT
- sqlmap：sqlmap -u "..." --dbs

## XSS
- <script>alert(1)</script>
- <img src=x onerror=alert(1)>

## 编码
- Base64：echo xxx | base64 -d
- Hex：xxd -r -p

（按方向持续补充）
```

网上也有很多现成的 CTF Cheat Sheet（如 PayloadsAllTheThings、CTF 各类速查表 GitHub 仓库），可以下载来改。第 31 章的 Writeup 也会帮你沉淀这些。

## 25.9 本章总结

| 工具 | 用途 | 核心命令 |
|------|------|---------|
| sqlmap | SQL 注入自动化 | `-u ... --dbs --dump` |
| nmap | 端口/服务扫描 | `-sV`、`-p-`、`-A` |
| hydra | 密码爆破 | `-l/-L -P` + 协议 |
| dirsearch/ffuf | 目录扫描 | 字典 + FUZZ |
| whatweb | 技术栈识别 | `whatweb url` |
| Misc 工具 | file/exiftool/binwalk/zsteg/Wireshark/Volatility | 见速查表 |
| 字典 | rockyou/SecLists/fuzzDicts | 先用小的 |

## 本章练习

1. 用 nmap 扫描一个授权靶场，记录开放的端口和服务。
2. 用 sqlmap 跑一道 SQL 注入题，读懂它输出的注入类型和 payload。
3. 用 hydra 对一个自己搭的 FTP/SSH 服务做爆破测试。
4. 用 dirsearch + common.txt 扫描一个靶场，记录发现的目录。
5. 整理一份属于你自己的 CTF 工具速查表（markdown 文件，持续更新）。
6. 下载 SecLists 或 PayloadsAllTheThings，浏览它的目录结构，了解有哪些资源。
