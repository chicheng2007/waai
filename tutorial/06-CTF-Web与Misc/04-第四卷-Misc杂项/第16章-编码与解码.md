# 第 16 章 编码与解码：Misc 的字母表

## 本章目标

读完这一章，你将能够：

- 理解编码与加密的区别（这点是新手最大的困惑）
- 识别并手工处理 Base64、Hex、URL、Morse 等常见编码
- 掌握多层嵌套编码的解题思路
- 用 Python 和 CyberChef 快速解码
- 建立起"看到字符串先判断编码类型"的直觉

> 编码是 Misc 方向的基础中的基础——几乎每道 Misc 题都涉及某种编码。学会快速识别和转换编码，你就掌握了 Misc 的"字母表"。这一章从最根本的概念讲起。

---

## 16.1 先分清：编码 vs 加密

这是新手最容易混淆的概念，必须一开始就搞清：

| | 编码（Encoding） | 加密（Encryption） |
|---|---|---|
| **目的** | 方便传输/存储，格式转换 | 保密，让内容不可读 |
| **可逆性** | 人人可解，无需密钥 | 需要密钥才能解 |
| **本质** | 换一种"表示方式" | 用算法+密钥"打乱"内容 |
| **例子** | Base64、Hex、URL 编码、Morse | AES、RSA、DES |

**类比**：
- 编码 = 把中文翻译成英文电报码——任何人有码表都能翻译回来
- 加密 = 把信装进带锁的箱子——没有钥匙打不开

**CTF 意义**：看到一段奇怪字符串，先判断它是"编码"（直接解）还是"加密"（需要找密钥，那是 Crypto 方向）。Misc 里的"编码题"通常是前者，解码就能拿到 flag 或下一层线索。

**小白问：Base64 是加密吗？**
> 不是！Base64 是最常见的编码，任何人都能瞬间解码。有人误以为"Base64 看起来乱糟糟的=加密了"，这是错的。CTF 里看到 Base64，直接解码即可。

## 16.2 Base64：最常见的编码

### 16.2.1 原理（够用即可）

Base64 把任意二进制数据（每 3 个字节 = 24 位）拆成 4 组 6 位，每组映射到一个字符（A-Z, a-z, 0-9, +, /）。如果不足 3 字节，用 `=` 补齐。

**识别特征**：
- 字符集：大小写字母 + 数字 + `+` `/`，结尾可能有 `=`（1 或 2 个）
- 长度通常是 4 的倍数

例子：

```
ZmxhZ3s=  → 解码 → flag{
SGVsbG8=  → 解码 → Hello
```

### 16.2.2 解码方法

**CyberChef**（最快）：打开网页 → 左侧搜 "Base64 Decode" → 拖入 → 输入字符串。

**Python**：

```python
import base64
s = "ZmxhZ3sidGhpcyBpcyBhIHRlc3R9"
print(base64.b64decode(s).decode())
# 输出：flag{this is a test}
```

**Linux 命令行**：

```bash
echo "ZmxhZ3s=" | base64 -d
```

### 16.2.3 变体与坑

- **Base64URL**：把 `+` → `-`、`/` → `_`，去掉 `=`（JWT 里用，见第 12 章）
- **多层嵌套**：解一层 Base64 又是 Base64，反复解（写个循环脚本更快）
- **自定义表**：出题人换掉字符表（如把标准表倒序），需要看题找规律

## 16.3 Hex（十六进制）编码

把每个字节用两个十六进制字符表示（0-9, a-f）。

**识别特征**：只有 `0-9a-fA-F`，长度通常是偶数，有时带 `0x` 前缀或空格分隔。

```
666c6167  → 解码 → flag
66 6c 61 67 7b 7d  → flag{}
```

**解码**：

```python
bytes.fromhex("666c6167").decode()
# 或
codecs.decode("666c6167", "hex")
```

```bash
echo "666c6167" | xxd -r -p
```

---

## 16.4 URL 编码（百分号编码）

把特殊字符用 `%XX`（XX 是 ASCII 的十六进制）表示。第 4 章讲过，这里系统梳理。

**识别特征**：大量 `%XX`，如 `%20`（空格）、`%3A`（冒号）。

```
flag%7Bhello%7D  → flag{hello}
```

```python
from urllib.parse import unquote
print(unquote("flag%7Bhello%7D"))
```

---

## 16.5 Morse 码（摩斯密码）

用点（`.`）和划（`-`）表示字符。CTF 里常以各种伪装出现：声音（滴答声）、灯光闪烁、`.` `-` 的字符串。

**识别特征**：只有 `.`、`-`、空格（字符间用空格，单词间用 `/`）。

```
.... . .-.. .-.. ---   → HELLO
```

**解码**：用 CyberChef 的 "Morse Code Decode"，或查摩斯码表。

**CTF 花式**：音频里藏摩斯（听滴答声）、图片里藏摩斯（长短线段）——第 17 章会提到。

---

## 16.6 其他常见编码/密码

| 名称 | 特征 | 说明 |
|------|------|------|
| **ASCII 十进制** | 一串数字如 `102 108 97 103` | 每个数是字符的 ASCII 码，`102=f` |
| **Binary 二进制** | 只有 0 和 1，常 8 位一组 | `01100110` = `f` |
| **ROT13** | 字母后移 13 位 | `synt` → `flag`；易识别（ Caesar 变体） |
| **Atbash** | 字母表倒序 | a↔z, b↔y |
| **Unicode 转义** | `\uXXXX` | 如 `\u0066` = f |
| **Quoted-printable** | `=XX` | 邮件编码 |
| **XXencode/UUencode** | 特殊字符集 | 老式编码，CyberChef 都能解 |

**ROT13 例子**：`synt{...}` 看着像乱码，ROT13 后变 `flag{...}`——CTF 里的经典送分题。

## 16.7 多层嵌套：剥洋葱

CTF 的编码题常把多种编码**层层嵌套**：Base64 → Hex → ROT13 → flag。解题像剥洋葱，一层层解。

**手工慢，脚本快**。写一个自动尝试常见编码的脚本：

```python
import base64, codecs
from urllib.parse import unquote

s = open("data.txt").read().strip()

for i in range(10):
    print(f"第 {i+1} 层: {s[:80]}")
    if "flag{" in s:
        print("找到 flag:", s)
        break
    try:
        # 依次尝试各种解码
        if all(c in "0123456789abcdefABCDEF" for c in s) and len(s)%2==0:
            s = bytes.fromhex(s).decode(errors="ignore")
        elif "=" in s or len(s)%4==0:
            s = base64.b64decode(s).decode(errors="ignore")
        elif "%" in s:
            s = unquote(s)
        else:
            break
    except Exception:
        break
```

**更省事**：CyberChef 的 "Magic" 功能能自动检测并尝试解码，Misc 神器。

## 16.8 解题流程

```
① 观察字符串特征：什么字符集？什么长度？有没有 =/%/\u/.- ？
② 判断编码类型：Base64 / Hex / URL / Morse / 其他
③ 解码：CyberChef 或 Python
④ 看结果：是 flag？还是下一层编码？还是提示文字？
⑤ 重复 ②–④ 直到拿到 flag
```

**经验之谈**：
- 结果里出现 `flag{` → 成功
- 结果是一句英文提示（如 "try again"）→ 可能是误导或需要继续深入
- 解出来还是乱字符 → 试别的编码，或考虑自定义表/加密

## 16.9 本章总结

| 编码 | 识别特征 | 解码方法 |
|------|---------|---------|
| 编码 vs 加密 | 编码无需密钥，加密需要 | 先判断类型 |
| Base64 | 大小写+数字+/+= | `base64.b64decode` / CyberChef |
| Hex | 0-9a-f，偶数长 | `bytes.fromhex` |
| URL | `%XX` | `urllib.parse.unquote` |
| Morse | `.` `-` `/` | CyberChef Morse Decode |
| ROT13 | 字母乱但格式像 | ROT13 变换 |
| 多层嵌套 | 解一层又一层 | 写循环脚本 / CyberChef Magic |
