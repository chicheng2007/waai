## 21.1 密码学在 CTF 里的定位

CTF 的 Crypto 方向通常数学性较强（数论、群论），门槛高。但 Misc 方向里的"密码题"通常是：

- 古典密码（凯撒、维吉尼亚） —— 靠观察和工具
- 简单哈希破解 —— 靠字典
- 编码 + 简单加密的组合 —— 靠第 16 章的解码 + 本章知识

**本章目标**：让你能应对这些"轻量密码题"，并理解 Web 里遇到的加密机制。想深入 Crypto 方向的读者，可在本教程基础上补数论。

**先复习**：第 16 章讲的编码（Base64/Hex）**不是加密**——无需密钥。本章讲的密码学**需要密钥**。这是根本区别。

## 21.2 古典密码

### 21.2.1 凯撒密码（Caesar）

**原理**：每个字母按字母表向后（或向前）移动固定位数（密钥 k）。

```
明文：HELLO，k=3
密文：KHOOR（H→K, E→H, L→O...）
```

**破解**：只有 26 种可能，暴力枚举所有偏移（ROT1–ROT25），看哪个结果有意义。ROT13（k=13）是最常见的特例（第 16 章提过）。

**工具**：CyberChef 的 "ROT13" / "Caesar Cipher"，或写脚本枚举 26 种。

```python
s = "KHOOR"
for k in range(26):
    dec = ''.join(chr((ord(c)-65-k)%26+65) if c.isupper() else c for c in s)
    print(k, dec)
```

### 21.2.2 维吉尼亚密码（Vigenère）

**原理**：用一个关键词作为"移动的凯撒"——每个字母根据关键词对应字母的偏移来移动。

```
明文：ATTACK，密钥：LEMON
密文：LXFOPV
```

**破解**：比凯撒难（26^n 种），但可用**卡西斯基试验**（找重复序列的间距推密钥长度）+ 频率分析。CTF 里通常给提示或密钥较短，可用工具（CyberChef 的 Vigenère Decode + 已知密钥）解决。

### 21.2.3 替换密码（Substitution）

**原理**：每个字母被固定替换成另一个字母（随机映射）。

**破解**：用**词频分析**——英文里 E/T/A/O 出现频率最高，通过统计密文字母频率推测映射。 CyberChef 有替换密码工具，配合在线"单表替换破解器"（quipqiup.com）能自动破解。

### 21.2.4 其他古典密码

| 密码 | 特征 | 破解 |
|------|------|------|
| Atbash | 字母表倒序（a↔z） | 直接反转映射 |
| 栅栏密码 | 字母按行/列重排 | 尝试不同栏数 |
| 培根密码 | 用 A/B 表示二进制 | 按 5 位一组解码 |
| 摩斯 | . 和 - | 第 16 章 |

## 21.3 哈希函数

### 21.3.1 什么是哈希

哈希（Hash）把任意长度的数据映射成固定长度的"指纹"：

```
MD5("hello") = 5d41402abc4b2a76b9719d911017c592
SHA256("hello") = 2cf24dba5fb0a30e...
```

**特性**：
- **单向性**：从哈希算不回原文（理论上）
- **确定性**：同样输入永远同样哈希
- **抗碰撞**：不同输入很难得到相同哈希

**CTF 里的哈希题**：给你一个 MD5/SHA 值，让你找出原文（通常是常见词/弱密码）——**用字典爆破**。

### 21.3.2 常见哈希与破解

| 哈希 | 长度 | 破解工具 |
|------|------|---------|
| MD5 | 32 位十六进制 | hashcat / John / 在线 CMD5 |
| SHA1 | 40 位 | hashcat |
| SHA256 | 64 位 | hashcat |
| NTLM | 32 位 | hashcat / John |

```bash
# hashcat 爆破 MD5（类型 0）
hashcat -m 0 hash.txt rockyou.txt

# 判断哈希类型用 hash-identifier
```

**CTF 套路**：flag 的 MD5 给出来，让你猜原文——如果 flag 内容是常见词/简单句，字典能爆出来；否则需要其他线索。

### 21.3.3 加盐（Salt）

为了防止字典爆破，实际系统会在密码后加一段随机"盐"再哈希。这样相同密码的哈希不同，彩虹表失效。CTF 里若给出盐值，爆破时要拼上盐。

## 21.4 RSA 入门

RSA 是最著名的**非对称加密**（公钥加密、私钥解密）。CTF Crypto 方向的核心考点。这里讲最基础的原理和常见攻击。

### 21.4.1 基本原理（够用版）

- **密钥生成**：选两个大质数 p、q → n = p×q → 算出公钥 (e, n) 和私钥 (d, n)
- **加密**：密文 c = m^e mod n（m 是明文）
- **解密**：明文 m = c^d mod n

**安全性基础**：从 n 很难分解出 p、q（大数分解困难）。如果能分解 n，就能算出私钥——很多 CTF RSA 题就是"想办法分解 n"。

### 21.4.2 常见攻击（CTF 高频）

| 攻击 | 条件 | 思路 |
|------|------|------|
| **小 e / 小 m** | e 很小（如 e=3），m^e < n | 直接对 c 开 e 次方（无模运算） |
| **小 n / n 可分解** | n 较小或用了已知质数 | 用 factordb.com 或 yafu 分解 n → 算私钥 |
| **共模攻击** | 两个密文用同一 n、不同 e 加密同一 m | 用扩展欧几里得算法恢复 m |
| **低指数广播** | 同一消息用不同 n、相同 e 发给多人 | 中国剩余定理 |
| **Wiener 攻击** | d 很小 | 连分数展开 |

**基础工具**：

```python
# 已知 p、q、e、c，解密 RSA
n = p * q
phi = (p-1) * (q-1)
d = pow(e, -1, phi)   # 求 e 的模逆元（Python 3.8+）
m = pow(c, d, n)
# 把 m 转成字节，得到明文
```

**小白问：这些攻击需要很深的数学吗？**
> 理解原理需要数论（模运算、欧拉函数、扩展欧几里得），但 CTF 解题往往有现成脚本和工具（如 RsaCtfTool）。入门阶段：理解"分解 n → 得私钥 → 解密"这条主线，会跑工具，就够了。深入后再补数学。

## 21.5 对称加密简介（AES/DES）

**对称加密**：加密解密用同一个密钥。CTF 里偶尔出现。

| 算法 | 特征 | 攻击 |
|------|------|------|
| AES | 现代标准，密钥 128/192/256 位 | 通常无法直接破，找密钥泄露 |
| DES | 老算法，56 位密钥 | 可被暴力破解 |
| XOR | 异或，最简单 | 单字节 XOR 可频率分析 |

**XOR 题**：CTF Misc 常见，用 Python 单字节爆破：

```python
data = bytes.fromhex("...密文...")
for key in range(256):
    dec = bytes(b ^ key for b in data)
    if b"flag" in dec:
        print(key, dec)
```

## 21.6 密码题通用思路

```
① 判断类型：是编码（第16章）还是密码（本章）？
   - Base64/Hex/URL → 编码，直接解
   - 字母被替换/位移 → 古典密码
   - 32/40/64 位十六进制 → 哈希，爆破
   - 给了 n/e/c 等参数 → RSA
② 收集线索：题目提示、字符集、长度、已知明文
③ 选择工具：CyberChef / hashcat / RsaCtfTool / 脚本
④ 破解 → 得到 flag 或下一层
```

**关键**：**先分类，再下手**。很多新手把 Base64 当加密去"破解"，白费力气——先判断类型，效率高一倍。

## 21.6 深度拓展：哈希攻击与 RSA 实战细节

21.1–21.6 覆盖了密码学基础。这一节补充实战中高频的哈希攻击和 RSA 细节。

### 21.6.1 哈希破解的三种方式

| 方式 | 原理 | 适用 |
|------|------|------|
| **字典攻击** | 用常见密码列表逐个哈希比对 | 弱密码，成功率最高 |
| **暴力破解** | 枚举所有可能字符组合 | 短密码（≤6 位） |
| **彩虹表** | 预计算大量明文→哈希的映射表，查表 | 无盐哈希，速度快 |

**hashcat 实战进阶**：

```bash
# 字典 + 规则（变形：加大小写、加数字后缀）
hashcat -m 0 hash.txt rockyou.txt -r rules/best64.rule

# 掩码攻击（已知密码格式，如 3 位数字+2 位字母）
hashcat -m 0 hash.txt -a 3 '?d?d?d?l?l'

# 组合攻击（两个字典拼接）
hashcat -m 0 hash.txt -a 1 dict1.txt dict2.txt
```

**掩码符号**：`?l` 小写字母、`?u` 大写、`?d` 数字、`?s` 特殊符号、`?a` 所有可打印字符。

### 21.6.2 如何识别哈希类型

拿到一串哈希，先判断类型再选攻击方式：

| 特征 | 可能类型 |
|------|---------|
| 32 位十六进制 | MD5 / NTLM |
| 40 位十六进制 | SHA1 |
| 64 位十六进制 | SHA256 |
| 以 `$2a$`/`$2b$` 开头 | bcrypt |
| 以 `$1$` 开头 | MD5 crypt |
| 以 `$6$` 开头 | SHA512 crypt |
| 以 `$argon2` 开头 | Argon2 |

工具：`hash-identifier` 或在线的哈希识别网站。

### 21.6.3 加盐哈希的破解

加盐（salt）让同样的密码产生不同哈希，彩虹表失效。但如果**盐值已知**（CTF 里常在源码/配置里给出），仍可字典攻击：

```bash
# hashcat 处理 salt|hash 格式（具体格式看 hash 类型）
hashcat -m 110 hash.txt rockyou.txt   # 例：salt:hash 格式
```

**CTF 套路**：给一个带盐哈希 + 盐值提示（如"盐是用户名"），构造 `密码+盐` 或 `盐+密码` 的字典再爆破。要尝试盐在密码前面还是后面。

### 21.6.4 RSA 的数学基础（够用版）

理解这几个概念就能应付大部分 CTF RSA 题：

**模运算**：`a mod n` 是 a 除以 n 的余数。RSA 的所有运算都在模 n 下进行。

**欧拉函数 φ(n)**：小于 n 且与 n 互质的正整数个数。当 n = p×q（p、q 是质数）时，φ(n) = (p-1)(q-1)。

**模逆元**：如果 `e × d ≡ 1 (mod φ(n))`，则 d 是 e 关于 φ(n) 的模逆元。RSA 里 d 就是私钥指数。

**加解密**：
```
公钥：(e, n)    私钥：(d, n)
加密：c = m^e mod n
解密：m = c^d mod n
```

**为什么能解密**：因为 `e×d ≡ 1 (mod φ(n))`，根据欧拉定理，`m^(e×d) ≡ m (mod n)`。

**安全性**：从 n 反推 p、q（大数分解）很困难。但如果你能分解 n，就能算出 φ(n)，进而算出 d，破解私钥。

### 21.6.5 RSA 常见攻击的实操

**攻击一：n 可分解（小 n 或已知因子）**

```bash
# 用 factordb.com 查 n 的分解（在线）
# 或用 yafu / msieve 本地分解
```

```python
# 分解出 p、q 后解密
p, q = 已知因子
n = p * q
phi = (p-1)*(q-1)
d = pow(e, -1, phi)   # Python 3.8+ 求模逆
m = pow(c, d, n)
flag = m.to_bytes((m.bit_length()+7)//8, 'big')
print(flag)
```

**攻击二：小 e + 小 m（低指数攻击）**

如果 e=3 且 `m^3 < n`（明文很小），那么 `c = m^3` 没有经过模运算，直接对 c 开三次方：

```python
import gmpy2
m, exact = gmpy2.iroot(c, 3)   # 整数开方
if exact:
    print(m.to_bytes((m.bit_length()+7)//8, 'big'))
```

**攻击三：共模攻击**

两条密文用同一个 n、不同的 e（e1、e2 互质）加密同一明文 m：

```python
# 扩展欧几里得：e1*s + e2*t = 1
s, t = egcd(e1, e2)
m = (pow(c1, s, n) * pow(c2, t, n)) % n
```

**攻击四：Wiener 攻击（d 很小）**

当 d < n^0.25 时，用连分数展开 e/n 能恢复 d。用 RsaCtfTool 一键处理。

**万能工具**：

```bash
# RsaCtfTool：自动尝试各种攻击
python3 RsaCtfTool.py --publickey pub.pem --uncipherfile cipher.bin
python3 RsaCtfTool.py -n <n> -e <e> --uncipher <c>
```

### 21.6.6 Python 密码学编程基础

```python
import hashlib, hmac

# 常见哈希
hashlib.md5(b"hello").hexdigest()
hashlib.sha256(b"hello").hexdigest()

# HMAC（带密钥的哈希）
hmac.new(b"secret", b"message", hashlib.sha256).hexdigest()

# 异或
a = b"flag{abc}"
key = 0x20
xor = bytes(b ^ key for b in a)

# Base64（虽然不是加密，但常配合）
import base64
base64.b64encode(b"hello")
base64.b64decode("aGVsbG8=")
```

**字节与字符串的转换**（CTF 密码题的高频坑）：

```python
s = "hello"
b = s.encode()              # str → bytes
s2 = b.decode()             # bytes → str
n = int.from_bytes(b, 'big')    # bytes → 整数（RSA 里常用）
b2 = n.to_bytes((n.bit_length()+7)//8, 'big')  # 整数 → bytes
```

### 21.6.7 密码题的思维模式

```
1. 分类：编码 / 古典密码 / 哈希 / 现代加密 / RSA？
2. 收集：字符集、长度、已知明文、题目提示、附件
3. 选择工具：CyberChef（编码+古典）/ hashcat（哈希）/ RsaCtfTool（RSA）
4. 尝试：从最简单的可能性开始（ROT13、弱密码、小 e）
5. 组合：解出来是下一层？还是另一个密码的输入？
```

**记住**：CTF 的密码题很少考"真正的密码学破译"（那需要超算），大多考"实现缺陷"（弱密钥、参数选错、经典攻击）。理解原理 + 会用工具 = 能解大部分题。
