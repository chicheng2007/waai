# 第 2 章 环境搭建与 CTF 工具箱

## 本章目标

读完这一章，你将能够：

- 选择并搭建适合自己的 CTF 学习环境（Kali / Ubuntu / WSL / 虚拟机）
- 配置浏览器与代理，为 Web 题做好准备
- 认识 CTF 常用工具箱，知道"什么题用什么工具"
- 搭建第一个本地靶场（DVWA），跑通"出题 → 解题 → 提交 flag"的完整流程

> 这一章是"磨刀"章。不追求一次配齐所有工具——先把基础环境跑通，工具用到时再装。装备是慢慢积累的。

---

## 2.1 三种环境方案，选一个

CTF 学习需要什么样的电脑环境？核心需求是：**能跑浏览器、能装工具、能起靶场、不污染日常系统**。有三种主流方案。

### 2.1.1 方案 A：虚拟机（推荐新手）

用 VMware Workstation（Windows/macOS 收费，个人学习有免费版）或 VirtualBox（免费开源）在你的电脑上"虚拟"出一台电脑，在里面装 Kali Linux 或 Ubuntu。

**优点**：
- 完全隔离：靶场和工具都在虚拟机里，弄坏了重装即可，不影响你的日常系统
- 快照功能：可以给干净系统拍"快照"，打题打乱了一键还原
-最接近真实的安全工作环境

**缺点**：
- 吃内存和 CPU（建议至少 8GB 内存，分 4GB 给虚拟机）
- 需要一定的配置时间

**小白问：Kali 和 Ubuntu 选哪个？**
> Kali Linux 是安全专用发行版，预装了数百个渗透测试工具（Burp、sqlmap、nmap、Wireshark……），开箱即用。**新手首选 Kali**。Ubuntu 更通用，适合你想兼顾开发/AI 学习时用。本教程以 Kali 为主，命令在 Ubuntu 上也通用。

### 2.1.2 方案 B：WSL（Windows 用户轻量方案）

WSL（Windows Subsystem for Linux）让 Windows 直接运行 Linux 命令行，不用虚拟机。

**优点**：轻量、启动快、与 Windows 文件系统互通
**缺点**：图形界面工具（Burp、浏览器）配置稍麻烦；部分需要内核级操作（如某些 PWN 题）支持有限

**适合**：主要做 Web/Misc、不想开虚拟机的 Windows 用户。本套的 Web/Misc 方向用 WSL 完全够。

### 2.1.3 方案 C：直接用本机 Linux

如果你本来就装了 Linux 当主力系统，直接用即可。但要注意：靶场服务只监听本地，别把有漏洞的服务暴露到公网。

### 决策表

| 你的情况 | 推荐方案 |
|---------|---------|
| Windows，内存 ≥ 8GB，想完整学习 | **虚拟机 + Kali** |
| Windows，内存小 / 想轻便 | WSL + Windows 浏览器 |
| macOS | VirtualBox + Kali，或 macOS 原生 + Homebrew 装工具 |
| 已是 Linux 用户 | 本机直接干，注意隔离 |

**本教程后续默认你有一个 Kali/Ubuntu 环境**（虚拟机或 WSL 均可），命令以 Linux 为主；Windows/macOS 差异会特别标注。

## 2.2 第一步：装好 Kali 并做基础配置

以虚拟机装 Kali 为例（VirtualBox/VMware 步骤类似）：

1. 到 Kali 官网（kali.org）下载对应虚拟机镜像（VMware/VirtualBox 版是现成的 OVA/OVF，导入即用）
2. 虚拟机设置：内存 ≥ 4096MB，处理器 ≥ 2 核，网络选 NAT 或桥接
3. 启动，默认账号 `kali` / 密码 `kali`
4. 更新系统：`sudo apt update && sudo apt full-upgrade -y`

几个基础配置：

```bash
# 安装常用小工具
sudo apt install -y vim curl wget git python3-pip

# 切换中文输入法（可选）
sudo apt install -y fcitx fcitx-googlepinyin

# 查看当前 IP（后面靶场要用）
ip addr
```

**常见坑**：
- 虚拟机连不上网：检查网络模式，NAT 一般可用；桥接需要选对物理网卡
- apt 更新慢：换国内源（清华/中科大镜像），具体方法搜"Kali 换源"
- 账号密码：Kali 默认 kali/kali，装完后建议改密码

## 2.3 浏览器与代理：Web 题的"眼睛和手"

Web 题的核心操作是**观察和改写 HTTP 请求**。你需要两样东西：一个能发自定义请求的浏览器配置，一个抓包工具。

### 2.3.1 浏览器

- **Firefox**：Kali 自带，扩展生态好，CTF 首选
- **Chrome**：也可以，配合 SwitchyOmega 扩展做代理切换

推荐安装的 Firefox 扩展：

| 扩展 | 作用 |
|------|------|
| **FoxyProxy** | 一键切换代理（把流量导到 Burp） |
| **HackBar**（或浏览器开发者工具） | 手动构造和发送 HTTP 请求 |
| **Cookie-Editor** | 查看/修改 Cookie |

### 2.3.2 Burp Suite：Web 安全的核心工具

Burp Suite 是 Web 题的"瑞士军刀"——它能拦截、查看、改写浏览器和目标网站之间的每一个 HTTP 请求。

**安装**：Kali 自带 Burp Suite Community（社区版）。免费版对 CTF 完全够用（专业版的扫描器在练习阶段非必需）。

**初次配置三步走**：

1. **启动 Burp** → 打开 Proxy 模块 → 确认 Proxy settings 里监听 `127.0.0.1:8080`
2. **浏览器配代理**：FoxyProxy 添加一个代理，地址 `127.0.0.1`，端口 `8080`，启用
3. **装 Burp 的 CA 证书**：浏览器访问 `http://burp`，下载证书并导入浏览器信任，否则 HTTPS 网站会报证书错误

完成后，你在浏览器里的每一次点击，请求都会先经过 Burp，可以拦截、修改、重放。第 23 章会深入讲 Burp 的高级用法。

**小白问：为什么要抓包？**
> 因为浏览器发出的请求你"看不见"——表单提交时偷偷加了什么参数、Cookie 里藏了什么、服务器返回了什么头，这些关键线索都在 HTTP 报文里。抓包就是把这些"暗线"变成"明线"。第 4 章会详细讲 HTTP。

## 2.4 CTF 工具箱全景

工具很多，新手容易陷入"收集癖"——装了一堆却不会用。记住原则：**用到再装，边用边学**。下面是按场景分类的工具地图，先混个脸熟。

### 2.4.1 Web 方向工具

| 工具 | 用途 | 对应章节 |
|------|------|---------|
| **Burp Suite** | 抓包、改包、重放、爆破 | 第 23 章 |
| **sqlmap** | SQL 注入自动化检测与利用 | 第 6、25 章 |
| **nmap** | 端口/服务扫描 | 第 25 章 |
| **dirsearch / gobuster** | 目录与文件爆破 | 第 5、25 章 |
| **hydra** | 密码爆破（HTTP/SSH/FTP 等） | 第 25 章 |
| **Python + requests** | 自己写脚本发包 | 第 24 章 |

### 2.4.2 Misc 方向工具

| 工具 | 用途 | 对应章节 |
|------|------|---------|
| **Stegsolve** | 图片隐写分析（LSB、通道） | 第 17 章 |
| **zsteg / steghide** | PNG/BMP 隐写提取 | 第 17 章 |
| **binwalk** | 文件分离、固件分析 | 第 18 章 |
| **foremost** | 按文件头 carving 提取文件 | 第 18 章 |
| **Wireshark** | 流量包分析 | 第 19 章 |
| **tshark** | Wireshark 命令行版，适合脚本化 | 第 19 章 |
| **Volatility** | 内存取证 | 第 22 章 |
| **openssl / hashcat** | 密码学计算与哈希破解 | 第 21 章 |

### 2.4.3 通用工具

| 工具 | 用途 |
|------|------|
| **Kali 自带字典** `/usr/share/wordlists/` | 爆破用的密码/目录字典 |
| **CyberChef**（在线工具） | 编码解码的"瑞士军刀"，Misc 神器 |
| **Python** | 万能胶水，写解题脚本 |

**小白问：CyberChef 是什么？**
> 一个网页版的"数据处理流水线"工具，把 Base64 解码、Hex 转换、字符串反转等操作像搭积木一样组合起来。Misc 题里做编码转换极其方便，浏览器打开就能用（搜 "CyberChef"）。

## 2.5 搭建第一个靶场：DVWA

理论讲完，动手搭一个真靶场，跑通完整流程。我们选 DVWA（Damn Vulnerable Web Application）——最经典的 Web 漏洞练习平台。

### 2.5.1 用 Docker 一键搭建（最简单）

如果你装了 Docker：

```bash
# 拉取并运行 DVWA 镜像
docker run -d -p 8081:80 vulnerables/web-dvwa

# 浏览器访问
# http://127.0.0.1:8081
```

第一次访问会提示初始化数据库，点页面上的 "Create / Reset Database" 即可。默认账号 `admin` / 密码 `password`。

### 2.5.2 手动搭建（理解原理）

不用 Docker 的话，需要 LAMP 环境（Linux + Apache + MySQL + PHP）：

```bash
# 安装 LAMP
sudo apt install -y apache2 mysql-server php php-mysql

# 下载 DVWA
cd /var/www/html
sudo git clone https://github.com/digininja/DVWA.git dvwa

# 配置数据库
cd dvwa/config
sudo cp config.inc.php.dist config.inc.php
# 编辑 config.inc.php，设置数据库账号密码（默认 root，密码空）

# 启动服务
sudo service apache2 start
sudo service mysql start
```

浏览器访问 `http://127.0.0.1/dvwa`，同样点初始化数据库。

### 2.5.3 跑通第一次"解题"

DVWA 里有个最简单的漏洞练习，我们走一遍流程感受一下：

1. 登录后，左侧 Security 设为 **Low**（低难度）
2. 点 "SQL Injection" 菜单
3. 在输入框输入 `1' or '1'='1`，点 Submit
4. 观察：页面列出了**所有用户**，而不是只查一个——这就是 SQL 注入

flag 在哪？DVWA 不是 flag 制，但你已经完成了第一次"利用漏洞让系统返回非预期数据"。这就是 Web 题的本质。

（这条 payload 的原理会在第 6 章讲透。现在你只需要感受"输入特殊内容→系统行为异常"这个感觉。）

### 2.5.4 靶场使用守则

- **只用本地地址**（127.0.0.1 / localhost）访问靶场，不要对外暴露
- 打乱了就重置数据库（DVWA 有按钮），或拍快照还原
- 靶场是给你"搞破坏"的，尽情试，但记住它只在你的隔离环境里

## 2.6 环境检查清单

开始前，确认你已具备：

- [ ] 一个可用的 Kali/Ubuntu 环境（虚拟机或 WSL）
- [ ] 能联网，apt 能装包
- [ ] Firefox + FoxyProxy 配置好
- [ ] Burp Suite 能启动，浏览器流量能经过它（访问 http://burp 测试）
- [ ] DVWA 能打开，能登录
- [ ] Python3 可用（`python3 --version`）

逐项打勾后，你就有了完整的 CTF 学习环境。工具不全没关系，用到时再装。

## 2.7 本章总结

| 知识点 | 内容 |
|--------|------|
| 三种环境方案 | 虚拟机（推荐）、WSL、本机 Linux；核心是隔离 |
| 首选系统 | Kali Linux（安全专用，工具齐全） |
| Web 标配 | Firefox + FoxyProxy + Burp Suite（抓包改包） |
| 工具箱原则 | 按场景分类，用到再装，不搞收集癖 |
| 第一个靶场 | Docker 一行命令起 DVWA，跑通"输入 payload → 系统异常" |
| 合规 | 靶场只用本地地址，隔离环境内随便练 |

## 本章练习

1. 按你的电脑情况，选择并搭建一种环境（虚拟机 / WSL）。
2. 装好 Firefox + FoxyProxy，把浏览器流量导到 Burp，确认能抓到包。
3. 用 Docker 或手动方式搭起 DVWA，登录并把 Security 设为 Low。
4. 在 SQL Injection 页面输入 `1' or '1'='1`，观察结果，记录你的感受。
5. 浏览 Kali 的 `/usr/share/wordlists/` 目录，看看有哪些字典（第 25 章会用到）。
6. 打开 CyberChef 网页，随便输一段 Base64 字符串试试解码。
