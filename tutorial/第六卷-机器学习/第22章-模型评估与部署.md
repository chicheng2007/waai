## 22.1 交叉验证

### 22.1.1 为什么需要交叉验证

单次划分训练集/测试集有随机性——这次划分恰好得到好成绩，换个划分可能就差了。交叉验证让评估更可靠。

### 22.1.2 K 折交叉验证

```python
from sklearn.model_selection import cross_val_score
from sklearn.ensemble import RandomForestClassifier
from sklearn.datasets import load_iris

iris = load_iris()
X, y = iris.data, iris.target

model = RandomForestClassifier(random_state=42)

# 5 折交叉验证
scores = cross_val_score(model, X, y, cv=5)
print("每折得分:", scores)
print(f"平均得分: {scores.mean():.3f} (+/- {scores.std():.3f})")
```

**原理**：把数据分成 5 份，轮流用 4 份训练、1 份测试，得到 5 个分数，取平均。这样每个样本都当过测试集，评估更稳健。

## 22.2 超参数调优

### 22.2.1 什么是超参数

超参数是模型训练前设定的参数（不是学出来的），比如：

- 随机森林的树的数量 `n_estimators`
- 树的最大深度 `max_depth`
- 学习率

超参数选得好不好，直接影响模型效果。

### 22.2.2 网格搜索（Grid Search）

```python
from sklearn.model_selection import GridSearchCV
from sklearn.ensemble import RandomForestClassifier

# 定义要尝试的参数组合
param_grid = {
    "n_estimators": [50, 100, 200],
    "max_depth": [None, 5, 10],
    "min_samples_split": [2, 5, 10],
}

model = RandomForestClassifier(random_state=42)

# 网格搜索 + 5折交叉验证
grid_search = GridSearchCV(model, param_grid, cv=5, scoring="accuracy", n_jobs=-1)
grid_search.fit(X, y)

print("最佳参数:", grid_search.best_params_)
print("最佳得分:", grid_search.best_score_)

# 用最佳模型预测
best_model = grid_search.best_estimator_
```

网格搜索会尝试所有参数组合（这里是 3×3×3=27 种），每种做 5 折交叉验证，找出最优组合。`n_jobs=-1` 表示用所有 CPU 核心并行加速。

### 22.2.3 随机搜索（Random Search）

参数组合太多时，网格搜索很慢。随机搜索随机采样组合，效率更高：

```python
from sklearn.model_selection import RandomizedSearchCV

random_search = RandomizedSearchCV(
    model, param_grid, n_iter=20, cv=5, random_state=42, n_jobs=-1
)
random_search.fit(X, y)
print("最佳参数:", random_search.best_params_)
```

## 22.3 深入评估指标

### 22.3.1 ROC 曲线与 AUC

**ROC 曲线**：横轴是误报率（FPR），纵轴是召回率（TPR），展示模型在不同阈值下的表现。

**AUC**：ROC 曲线下的面积，0.5 是随机猜测，1.0 是完美模型。

```python
from sklearn.metrics import roc_curve, auc
import matplotlib.pyplot as plt

# 用预测概率（而不是类别）
y_scores = best_model.predict_proba(X_test)[:, 1]

fpr, tpr, thresholds = roc_curve(y_test, y_scores)
roc_auc = auc(fpr, tpr)

plt.figure()
plt.plot(fpr, tpr, label=f"ROC曲线 (AUC={roc_auc:.3f})")
plt.plot([0, 1], [0, 1], "k--", label="随机猜测")
plt.xlabel("误报率 (FPR)")
plt.ylabel("召回率 (TPR)")
plt.title("ROC 曲线")
plt.legend()
plt.show()
```

> **安全场景**：AUC 能衡量模型在"误报"和"漏报"之间的整体权衡能力，比单一准确率更全面。

### 22.3.2 PR 曲线（不平衡数据更可靠）

当正负样本极度不平衡时（安全场景常见），PR 曲线比 ROC 更能反映真实性能：

```python
from sklearn.metrics import precision_recall_curve, average_precision_score

precision, recall, _ = precision_recall_curve(y_test, y_scores)
ap = average_precision_score(y_test, y_scores)

plt.figure()
plt.plot(recall, precision, label=f"PR曲线 (AP={ap:.3f})")
plt.xlabel("召回率")
plt.ylabel("精确率")
plt.title("Precision-Recall 曲线")
plt.legend()
plt.show()
```

### 22.3.3 分类报告解读

```python
from sklearn.metrics import classification_report
print(classification_report(y_test, predictions, target_names=["正常", "恶意"]))
```

输出包含：

- **precision（精确率）**：预测为恶意的有多少真恶意
- **recall（召回率）**：所有恶意的抓到多少
- **f1-score**：两者的调和平均
- **support**：该类样本数

> **安全提示**：永远不要只看 accuracy！特别是恶意样本占比很低时，务必看 precision、recall 和 PR 曲线。

## 22.4 模型保存与加载

训练好的模型要保存下来，下次直接用，不用重新训练：

```python
import joblib

# 保存模型
joblib.dump(best_model, "malware_detector.pkl")

# 加载模型
loaded_model = joblib.load("malware_detector.pkl")

# 使用
prediction = loaded_model.predict(X_new)
```

也可以保存为 ONNX 格式（跨平台部署用），初学阶段 joblib 够用。

## 22.5 部署：用 FastAPI 做模型服务

把模型包装成一个 HTTP API，让其他程序（或前端）能调用：

### 22.5.1 安装 FastAPI

```bash
pip install fastapi uvicorn
```

### 22.5.2 编写 API 服务

```python
# app.py
from fastapi import FastAPI
from pydantic import BaseModel
import joblib
import numpy as np

# 加载模型
model = joblib.load("malware_detector.pkl")

app = FastAPI(title="恶意软件检测 API")

# 定义请求数据格式
class FileFeatures(BaseModel):
    file_size: float
    entropy: float
    api_calls: int
    packed: int
    signed: int

@app.post("/detect")
def detect(features: FileFeatures):
    """检测文件是否恶意"""
    X = np.array([[
        features.file_size,
        features.entropy,
        features.api_calls,
        features.packed,
        features.signed,
    ]])
    
    prediction = model.predict(X)[0]
    probability = model.predict_proba(X)[0][1]
    
    return {
        "is_malicious": bool(prediction),
        "malicious_probability": round(float(probability), 4),
        "verdict": "恶意" if prediction == 1 else "正常",
    }

@app.get("/")
def home():
    return {"message": "恶意软件检测 API 运行中"}
```

### 22.5.3 启动服务

```bash
uvicorn app:app --reload --host 0.0.0.0 --port 8000
```

访问 `http://localhost:8000/docs` 可以看到自动生成的 API 文档，还能直接在页面上测试。

### 22.5.4 调用 API

```python
import requests

response = requests.post("http://localhost:8000/detect", json={
    "file_size": 2000,
    "entropy": 7.6,
    "api_calls": 18,
    "packed": 1,
    "signed": 0,
})
print(response.json())
# {'is_malicious': True, 'malicious_probability': 0.95, 'verdict': '恶意'}
```

> **作品集提示**：把这个 API 服务 + 训练代码 + README 打包成 GitHub 仓库，就是一个完整的"AI 安全服务"项目，非常适合展示你的能力。

## 22.6 模型监控与迭代

部署不是终点。真实环境中：

1. **数据漂移**：攻击手法变化，模型会逐渐失效，需要定期用新数据重训
2. **反馈闭环**：把误报/漏报的案例收集起来，加入训练集
3. **A/B 测试**：新模型和旧模型对比，确认更好再上线
4. **日志记录**：记录每次预测，便于审计和改进
