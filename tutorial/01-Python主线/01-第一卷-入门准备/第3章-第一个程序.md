## 3.1 让程序说话：print() 详解

### 3.1.1 打印不同类型的内容

`print()` 是 Python 最常用的函数。它几乎什么都能打印：

```python
# 打印文字（字符串）
print("人工智能")

# 打印整数
print(2026)

# 打印小数（浮点数）
print(3.14159)

# 打印布尔值
print(True)
print(False)

# 做计算并打印结果
print(100 + 200)
print(10 / 3)
```

输出：

```
人工智能
2026
3.14159
True
False
300
3.3333333333333335
```

注意到 `10 / 3` 的结果是一长串小数吗？这是浮点数在计算机里的精度问题，后面会讲。

### 3.1.2 一次打印多个内容

用逗号 `,` 隔开，`print()` 可以一次打印多个东西，默认用空格隔开：

```python
name = "小明"
age = 18
print("我叫", name, "今年", age, "岁")
```

输出：

```
我叫 小明 今年 18 岁
```

你也可以用 `sep` 参数改变分隔符：

```python
print("苹果", "香蕉", "橘子", sep=" | ")
```

输出：

```
苹果 | 香蕉 | 橘子
```

### 3.1.3 控制结尾：end 参数

默认情况下，`print()` 打印完会自动换行。用 `end` 参数可以改变这个行为：

```python
print(" loading ", end="")
print("loading ", end="")
print("loading ", end="")
print("完成!")
```

输出：

```
 loading loading loading 完成!
```

这在制作进度条效果时很有用：

```python
import time

for i in range(1, 11):
    print(f"\r进度: {i*10}%", end="")
    time.sleep(0.2)
print("\n加载完成!")
```

> **小白问**：`\r` 和 `\n` 是什么？
>
> **答**：它们是转义字符。`\n` 表示换行，`\r` 表示回到行首（覆盖当前行）。`f"..."` 是 f-string，一种格式化字符串的写法，第 8 章会详解。现在你只需要照着敲，看到效果就行。

## 3.2 给代码做笔记：注释

### 3.2.1 为什么需要注释

代码是写给人看的，顺便让机器执行。好的注释能解释"这段代码在干什么、为什么这么写"，未来的你和同事都会感谢你。

### 3.2.2 单行注释

用 `#` 开头，`#` 后面的内容 Python 会忽略：

```python
# 这是一个注释，Python 不会执行它
print("Hello")  # 这也是注释，写在代码后面
```

### 3.2.3 多行注释

Python 没有专门的多行注释语法，但可以用三引号 `'''` 或 `"""` 包起来：

```python
"""
这是多行注释
可以写很多行
Python 不会执行三引号里的内容
"""
print("你好")
```

> **注意**：三引号实际上是用来定义"多行字符串"的，只有当它没有赋值给变量时，才被当作注释使用。我们会在第 8 章详细讲字符串。

### 3.2.4 注释的最佳实践

```python
# 好的注释：解释"为什么"
# 使用 0.001 而不是 0.01，是为了让梯度下降更稳定（经验值）
learning_rate = 0.001

# 不好的注释：重复代码已经表达的意思
# 把 learning_rate 设为 0.001
learning_rate = 0.001
```

记住：**注释解释"为什么"，代码本身说明"是什么"**。

## 3.3 让程序听你说话：input()

### 3.3.1 基本用法

`input()` 函数会暂停程序，等待用户输入内容，用户按回车后，输入的内容作为字符串返回：

```python
name = input("请输入你的名字: ")
print("你好,", name)
```

运行后，程序会显示 `请输入你的名字: `，等你输入并回车，才会继续执行。

### 3.3.2 input() 返回的永远是字符串

这是一个超级重要的点，新手经常在这里栽跟头：

```python
age = input("请输入你的年龄: ")
print(type(age))        # <class 'str'> —— 字符串类型
print(age + 1)          # 报错！字符串不能和数字相加
```

即使用户输入的是 `18`，`input()` 拿到的也是字符串 `"18"`，不是数字 `18`。

**解决方法：类型转换**

```python
age = input("请输入你的年龄: ")
age = int(age)          # 把字符串转换成整数
print(age + 1)          # 现在可以了
```

常用转换函数：

```python
int("18")       # 转成整数 18
float("3.14")   # 转成小数 3.14
str(123)        # 转成字符串 "123"
```

### 3.3.3 一个完整的小程序：BMI 计算器

```python
# BMI 计算器
# BMI = 体重(kg) / 身高(m) 的平方

height = float(input("请输入你的身高(米): "))
weight = float(input("请输入你的体重(千克): "))

bmi = weight / (height ** 2)   # ** 表示乘方

print("你的 BMI 是:", bmi)

if bmi < 18.5:
    print("偏瘦，多吃点!")
elif bmi < 24:
    print("正常，保持住!")
else:
    print("偏高，注意锻炼!")
```

> **注意**：这个程序里用到了 `if-elif-else`（条件判断）和 `**`（乘方运算），第 4、5 章会详细讲。现在你只需要运行它，感受一下程序"根据你的输入做出不同反应"的魔力。

## 3.4 变量：给数据起名字

### 3.4.1 什么是变量

变量就是**给数据贴的标签**，方便你后面引用它。

```python
name = "小明"    # 把 "小明" 这个值，存进名为 name 的变量
age = 18         # 把 18 这个数字，存进名为 age 的变量
print(name, age)
```

你可以把变量想象成一个**带名字的盒子**，数据放在盒子里，`name = "小明"` 就是"往叫 name 的盒子里放 '小明' 这个值"。

### 3.4.2 变量的命名规则

- 只能用字母、数字、下划线，不能以数字开头
- 不能是 Python 的关键字（如 `if`、`for`、`class` 等）
- 区分大小写（`Name` 和 `name` 是两个不同的变量）
- 建议用小写字母+下划线，如 `user_name`、`learning_rate`

```python
# 合法的变量名
name = "Tom"
user_age = 20
_num = 100

# 非法的变量名
2name = "Tom"      # 不能以数字开头
user-name = "Tom"  # 不能用连字符
if = 10            # 不能用关键字
```

### 3.4.3 变量可以"变身"

Python 是动态类型语言，同一个变量可以先存数字，后存文字：

```python
x = 10
print(x)      # 10
x = "hello"
print(x)      # hello
```

这很灵活，但也容易出错，所以实际开发中尽量保持一个变量的类型不变。

## 3.5 最简单的 AI 程序：一个"假装智能"的问答机器人

学了 `print()`、`input()`、变量和条件判断，我们已经可以写一个"看起来有点智能"的程序了：

```python
# 一个简单的规则式问答机器人
# 注意：这不是真正的 AI，只是 if-else 规则，但能让你体会"程序响应输入"的感觉

print("你好，我是小智，一个简易问答机器人。")
print("我可以回答一些问题，输入 '退出' 结束对话。")

while True:  # while True 表示无限循环，第 5 章会讲
    question = input("\n请问你想问什么? ")
    
    if question == "退出":
        print("再见!")
        break
    elif "你好" in question:
        print("你好呀! 很高兴和你聊天。")
    elif "天气" in question:
        print("今天天气不错，适合学习 Python!")
    elif "名字" in question:
        print("我叫小智，是你在 Python 世界里交到的第一个朋友。")
    else:
        print("这个问题我答不上来，但我还在学习中...")
```

运行它，和它聊几句。虽然它很"傻"（本质是几个 if-else），但你已经构造了一个能根据输入做不同反应的程序——这离"AI"的概念近了一小步。

> **思考**：这个机器人和真正的 AI（如 ChatGPT）有什么本质区别？
>
> **答**：这个机器人的规则是人手写死的，只能回答预设的问题。真正的 AI 是从海量数据中"学"出规则的，能回答从未见过的问题。但万变不离其宗——它们都是"接收输入 → 处理 → 给出输出"。你现在写的代码，已经包含了这个最核心的框架。

## 3.6 常见报错及解决方法

### 3.6.1 SyntaxError: invalid syntax（语法错误）

```python
print("Hello"    # 少了右括号
```

报错：

```
SyntaxError: '(' was never closed
```

**解决**：检查括号、引号是否成对。

### 3.6.2 NameError: name 'xxx' is not defined（名字未定义）

```python
print(age)   # 前面没有定义 age
```

报错：

```
NameError: name 'age' is not defined
```

**解决**：检查变量名是否拼错，是否在使用前赋值。

### 3.6.3 TypeError: can only concatenate str (not "int") to str（类型错误）

```python
age = input("年龄: ")   # 输入的是字符串
print("明年你" + age + 1 + "岁")  # 字符串和数字直接相加
```

**解决**：用 `int(age)` 或 `str()` 统一类型。

### 3.6.4 IndentationError: expected an indented block（缩进错误）

```python
if True:
print("hello")   # 没有缩进
```

**解决**：`if`、`for`、`while`、函数等代码块后的语句必须缩进（通常 4 个空格）。

> **看报错的诀窍**：报错信息最后一行才是真正的错误类型和原因，上面的内容显示了出错的文件和行号。先读最后一行，再定位到那一行代码。
