## 18.1 概率基础

### 18.1.1 什么是概率

概率是衡量"某件事发生可能性"的数字，取值在 0 到 1 之间。

- 0：不可能发生
- 1：必然发生
- 0.5：一半可能性

**古典概型**：如果所有结果等可能，概率 = 有利结果数 / 总结果数。

```python
# 掷骰子，掷出偶数的概率
total = 6
favorable = 3   # 2, 4, 6
print(favorable / total)   # 0.5
```

### 18.1.2 随机变量

随机变量就是把随机事件的结果"数值化"：

- 掷骰子的点数 X ∈ {1,2,3,4,5,6}
- 明天是否下雨 X ∈ {0, 1}
- 某网站的访问量 X ∈ {0, 1, 2, ...}

### 18.1.3 概率分布

概率分布描述随机变量取每个值的概率。

```python
import numpy as np

# 模拟掷骰子 10000 次
np.random.seed(42)
rolls = np.random.randint(1, 7, 10000)

# 统计每个点数出现的频率（近似概率）
for i in range(1, 7):
    prob = np.mean(rolls == i)
    print(f"点数 {i}: {prob:.3f}")
# 每个都接近 1/6 ≈ 0.167
```

这就是"频率近似概率"——当试验次数足够多，频率会收敛到真实概率（大数定律）。

## 18.2 常见概率分布

### 18.2.1 伯努利分布（0/1 分布）

只有两种结果的单次试验：成功(1)或失败(0)。

```python
# 模拟一次登录尝试：成功概率 0.8
p = 0.8
result = np.random.rand() < p   # 生成 0-1 随机数，小于 0.8 视为成功
print(1 if result else 0)
```

AI 里的二分类问题（是/否、恶意/正常）就是伯努利分布。

### 18.2.2 正态分布（高斯分布）

最重要的分布！现实世界大量数据服从正态分布：身高、体重、测量误差、网络流量...

```python
import numpy as np

mu, sigma = 50, 10   # 均值 50，标准差 10
data = np.random.normal(mu, sigma, 10000)

print(f"均值: {data.mean():.2f}")   # 接近 50
print(f"标准差: {data.std():.2f}")  # 接近 10
```

正态分布的经验法则（68-95-99.7）：

- 约 68% 的数据落在 μ±1σ 内
- 约 95% 的数据落在 μ±2σ 内
- 约 99.7% 的数据落在 μ±3σ 内

这就是第 13、16 章用的"3σ 异常检测法"的理论基础——**超过 3σ 的数据几乎不可能正常出现，所以判为异常**。

### 18.2.3 其他分布（了解）

| 分布 | 适用场景 |
|------|---------|
| 二项分布 | n 次伯努利试验的成功次数 |
| 泊松分布 | 单位时间内的事件发生次数（如每秒请求数） |
| 均匀分布 | 等概率的连续取值 |

```python
# 泊松分布：模拟每秒到达的请求数（平均 5 个）
requests = np.random.poisson(5, 100)
print(requests[:10])
```

> **安全应用**：DDoS 检测中，请求数突然偏离泊松分布的正常范围，就可能是攻击。

## 18.3 条件概率与贝叶斯公式

### 18.3.1 条件概率

`P(A|B)` 表示"在 B 已经发生的条件下，A 发生的概率"。

**例子**：在安全场景，已知一个 IP 来自某个地区（B），求它是攻击者（A）的概率。

```python
# 假设统计数据：
# 总共 10000 个 IP，其中 100 个是攻击者
# 攻击者中有 80 个来自地区 X
# 正常用户中有 900 个来自地区 X

P_attacker = 100 / 10000          # 0.01  先验概率：任意 IP 是攻击者的概率
P_X_given_attacker = 80 / 100     # 0.8   攻击者中来自 X 的比例
P_X = (80 + 900) / 10000          # 0.098 所有 IP 中来自 X 的比例

# 贝叶斯公式：P(攻击者|X) = P(X|攻击者) * P(攻击者) / P(X)
P_attacker_given_X = P_X_given_attacker * P_attacker / P_X
print(f"来自地区X的IP是攻击者的概率: {P_attacker_given_X:.3f}")
# ≈ 0.082  约 8.2%
```

### 18.3.2 贝叶斯公式的意义

```
后验概率 = 似然 × 先验 / 证据
P(A|B) = P(B|A) × P(A) / P(B)
```

直觉理解：

- **先验 P(A)**：在没有新证据前的信念
- **似然 P(B|A)**：如果 A 是真的，看到证据 B 的可能性
- **后验 P(A|B)**：看到证据 B 后，对 A 的更新信念

> **AI 应用**：朴素贝叶斯分类器就是直接应用贝叶斯公式做文本分类（如垃圾邮件检测）。它简单但非常有效，是机器学习的经典入门算法。

### 18.3.3 一个反直觉的例子（基础概率谬误）

假设有一种疾病，发病率 0.1%（千分之一）。有一种检测方法：
- 患病者检测呈阳性的概率是 99%（灵敏度）
- 健康者检测呈阳性的概率是 5%（误报率）

问：检测呈阳性，真正患病的概率是多少？

很多人会答 99%，但正确答案是：

```python
P_disease = 0.001
P_pos_given_disease = 0.99
P_pos_given_healthy = 0.05
P_healthy = 0.999

P_pos = P_pos_given_disease * P_disease + P_pos_given_healthy * P_healthy
P_disease_given_pos = P_pos_given_disease * P_disease / P_pos
print(f"阳性后真正患病的概率: {P_disease_given_pos:.3f}")
# ≈ 0.019  只有约 1.9%！
```

原因：健康人基数太大，即使误报率只有 5%，误报的绝对数量也远超真阳性。

> **安全启示**：这解释了为什么安全告警系统会有大量误报——正常流量基数巨大，即使误报率很低，产生的误报数量也会淹没真实告警。做安全分析时必须考虑这个"基础概率"问题。

## 18.4 描述性统计

### 18.4.1 集中趋势

```python
import numpy as np

data = np.array([10, 20, 20, 30, 40, 100])

print(np.mean(data))    # 36.67  均值（受极端值影响大）
print(np.median(data))  # 25  中位数（抗极端值）
```

> 均值容易被异常值拉偏。比如上面数据里有个 100，均值被拉到 36.67，而中位数 25 更能代表"典型值"。分析带异常的安全数据时，中位数往往更可靠。

### 18.4.2 离散程度

```python
print(np.std(data))     # 标准差：数据分散程度
print(np.var(data))     # 方差：标准差的平方
print(np.percentile(data, 95))  # 95 分位数：95% 的数据小于这个值
```

> **安全应用**：用百分位数设阈值比用均值更稳健。比如把"请求时间 > P99"的请求判为异常。

## 18.5 最大似然估计（MLE）

### 18.5.1 直觉理解

最大似然估计的思想：**找到一组参数，使得我们观察到的数据出现的概率最大**。

打个比方：你抛硬币 10 次，结果 7 次正面 3 次反面。问硬币正面朝上的概率 p 是多少？

直觉告诉你 p ≈ 0.7。这个直觉就是最大似然估计——因为 p=0.7 时，"抛出 7 正 3 反"这个结果的概率最大。

```python
from scipy.stats import binom

# 计算不同 p 值下，观察到 7 正 3 反的概率
for p in [0.5, 0.6, 0.7, 0.8]:
    prob = binom.pmf(7, 10, p)
    print(f"p={p}: 概率={prob:.4f}")
# p=0.7 时概率最大 → 最大似然估计就是 0.7
```

> **AI 应用**：训练机器学习模型，本质上就是在做最大似然估计——找到最优的模型参数，使得训练数据出现的概率最大。

## 18.6 本章总结

| 概念 | 核心要点 |
|------|---------|
| 概率 | 0-1 之间的可能性度量 |
| 频率近似概率 | 大数定律：试验多了频率收敛到概率 |
| 伯努利分布 | 0/1 二分类 |
| 正态分布 | 68-95-99.7 法则；3σ 异常检测的基础 |
| 条件概率 | P(A\|B)：B 发生时 A 的概率 |
| 贝叶斯公式 | 后验 = 似然 × 先验 / 证据 |
| 基础概率谬误 | 别忽视基数，安全误报的根源 |
| 均值/中位数 | 中位数抗异常值 |
| 标准差/分位数 | 衡量离散程度，分位数设阈值更稳健 |
| 最大似然估计 | 找使数据概率最大的参数；模型训练的本质 |
