## 19.1 导数：变化率

### 19.1.1 直觉理解

导数衡量的是"函数在某一点的变化速度"，也就是**斜率**。

- 导数 > 0：函数在该点上升
- 导数 < 0：函数在该点下降
- 导数 = 0：函数在该点平坦（可能是极小值或极大值）

打个比方：你站在山坡上，导数告诉你"脚下这个坡是往上还是往下，有多陡"。

```python
# 函数 f(x) = x^2 的导数是 f'(x) = 2x
# 在 x=3 处，导数 = 6，表示函数在这里以"每单位 x 上升 6"的速度增长
```

### 19.1.2 数值求导

我们不需要手动推导公式，可以用数值方法近似：

```python
def derivative(f, x, h=1e-5):
    """数值求导：用很小的 h 近似导数"""
    return (f(x + h) - f(x - h)) / (2 * h)

f = lambda x: x ** 2
print(derivative(f, 3))   # ≈ 6.0
print(derivative(f, -2))  # ≈ -4.0
print(derivative(f, 0))   # ≈ 0.0  （最低点）
```

## 19.2 梯度下降：AI 训练的核心算法

### 19.2.1 一个直观的例子

假设你蒙着眼睛站在山上，想走到山谷最低点。你会怎么做？

**最简单的方法**：用脚感受周围哪个方向是下坡，然后朝那个方向迈一步。重复这个过程，最终就能走到谷底。

**梯度下降**就是这个过程的数学版本：

1. 计算当前位置的梯度（导数）——告诉我们"上坡方向"
2. 朝梯度的**反方向**走一步（下坡）——因为我们要找最小值
3. 重复直到收敛

### 19.2.2 用梯度下降求函数最小值

```python
import numpy as np

# 目标函数：f(x) = x^2，最小值在 x=0
f = lambda x: x ** 2

# 梯度下降
x = 10.0           # 初始位置
learning_rate = 0.1  # 学习率（步长）
epochs = 50        # 迭代次数

for i in range(epochs):
    grad = 2 * x    # f(x)=x^2 的导数是 2x
    x = x - learning_rate * grad   # 朝反方向走一步
    if i % 10 == 0:
        print(f"第 {i} 步: x = {x:.4f}, f(x) = {f(x):.4f}")

print(f"\n最终结果: x = {x:.6f}")   # 接近 0
```

**关键参数**：

- **学习率（learning rate）**：步子迈多大
  - 太大：可能越过最低点，来回震荡甚至发散
  - 太小：走得极慢，可能永远到不了
- **迭代次数（epochs）**：走多少步

> **调参直觉**：学习率是 AI 训练中最重要的超参数之一。第 6 章注释里提到的 `learning_rate = 0.001` 就是经验值——小步慢走更稳定。

### 19.2.3 学习率的影响

```python
def gradient_descent(lr, epochs=30):
    x = 10.0
    for _ in range(epochs):
        x -= lr * (2 * x)
    return x

for lr in [0.01, 0.1, 0.5, 1.0, 1.1]:
    print(f"学习率 {lr}: 最终 x = {gradient_descent(lr):.6f}")

# lr=0.01: 收敛慢
# lr=0.1:  收敛良好
# lr=0.5:  快速收敛
# lr=1.0:  震荡不收敛
# lr=1.1:  发散（越来越远）
```

## 19.3 偏导数与梯度

### 19.3.1 多元函数

现实中的模型有成千上万个参数，`f(x)` 变成了 `f(x1, x2, ..., xn)`。

**偏导数**：固定其他变量，只对某一个变量求导。

**梯度**：所有偏导数组成的向量，记作 `∇f`。

### 19.3.2 梯度下降的通用形式

```
θ_new = θ_old - 学习率 × ∇J(θ)
```

其中 θ 是所有参数，J 是损失函数。

```python
# 二维函数 f(x, y) = x^2 + y^2 的最小值在 (0, 0)
x, y = 5.0, 5.0
lr = 0.1

for i in range(50):
    grad_x = 2 * x   # ∂f/∂x
    grad_y = 2 * y   # ∂f/∂y
    x -= lr * grad_x
    y -= lr * grad_y

print(f"结果: ({x:.6f}, {y:.6f})")   # 接近 (0, 0)
```

## 19.4 损失函数：衡量模型有多"差"

### 19.4.1 什么是损失函数

损失函数（Loss Function）衡量模型预测值和真实值之间的差距。训练模型就是让损失最小化。

**均方误差（MSE）**（回归任务常用）：

```python
def mse(y_true, y_pred):
    return np.mean((np.array(y_true) - np.array(y_pred)) ** 2)

y_true = [1, 2, 3, 4]
y_pred = [1.1, 1.9, 3.2, 3.8]
print(mse(y_true, y_pred))   # 0.015
```

**交叉熵损失（Cross Entropy）**（分类任务常用，AI 里最常用）：

```python
def cross_entropy(y_true, y_pred_prob):
    """y_true: 真实类别(0或1), y_pred_prob: 预测为类别1的概率"""
    epsilon = 1e-15  # 防止 log(0)
    y_pred_prob = np.clip(y_pred_prob, epsilon, 1 - epsilon)
    if y_true == 1:
        return -np.log(y_pred_prob)
    else:
        return -np.log(1 - y_pred_prob)

print(cross_entropy(1, 0.9))   # 很小，预测对了
print(cross_entropy(1, 0.1))   # 很大，预测错了
```

### 19.4.2 完整示例：用梯度下降拟合一条直线

```python
import numpy as np

# 假设真实关系是 y = 2x + 1，我们想让模型学出这两个参数
np.random.seed(42)
X = np.linspace(0, 5, 50)
y = 2 * X + 1 + np.random.randn(50) * 0.5   # 加噪声

# 模型: y_pred = w*x + b，要学习 w 和 b
w, b = 0.0, 0.0   # 初始参数
lr = 0.05
epochs = 200

for i in range(epochs):
    # 预测
    y_pred = w * X + b
    
    # 计算梯度（对 MSE 求导）
    dw = (2/len(X)) * np.sum((y_pred - y) * X)
    db = (2/len(X)) * np.sum(y_pred - y)
    
    # 更新参数
    w -= lr * dw
    b -= lr * db
    
    if i % 40 == 0:
        loss = np.mean((y_pred - y) ** 2)
        print(f"第 {i} 轮: w={w:.3f}, b={b:.3f}, 损失={loss:.4f}")

print(f"\n最终结果: w={w:.3f}, b={b:.3f}  (真实值 w=2, b=1)")
```

**这就是机器学习！** 模型从数据里"学"出了参数 w 和 b，而且是用梯度下降一步步逼近的。你刚刚手写了一个最简单的机器学习训练过程。

## 19.5 常见优化器

基本的梯度下降有很多变体，实际框架（PyTorch/TensorFlow）里用的是更聪明的版本：

| 优化器 | 特点 |
|--------|------|
| SGD | 最基础的随机梯度下降 |
| SGD + Momentum | 加入"惯性"，加速收敛、减少震荡 |
| RMSprop | 自适应学习率 |
| **Adam** | 结合 Momentum 和 RMSprop，目前最流行 |

## 19.6 本章总结

| 概念 | 核心要点 |
|------|---------|
| 导数 | 变化率/斜率；指导调整方向 |
| 梯度下降 | 朝梯度反方向走，找最小值 |
| 学习率 | 步长；太大震荡/发散，太小太慢 |
| 偏导数/梯度 | 多元函数的导数向量 |
| 损失函数 | 衡量预测误差；MSE（回归）、交叉熵（分类） |
| 训练本质 | 用梯度下降最小化损失函数 |
| 优化器 | SGD、Momentum、Adam（默认选 Adam） |
