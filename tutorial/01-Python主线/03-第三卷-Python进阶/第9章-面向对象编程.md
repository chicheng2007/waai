## 9.1 什么是面向对象

### 9.1.1 从生活例子说起

假设你要写一个"端口扫描器"程序，用面向过程（前面学的）思路：

```python
# 面向过程：一堆函数和变量
target_ip = "192.168.1.1"
ports = [22, 80, 443]

def scan_port(ip, port):
    # 扫描逻辑
    pass

def generate_report(results):
    # 生成报告
    pass

scan_port(target_ip, 80)
generate_report([])
```

数据和操作数据的函数是分离的。随着程序变复杂，函数越来越多，数据到处传，难以管理。

**面向对象**的思路：把"数据"和"操作数据的函数"打包成一个整体——**对象**。

```python
# 面向对象：把扫描器做成一个"对象"
scanner = PortScanner("192.168.1.1")   # 创建一个扫描器对象
scanner.scan([22, 80, 443])            # 对象自己会扫描
report = scanner.generate_report()     # 对象自己会生成报告
```

`scanner` 是一个对象，它**有自己的数据**（目标 IP）和**自己的行为**（扫描、生成报告）。

### 9.1.2 类与对象

- **类（Class）**：蓝图/模板。比如"PortScanner 类"定义了扫描器应该有什么属性和行为
- **对象（Object）**：根据蓝图造出来的实体。比如 `scanner = PortScanner(...)` 造出了一个具体的扫描器

类比：

- 类 = 汽车设计图
- 对象 = 根据设计图造出来的一辆具体汽车
- 属性 = 汽车的颜色、型号（数据）
- 方法 = 汽车的启动、刹车（行为）

## 9.2 定义类和创建对象

### 9.2.1 基本语法

```python
class Dog:
    """狗的类"""
    
    def bark(self):
        print("汪汪!")
```

- 用 `class` 关键字定义类
- 类名习惯用大驼峰命名（首字母大写）
- 类里面的函数叫**方法**（method）

**创建对象**：

```python
my_dog = Dog()      # 实例化：根据 Dog 类创建一个对象
my_dog.bark()       # 调用对象的方法 → 汪汪!
```

### 9.2.2 __init__ 构造方法

`__init__` 是创建对象时自动调用的方法，用来初始化对象的属性：

```python
class Dog:
    def __init__(self, name, age):
        self.name = name   # 实例属性
        self.age = age
    
    def bark(self):
        print(f"{self.name} 汪汪! 我 {self.age} 岁了")

dog1 = Dog("旺财", 3)
dog2 = Dog("小白", 1)

dog1.bark()   # 旺财 汪汪! 我 3 岁了
dog2.bark()   # 小白 汪汪! 我 1 岁了
```

要点：

- `__init__` 在创建对象时自动执行，不需要手动调用
- `self` 代表"对象自己"，通过 `self.xxx` 访问对象的属性
- 创建对象时传入的参数（`name`, `age`）会传给 `__init__`

> **小白问**：`self` 到底是什么？
>
> **答**：`self` 就是对象自己。当你调用 `dog1.bark()` 时，Python 自动把 `dog1` 作为第一个参数传给 `bark` 方法，所以方法里的 `self` 就指向 `dog1`。你**必须**在定义方法时把 `self` 作为第一个参数（名字可以换，但约定用 `self`）。它不用在调用时手动传。

### 9.2.3 实例属性 vs 类属性

**实例属性**：每个对象独有的数据（在 `__init__` 里用 `self.xxx` 定义）

**类属性**：所有对象共享的数据（在类内部、方法外部定义）

```python
class Dog:
    species = "犬科"   # 类属性，所有狗共享
    
    def __init__(self, name):
        self.name = name   # 实例属性，每只狗不同

d1 = Dog("旺财")
d2 = Dog("小白")

print(d1.name, d2.name)         # 旺财 小白
print(d1.species, d2.species)   # 犬科 犬科
print(Dog.species)              # 犬科（通过类访问）
```

## 9.3 三大特性

### 9.3.1 封装（Encapsulation）

封装 = 把数据和操作数据的方法打包在一起，并**隐藏内部细节**。

```python
class BankAccount:
    def __init__(self, balance=0):
        self.__balance = balance   # 双下划线开头 = 私有属性
    
    def deposit(self, amount):
        if amount > 0:
            self.__balance += amount
    
    def get_balance(self):
        return self.__balance

account = BankAccount(100)
account.deposit(50)
print(account.get_balance())   # 150
# print(account.__balance)     # 报错！私有属性不能从外部直接访问
```

**私有属性**（`__` 开头）的意义：

- 防止外部代码随意修改内部数据
- 强制通过方法访问，可以在方法里加验证逻辑（比如存款金额必须为正）

> **注意**：Python 的"私有"只是约定（通过名称改写实现），不是真正的强制。但它表达了一种设计意图："这是内部实现，别从外面碰"。

### 9.3.2 继承（Inheritance）

继承 = 子类可以继承父类的属性和方法，并添加自己的特性。

```python
# 父类
class Animal:
    def __init__(self, name):
        self.name = name
    
    def eat(self):
        print(f"{self.name} 在吃东西")

# 子类
class Dog(Animal):
    def bark(self):
        print(f"{self.name} 汪汪叫")

class Cat(Animal):
    def meow(self):
        print(f"{self.name} 喵喵叫")

dog = Dog("旺财")
dog.eat()     # 旺财 在吃东西（继承自父类）
dog.bark()    # 旺财 汪汪叫（自己的方法）

cat = Cat("咪咪")
cat.eat()     # 咪咪 在吃东西
cat.meow()    # 咪咪 喵喵叫
```

**重写（Override）**：子类可以覆盖父类的方法：

```python
class Dog(Animal):
    def eat(self):
        print(f"{self.name} 在啃骨头")   # 重写父类的 eat

dog = Dog("旺财")
dog.eat()   # 旺财 在啃骨头（用子类自己的版本）
```

**super()**：在子类中调用父类的方法：

```python
class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)   # 先调用父类的 __init__
        self.breed = breed       # 再添加自己的属性
```

继承的意义：**代码复用** + **建立类之间的层次关系**。安全工具中常用继承构建"基础扫描器 → 端口扫描器 → Web 扫描器"这样的层级。

### 9.3.3 多态（Polymorphism）

多态 = 不同的对象对同一个方法调用，表现出不同的行为。

```python
class Dog:
    def speak(self):
        return "汪汪"

class Cat:
    def speak(self):
        return "喵喵"

class Duck:
    def speak(self):
        return "嘎嘎"

# 统一调用，不同表现
for animal in [Dog(), Cat(), Duck()]:
    print(animal.speak())
# 汪汪
# 喵喵
# 嘎嘎
```

只要对象有 `speak()` 方法，就能放进循环里统一处理，不需要关心它具体是什么类。这就是多态的威力——**相同的接口，不同的实现**。

> **小白问**：OOP 在 AI 和安全里有什么用？
>
> **答**：你用的几乎所有库都是 OOP 设计的。比如 PyTorch 里 `model = nn.Linear(...)` 创建了一个层对象，`model.forward(...)` 调用它的方法；scikit-learn 里 `model = LogisticRegression(); model.fit(X, y)`，都是对象和方法的调用。不懂 OOP，你只能"照猫画虎"地抄代码；懂了 OOP，你能读懂源码、自己封装工具。

## 9.4 特殊方法（魔术方法）

Python 类里有一批以双下划线开头和结尾的方法，叫特殊方法/魔术方法。它们在特定情况下自动调用：

| 方法 | 何时调用 | 作用 |
|------|---------|------|
| `__init__` | 创建对象时 | 初始化 |
| `__str__` | `print(对象)` 时 | 定义对象的字符串表示 |
| `__repr__` | 在交互环境显示对象时 | 定义对象的"官方"表示 |
| `__len__` | `len(对象)` 时 | 定义长度 |
| `__eq__` | `对象1 == 对象2` 时 | 定义相等比较 |
| `__getitem__` | `对象[下标]` 时 | 定义索引访问 |

```python
class Port:
    def __init__(self, number, service):
        self.number = number
        self.service = service
    
    def __str__(self):
        return f"Port({self.number}: {self.service})"
    
    def __len__(self):
        return 1
    
    def __eq__(self, other):
        return self.number == other.number

p1 = Port(80, "HTTP")
p2 = Port(80, "WWW")
print(p1)          # Port(80: HTTP)  —— 调用了 __str__
print(len(p1))     # 1  —— 调用了 __len__
print(p1 == p2)    # True  —— 调用了 __eq__
```

> **注意**：`__str__` 让对象打印出来更友好，调试时非常有用。定义类时建议都加上。

## 9.5 综合实战：面向对象版端口扫描器

```python
import socket

class PortScanner:
    """端口扫描器类"""
    
    def __init__(self, target, timeout=0.5):
        self.target = target
        self.timeout = timeout
        self.open_ports = []   # 存放扫描结果
    
    def scan_port(self, port):
        """扫描单个端口"""
        try:
            sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
            sock.settimeout(self.timeout)
            result = sock.connect_ex((self.target, port))
            sock.close()
            return result == 0   # 0 表示端口开放
        except Exception:
            return False
    
    def scan(self, ports):
        """扫描多个端口"""
        self.open_ports = []   # 清空上次结果
        for port in ports:
            if self.scan_port(port):
                self.open_ports.append(port)
                print(f"[+] {self.target}:{port} 开放")
        return self.open_ports
    
    def generate_report(self):
        """生成报告"""
        print("\n=== 扫描报告 ===")
        print(f"目标: {self.target}")
        print(f"开放端口: {len(self.open_ports)} 个")
        if self.open_ports:
            print("端口列表:", ", ".join(map(str, self.open_ports)))
        else:
            print("未发现开放端口")
    
    def __str__(self):
        return f"PortScanner(target={self.target}, open_ports={len(self.open_ports)})"

# 使用（请在你有授权的环境测试，比如 localhost）
if __name__ == "__main__":
    scanner = PortScanner("127.0.0.1")
    scanner.scan([80, 443, 8080, 3306, 8888])
    scanner.generate_report()
    print(scanner)
```

> **伦理提示**：端口扫描本身是安全从业者的基本技能，但**只能对自己的设备或明确授权的目标进行**。对他人系统进行扫描可能违反《网络安全法》。练习时请用 `127.0.0.1`（本机）或搭建自己的靶场（如 DVWA、VulnHub）。

**观察 OOP 的优势**：

- 扫描器有自己的状态（`target`, `open_ports`），不用到处传参
- 功能被组织成方法，清晰明了
- 想扫描多个目标？创建多个对象即可，互不干扰

## 9.6 本章总结

| 概念 | 核心内容 |
|------|---------|
| 类与对象 | 类是蓝图，对象是实例 |
| `__init__` | 构造方法，创建对象时自动调用 |
| `self` | 代表对象自己，访问实例属性 |
| 封装 | 用 `__私有属性` 隐藏内部细节 |
| 继承 | 子类继承父类，`super()` 调用父类方法 |
| 多态 | 相同接口，不同实现 |
| 魔术方法 | `__str__`、`__len__`、`__eq__` 等自动调用 |
