## 10.1 模块（Module）

### 10.1.1 什么是模块

一个 `.py` 文件就是一个模块。模块里可以定义函数、类、变量。把代码拆成多个模块，便于组织和管理。

假设有这样一个文件 `ip_utils.py`：

```python
# ip_utils.py
"""IP 工具模块"""

def is_valid(ip):
    parts = ip.split(".")
    return len(parts) == 4 and all(p.isdigit() and 0 <= int(p) <= 255 for p in parts)

def is_private(ip):
    return ip.startswith(("192.168.", "10.", "172."))
```

在另一个文件里使用它：

```python
# main.py
import ip_utils

print(ip_utils.is_valid("192.168.1.1"))   # True
print(ip_utils.is_private("192.168.1.1")) # True
```

### 10.1.2 import 的几种写法

```python
# 1. 导入整个模块
import ip_utils
ip_utils.is_valid("192.168.1.1")

# 2. 导入模块并起别名（常用）
import ip_utils as ipu
ipu.is_valid("192.168.1.1")

# 3. 只导入特定的函数/类
from ip_utils import is_valid, is_private
is_valid("192.168.1.1")   # 直接用，不用加模块名

# 4. 导入全部（不推荐，容易命名冲突）
from ip_utils import *

# 5. 导入时起别名
from ip_utils import is_valid as check_ip
```

> **建议**：优先用 `import 模块` 或 `from 模块 import 具体名字`，避免 `import *`（会污染命名空间，且看不出函数来自哪里）。

### 10.1.3 标准库模块

Python 自带大量实用模块（标准库），直接 import 就能用：

```python
import os        # 操作系统相关：文件、路径、环境变量
import sys       # Python 解释器相关
import math      # 数学函数
import random    # 随机数
import datetime  # 日期时间
import json      # JSON 处理
import re        # 正则表达式
import csv       # CSV 处理
import hashlib   # 哈希（加密相关，安全常用）
import socket    # 网络编程
```

示例：

```python
import os
import datetime

print(os.getcwd())                     # 当前工作目录
print(datetime.datetime.now())         # 当前时间
print(math.sqrt(16))                   # 4.0  （需先 import math）
```

### 10.1.4 模块的搜索路径

Python 导入模块时，会按以下顺序查找：

1. 当前目录
2. 环境变量 PYTHONPATH 指定的目录
3. Python 标准库目录
4. 第三方库目录（site-packages）

查看搜索路径：

```python
import sys
print(sys.path)
```

> **注意**：如果你自己写了 `random.py`，然后 `import random`，会导入你自己的文件而不是标准库的 random 模块！所以**别用标准库的名字命名自己的文件**。

## 10.2 包（Package）

### 10.2.1 什么是包

包是包含多个模块的文件夹。包里必须有一个 `__init__.py` 文件（Python 3.3+ 可以省略，但建议保留），用来标识这是一个包。

```
myproject/
├── __init__.py
├── utils.py
├── scanner.py
└── models/
    ├── __init__.py
    └── detector.py
```

导入方式：

```python
from myproject import utils
from myproject.scanner import PortScanner
from myproject.models.detector import Detector
```

### 10.2.2 __init__.py 的作用

1. 标识这是一个包
2. 可以在里面写包的初始化代码
3. 可以控制 `from 包 import *` 时导出哪些内容

```python
# myproject/__init__.py
from .utils import is_valid
from .scanner import PortScanner

__all__ = ["is_valid", "PortScanner"]
```

这样别人就能 `from myproject import PortScanner` 了。

## 10.3 __name__ == "__main__"

### 10.3.1 一个关键概念

每个 Python 文件都有一个 `__name__` 变量：

- 直接运行文件时，`__name__` = `"__main__"`
- 被其他文件 import 时，`__name__` = 模块名（文件名）

### 10.3.2 为什么要用它

```python
# ip_utils.py
def is_valid(ip):
    ...

# 下面的代码只在直接运行本文件时执行
# 被 import 时不会执行
if __name__ == "__main__":
    print("测试:", is_valid("192.168.1.1"))
```

这样，模块既能被别人 import（不会执行测试代码），又能自己运行做测试。

> **注意**：这是 Python 的重要惯例，几乎所有规范的模块都会写。养成习惯：**把"只在直接运行时执行"的代码放进 `if __name__ == "__main__":` 里**。

## 10.4 异常处理

### 10.4.1 什么是异常

异常 = 程序运行时发生的错误。如果不处理，程序会崩溃并打印 Traceback（错误追踪）。

```python
x = int("abc")   # ValueError
```

### 10.4.2 常见异常类型

| 异常 | 何时发生 |
|------|---------|
| `ValueError` | 传入的值不合法（`int("abc")`） |
| `TypeError` | 类型不匹配（`1 + "a"`） |
| `NameError` | 变量名不存在 |
| `IndexError` | 列表下标越界 |
| `KeyError` | 字典键不存在 |
| `FileNotFoundError` | 文件不存在 |
| `ZeroDivisionError` | 除以零 |
| `AttributeError` | 对象没有该属性/方法 |
| `ImportError` | 导入模块失败 |
| `ConnectionError` | 网络连接错误 |

### 10.4.3 try-except 基本用法

```python
try:
    # 可能出错的代码
    num = int(input("请输入数字: "))
    print(f"你输入的是 {num}")
except ValueError:
    # 出错时执行
    print("输入不是合法数字!")
```

语法：

- `try` 里放可能出错的代码
- `except` 里放出错后的处理代码
- 如果 try 里没错，except 不执行

### 10.4.4 捕获多个异常

```python
try:
    result = 10 / int(input("输入数字: "))
except ValueError:
    print("不是数字")
except ZeroDivisionError:
    print("不能除以零")
```

或者一次捕获多个：

```python
try:
    ...
except (ValueError, ZeroDivisionError) as e:
    print(f"出错了: {e}")
```

### 10.4.5 捕获所有异常

```python
try:
    ...
except Exception as e:
    print(f"发生错误: {e}")
```

`Exception` 是所有异常的父类，能捕获大部分异常。

> **注意**：不要滥用"捕获所有异常"。过度捕获会隐藏真正的 bug，让调试变困难。只捕获你能处理的异常，其他的让它暴露出来。

### 10.4.6 try-except-else-finally

完整的异常处理结构：

```python
try:
    # 可能出错的代码
    f = open("data.txt", "r", encoding="utf-8")
except FileNotFoundError:
    print("文件不存在")
else:
    # 没出错时执行
    content = f.read()
    print(content)
    f.close()
finally:
    # 无论是否出错都执行
    print("清理工作完成")
```

各部分作用：

- `try`：可能出错的代码
- `except`：出错时处理
- `else`：没出错时执行（可选）
- `finally`：无论是否出错都执行（可选），常用于释放资源

**finally 的典型用途**：

```python
try:
    f = open("data.txt", "r", encoding="utf-8")
    content = f.read()
finally:
    f.close()   # 一定会被关闭，即使读取时出错
```

（实际上用 `with` 语句更简洁，但理解 finally 的原理很重要。）

### 10.4.7 抛出异常：raise

有时候你需要主动抛出异常：

```python
def divide(a, b):
    if b == 0:
        raise ValueError("除数不能为零!")
    return a / b

try:
    divide(10, 0)
except ValueError as e:
    print("捕获到异常:", e)   # 捕获到异常: 除数不能为零!
```

### 10.4.8 自定义异常

```python
class PortScanError(Exception):
    """端口扫描异常"""
    pass

def scan(port):
    if not (1 <= port <= 65535):
        raise PortScanError(f"非法端口: {port}")
    # 扫描逻辑...

try:
    scan(99999)
except PortScanError as e:
    print(e)
```

## 10.5 综合实战：健壮的配置加载器

```python
import json

class ConfigLoader:
    """健壮的配置加载器"""
    
    def __init__(self, filepath):
        self.filepath = filepath
        self.config = {}
    
    def load(self):
        """加载配置文件，处理各种可能的错误"""
        try:
            with open(self.filepath, "r", encoding="utf-8") as f:
                self.config = json.load(f)
            print(f"配置加载成功: {self.filepath}")
            return True
        except FileNotFoundError:
            print(f"错误: 配置文件 {self.filepath} 不存在")
        except json.JSONDecodeError as e:
            print(f"错误: 配置文件格式不正确 - {e}")
        except PermissionError:
            print(f"错误: 没有权限读取 {self.filepath}")
        except Exception as e:
            print(f"未知错误: {e}")
        return False
    
    def get(self, key, default=None):
        """安全获取配置项"""
        return self.config.get(key, default)

# 测试
if __name__ == "__main__":
    loader = ConfigLoader("config.json")
    if loader.load():
        print("主机:", loader.get("host", "localhost"))
        print("端口:", loader.get("port", 8080))
```

这个加载器能优雅地处理"文件不存在""格式错误""权限不足"等各种情况，不会因为意外输入而崩溃。这就是健壮程序的样子。

## 10.6 本章总结

| 知识点 | 核心内容 |
|--------|---------|
| 模块 | 一个 .py 文件；`import` 导入 |
| import 写法 | `import x`、`import x as y`、`from x import y` |
| 包 | 含 `__init__.py` 的文件夹 |
| `__name__` | 直接运行是 `__main__`，被 import 是模块名 |
| try-except | 捕获并处理异常 |
| 异常类型 | ValueError、TypeError、KeyError、FileNotFoundError 等 |
| else/finally | 无错时执行 / 无论如何都执行 |
| raise | 主动抛出异常 |
| 自定义异常 | 继承 `Exception` |
