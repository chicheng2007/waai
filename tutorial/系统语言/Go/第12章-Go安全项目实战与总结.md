## 12.1 综合项目：并发 Web 漏洞巡检器

```go
package main

import (
    "fmt"
    "net/http"
    "sync"
    "time"
)

type Check struct {
    Name    string
    Path    string
    Pattern string   // 响应中期望出现的特征（表示存在漏洞/问题）
}

var checks = []Check{
    {"目录列表", "/", "Index of /"},
    {"敏感文件 .env", "/.env", "DB_PASSWORD"},
    {"Git 泄露", "/.git/config", "[core]"},
    {"PHPInfo", "/phpinfo.php", "phpinfo()"},
}

func checkTarget(baseURL string, check Check, client *http.Client,
                 wg *sync.WaitGroup, sem chan struct{}, results chan<- string) {
    defer wg.Done()
    sem <- struct{}{}
    defer func() { <-sem }()
    
    resp, err := client.Get(baseURL + check.Path)
    if err != nil { return }
    defer resp.Body.Close()
    
    if resp.StatusCode == 200 {
        buf := make([]byte, 4096)
        n, _ := resp.Body.Read(buf)
        body := string(buf[:n])
        if len(check.Pattern) == 0 || contains(body, check.Pattern) {
            results <- fmt.Sprintf("[发现] %s: %s%s", check.Name, baseURL, check.Path)
        }
    }
}

func contains(s, sub string) bool {
    return len(sub) == 0 || (len(s) >= len(sub) && stringContains(s, sub))
}

func stringContains(s, sub string) bool {
    for i := 0; i <= len(s)-len(sub); i++ {
        if s[i:i+len(sub)] == sub { return true }
    }
    return false
}

func main() {
    target := "http://127.0.0.1:8080"   // 自己的靶场
    client := &http.Client{Timeout: 3 * time.Second}
    sem := make(chan struct{}, 10)
    results := make(chan string)
    var wg sync.WaitGroup
    
    for _, check := range checks {
        wg.Add(1)
        go checkTarget(target, check, client, &wg, sem, results)
    }
    
    go func() { wg.Wait(); close(results) }()
    
    fmt.Printf("=== 巡检 %s ===\n", target)
    count := 0
    for r := range results {
        fmt.Println(r)
        count++
    }
    fmt.Printf("发现 %d 个问题\n", count)
}
```

> **伦理提示**：仅对自己的靶场（DVWA、本地服务）巡检。

## 12.3 三门语言总览与选择

| 维度 | C/C++ | Rust | Go |
|------|-------|------|-----|
| 定位 | 底层、逆向、漏洞 | 安全系统工具 | 云平台、网络工具 |
| 性能 | 极高 | 极高 | 高 |
| 安全 | 手动管理，易出漏洞 | 编译期保证 | GC + 安全默认 |
| 学习难度 | 高 | 很高 | 低 |
| 并发 | 复杂 | 强但复杂 | 简单强大 |
| 部署 | 复杂 | 单二进制 | 单二进制 |
| AI 中 | 推理引擎底层 | 高性能推理服务 | AI 网关/工程化 |
| 安全中 | 漏洞/逆向/利用 | 安全工具/系统组件 | 扫描器/云安全/C2 |

**选择指南**：

- 想做**逆向、漏洞挖掘、二进制安全、AI 底层优化** → **C/C++**
- 想写**内存安全、高性能的系统级安全工具**，追求极致安全 → **Rust**
- 想做**云安全、高并发扫描器、网络工具、AI 服务工程化**，快速上手 → **Go**

## 12.4 代码组织与工程化

写安全工具不只是能跑，还要工程化——便于维护、测试、分享：

### 12.4.1 单元测试

```go
package main

import "testing"

func TestClassifyPort(t *testing.T) {
    tests := []struct {
        port int
        want string
    }{
        {22, "知名端口"},
        {8080, "注册端口"},
        {50000, "动态端口"},
        {0, "非法端口"},
    }
    
    for _, tt := range tests {
        got := classifyPort(tt.port)
        if got != tt.want {
            t.Errorf("classifyPort(%d) = %s, want %s", tt.port, got, tt.want)
        }
    }
}
```

运行：`go test ./...`。测试是重构和迭代的安全网——尤其安全工具，逻辑错误可能导致漏报（漏掉真实漏洞）。

### 12.4.2 配置化

把硬编码的参数（目标、超时、并发数）移到配置文件或命令行参数，让工具更通用：

```go
type Config struct {
    Target  string `json:"target"`
    Timeout int    `json:"timeout_ms"`
    Workers int    `json:"workers"`
}

func loadConfig(path string) (*Config, error) {
    data, err := os.ReadFile(path)
    if err != nil { return nil, err }
    var cfg Config
    if err := json.Unmarshal(data, &cfg); err != nil { return nil, err }
    return &cfg, nil
}
```

### 12.4.3 结构化日志

```go
import "log/slog"   // Go 1.21+ 结构化日志

logger := slog.New(slog.NewJSONHandler(os.Stdout, nil))
logger.Info("发现开放端口",
    "ip", target,
    "port", port,
    "severity", "info",
)
```

结构化日志（JSON 格式）便于被 SIEM 系统（如 ELK、Splunk）采集分析。安全工具的输出往往要接入这些平台。

1. **C/C++ 深入**：汇编基础、ELF/PE 文件格式、调试器、Fuzzing
2. **Rust 深入**：异步 tokio、unsafe 深入、嵌入式
3. **Go 深入**：gin 框架、微服务、eBPF（Go 可写）、goroutine 调度原理
4. **通用**：CTF 竞赛、漏洞复现、读源码、贡献开源

### 从读者到贡献者

学习开源项目有三个层次：

1. **使用者**：会装、会用工具，知道基本参数
2. **阅读者**：能读懂源码，理解设计思路和实现细节
3. **贡献者**：能提交 Issue、修复 bug、贡献新功能

从"使用者"到"阅读者"，是能力的一次跃升；从"阅读者"到"贡献者"，则让你真正进入开源社区。

给贡献者的建议：

- 从"good first issue"标签的任务开始
- 先在本地复现问题，再动手修改
- 提交前运行全部测试（`go test ./...`）
- 写清楚 commit message，说明"为什么改"而不只是"改了什么"
- 尊重项目维护者的 review 意见

> 在 GitHub 上有高质量的开源贡献记录，比任何证书都能证明你的能力。安全领域的雇主非常看重这一点——它证明你能读懂真实世界的代码、能与团队协作、能产出可用的东西。把这套教程的练习工具开源出去，就是最好的起点。

## 12.5 全系列结语

从 Python 到 C/C++、Rust、Go，你已经建立了一座完整的技能金字塔：

```
        Python（应用、AI、脚本）
           ↑
    Go（工程化、云安全、并发）
           ↑
    Rust（安全系统、现代工具）
           ↑
    C/C++（底层、逆向、漏洞、性能）
```

- **Python** 让你快速实现想法、玩转 AI 和安全应用
- **C/C++** 让你理解底层、看透漏洞、优化性能
- **Rust** 让你写出内存安全的现代系统工具
- **Go** 让你高效构建云平台和并发网络工具

技术深度决定你能走多远，而**合法合规的白帽精神**决定你走的方向。愿你用这些能力，守护网络世界的安全。
