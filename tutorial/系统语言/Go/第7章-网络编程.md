## 7.1 HTTP 客户端

```go
package main

import (
    "fmt"
    "io"
    "net/http"
)

func main() {
    resp, err := http.Get("https://www.example.com")
    if err != nil {
        fmt.Println("请求失败:", err)
        return
    }
    defer resp.Body.Close()
    
    body, err := io.ReadAll(resp.Body)
    if err != nil {
        fmt.Println("读取失败:", err)
        return
    }
    
    fmt.Println("状态码:", resp.StatusCode)
    fmt.Println(string(body[:500]))   // 前500字节
}
```

### 7.1.1 自定义请求

```go
req, _ := http.NewRequest("POST", "http://api.example.com", strings.NewReader(`{"key":"value"}`))
req.Header.Set("Content-Type", "application/json")
req.Header.Set("User-Agent", "SecurityScanner/1.0")

client := &http.Client{Timeout: 5 * time.Second}
resp, err := client.Do(req)
```

> **安全提示**：一定要设置 Timeout，否则请求可能永久阻塞（被恶意服务器拖住）。

## 7.2 HTTP 服务端

```go
package main

import (
    "fmt"
    "net/http"
)

func handler(w http.ResponseWriter, r *http.Request) {
    fmt.Fprintf(w, "路径: %s\n", r.URL.Path)
}

func main() {
    http.HandleFunc("/", handler)
    fmt.Println("服务启动 :8080")
    http.ListenAndServe(":8080", nil)
}
```

### 7.2.1 RESTful API

```go
func apiHandler(w http.ResponseWriter, r *http.Request) {
    w.Header().Set("Content-Type", "application/json")
    
    switch r.Method {
    case "GET":
        fmt.Fprint(w, `{"status":"ok"}`)
    case "POST":
        // 处理 POST 数据
        body, _ := io.ReadAll(r.Body)
        fmt.Fprintf(w, `{"received":%q}`, body)
    default:
        http.Error(w, "方法不允许", http.StatusMethodNotAllowed)
    }
}
```

> **Web 安全提示**：
> - 永远验证和转义用户输入（防 SQL 注入、XSS）
> - 设置合理的超时和请求大小限制（防 DoS）
> - 用 HTTPS（防中间人）

## 7.3 TCP 编程

### 7.3.1 TCP 服务端

```go
package main

import (
    "bufio"
    "fmt"
    "net"
)

func main() {
    listener, err := net.Listen("tcp", ":9999")
    if err != nil {
        fmt.Println("监听失败:", err)
        return
    }
    defer listener.Close()
    
    fmt.Println("TCP 服务启动 :9999")
    
    for {
        conn, err := listener.Accept()
        if err != nil { continue }
        
        // 每个连接一个 goroutine
        go handleConn(conn)
    }
}

func handleConn(conn net.Conn) {
    defer conn.Close()
    reader := bufio.NewReader(conn)
    for {
        line, err := reader.ReadString('\n')
        if err != nil { break }
        fmt.Printf("收到: %s", line)
        conn.Write([]byte("已收到\n"))
    }
}
```

> **Go 的并发优势**：每个连接一个 goroutine，轻松处理几千个并发连接。这是写高性能网络服务/代理的基础。

### 7.3.2 TCP 客户端

```go
conn, err := net.Dial("tcp", "127.0.0.1:9999")
if err != nil { return }
defer conn.Close()

conn.Write([]byte("hello\n"))

buf := make([]byte, 1024)
n, _ := conn.Read(buf)
fmt.Println(string(buf[:n]))
```

## 7.4 实战：Web 指纹识别

```go
package main

import (
    "fmt"
    "net/http"
    "strings"
    "time"
)

func fingerprint(url string) {
    client := &http.Client{Timeout: 3 * time.Second}
    resp, err := client.Get(url)
    if err != nil {
        fmt.Printf("%s: 无法访问\n", url)
        return
    }
    defer resp.Body.Close()
    
    fmt.Printf("=== %s ===\n", url)
    fmt.Printf("服务器: %s\n", resp.Header.Get("Server"))
    fmt.Printf("状态码: %d\n", resp.StatusCode)
    
    if x powered := resp.Header.Get("X-Powered-By"); x != "" {
        fmt.Printf("技术栈: %s\n", x)
    }
    
    // 从 Server 头推断
    server := strings.ToLower(resp.Header.Get("Server"))
    switch {
    case strings.Contains(server, "nginx"):
        fmt.Println("推断: Nginx")
    case strings.Contains(server, "apache"):
        fmt.Println("推断: Apache")
    case strings.Contains(server, "iis"):
        fmt.Println("推断: IIS")
    }
}

func main() {
    fingerprint("http://127.0.0.1:8080")
}
```

> **伦理提示**：仅对授权目标做指纹识别。

## 7.5 HTTP 安全实践

### 7.5.1 防止常见 Web 攻击

用 Go 写 Web 服务时，必须主动防御常见漏洞：

```go
// 1. SQL 注入防御：用参数化查询
// 错误：db.Query("SELECT * FROM users WHERE name='" + name + "'")
// 正确（database/sql）：
row := db.QueryRow("SELECT * FROM users WHERE name=?", name)

// 2. XSS 防御：输出转义
import "html/template"   // 而非 text/template，自动转义
tmpl := template.Must(template.ParseFiles("page.html"))
tmpl.Execute(w, userData)   // 自动对 HTML 特殊字符转义

// 3. CSRF 防御：验证 Token
func csrfMiddleware(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        if r.Method == "POST" {
            token := r.FormValue("csrf_token")
            if token != getSessionToken(r) {
                http.Error(w, "CSRF 验证失败", http.StatusForbidden)
                return
            }
        }
        next.ServeHTTP(w, r)
    })
}
```

### 7.5.2 请求限流与防护

```go
// 限制请求体大小，防止 DoS
r.Body = http.MaxBytesReader(w, r.Body, 1<<20)   // 最大 1MB

// 设置服务器超时，防止慢速攻击（Slowloris）
server := &http.Server{
    Addr:         ":8080",
    Handler:      mux,
    ReadTimeout:  10 * time.Second,
    WriteTimeout: 10 * time.Second,
    IdleTimeout:  60 * time.Second,
    MaxHeaderBytes: 1 << 20,
}
server.ListenAndServe()
```

> **安全要点**：Go 的 `http.Server` 默认没有超时限制，这在某些攻击下是危险的。生产环境务必设置 `ReadTimeout`、`WriteTimeout`、`IdleTimeout`。这是很多 Go Web 服务容易忽略的安全配置。

### 7.5.3 TLS/HTTPS 配置

```go
// 使用 HTTPS
http.ListenAndServeTLS(":443", "cert.pem", "key.pem", mux)

// 强制最低 TLS 版本（禁用老旧的 TLS 1.0/1.1）
server := &http.Server{
    TLSConfig: &tls.Config{
        MinVersion: tls.VersionTLS12,
    },
}
```
