# 第 6 章 数组、字符串与指针（核心）

## 本章目标

- 透彻理解数组和字符串
- 彻底搞懂指针（C 语言的灵魂）
- 理解指针与数组的关系
- 掌握指针运算
- 理解指针与内存安全的关系

**这是整套 C/C++ 教程最重要的一章。** 指针是 C 语言的灵魂，也是绝大多数内存漏洞的根源。学懂指针，你就理解了计算机内存的运作方式，也就理解了漏洞利用的本质。

---

## 6.1 数组

### 6.1.1 数组基础

```c
int nums[5] = {10, 20, 30, 40, 50};

printf("%d\n", nums[0]);   // 10  下标从 0 开始
printf("%d\n", nums[4]);   // 50

nums[2] = 99;              // 修改元素
```

### 6.1.2 数组的连续存储

数组在内存中是**连续**存储的：

```
地址:   1000  1004  1008  1012  1016
值:     10    20    30    40    50
下标:   [0]   [1]   [2]   [3]   [4]
```

每个 int 占 4 字节，所以相邻元素地址差 4。这个"连续性"是理解指针运算和数组越界的关键。

```c
int nums[5];
printf("数组首地址: %p\n", (void*)nums);       // 如 0x7ffd...
printf("第二个元素: %p\n", (void*)&nums[1]);   // 首地址+4
```

### 6.1.3 数组越界（安全重点）

```c
int nums[5] = {1, 2, 3, 4, 5};
printf("%d\n", nums[5]);    // 越界！读取了数组后面的内存
printf("%d\n", nums[-1]);   // 也越界！读取了数组前面的内存
nums[10] = 100;             // 更危险：写入越界！
```

> **安全警示**：C 语言**不检查数组边界**！越界读写不会报错，而是悄悄操作相邻内存。这正是缓冲区溢出漏洞的根源——攻击者通过越界写入，可以覆盖返回地址、函数指针，进而劫持程序执行流程。第 10 章会详细讲。

## 6.2 字符串

### 6.2.1 字符串的本质

C 语言没有专门的"字符串类型"，字符串就是**字符数组**，以 `\0`（空字符）结尾：

```c
char str[] = "hello";
```

实际内存布局：

```
地址:  1000 1001 1002 1003 1004 1005
字符:  'h'  'e'  'l'  'l'  'o'  '\0'
                               ↑ 结束标志
```

`"hello"` 看起来是 5 个字符，实际占 **6 字节**（含 `\0`）。

### 6.2.2 字符串操作函数

需要 `#include <string.h>`：

```c
char s1[50] = "hello";
char s2[50] = "world";

strlen(s1);           // 5，长度（不含 \0）
strcpy(s1, s2);       // 复制
strcat(s1, "!!!");    // 拼接
strcmp(s1, s2);       // 比较，相等返回 0
strstr(s1, "or");     // 查找子串
```

### 6.2.3 strcpy 的危险（经典漏洞）

```c
char buf[8];
char *input = "这是一个非常非常长的字符串";
strcpy(buf, input);   // 灾难！源字符串远超 8 字节
```

`strcpy` **不检查目标缓冲区大小**，会一直复制直到遇到 `\0`，导致缓冲区溢出。

**安全替代**：

```c
// 用 strncpy 限制长度
strncpy(buf, input, sizeof(buf) - 1);
buf[sizeof(buf) - 1] = '\0';   // 确保以 \0 结尾

// 或 snprintf（更安全）
snprintf(buf, sizeof(buf), "%s", input);
```

> **真实漏洞**：strcpy、strcat、sprintf、gets 这些"不安全函数"是历史上无数漏洞的源头。现代安全编码规范（如 CERT C）明确禁用它们。

## 6.3 指针（C 语言灵魂）

### 6.3.1 什么是指针

**指针就是存储内存地址的变量。**

```
普通变量: 存的是"值"（如 10）
指针变量: 存的是"地址"（如 0x7ffd1234）
```

```c
int a = 10;        // 普通变量，存值 10
int *p = &a;       // 指针变量，存 a 的地址

printf("%d\n", a);   // 10，a 的值
printf("%p\n", p);   // 地址，如 0x7ffd...
printf("%d\n", *p);  // 10，通过地址取出值（解引用）
```

图解：

```
变量 a:  [ 10 ]     地址 0x1000
指针 p:  [0x1000]   地址 0x2000，存的是 a 的地址

*p = 通过 p 里存的地址(0x1000)找到 a，取出值 10
```

### 6.3.2 & 与 * 运算符

- `&变量`：取地址
- `*指针`：解引用（取指针指向的值）

```c
int a = 5;
int *p = &a;    // p 指向 a

*p = 20;        // 通过指针修改 a
printf("%d\n", a);   // 20，a 被改了
```

### 6.3.3 指针的声明

```c
int *p;        // 指向 int 的指针
char *c;       // 指向 char 的指针
double *d;     // 指向 double 的指针
void *v;       // 通用指针（不能直接解引用）

int **pp;      // 指向指针的指针（二级指针）
```

> **注意**：`int *p, q;` 中，p 是指针，q 是普通 int！`*` 只作用于紧跟的变量。写 `int *p, *q;` 才是两个指针。

### 6.3.4 指针与数组

数组名本质上是**指向首元素的指针**：

```c
int nums[5] = {10, 20, 30, 40, 50};

printf("%d\n", nums[2]);    // 30
printf("%d\n", *(nums+2));  // 30，等价写法！

int *p = nums;              // p 指向数组首元素
printf("%d\n", p[2]);       // 30
printf("%d\n", *(p+2));     // 30
```

`nums[2]` 本质就是 `*(nums + 2)`：从首地址偏移 2 个元素，再解引用。

### 6.3.5 指针运算

```c
int nums[5] = {10, 20, 30, 40, 50};
int *p = nums;

p++;        // 指向下一个元素（地址 + sizeof(int)，即 +4 字节）
printf("%d\n", *p);   // 20

p += 2;     // 向后移动 2 个元素
printf("%d\n", *p);   // 40

p--;        // 向前移动
printf("%d\n", *p);   // 30
```

> **关键**：`p+1` 不是地址 +1 字节，而是 +`sizeof(*p)` 字节。编译器知道指针类型，自动计算步长。

### 6.3.6 野指针与空指针（安全重点）

```c
// 空指针：指向 0，表示"不指向任何东西"
int *p = NULL;

// 野指针：指向无效内存（危险！）
int *q;        // 未初始化，指向随机地址
*q = 10;       // 灾难！可能崩溃或破坏其他数据

// 悬垂指针：指向已释放的内存
int *r = malloc(sizeof(int));
free(r);
*r = 20;       // 错误！r 指向的内存已释放（Use-After-Free）
```

> **安全警示**：野指针和悬垂指针是"Use-After-Free"（UAF）漏洞的根源。攻击者利用已释放但仍被使用的内存，可以劫持程序执行。这是现代浏览器、内核漏洞中最常见的类型之一。

**好习惯**：

```c
int *p = NULL;        // 初始化
// ... 使用 ...
free(p);
p = NULL;             // 释放后立即置空，防止悬垂指针
```

## 6.4 指针与函数

### 6.4.1 传址调用（回顾）

```c
void modify(int *p) {
    *p = 100;
}
int main() {
    int x = 5;
    modify(&x);       // 传地址
    printf("%d", x);  // 100
}
```

### 6.4.2 指针作为返回值

```c
// 在数组中查找，返回找到元素的指针
int* find(int *arr, int size, int target) {
    for (int i = 0; i < size; i++) {
        if (arr[i] == target) {
            return &arr[i];   // 返回地址
        }
    }
    return NULL;
}
```

> **警告**：不要返回局部变量的地址！函数结束后局部变量被销毁，返回的地址无效：
> ```c
> int* bad() {
>     int x = 10;
>     return &x;   // 错误！x 是局部变量，函数结束就没了
> }
> ```

### 6.4.3 const 与指针

```c
const int *p;      // 指向 const int，不能通过 p 修改值
int *const p;      // 常量指针，p 不能指向别处，但能改指向的值
const int *const p;// 都不能改
```

记忆技巧：**const 在 `*` 左边，限制值；const 在 `*` 右边，限制指针本身。**

## 6.5 综合实战：安全的字符串处理

```c
#include <stdio.h>
#include <string.h>

// 安全的字符串复制（带长度检查）
int safe_copy(char *dest, size_t dest_size, const char *src) {
    if (dest == NULL || src == NULL || dest_size == 0) {
        return -1;   // 参数错误
    }
    strncpy(dest, src, dest_size - 1);
    dest[dest_size - 1] = '\0';   // 确保终止
    return 0;
}

// 统计字符串中某字符出现次数
int count_char(const char *str, char c) {
    int count = 0;
    while (*str != '\0') {
        if (*str == c) count++;
        str++;   // 指针后移
    }
    return count;
}

int main() {
    char buf[16];
    char *input = "This is a long string that could overflow";
    
    if (safe_copy(buf, sizeof(buf), input) == 0) {
        printf("安全复制结果: %s\n", buf);
    }
    
    char text[] = "hello world";
    printf("'l' 出现次数: %d\n", count_char(text, 'l'));   // 3
    
    return 0;
}
```

## 6.6 多级指针与指针数组

### 6.6.1 二级指针

```c
int a = 10;
int *p = &a;      // 一级指针：指向 int
int **pp = &p;    // 二级指针：指向 int*

printf("%d\n", **pp);   // 10，两次解引用

**pp = 20;              // 通过二级指针修改 a
printf("%d\n", a);      // 20
```

图解：

```
pp (0x3000) → p (0x2000) → a (0x1000)
  存 0x2000      存 0x1000      存 10
```

二级指针的常见用途：

```c
// 函数内修改指针本身（分配内存）
void allocate(int **p) {
    *p = malloc(sizeof(int));   // 修改调用者的指针
    **p = 100;
}

int main() {
    int *ptr = NULL;
    allocate(&ptr);
    printf("%d\n", *ptr);   // 100
    free(ptr);
}
```

### 6.6.2 指针数组 vs 数组指针

这两个概念容易混淆：

```c
// 指针数组：数组里存的是指针
int *arr[5];    // 5 个元素，每个是 int*

// 数组指针：指针指向整个数组
int (*p)[5];    // 指向"含5个int的数组"的指针

// 应用：命令行参数就是指针数组
int main(int argc, char *argv[]) {
    // argv 是 char* 数组，每个元素是一个字符串
    printf("%s\n", argv[0]);   // 程序名
}
```

> **记忆技巧**：看括号。`int *arr[5]` 中 `[]` 优先，所以是数组；`int (*p)[5]` 中 `()` 优先，所以是指针。

### 6.6.3 函数指针

```c
// 指向函数的指针
int (*func_ptr)(int, int) = add;

printf("%d\n", func_ptr(3, 5));   // 8

// 作为函数参数（回调）
void process(int (*callback)(int, int)) {
    printf("%d\n", callback(10, 20));
}
```

> **安全关联**：函数指针是攻击者的另一个目标。通过覆盖函数指针（如 C++ 虚表、GOT 表），可以劫持程序执行流。这就是为什么要启用 RELRO、CFI（控制流完整性）等防护。

## 6.7 void 指针与类型转换

```c
// void* 是通用指针，可以指向任意类型
void *ptr = malloc(100);   // malloc 返回 void*

int *ip = (int*)ptr;       // 使用时转换
char *cp = (char*)ptr;

// void* 不能直接解引用
// *ptr   // 错误！不知道类型，无法解引用
```

**memcpy 的原型就用 void\***：

```c
void *memcpy(void *dest, const void *src, size_t n);
```

它不关心数据类型，只按字节复制。这也是为什么用 memcpy 时容易出错——它不做任何类型/边界检查。

## 6.8 本章总结

| 知识点 | 内容 |
|--------|------|
| 数组 | 连续存储；越界不检查（安全漏洞根源） |
| 字符串 | 字符数组 + `\0` 结尾；占 n+1 字节 |
| 危险函数 | strcpy/strcat/sprintf/gets 会导致溢出；用 strncpy/snprintf |
| 指针 | 存地址的变量；`&` 取地址，`*` 解引用 |
| 指针运算 | p+1 移动 sizeof(类型) 字节 |
| 数组与指针 | `arr[i]` 等价 `*(arr+i)` |
| 多级指针 | 二级指针修改指针本身 |
| 函数指针 | 回调；攻击目标 |
| void* | 通用指针；memcpy 参数 |
| 野指针/悬垂指针 | UAF 漏洞的根源；free 后置 NULL |
| const 指针 | const 在 * 左限制值，右限制指针 |
