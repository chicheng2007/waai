# 第 3 章 C 语言基础：变量、类型与运算符

## 本章目标

- 掌握 C 的基本数据类型和它们占用的内存大小
- 理解变量声明、初始化
- 掌握运算符
- 理解 `sizeof` 和数据类型的底层含义
- 初识格式化输入输出

C 语言和 Python 最大的区别之一：**C 的变量有明确的类型和大小**。这是理解内存和漏洞的关键。

---

## 3.1 基本数据类型

### 3.1.1 数据类型一览

| 类型 | 说明 | 典型大小 | 格式符 |
|------|------|---------|--------|
| `char` | 字符 | 1 字节 | `%c` |
| `int` | 整数 | 4 字节 | `%d` |
| `short` | 短整数 | 2 字节 | `%hd` |
| `long` | 长整数 | 8 字节（64位） | `%ld` |
| `float` | 单精度浮点 | 4 字节 | `%f` |
| `double` | 双精度浮点 | 8 字节 | `%lf` |
| `_Bool` / `bool` | 布尔（C99/C23） | 1 字节 | `%d` |

### 3.1.2 sizeof：查看类型大小

```c
#include <stdio.h>

int main() {
    printf("char:  %zu 字节\n", sizeof(char));
    printf("short: %zu 字节\n", sizeof(short));
    printf("int:   %zu 字节\n", sizeof(int));
    printf("long:  %zu 字节\n", sizeof(long));
    printf("float: %zu 字节\n", sizeof(float));
    printf("double:%zu 字节\n", sizeof(double));
    return 0;
}
```

> **注意**：大小可能因平台而异。`%zu` 是 `size_t` 类型的格式符。

### 3.1.3 为什么大小很重要（安全视角）

```c
char buf[8];      // 只分配了 8 字节
int value = 100;  // 需要 4 字节

// 如果把 value 写进 buf 的相邻内存，会发生什么？
// 这就是缓冲区溢出的本质——写入超出了分配的空间
```

理解每个类型占多少字节，是理解内存漏洞的第一步。

### 3.1.4 有符号与无符号

```c
int a = -10;              // 有符号，范围 -21亿 ~ 21亿
unsigned int b = 10;      // 无符号，范围 0 ~ 42亿

unsigned int x = 0;
x = x - 1;   // 下溢！结果变成 4294967295，不是 -1
printf("%u\n", x);
```

> **经典漏洞**：无符号整数下溢/上溢常被用来绕过安全检查。比如 `if (size > 0)` 检查后 `size - 1` 变成巨大值，导致缓冲区溢出。这是安全必须理解的概念。

## 3.2 变量与常量

### 3.2.1 变量声明和初始化

```c
int age;           // 声明
age = 18;          // 赋值
int score = 100;   // 声明并初始化（推荐）

int a = 1, b = 2, c = 3;   // 一次声明多个
```

> **警告**：C 语言不会自动初始化局部变量！未初始化的变量值是"垃圾"（内存中残留的随机值），这是很多 bug 和漏洞的来源。
>
> ```c
> int x;         // 未初始化，值未知！
> printf("%d", x);  // 未定义行为
> ```

### 3.2.2 常量

```c
#define MAX_SIZE 100        // 宏定义（预处理阶段替换）

const int MAX_USERS = 50;   // const 常量（推荐，有类型检查）

// 枚举常量
enum Color { RED, GREEN, BLUE };  // RED=0, GREEN=1, BLUE=2
```

## 3.3 运算符

### 3.3.1 算术运算符

```c
int a = 10, b = 3;
printf("%d\n", a + b);   // 13
printf("%d\n", a - b);   // 7
printf("%d\n", a * b);   // 30
printf("%d\n", a / b);   // 3  整数除法！不是 3.33
printf("%d\n", a % b);   // 1  取余

// 想要小数？用浮点数
printf("%f\n", 10.0 / 3); // 3.333333
```

> **坑**：`10 / 3` 在 C 里是 `3`（整数除法，截断小数）。这和 Python 的 `/` 不同。要得到小数，至少一个操作数必须是浮点类型。

### 3.3.2 复合赋值与自增

```c
int x = 5;
x += 3;   // x = x + 3 → 8
x -= 2;   // 6
x *= 4;   // 24
x++;      // 25  后置自增
++x;      // 26  前置自增
```

`i++` 和 `++i` 的区别在单独使用时一样，但在表达式中不同：

```c
int i = 5;
int a = i++;   // a = 5, i = 6（先取值后自增）
int b = ++i;   // i = 7, b = 7（先自增后取值）
```

### 3.3.3 位运算符（安全/底层核心）

```c
unsigned char a = 0b1100;  // 12
unsigned char b = 0b1010;  // 10

printf("%d\n", a & b);  // 8  按位与：1000
printf("%d\n", a | b);  // 14 按位或：1110
printf("%d\n", a ^ b);  // 6  按位异或：0110
printf("%d\n", ~a);     // 按位取反
printf("%d\n", a << 2); // 48 左移2位（×4）
printf("%d\n", a >> 1); // 6  右移1位（÷2）
```

**位运算在安全中的应用**：

```c
// 权限标志（类似 Linux 文件权限）
#define READ  4   // 100
#define WRITE 2   // 010
#define EXEC  1   // 001

int perm = READ | WRITE;   // 6 = 110，读写权限
if (perm & EXEC) {
    printf("有执行权限\n");
}

// 掩码提取
unsigned int ip = 0xC0A80101;  // 192.168.1.1
unsigned int first_octet = (ip >> 24) & 0xFF;  // 192
printf("%u\n", first_octet);
```

## 3.4 输入输出

### 3.4.1 printf 格式化输出

```c
int age = 18;
float pi = 3.14f;
char name[] = "Tom";

printf("姓名: %s\n", name);      // %s 字符串
printf("年龄: %d\n", age);       // %d 整数
printf("圆周率: %.2f\n", pi);    // %.2f 保留2位小数
printf("地址: %p\n", &age);      // %p 打印地址（安全分析常用）
printf("十六进制: 0x%x\n", age); // %x 十六进制
```

### 3.4.2 scanf 输入

```c
int age;
printf("请输入年龄: ");
scanf("%d", &age);   // 注意 & 取地址！
printf("你输入的是: %d\n", age);
```

> **超级重要的坑**：`scanf` 必须传变量的**地址**（`&age`），否则程序会崩溃或行为异常。这是 C 语言"指针"概念的第一次接触。

### 3.4.3 格式化字符串漏洞（安全重点）

```c
// 危险！用户输入直接作为格式字符串
char input[100];
scanf("%s", input);
printf(input);   // 如果用户输入 "%x %x %x"，会泄露栈上的数据！
```

> **安全警示**：永远不要让用户可控的数据作为 `printf` 的第一个参数！正确写法：
> ```c
> printf("%s", input);
> ```
> 这是经典的"格式化字符串漏洞"，是 CTF 和漏洞利用的常见考点。

## 3.5 综合示例：IP 地址转换

```c
#include <stdio.h>

int main() {
    // 把点分十进制 IP 转成 32 位整数
    unsigned int a, b, c, d;
    printf("请输入 IP (格式 a.b.c.d): ");
    scanf("%u.%u.%u.%u", &a, &b, &c, &d);
    
    // 组合成 32 位整数（网络字节序）
    unsigned int ip = (a << 24) | (b << 16) | (c << 8) | d;
    printf("整数表示: 0x%08X\n", ip);
    printf("十进制: %u\n", ip);
    
    // 反向提取
    printf("还原: %u.%u.%u.%u\n", 
           (ip >> 24) & 0xFF,
           (ip >> 16) & 0xFF,
           (ip >> 8) & 0xFF,
           ip & 0xFF);
    return 0;
}
```

这个例子综合了位运算、格式化输入输出，也是网络安全中处理 IP 的基础。

## 3.6 类型转换与安全

### 3.6.1 隐式转换的陷阱

C 会自动做类型转换，但规则复杂，容易出错：

```c
int a = 5;
unsigned int b = 10;

// a - b 的结果是什么？
// int 会被转成 unsigned int，5 - 10 变成巨大正数！
printf("%d\n", a - b);   // 可能是 -5（用 %d 解读），但实际是无符号的大数
printf("%u\n", a - b);   // 4294967291
```

> **安全影响**：这种有符号/无符号混用导致的错误，常被用来绕过安全检查。经典案例：
> ```c
> if (len < sizeof(buf)) {       // len 是 int，sizeof 返回 size_t（无符号）
>     memcpy(buf, src, len);     // 如果 len 是负数，检查通过，但 memcpy 把它当巨大值！
> }
> ```

### 3.6.2 显式转换

```c
int i = 10;
double d = (double)i;   // 显式转换，10.0

// 危险：大类型转小类型会截断
int big = 100000;
char c = (char)big;     // 截断，结果不可预期
```

### 3.6.3 浮点数精度问题

```c
float f = 0.1f;
double d = 0.1;
printf("%.20f\n", f);   // 0.10000000149011611938
printf("%.20f\n", d);   // 0.10000000000000000555

// 永远不要用 == 比较浮点数
if (0.1 + 0.2 == 0.3) { }  // 结果为假！

// 正确：比较差值
#include <math.h>
if (fabs(a - b) < 1e-9) { }  // 接近相等
```

**AI 中的影响**：深度学习用 float32 而不是 float64，就是为了性能和内存。但精度损失需要小心——梯度很小时可能被"抹掉"，这就是混合精度训练要处理的问题。
