# 第 1 章 为什么学 Rust：安全、性能、现代性

## 本章目标

- 理解 Rust 的核心价值：内存安全 + 高性能
- 理解 Rust 在 AI + 网络安全中的定位
- 建立学习 Rust 的正确预期

---

## 1.1 一个两难困境

C/C++ 性能好，但内存不安全——缓冲区溢出、UAF、Double Free 等漏洞层出不穷。

Python/Java 内存安全（有 GC），但性能差、有 GC 停顿，不适合系统级编程。

**有没有语言既能像 C++ 一样快，又能保证内存安全？**

这就是 Rust 要回答的问题。

---

## 1.2 Rust 是什么

Rust 是 Mozilla 开发的系统编程语言（2010 年正式发布），设计目标：

> **安全（Safe） + 快（Fast） + 并发（Concurrent）**

核心创新：**所有权系统（Ownership）**——在编译期就保证内存安全，不需要 GC，也不需要程序员手动 malloc/free。

```rust
fn main() {
    let s = String::from("hello");  // 分配内存
    // s 离开作用域，内存自动释放，无需 free
}
```

编译器会在编译期检查：

- 有没有使用已释放的内存（UAF）
- 有没有重复释放（Double Free）
- 有没有数据竞争（并发场景）
- 有没有空指针解引用

**这些错误在编译期就被拦截，而不是运行时崩溃或被攻击者利用。**

---

## 1.3 三性对比

| 特性 | C/C++ | Rust | Python/Go |
|------|-------|------|----------|
| 性能 | 极高 | 极高（相当） | 较低 |
| 内存安全 | 手动保证，易出错 | 编译期保证 | GC 保证 |
| GC 停顿 | 无 | 无 | 有 |
| 学习曲线 | 中（难精通） | 陡峭 | 平缓 |
| 底层控制 | 强 | 强 | 弱 |

Rust 的独特之处：**零成本抽象**——高级特性（迭代器、所有权）编译后和手写的底层代码性能一样，没有额外开销。

## 1.4 Rust 在网络安全中的价值

### 1.4.1 安全工具的新宠

越来越多安全工具用 Rust 重写：

- **ripgrep**：超快文本搜索（替代 grep）
- **fd**：文件查找
- **bat**：cat 替代品
- **Zed**：代码编辑器
- 大量 CTF 工具、漏洞扫描器、C2 框架

为什么？因为安全工具本身也应该安全——你不会希望一个漏洞扫描器自己有缓冲区溢出漏洞。

### 1.4.2 内存安全 = 减少攻击面

用 C 写的程序，内存漏洞是"默认选项"；用 Rust，编译器帮你堵上这类漏洞。

> 微软安全团队研究：约 70% 的严重漏洞是内存安全漏洞。如果这些软件用 Rust 写，这些漏洞大部分不会出现。

### 1.4.3 系统级安全组件

- 操作系统内核（Linux 正在引入 Rust）
- 浏览器引擎（Firefox 的 Servo 部分）
- 沙箱、隔离组件
- 加密库、协议实现

## 1.5 Rust 在 AI 中的价值

### 1.5.1 高性能推理

- **candle**：Hugging Face 的 Rust 深度学习框架
- **llama.cpp 的 Rust 绑定**
- 大模型推理服务需要高性能 + 内存安全 + 并发，Rust 很合适

### 1.5.2 AI 基础设施

- 向量数据库（如 Qdrant）用 Rust 写
- 高性能数据处理管道
- 模型服务的高并发 API

---

## 1.6 学习 Rust 的心理准备

### 1.6.1 你会"战斗"编译器

Rust 的编译器（ borrow checker，借用检查器）很严格，初学者经常"编译不过"。这是正常的——编译器在帮你抓错误。

> **心态转变**：别把编译错误当敌人，把它当老师。它会告诉你为什么这段代码不安全。当你理解了规则，写代码自然就对了。

### 1.6.2 核心概念就三个

1. **所有权（Ownership）**
2. **借用（Borrowing）**
3. **生命周期（Lifetime）**

这三个搞懂了，Rust 就通了。第 4 章会集中讲。
