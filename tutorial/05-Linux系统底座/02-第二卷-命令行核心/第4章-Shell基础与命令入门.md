## 4.1 让命令行变快的几个技巧

在正式学命令之前，先学几个"加速器"。这些技巧能让你后面的学习效率和工作体验提升一大截。

### 4.1.1 Tab 补全

敲命令或路径时，按 **`Tab`** 键，Shell 会自动补全。

```bash
# 输入 l 后按 Tab，可能补全为 ls
l<Tab>

# 输入 /etc/pass 后按 Tab，补全为 /etc/passwd
cat /etc/pass<Tab>
```

- 如果有多个匹配项，按两下 `Tab` 会列出所有可能。
- 补全不仅对命令有效，对文件名、目录名、用户名也有效。

> 这是 Linux 用户最依赖的技巧之一。**养成任何时候都先按 Tab 的习惯**，既快又不容易拼错。

### 4.1.2 历史记录

Shell 会记住你敲过的命令。

| 操作 | 作用 |
|------|------|
| 按 `↑` / `↓` 方向键 | 在历史命令间切换 |
| `history` | 列出所有历史命令 |
| `history 10` | 显示最近 10 条 |
| `!编号` | 执行历史中第"编号"条命令 |
| `!!` | 重复上一条命令 |
| `!$` | 引用上一条命令的最后一个参数 |

例如：

```bash
cat /var/log/auth.log
sudo !$        # 等价于 sudo /var/log/auth.log，常用于给上条命令加 sudo
```

还可搜索历史：按 `Ctrl + R`，输入关键词，找到以前敲过的命令。

### 4.1.3 光标移动快捷键

| 快捷键 | 作用 |
|--------|------|
| `Ctrl + A` | 光标跳到行首 |
| `Ctrl + E` | 光标跳到行尾 |
| `Ctrl + U` | 删除光标前所有内容 |
| `Ctrl + K` | 删除光标后所有内容 |
| `Ctrl + L` | 清屏（等同 `clear`） |
| `Ctrl + C` | 终止当前正在运行的命令 |
| `Ctrl + D` | 退出终端 / 表示输入结束 |

这些技巧在长命令、输错命令时特别有用。

## 4.2 命令的组成部分

一条 Linux 命令通常由三部分构成：

```bash
命令 [选项] [参数]
```

### 4.2.1 命令（Command）

要执行什么操作，如 `ls`（列目录）、`cat`（看文件）、`whoami`（我是谁）。

### 4.2.2 选项（Option / Flag）

调整命令的行为，通常以 `-` 或 `--` 开头。

```bash
ls -l          # 单个短选项
ls -la         # 多个短选项合并
ls --all       # 长选项
ls -l --all    # 混合使用
```

选项的本质是"开关"——告诉命令用哪种模式工作。短选项简洁，长选项可读性好。

### 4.2.3 参数（Argument / Operand）

命令作用的对象，通常是文件名、目录名、用户名等。

```bash
cat /etc/passwd       # 参数是文件
ls /home/zhangsan     # 参数是目录
```

有些命令可以没有参数（如 `whoami`），有些需要多个参数（如 `cp 源 目标`）。

### 4.2.4 一个完整例子

```bash
ls -lah /var/log
```

拆解：

- `ls`：命令
- `-l`：详细列表格式
- `-a`：显示隐藏文件
- `-h`：以人类可读的大小显示（如 4K、2M）
- `/var/log`：参数，要列出的目录

以后看到任何命令，都这样拆解，就不难理解了。

## 4.3 三种查帮助的方式

记不住命令参数是常态，关键是会查。

### 4.3.1 `--help`：快速帮助

```bash
ls --help
```

几乎所有命令都支持，输出简洁的用法说明。

### 4.3.2 `man`：完整手册

```bash
man ls
```

man = manual（手册）。输出非常详细，包含所有选项和示例。

操作：

| 按键 | 作用 |
|------|------|
| 空格 / Page Down | 下一页 |
| Page Up / b | 上一页 |
| `/关键词` | 搜索关键词 |
| n | 跳到下一个匹配 |
| q | 退出 |

> man 手册有章节编号：`man 5 passwd` 看的是 passwd 文件格式（第 5 章），`man 1 passwd` 看的是 passwd 命令（第 1 章）。数字代表手册章节类型：1=命令，5=文件格式，8=管理命令。

### 4.3.3 `help`：Shell 内置命令帮助

有些命令是 Shell 自带的（如 `cd`、`echo`），没有 man 页，要用：

```bash
help cd
```

> **小白问**：怎么知道一个命令是外部命令还是 Shell 内置？
>
> 用 `type` 命令：
> ```bash
> type ls      # 显示 ls 是外部命令及其路径
> type cd      # 显示 cd is a shell builtin
> ```

### 4.3.4 `apropos`：按关键词找命令

当你"想做某件事但忘了命令叫什么"时：

```bash
apropos "list directory"
```

它会搜索手册页描述，列出相关命令。这是个救命工具。

## 4.4 环境变量与 PATH

### 4.4.1 为什么敲 `ls` 就能运行

你在任何目录敲 `ls` 都能执行，是因为系统知道去哪里找这个程序。这个"去哪里找"的清单，就是 **PATH 环境变量**。

查看 PATH：

```bash
echo $PATH
```

输出类似：

```bash
/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin
```

冒号分隔的每个路径都是一个"搜索目录"。当你敲 `ls`，Shell 按这个顺序逐个目录找 `ls` 这个可执行文件，找到就运行。

### 4.4.2 环境变量是什么

环境变量是 Shell 维护的一些"全局设置"，格式是 `名称=值`。常见的：

| 变量 | 含义 |
|------|------|
| `$HOME` | 你的家目录路径 |
| `$USER` | 当前用户名 |
| `$SHELL` | 当前 Shell |
| `$PATH` | 命令搜索路径 |
| `$PWD` | 当前工作目录 |
| `$LANG` | 语言设置 |

查看某个变量：

```bash
echo $HOME
echo $USER
```

查看所有环境变量：

```bash
env
# 或
printenv
```

### 4.4.3 临时设置环境变量

```bash
MYVAR="hello"
echo $MYVAR
```

注意：**等号两边不能有空格**。这个变量只在当前 Shell 会话有效，关闭终端就没了。

想永久生效，需要写进 `~/.bashrc` 文件（第 12 章详解）。

> **安全提示**：PATH 如果被恶意修改（比如把当前目录 `.` 放到最前面），可能导致你执行到攻击者伪造的同名命令（如假的 `ls`）。所以不要随意修改 PATH，尤其不要在生产环境把 `.` 加进 PATH。这是真实的攻击手法之一。

## 4.5 输入输出的重定向概念（初识）

第 7 章会详解重定向，这里先建立概念。

默认情况下：

- 命令从**键盘**读取输入 → 标准输入（stdin）
- 命令把结果输出到**屏幕** → 标准输出（stdout）
- 命令把错误信息输出到**屏幕** → 标准错误（stderr）

Shell 允许你改变这些"默认流向"：

```bash
echo "hello" > file.txt      # 输出写到文件，而不是屏幕
cat < file.txt               # 从文件读入，而不是键盘
```

`>` 是输出重定向，`<` 是输入重定向。记住：**箭头指向数据流动的方向**。第 7 章会展开讲。

## 4.6 命令链：一行做多件事

### 4.6.1 分号 `;`

按顺序执行多个命令，不管前一个成功与否：

```bash
cd /home; ls; pwd
```

### 4.6.2 `&&`（逻辑与）

只有前一个命令**成功**，才执行后一个：

```bash
mkdir test && cd test
```

如果 `mkdir` 失败（比如目录已存在），`cd` 不会执行。这在脚本中很常用——保证步骤按顺序成功推进。

### 4.6.3 `||`（逻辑或）

只有前一个命令**失败**，才执行后一个：

```bash
cat nofile || echo "文件不存在"
```

常用于"失败时给个提示或补救"。

### 4.6.4 一个实用组合

```bash
ping -c 1 example.com && echo "网络正常" || echo "网络不通"
```

先 ping 一次，成功打印"网络正常"，失败打印"网络不通"。这是最简洁的网络检测写法。

## 4.7 常见报错与解决

| 报错 | 原因 | 解决 |
|------|------|------|
| `command not found` | 拼错 / 未安装 / 不在 PATH | 用 `type` 检查；`apt install` 安装 |
| `No such option` | 选项不支持 | 用 `--help` 查正确选项 |
| `Permission denied` | 权限不足 | 加 `sudo`；检查文件权限 |
| `Is a directory` | 对目录用了读文件命令 | 检查路径是否指向目录 |
