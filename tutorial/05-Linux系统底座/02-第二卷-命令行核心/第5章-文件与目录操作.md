# 第 5 章 文件与目录操作

## 本章目标

读完这一章，你将能够：

- 熟练创建、查看、复制、移动、删除文件和目录
- 掌握 `find` 和 `locate` 查找文件，特别是按权限、时间、大小的高级查找
- 理解硬链接与软链接的区别
- 掌握打包压缩（tar / gzip / zip）
- 用文件操作命令完成安全场景任务

---

## 5.1 浏览目录与文件

### 5.1.1 `ls`：列出内容

```bash
ls              # 列出当前目录
ls -l           # 详细列表（long）
ls -a           # 显示隐藏文件（以 . 开头）
ls -la          # 两者结合，最常用
ls -lh          # 人类可读的大小（K/M/G）
ls -lt          # 按修改时间排序
ls -lS          # 按大小排序
ls -R           # 递归列出子目录
```

详细列表的输出示例：

```bash
-rw-r--r-- 1 zhangsan zhangsan 4.0K Nov 25 10:30 note.txt
drwxr-xr-x 2 zhangsan zhangsan 4.0K Nov 25 09:00 Documents
```

第一列是权限，第二列是硬链接数，第三四列是所有者/组，第五列是大小，后面是时间和名字。

> **安全场景**：`ls -la` 是检查目录的第一动作。比如查看家目录有没有可疑的隐藏文件（攻击者常把后门藏在 `.` 开头的文件里）：
> ```bash
> ls -la ~
> ```

### 5.1.2 `pwd` 与 `cd`

```bash
pwd             # 显示当前路径
cd /etc         # 切换到 /etc
cd ~            # 回家目录
cd ..           # 回上级
cd -            # 回到上一个目录
cd              # 不带参数，回家目录
```

### 5.1.3 `file`：判断文件类型

```bash
file /etc/passwd
file /bin/ls
file photo.jpg
```

`file` 通过检查文件内容和魔数（magic number）判断真实类型，而不只看扩展名。

> **安全场景**：攻击者会把可执行文件伪装成图片（`shell.jpg` 实际是 ELF 可执行文件）。用 `file` 一查便知真伪。

## 5.2 查看文件内容

### 5.2.1 `cat`：一次性显示全部

```bash
cat /etc/passwd
cat -n file.txt      # 显示行号
cat file1 file2      # 显示多个文件
```

适合小文件。大文件会刷屏，用下面的工具。

### 5.2.2 `less` / `more`：分页查看

```bash
less /var/log/syslog
```

`less` 是 `more` 的改进版，支持上下翻页、搜索。操作：空格翻页，`b` 上翻，`/关键词` 搜索，`q` 退出。

> 记住：**看长文件用 less，别用 cat 刷屏**。

### 5.2.3 `head` / `tail`：看开头和结尾

```bash
head file.txt           # 前 10 行
head -n 20 file.txt     # 前 20 行
tail file.txt           # 后 10 行
tail -n 50 file.txt     # 后 50 行
tail -f /var/log/syslog # 实时跟踪文件末尾（日志监控利器）
```

> **安全场景**：`tail -f` 是实时监控日志的经典方式。盯着认证日志，有人暴力破解时你能立刻看到：
> ```bash
> sudo tail -f /var/log/auth.log
> ```

### 5.2.4 `wc`：统计行数、词数、字节数

```bash
wc file.txt         # 输出：行数 词数 字节数 文件名
wc -l file.txt      # 只统计行数
wc -w file.txt      # 只统计词数
wc -c file.txt      # 只统计字节数
```

> **安全场景**：统计日志里失败登录的次数：
> ```bash
> grep "Failed password" /var/log/auth.log | wc -l
> ```

## 5.3 创建、复制、移动、删除

### 5.3.1 `touch`：创建空文件 / 更新时间戳

```bash
touch newfile.txt
touch -t 202601010000 file.txt   # 修改时间戳（取证/隐藏痕迹相关）
```

### 5.3.2 `mkdir`：创建目录

```bash
mkdir mydir
mkdir -p a/b/c       # 递归创建多级目录，父目录不存在也一起建
mkdir -m 700 secret  # 创建时指定权限
```

`-p` 非常重要，避免"父目录不存在"的报错。

### 5.3.3 `cp`：复制

```bash
cp file.txt backup.txt          # 复制文件
cp file.txt /tmp/               # 复制到目录
cp -r dir/ /tmp/                # 递归复制目录（-r 必需）
cp -a dir/ /tmp/                # 归档模式，保留权限、时间戳等所有属性
cp -i file.txt backup.txt       # 覆盖前询问（i = interactive）
```

> **小白问**：`cp -r` 和 `cp -a` 有什么区别？
>
> `-r` 只是递归复制内容，权限等属性可能变化；`-a` 是"归档"，完整保留权限、属主、时间戳、符号链接等，做备份时应该用 `-a`。

### 5.3.4 `mv`：移动 / 重命名

```bash
mv file.txt newname.txt         # 重命名
mv file.txt /tmp/               # 移动
mv -i file.txt /tmp/            # 覆盖前询问
```

Linux 里"重命名"其实就是"移动到同一个目录下的另一个名字"，所以只有一个 `mv` 命令。

### 5.3.5 `rm`：删除

```bash
rm file.txt
rm -i file.txt       # 删除前询问
rm -r dir/           # 递归删除目录
rm -f file.txt       # 强制删除，不提示不存在的文件
rm -rf dir/          # 强制递归删除（极度危险！）
```

> ⚠️ **警告**：`rm -rf` 是 Linux 里最危险的命令之一，误用可以瞬间删除整个系统且无法恢复。永远不要在根目录或不确定路径时使用，尤其不要 `rm -rf /` 或 `rm -rf $变量`（变量为空时可能变成 `rm -rf /`）。**删之前先 `pwd` 和 `ls` 确认位置。**
>
> 更安全的做法：先用 `rm -i` 或把要删的文件移到"回收站目录"观察一段时间再彻底删除。

## 5.4 查找文件

### 5.4.1 `find`：功能最强

`find` 是 Linux 查找文件的瑞士军刀，语法：

```bash
find 起始目录 [条件] [动作]
```

基础用法：

```bash
find /home -name "*.txt"          # 按名字找
find / -name "passwd"             # 全盘找（可能很慢）
find . -type f                    # 只找文件
find . -type d                    # 只找目录
find /var/log -mtime -7           # 找 7 天内修改过的
find /home -size +10M             # 找大于 10M 的
find /tmp -user zhangsan          # 找属于某用户的
```

组合条件：

```bash
find /home -name "*.log" -size +1M        # -a 隐含的"与"
find /home \( -name "*.tmp" -o -name "*.bak" \)   # -o 是"或"，注意括号转义
```

执行动作：

```bash
find /tmp -name "*.tmp" -delete                    # 直接删除
find /home -name "*.log" -exec grep -l "ERROR" {} \;  # 对每个结果执行命令
```

`-exec` 里的 `{}` 代表找到的每个文件，`\;` 是结束符。这是极强大的批量处理模式。

> **安全场景**（非常重要）：
> ```bash
> # 查找所有 SUID 文件——攻击者提权的常见入口
> find / -perm -4000 -type f 2>/dev/null
>
> # 查找 7 天内被修改的系统配置文件（可能被入侵篡改）
> find /etc -mtime -7 -type f
>
> # 查找所有人可写的文件（权限过松）
> find / -perm -o=w -type f 2>/dev/null
> ```
>
> `2>/dev/null` 是把错误信息丢弃，避免满屏 "Permission denied"。重定向第 7 章详解。

### 5.4.2 `locate`：快速但依赖数据库

```bash
locate passwd
```

`locate` 查的是预建数据库（`updatedb` 更新），速度极快，但结果可能不是最新的。

```bash
sudo updatedb       # 手动更新数据库
```

适合"找已知名字的文件"，不适合"找最近修改的"。

## 5.5 链接：硬链接与软链接

### 5.5.1 软链接（符号链接）

类似 Windows 的快捷方式：

```bash
ln -s /path/to/original linkname
```

```bash
ln -s /etc/passwd ~/passwd_link
ls -l ~/passwd_link
# lrwxrwxrwx 1 zhangsan zhangsan 11 Nov 25 10:30 passwd_link -> /etc/passwd
```

特点：

- 存的是目标路径，删除原文件后链接失效（断链）
- 可以跨文件系统、可以指向目录
- 权限显示为 `lrwxrwxrwx`（无用，实际看目标权限）

### 5.5.2 硬链接

```bash
ln /path/to/original linkname
```

特点：

- 是同一个文件的另一个"名字"，指向同一份数据（同一个 inode）
- 删除原文件，硬链接仍能访问数据
- 不能跨文件系统，不能指向目录
- 修改任一名字，内容同步变化

> **安全场景**：攻击者有时会用硬链接在受保护目录留"后门入口"，或用软链接引导管理员访问恶意文件。审计时留意 `find -type l`（软链接）和异常多硬链接的文件。

## 5.6 打包与压缩

### 5.6.1 `tar`：打包（归档）

```bash
tar -cvf archive.tar file1 file2      # 打包（-c 创建，-v 详细，-f 指定文件名）
tar -tvf archive.tar                  # 查看包内容（-t 列出）
tar -xvf archive.tar                  # 解包（-x 提取）
tar -xvf archive.tar -C /tmp          # 解包到指定目录
```

常用组合（加压缩）：

```bash
tar -czvf archive.tar.gz dir/         # 打包并用 gzip 压缩（z）
tar -xzvf archive.tar.gz              # 解压 gzip 包
tar -cjvf archive.tar.bz2 dir/        # 用 bzip2 压缩（j）
tar -xjvf archive.tar.bz2             # 解压 bzip2 包
```

> **记忆技巧**：`c`=create 创建，`x`=extract 提取，`t`=list 列出，`v`=verbose 详细，`f`=file 文件，`z`=gzip，`j`=bzip2。

### 5.6.2 `gzip` / `gunzip`

```bash
gzip file.txt        # 压缩成 file.txt.gz，原文件消失
gunzip file.txt.gz   # 解压
gzip -d file.txt.gz  # 同上
```

### 5.6.3 `zip` / `unzip`

```bash
zip archive.zip file1 file2
unzip archive.zip
unzip -l archive.zip       # 查看内容
```

> **安全场景**：取证时打包保留证据：
> ```bash
> tar -czvf evidence_$(date +%F).tar.gz /var/log/
> ```
> `$(date +%F)` 会替换成当天日期（命令替换，第 12 章详解）。

## 5.7 常见报错与解决

| 报错 | 原因 | 解决 |
|------|------|------|
| `No such file or directory` | 路径不对 | 用 `pwd`/`ls` 确认 |
| `Is a directory` | 对目录用了文件操作 | 加 `-r`（复制/删除目录） |
| `Permission denied` | 权限不足 | 加 `sudo` 或改权限 |
| `cannot remove ... Is a directory` | `rm` 没加 `-r` | 用 `rm -r` |
| `omitting directory` | `cp` 复制目录没加 `-r` | 用 `cp -r` |

## 5.8 本章总结

| 命令 | 作用 |
|------|------|
| `ls -la` | 列出全部文件含隐藏，看权限时间 |
| `file` | 判断真实文件类型（识别伪装） |
| `cat` / `less` | 查看小文件 / 分页看大文件 |
| `head` / `tail` | 看开头 / 结尾，`tail -f` 实时跟踪 |
| `wc -l` | 统计行数 |
| `touch` / `mkdir -p` | 创建文件 / 递归创建目录 |
| `cp -r/-a`、`mv`、`rm -rf` | 复制 / 移动 / 删除（rm 慎用） |
| `find` | 按名字/类型/时间/大小/权限查找，`-exec` 批量处理 |
| `ln -s` / `ln` | 软链接 / 硬链接 |
| `tar -czvf` / `-xzvf` | 打包压缩 / 解包 |
