## 32.3 检测规则设计

`config/rules.conf`：

```bash
# 规则格式: 规则名:类型:阈值:时间窗口(秒)
SSH_BRUTE_FORCE:count:10:300       # 5分钟内失败10次
WEB_SCAN:count:50:60               # 1分钟内404达50次（目录扫描）
SQL_INJECTION:pattern:1:0          # 出现1次注入特征
SCANNER_UA:pattern:1:0             # 扫描器UA
ROOT_LOGIN:pattern:1:0             # root登录尝试
```

规则分两类：

- **count 型**：时间窗口内事件数超过阈值（暴力破解、扫描）
- **pattern 型**：匹配到特征立即告警（注入、扫描器）

## 32.4 检测引擎（Python）

`bin/detector.py`：

```python
#!/usr/bin/env python3
"""日志入侵检测引擎"""
import re
import sqlite3
from datetime import datetime, timedelta
from collections import defaultdict

AUTH_LOG = "/var/log/auth.log"
NGINX_LOG = "/var/log/nginx/access.log"
DB = "data/events.db"

# 特征规则
PATTERNS = {
    "SQL_INJECTION": re.compile(r"(union\s+select|select.+from|\.\./|<script|or\s+1=1)", re.I),
    "SCANNER_UA": re.compile(r"(sqlmap|nmap|nikto|masscan|acunetix)", re.I),
    "WEB_SHELL": re.compile(r"(\.php.*(cmd|exec|system)|base64_decode)", re.I),
}

def init_db():
    conn = sqlite3.connect(DB)
    conn.execute("""CREATE TABLE IF NOT EXISTS events (
        id INTEGER PRIMARY KEY, ts TEXT, type TEXT, src TEXT, detail TEXT)""")
    conn.commit()
    return conn

def parse_auth(log):
    """解析认证日志，返回失败登录事件"""
    events = []
    try:
        with open(log, encoding="utf-8", errors="ignore") as f:
            for line in f:
                if "Failed password" in line:
                    ip_match = re.search(r"from (\d+\.\d+\.\d+\.\d+)", line)
                    user_match = re.search(r"for (\w+)", line)
                    if ip_match:
                        events.append({
                            "type": "SSH_FAIL",
                            "src": ip_match.group(1),
                            "detail": f"用户={user_match.group(1) if user_match else '未知'}"
                        })
                elif "Accepted password" in line:
                    ip_match = re.search(r"from (\d+\.\d+\.\d+\.\d+)", line)
                    if ip_match:
                        events.append({"type": "SSH_SUCCESS", "src": ip_match.group(1), "detail": "登录成功"})
    except FileNotFoundError:
        pass
    return events

def parse_nginx(log):
    """解析 Nginx 日志"""
    events = []
    try:
        with open(log, encoding="utf-8", errors="ignore") as f:
            for line in f:
                for name, pattern in PATTERNS.items():
                    if pattern.search(line):
                        ip = line.split()[0]
                        events.append({"type": name, "src": ip, "detail": line[:120]})
                # 404 统计
                parts = line.split()
                if len(parts) > 8 and parts[8] == "404":
                    events.append({"type": "HTTP_404", "src": parts[0], "detail": parts[6]})
    except FileNotFoundError:
        pass
    return events

def detect(conn, events):
    """检测规则引擎"""
    alerts = []
    now = datetime.now()

    # count 型：统计各 IP 的失败登录
    fail_count = defaultdict(int)
    for e in events:
        if e["type"] == "SSH_FAIL":
            fail_count[e["src"]] += 1

    for ip, count in fail_count.items():
        if count >= 10:
            alerts.append(f"[HIGH] SSH暴力破解: {ip} 失败 {count} 次")

    # 404 扫描检测
    scan_count = defaultdict(int)
    for e in events:
        if e["type"] == "HTTP_404":
            scan_count[e["src"]] += 1
    for ip, count in scan_count.items():
        if count >= 50:
            alerts.append(f"[MEDIUM] Web目录扫描: {ip} 404达 {count} 次")

    # pattern 型：立即告警
    for e in events:
        if e["type"] in PATTERNS:
            alerts.append(f"[HIGH] {e['type']}: {e['src']} - {e['detail']}")
        if e["type"] == "SSH_SUCCESS":
            alerts.append(f"[INFO] 登录成功: {e['src']}")

    # 存入数据库
    for e in events:
        conn.execute("INSERT INTO events (ts,type,src,detail) VALUES (?,?,?,?)",
                     (now.isoformat(), e["type"], e["src"], e["detail"]))
    conn.commit()
    return alerts

def main():
    conn = init_db()
    events = parse_auth(AUTH_LOG) + parse_nginx(NGINX_LOG)
    alerts = detect(conn, events)
    for alert in alerts:
        print(alert)
    conn.close()

if __name__ == "__main__":
    main()
```

这个引擎用正则（第 14 章）、Python 数据结构、SQLite——把多章知识整合。

## 32.5 告警模块

`bin/alerter.sh`：

```bash
#!/bin/bash
# 告警分发
set -euo pipefail

ALERT_LOG="$(dirname "$0")/../logs/alerts.log"
WEBHOOK_URL=""   # 可选：钉钉/企业微信 webhook

alert() {
    local level=$1 msg=$2
    local line="[$(date +'%F %T')] [$level] $msg"
    echo "$line" | tee -a "$ALERT_LOG"

    # 可选：发送 Webhook（企业微信示例）
    if [ -n "$WEBHOOK_URL" ]; then
        curl -s -X POST "$WEBHOOK_URL" \
          -H 'Content-Type: application/json' \
          -d "{\"msgtype\":\"text\",\"text\":{\"content\":\"$line\"}}" >/dev/null
    fi
}

# 从检测结果读取告警并分发
python3 "$(dirname "$0")/detector.py" | while IFS= read -r line; do
    case "$line" in
        \[HIGH\]*)   alert "HIGH" "$line" ;;
        \[MEDIUM\]*) alert "MEDIUM" "$line" ;;
        \[INFO\]*)   alert "INFO" "$line" ;;
    esac
done
```

告警分级（HIGH/MEDIUM/INFO）让你能区分紧急程度。Webhook 可接入钉钉、企业微信、Slack 等，实现实时通知。

## 32.8 可视化看板（简单版）

用 Python 生成一个 HTML 报告：

```python
# 生成简单统计报告
import sqlite3
conn = sqlite3.connect("data/events.db")
rows = conn.execute("SELECT type, COUNT(*) FROM events GROUP BY type ORDER BY COUNT(*) DESC").fetchall()

html = "<html><head><title>IDS 报告</title></head><body>"
html += "<h1>入侵检测统计</h1><table border='1'>"
html += "<tr><th>事件类型</th><th>数量</th></tr>"
for typ, count in rows:
    html += f"<tr><td>{typ}</td><td>{count}</td></tr>"
html += "</table></body></html>"

open("reports/dashboard.html", "w").write(html)
```

用浏览器打开 `reports/dashboard.html` 就能看到统计。这是最简单的"看板"，可进一步用 Grafana、ELK 做专业可视化。

## 32.9 系统优化方向

| 方向 | 说明 |
|------|------|
| 增量读取 | 记录文件偏移，只处理新增日志（避免重复告警） |
| 白名单 | 忽略已知可信 IP，减少误报 |
| 规则热加载 | 修改规则无需重启 |
| 关联分析 | 关联多个事件（先扫描后破解） |
| 专业方案 | 用 ELK/Splunk/Wazuh 替代自建系统 |

> **现实建议**：自建 IDS 用于学习和小规模场景。生产环境建议用 Wazuh、Suricata、ELK 等成熟方案——它们有完善的规则库、告警机制和可扩展性。自建的价值在于**理解原理**。
