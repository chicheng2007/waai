## 12.1 变量

### 12.1.1 定义与引用

```bash
name="张三"          # 等号两边不能有空格！
echo $name           # 引用变量，输出 张三
echo ${name}         # 加花括号更明确（推荐）
echo "你好，$name"    # 字符串中引用
```

> ⚠️ **最常见的坑**：`name = "张三"`（等号两边有空格）会被 Shell 当成命令 `name` 和参数，报错。**定义变量时等号两边绝不能有空格**。

用花括号 `${name}` 的好处：紧跟其他字符时不会歧义：

```bash
echo "$nameabc"      # Shell 会找变量 nameabc（可能为空）
echo "${name}abc"    # 明确是变量 name 后接 abc
```

### 12.1.2 变量命名规则

- 只能含字母、数字、下划线，不能以数字开头
- 区分大小写（`Name` 和 `name` 不同）
- 习惯上：普通变量小写，环境变量大写

### 12.1.3 只读变量与删除

```bash
readonly PI=3.14     # 只读，不能修改
unset name           # 删除变量
```

### 12.1.4 环境变量与 export

普通变量只在当前 Shell 有效，子进程看不到。`export` 把它变成环境变量，传给子进程：

```bash
MY_VAR="hello"
export MY_VAR
```

或一步到位：

```bash
export MY_VAR="hello"
```

前面学的 `PATH`、`HOME` 都是环境变量。想让变量永久生效，写进 `~/.bashrc`（bash 配置）或 `/etc/profile`（全局）：

```bash
echo 'export MY_VAR="hello"' >> ~/.bashrc
source ~/.bashrc       # 立即生效（source 让配置在当前 Shell 执行）
```

### 12.1.5 特殊变量

| 变量 | 含义 |
|------|------|
| `$0` | 脚本名 |
| `$1`, `$2`, ... | 第 1、2 个参数 |
| `$#` | 参数个数 |
| `$*` / `$@` | 所有参数 |
| `$?` | 上一条命令退出码 |
| `$$` | 当前脚本的 PID |
| `$USER` | 当前用户名 |

示例脚本：

```bash
#!/bin/bash
echo "脚本名: $0"
echo "第一个参数: $1"
echo "参数总数: $#"
echo "所有参数: $@"
```

运行 `bash script.sh foo bar`，你会看到参数如何传入。这让脚本能接受用户输入，变得通用。

### 12.1.6 命令替换与算术

```bash
files=$(ls | wc -l)      # 命令替换：把命令输出存入变量（推荐 $()）
echo "文件数: $files"

a=5; b=3
sum=$((a + b))           # 算术运算用 $(( ))
echo $sum

# 算术运算符：+ - * / % **（幂）
echo $((2 ** 10))        # 1024
```

> **注意**：Shell 默认把变量当字符串，算术要用 `$(( ))`。`expr` 是老写法，现在少用。

## 12.2 条件判断

### 12.2.1 if 语句

```bash
if 条件; then
    命令
elif 条件; then
    命令
else
    命令
fi
```

记住结尾是倒过来的 `fi`。

### 12.2.2 test 命令与 [ ]

条件通常用 `test` 命令或其简写 `[ ]`：

```bash
[ -f file.txt ]          # 文件是否存在且是普通文件
[ -d dir ]               # 目录是否存在
[ -e path ]              # 路径是否存在（任意类型）
[ -r file ]              # 是否可读
[ -w file ]              # 是否可写
[ -x file ]              # 是否可执行
[ -s file ]              # 文件是否非空
[ "$a" = "$b" ]          # 字符串相等
[ "$a" != "$b" ]         # 字符串不等
[ -z "$a" ]              # 字符串为空
[ -n "$a" ]              # 字符串非空
[ "$a" -eq "$b" ]        # 数字相等
[ "$a" -ne "$b" ]        # 数字不等
[ "$a" -gt "$b" ]        # 大于
[ "$a" -lt "$b" ]        # 小于
[ "$a" -ge "$b" ]        # 大于等于
[ "$a" -le "$b" ]        # 小于等于
```

> ⚠️ **`[ ]` 里前后都要有空格**！`[ -f file ]` 正确，`[-f file]` 错误。因为 `[` 本身是个命令，需要空格分隔参数。
>
> 字符串比较用 `=`，数字比较用 `-eq`。搞混会导致诡异错误。

### 12.2.3 逻辑组合

```bash
[ -f file ] && [ -r file ]       # 两个条件都成立（与）
[ -f file ] || [ -d file ]       # 至少一个成立（或）
[ ! -f file ]                    # 取反（非）

# 在 [[ ]] 里可以用 && ||（bash 增强版，推荐）
[[ -f file && -r file ]]
```

推荐用 `[[ ]]`（双方括号）替代 `[ ]`：它能用 `&&`、`||`、支持模式匹配、且不会因空变量出错。但注意它是 bash 特性，sh 不支持。

### 12.2.4 条件判断示例

```bash
#!/bin/bash
# 检查文件是否存在且可读
if [ -f /etc/passwd ] && [ -r /etc/passwd ]; then
    echo "文件存在且可读"
else
    echo "文件不存在或不可读"
fi

# 判断数字大小
num=85
if [ $num -ge 60 ]; then
    echo "及格"
else
    echo "不及格"
fi

# 判断字符串
read -p "输入 yes/no: " ans
if [ "$ans" = "yes" ]; then
    echo "你选择了 yes"
fi
```

> **最佳实践**：字符串变量在 `[ ]` 里要加引号（如 `[ "$ans" = "yes" ]`），否则变量为空时会变成 `[ = yes ]` 语法错误。

### 12.2.5 case 多分支

当有多个互斥选项时，`case` 比一长串 `if-elif` 清晰：

```bash
case $变量 in
    模式1)
        命令
        ;;
    模式2|模式3)
        命令
        ;;
    *)
        默认命令
        ;;
esac
```

示例：

```bash
#!/bin/bash
read -p "请输入服务名(nginx/mysql/ssh): " svc
case $svc in
    nginx)
        echo "重启 nginx"
        sudo systemctl restart nginx
        ;;
    mysql)
        echo "重启 mysql"
        sudo systemctl restart mysql
        ;;
    ssh|sshd)
        echo "重启 ssh"
        sudo systemctl restart ssh
        ;;
    *)
        echo "未知服务: $svc"
        exit 1
        ;;
esac
```

结尾是 `esac`（case 倒过来）。

## 12.3 循环

### 12.3.1 for 循环（遍历列表）

```bash
for 变量 in 列表; do
    命令
done
```

示例：

```bash
# 遍历固定列表
for fruit in apple banana orange; do
    echo "水果: $fruit"
done

# 遍历数字范围（seq）
for i in $(seq 1 10); do
    echo "第 $i 次"
done

# C 风格 for 循环（bash 支持）
for ((i=1; i<=10; i++)); do
    echo $i
done

# 遍历文件
for f in /var/log/*.log; do
    echo "处理: $f"
done
```

### 12.3.2 while 循环（条件为真时重复）

```bash
while 条件; do
    命令
done
```

示例：

```bash
# 计数
i=1
while [ $i -le 5 ]; do
    echo $i
    i=$((i + 1))       # 别忘了更新条件变量，否则死循环！
done

# 逐行读取文件（经典用法）
while read line; do
    echo "行: $line"
done < file.txt
```

`while read line; do ... done < file` 是逐行处理文件的标准写法，比 `cat file | while` 更好（后者在子 Shell 中，变量修改不会保留）。

### 12.3.3 until 循环（条件为假时重复）

与 while 相反：

```bash
until [ $i -ge 5 ]; do
    echo $i
    i=$((i+1))
done
```

### 12.3.4 循环控制

```bash
break        # 跳出循环
continue     # 跳过本次循环，进入下一次
```

示例：

```bash
for i in $(seq 1 10); do
    if [ $i -eq 5 ]; then
        break           # 到 5 就停
    fi
    if [ $i -eq 2 ]; then
        continue        # 跳过 2
    fi
    echo $i
done
# 输出 1 3 4
```

### 12.3.5 无限循环

```bash
while true; do
    echo "持续运行中..."
    sleep 5
done
```

配合 `trap` 捕获 Ctrl+C 做清理（第 16 章详讲）。

## 12.4 综合实战：批量安全检查脚本

把变量、条件、循环组合起来，写一个批量检查脚本：

```bash
#!/bin/bash
# 批量检查多个主机的端口是否开放
# 用法: bash check_ports.sh 192.168.1.1 192.168.1.2

set -u

if [ $# -eq 0 ]; then
    echo "用法: $0 <IP1> <IP2> ..."
    exit 1
fi

PORTS="22 80 443 3306"

for host in "$@"; do
    echo "===== 检查主机: $host ====="
    for port in $PORTS; do
        # 用 /dev/tcp 测试端口（bash 内置，无需 nmap）
        if (echo > /dev/tcp/$host/$port) >/dev/null 2>&1; then
            echo "  端口 $port: 开放"
        else
            echo "  端口 $port: 关闭"
        fi
    done
done
```

知识点综合：

- `$@` 接收所有参数，`$#` 检查参数个数
- 嵌套 `for` 循环：遍历主机 × 遍历端口
- `/dev/tcp/host/port` 是 bash 的网络测试特性（仅授权环境使用！）
- `if` + 退出码判断端口状态
- `(...) >/dev/null 2>&1` 抑制所有输出，只看退出码

> ⚠️ **合规提醒**：端口扫描只能对你拥有或获得授权的目标进行。这个脚本请只在自己的实验环境（如本地虚拟机）练习。

## 12.5 常见报错与解决

| 现象 | 原因 | 解决 |
|------|------|------|
| `command not found: name` | 变量赋值等号两边有空格 | 写成 `name=value` |
| `[: missing ]` | `[` 后或 `]` 前缺空格 | `[ -f file ]` |
| `integer expression expected` | 用 `-eq` 比较非数字 | 数字用 `-eq`，字符串用 `=` |
| 死循环 | while 里没更新条件变量 | 检查循环内是否修改变量 |
| 变量在管道后丢失 | `cat file | while` 在子 Shell | 用 `done < file` 重定向 |

## 12.6 本章总结

| 知识点 | 内容 |
|--------|------|
| 变量 | `name=value`（等号无空格）；`$name`/`${name}` 引用；`export` 变环境变量 |
| 特殊变量 | `$0` 脚本名、`$1..` 参数、`$#` 个数、`$@` 所有参数、`$?` 退出码 |
| 算术 | `$((a+b))`；命令替换 `$(command)` |
| 条件 | `if/then/elif/else/fi`；`[ ]` 前后加空格；`[[ ]]` 增强版 |
| 比较 | 字符串 `=`/`!=`；数字 `-eq/-ne/-gt/-lt`；文件 `-f/-d/-e/-r/-w/-x` |
| case | 多分支；模式 `)`；`;;` 结束；`*` 默认；`esac` 结尾 |
| 循环 | `for ... in`、`while`、`until`；`break`/`continue` |
| 实践 | `while read line; do ... done < file` 逐行处理文件 |
