## 13.1 函数：把代码封装成模块

### 13.1.1 为什么用函数

当脚本里有一段逻辑要重复用多次，或者脚本变得很长时，把它拆成函数：

- **避免重复**：一段代码写一次，调用多次
- **结构清晰**：主流程一目了然，细节藏在函数里
- **易于维护**：改一处，所有调用点都生效

### 13.1.2 定义与调用

```bash
# 语法一（推荐）
函数名() {
    命令
}

# 语法二
function 函数名 {
    命令
}
```

示例：

```bash
#!/bin/bash
say_hello() {
    echo "你好，我叫 $1"     # $1 是函数的第一个参数
}

say_hello "张三"
say_hello "李四"
```

输出：

```bash
你好，我叫 张三
你好，我叫 李四
```

### 13.1.3 函数参数

函数的参数规则和脚本一样：`$1`、`$2`、`$#`、`$@`。

> ⚠️ **关键点**：函数里的 `$1` 是**函数的参数**，不是脚本的参数。调用函数时传什么，`$1` 就是什么。

```bash
add() {
    echo $(($1 + $2))
}
result=$(add 3 5)      # 用命令替换获取函数输出
echo "结果: $result"
```

### 13.1.4 返回值

Shell 函数有两种"返回"：

**1. return：返回退出码（0–255）**

```bash
is_root() {
    if [ "$USER" = "root" ]; then
        return 0       # 成功
    else
        return 1       # 失败
    fi
}

if is_root; then
    echo "你是 root"
else
    echo "你不是 root"
fi
```

`return` 只能返回数字退出码，用 `$?` 获取。

**2. echo：返回字符串（通过命令替换捕获）**

```bash
get_date() {
    date +%F
}
today=$(get_date)      # 函数里的 echo 输出被捕获到变量
echo "今天: $today"
```

这是 Shell 函数"返回数据"的常用方式——函数里 `echo`，调用处用 `$(...)` 接收。

### 13.1.5 局部变量

默认情况下，函数里定义的变量是全局的（函数外也能访问）。用 `local` 定义局部变量：

```bash
greet() {
    local name=$1      # 局部变量，只在函数内有效
    echo "你好, $name"
}
```

> **最佳实践**：函数内的变量一律用 `local`，避免污染全局命名空间、避免意外覆盖外部变量。这是写出可靠脚本的重要习惯。

### 13.1.6 一个实用函数库例子

```bash
#!/bin/bash

# 打印带时间戳的日志
log() {
    echo "[$(date +'%F %T')] $*"
}

# 检查命令是否存在
check_cmd() {
    if command -v "$1" >/dev/null 2>&1; then
        log "$1 已安装"
        return 0
    else
        log "$1 未安装"
        return 1
    fi
}

# 主流程
log "开始检查工具"
check_cmd nmap
check_cmd htop
check_cmd tcpdump
log "检查完成"
```

`command -v` 是检查命令是否存在的标准方法，比 `which` 更可靠。`$*` 是函数的所有参数。

## 13.2 数组

### 13.2.1 普通数组（索引数组）

定义：

```bash
# 方式一
arr=(apple banana orange)

# 方式二：按下标赋值
arr[0]=apple
arr[1]=banana
arr[2]=orange

# 方式三：命令结果作为数组
files=(/var/log/*.log)
```

访问：

```bash
echo ${arr[0]}         # 第一个元素
echo ${arr[2]}         # 第三个元素
echo ${arr[@]}         # 所有元素
echo ${arr[*]}         # 所有元素（略有差异）
echo ${#arr[@]}        # 数组长度
echo ${!arr[@]}        # 所有下标
```

> **小白问**：为什么要写 `${arr[0]}` 这种花括号？
>
> 因为 `[0]` 对 Shell 来说是特殊字符（通配符的一部分），不加花括号会被误解析。访问数组元素**必须加大括号**。

### 13.2.2 数组遍历

```bash
# 遍历元素
for item in "${arr[@]}"; do
    echo "$item"
done

# 遍历下标
for i in "${!arr[@]}"; do
    echo "$i: ${arr[$i]}"
done
```

> **最佳实践**：用 `"${arr[@]}"`（带双引号）遍历，能保证含空格的元素不被拆开。

### 13.2.3 数组操作

```bash
arr+=(grape)                    # 追加元素
unset arr[1]                    # 删除某元素（下标留空）
arr=( "${arr[@]}" newitem )     # 另一种追加
```

### 13.2.4 关联数组（bash 4+）

类似其他语言的"字典/Map"，用字符串作下标：

```bash
declare -A ports               # 必须先声明
ports[ssh]=22
ports[http]=80
ports[https]=443

echo ${ports[ssh]}             # 22
echo ${!ports[@]}              # 所有键：ssh http https

for key in "${!ports[@]}"; do
    echo "$key -> ${ports[$key]}"
done
```

关联数组非常适合"名字→值"的映射，比如服务名到端口、IP 到计数。

## 13.3 综合实战：模块化安全工具脚本

把函数和数组结合，写一个更专业的工具：

```bash
#!/bin/bash
# 端口与服务检查工具（模块化版本）
# 仅在授权环境使用

declare -A SERVICES           # 关联数组：服务名 → 端口
SERVICES[ssh]=22
SERVICES[http]=80
SERVICES[https]=443
SERVICES[mysql]=3306
SERVICES[redis]=6379

log() {
    echo "[$(date +%H:%M:%S)] $*"
}

# 检查单个端口
check_port() {
    local host=$1
    local port=$2
    local service=$3
    if (echo > /dev/tcp/$host/$port) >/dev/null 2>&1; then
        log "开放: $service ($host:$port)"
        return 0
    else
        log "关闭: $service ($host:$port)"
        return 1
    fi
}

# 检查主机所有服务
check_host() {
    local host=$1
    log "===== 开始检查 $host ====="
    for service in "${!SERVICES[@]}"; do
        check_port "$host" "${SERVICES[$service]}" "$service"
    done
    log "===== 检查完毕 ====="
}

# 主流程
if [ $# -eq 0 ]; then
    echo "用法: $0 <主机IP>"
    exit 1
fi

for host in "$@"; do
    check_host "$host"
done
```

改进点：

- 用关联数组管理服务→端口映射，增删服务只改一处
- 用函数分层：`check_port` 做底层检测，`check_host` 做组织，`log` 统一输出
- 用 `local` 保护变量
- 主流程简洁清晰

这才是"可维护的脚本"，而不是一坨长命令。

## 13.4 常见报错与解决

| 现象 | 原因 | 解决 |
|------|------|------|
| 数组只取到第一个元素 | 忘了 `${arr[@]}` 的花括号 | 加花括号和引号 |
| 函数改了全局变量 | 没用 `local` | 函数内变量加 `local` |
| `declare: -A: invalid option` | bash 版本太低（<4） | 升级 bash 或用普通数组 |
| 函数返回值不对 | `return` 只能返回 0-255 | 返回数据用 echo + 命令替换 |
| 元素含空格被拆开 | 遍历没加引号 | 用 `"${arr[@]}"` |

## 13.5 本章总结

| 知识点 | 内容 |
|--------|------|
| 函数定义 | `函数名() { ... }` 或 `function 函数名 { ... }` |
| 函数参数 | `$1`、`$2`、`$@`、`$#`（是函数的参数，非脚本的） |
| 返回值 | `return` 返回退出码；`echo` + `$(函数)` 返回字符串 |
| 局部变量 | `local var=value`，避免污染全局 |
| 普通数组 | `arr=(a b c)`；`${arr[0]}`、`${arr[@]}`、`${#arr[@]}` |
| 关联数组 | `declare -A arr`；`arr[key]=value`；bash 4+ |
| 遍历 | `for x in "${arr[@]}"`；`for i in "${!arr[@]}"` |
| 模块化 | 用函数分层，主流程清晰，易维护 |
