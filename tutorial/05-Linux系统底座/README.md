# Linux 通关 AI + 网络安全：从零基础到实战

> 一套为 AI + 网络安全方向量身打造的 Linux 零基础教程。不要求你提前懂任何操作系统知识，从"打开终端"开始，一路走到能独立搭建安全加固、日志检测、容器隔离的 Linux 系统，并把它作为 AI 训练与部署的底座。

---

## 为什么是这套教程

市面上 Linux 教程很多，但大多有两个问题：一是只教"敲命令"，不讲背后的原理和真实场景；二是面向运维或开发，和 AI、网络安全脱节。这套教程想解决的就是这个缺口。

我们始终坚持三条原则：

1. **零基础友好**：每一条命令都解释"为什么这么写"，每个概念都用生活类比，配"小白问"答疑、逐行解析、常见报错。
2. **代码/命令驱动**：不空谈理论。你会在终端里亲手完成每一次操作，看得见反馈。
3. **面向 AI + 安全**：案例大量取自真实安全场景——日志分析、权限检查、进程排查、SSH 加固、防火墙、入侵检测、容器隔离、GPU 训练环境，让学到的东西直接能用。

> **合规底线**：本教程所有涉及攻防、扫描、渗透的内容，都必须且只能在**你自己搭建的环境、授权靶场或实验虚拟机**中练习。未经授权对他人系统进行测试是违法行为。每卷开头都有伦理声明，请务必遵守。

## 七卷结构（33 章）

### 第一卷 · Linux 入门（第 1–3 章）
建立整体认知。讲清 Linux 是什么、为什么 AI 和安全都离不开它、如何选发行版并安装（虚拟机 / WSL / 云服务器）、Linux 的核心哲学与目录结构、用户与权限的雏形。

### 第二卷 · 命令行核心（第 4–10 章）
命令行是 Linux 的灵魂。系统掌握 Shell 基础、文件与目录操作、文本处理三剑客（grep / sed / awk）、管道与重定向、用户与权限、进程管理、软件包管理。大量安全场景案例：从日志里揪出暴力破解 IP、批量检查文件权限、排查可疑进程。

### 第三卷 · Shell 脚本编程（第 11–16 章）
把零散命令变成自动化武器。变量、条件、循环、函数、数组、正则表达式、cron 定时任务、脚本调试与最佳实践。最终你能写出自己的安全检查脚本、日志统计脚本、批量扫描脚本。

### 第四卷 · Linux 系统安全（第 17–21 章）★核心特色卷
从"会用"到"会守"。Linux 安全模型（用户 / 权限 / capability / SELinux）、防火墙（iptables / nftables / firewalld）、SSH 安全加固、日志分析与入侵检测、系统加固与漏洞防护。**本卷所有攻防内容仅限授权环境。**

### 第五卷 · 网络与服务（第 22–25 章）
Linux 是网络服务的王者。TCP/IP 与网络配置、常见网络服务（Web / DNS / DHCP）、Docker 容器与容器安全、systemd 服务管理。理解"服务是怎么跑起来、怎么被隔离、怎么被保护的"。

### 第六卷 · Linux 与编程 AI（第 26–30 章）
把 Linux 变成开发与安全的主场。开发环境（gcc / make / cmake / git）、Linux 下的 Python / C/C++ / Rust / Go（与前四套教程呼应）、性能分析与调优、AI 训练部署环境（GPU / CUDA / 驱动）、Linux 安全工具链。

### 第七卷 · 综合实战（第 31–33 章）
全链路收官。Linux 安全加固脚本实战、日志分析入侵检测系统、综合项目——AI + 安全的 Linux 服务器防护体系（从加固、检测、到响应，并接入 AI 分析）。

## 学习路线

### 路线 A：纯零基础（推荐）
按章节顺序从第 1 章读到第 33 章。前三卷打地基，第四卷学防守，后三卷做实战。每天 1–2 章，配合动手实验，约 2–3 个月完成。

### 路线 B：有编程经验，想补 Linux 安全
快速过第 1–3 章，重点读第 6、8、9、17–21 章（文本处理、权限、进程、安全模型、防火墙、SSH、日志、加固），再直接做第七卷实战。

### 路线 C：目标 AI 工程 / 部署
重点读第 1–5、9、22–30 章，把命令行、进程、网络、容器、开发环境、GPU 环境打通，最后做第 33 章。

## 环境准备

| 方式 | 适合人群 | 说明 |
|------|---------|------|
| 虚拟机（VirtualBox / VMware） | 零基础、想完整体验 | 安装 Ubuntu，最接近真实服务器 |
| WSL 2 | Windows 用户、想快速上手 | 在 Windows 里跑原生 Linux，轻便 |
| 云服务器 | 想学真实运维 / 安全 | 阿里云 / 腾讯云轻量服务器，注意安全组 |
| Live USB | 想先体验不安装 | U 盘启动，不改动硬盘 |

**推荐配置**：Ubuntu 22.04 LTS，至少 2GB 内存（AI 部分建议更大），20GB 磁盘。所有命令以 Ubuntu/Debian 为主，Red Hat 系（CentOS / Rocky）的差异会特别标注。
