# 第 2 章 发行版、安装与第一个终端

## 本章目标

读完这一章，你将能够：

- 理解什么是"发行版"，知道该选哪一个
- 用自己的电脑完成 Linux 安装（虚拟机 / WSL 二选一）
- 打开终端，敲下第一条命令，理解命令行的提示符
- 知道遇到问题去哪里查资料

---

## 2.1 什么是发行版

Linux 本身只是一个内核，普通人没法直接用。需要有人把内核 + 命令行工具 + 图形界面 + 软件包管理器 + 各种软件打包在一起，做成一个能用的完整系统——这就是**发行版（Distribution，简称 distro）**。

打个比方：Linux 内核像"发动机"，发行版像"整车"。不同厂商用同一个发动机，造出不同的车：有的适合家用（Ubuntu），有的适合越野（Kali），有的适合跑长途货运（CentOS/RHEL）。

### 2.1.1 主流发行版一览

| 发行版 | 特点 | 适合谁 |
|--------|------|--------|
| **Ubuntu** | 用户友好、社区大、资料多、软件新 | **零基础首选**，本教程以其为主 |
| **Debian** | 极其稳定、Ubuntu 的 upstream | 追求稳定的服务器 |
| **CentOS / Rocky Linux** | 企业服务器主流、稳定性极强 | 企业运维、生产服务器 |
| **Fedora** | 技术前沿、新特性多 | 喜欢尝鲜的开发者 |
| **Kali Linux** | 预装几百个安全工具 | 渗透测试、安全研究 |
| **Arch Linux** | 高度可定制、滚动更新 | 有经验的玩家 |

> **小白问**：我该选哪个？
>
> 零基础且跟着本教程学 → **Ubuntu 22.04 LTS**。资料最多，遇到问题最容易搜到答案。
> 想做渗透测试 → 先学 Ubuntu 打基础，再装 Kali。直接在 Kali 上从零学会混乱（Kali 默认 root 登录，不适合学权限管理）。
> 注意 **LTS** 表示"长期支持版"，更新周期长、更稳定，适合学习和生产。

### 2.1.2 包管理器的差异

不同发行版用不同的包管理器（后面第 10 章详解）：

| 发行版家族 | 包管理器 | 安装软件命令示例 |
|-----------|---------|-----------------|
| Debian / Ubuntu | apt | `sudo apt install nmap` |
| RHEL / CentOS / Rocky | dnf / yum | `sudo dnf install nmap` |
| Arch | pacman | `sudo pacman -S nmap` |

本教程以 **Ubuntu / Debian** 的 `apt` 为主，遇到 Red Hat 系的差异会特别标注。

## 2.2 安装方式选择

你有四条路，按推荐顺序：

### 方式一：虚拟机（最推荐给零基础）

在 Windows / macOS 上装一个虚拟机软件（VirtualBox 免费，VMware Workstation 功能强），然后在虚拟机里安装 Ubuntu。

**优点**：完全隔离，随便折腾不损坏真实系统；可以随时快照、回滚。
**缺点**：占用一定内存和磁盘（建议分配 2GB+ 内存、20GB+ 磁盘）。

步骤概要：
1. 下载 VirtualBox（virtualbox.org）并安装。
2. 到 ubuntu.com 下载 Ubuntu 22.04 LTS 的 ISO 镜像。
3. 在 VirtualBox 里"新建"虚拟机，选择该 ISO，按提示安装。
4. 安装完成后启动，进入桌面。

### 方式二：WSL 2（Windows 用户最轻便）

WSL（Windows Subsystem for Linux）让你在 Windows 里直接运行 Linux，不需要虚拟机，启动快、资源占用少。

步骤概要（在管理员 PowerShell 中）：

```powershell
wsl --install
```

重启后会自动安装 Ubuntu。首次启动设置用户名和密码即可。

> **小白问**：WSL 和虚拟机哪个好？
>
> 想学完整的 Linux（包括图形界面、系统服务、网络配置）→ 虚拟机更全面。
> 主要想在 Windows 上用 Linux 命令行、做开发 → WSL 更轻便。
> 本教程的命令在两者上都能跑，少数涉及系统服务的部分会用虚拟机演示。

### 方式三：云服务器（最接近真实生产环境）

在阿里云、腾讯云等申请一台按量付费的轻量服务器（选择 Ubuntu 镜像），用 SSH 远程连接。

**优点**：真实服务器环境、有公网 IP，可以练习远程管理、防火墙、Web 服务。
**缺点**：要花钱（学生机很便宜），误操作可能影响服务。

### 方式四：Live USB（先体验不安装）

把 Ubuntu 镜像写到 U 盘，从 U 盘启动电脑，可以临时体验而不改动硬盘。适合先看看再决定。

## 2.3 第一次进入系统

安装完成后，你会看到登录界面。输入你安装时设置的用户名和密码，进入桌面。

### 2.3.1 打开终端

在 Ubuntu 桌面，按快捷键 **`Ctrl + Alt + T`** 打开终端（Terminal）。你会看到一个黑底（或紫底）白字的窗口，等着你输入命令。

恭喜，这就是你的 Linux 主场。

### 2.3.2 认识提示符

终端里通常会看到类似这样的提示符：

```bash
zhangsan@ubuntu:~$
```

拆解一下：

| 部分 | 含义 |
|------|------|
| `zhangsan` | 当前用户名 |
| `@` | 分隔符 |
| `ubuntu` | 主机名（你的电脑名字） |
| `~` | 当前所在目录，`~` 代表你的家目录（home directory） |
| `$` | 提示符，表示当前是**普通用户** |

如果是 **`#`** 结尾，表示当前是 **root 用户**（超级管理员），权限极高，要小心。

> **小白问**：root 是什么？
>
> root 是 Linux 的超级管理员账户，拥有系统最高权限，可以删除任何文件、修改任何配置。日常操作**不要用 root**，用普通用户 + `sudo` 临时提权（后面第 8 章详解）。Kali 默认用 root 登录，所以不推荐零基础直接在 Kali 上学。

### 2.3.3 你的第一条命令

敲下这条命令，然后回车：

```bash
whoami
```

输出你的用户名。再试试：

```bash
pwd
```

输出当前所在目录的完整路径（`pwd` = print working directory）。

再试试查看当前目录有什么：

```bash
ls
```

你可能会看到 `Desktop`、`Documents`、`Downloads` 等文件夹。

三条命令小结：

| 命令 | 作用 | 记忆技巧 |
|------|------|---------|
| `whoami` | 我是谁 | who am I |
| `pwd` | 我在哪 | print working directory |
| `ls` | 这里有什么 | list |

### 2.3.4 一条完整的命令长什么样

Linux 命令的通用格式：

```bash
命令 [选项] [参数]
```

例如：

```bash
ls -la /home
```

- `ls` 是命令
- `-la` 是选项（`-l` 详细列表，`-a` 显示隐藏文件），多个选项可以合并写
- `/home` 是参数（要列出的目录）

选项通常以 `-` 开头（短选项，如 `-l`），或 `--` 开头（长选项，如 `--help`）。

**最重要的技巧**：任何命令不熟，就用 `--help` 查帮助：

```bash
ls --help
```

想看更详细的"手册页"：

```bash
man ls
```

在 man 页面里按 `q` 退出，按空格翻页。

## 2.4 几个立刻能用的实用命令

先感受一下命令行的便利（后面章节会详细讲）：

```bash
# 查看系统信息
uname -a

# 查看当前日期时间
date

# 查看磁盘使用情况
df -h

# 查看内存使用
free -h

# 清屏（或者 Ctrl + L）
clear
```

试着敲一敲，看看输出。不要怕敲错——命令行敲错顶多报错，不会炸掉电脑。**多敲、多观察，是学好 Linux 的捷径。**

---

## 2.5 常见报错与解决

| 报错 | 原因 | 解决 |
|------|------|------|
| `command not found` | 命令不存在或拼写错误 | 检查拼写；确认软件是否安装 |
| `Permission denied` | 权限不足 | 在命令前加 `sudo`（需管理员密码） |
| `No such file or directory` | 文件或路径不存在 | 用 `pwd`、`ls` 确认当前位置 |
| 终端无响应 | 某个程序卡住了 | 按 `Ctrl + C` 强制终止当前命令 |

> **小白问**：敲命令时中文输入法有影响吗？
>
> 建议切换到英文输入法。Linux 命令和参数都是英文字符，中文标点（比如全角空格、中文引号）会导致奇怪的错误。

## 2.6 本章总结

| 知识点 | 内容 |
|--------|------|
| 发行版 | Linux 内核 + 软件的完整系统；零基础选 Ubuntu 22.04 LTS |
| 安装方式 | 虚拟机最全面、WSL 最轻便、云服务器最真实 |
| 终端 | `Ctrl+Alt+T` 打开；提示符 `用户@主机:目录$` |
| root | 超级管理员，日常用普通用户 + `sudo` |
| 命令格式 | `命令 [选项] [参数]`；`--help` 和 `man` 查帮助 |
| 首条命令 | `whoami`、`pwd`、`ls`、`uname -a`、`df -h` |

## 本章练习

1. 完成 Ubuntu 安装（虚拟机或 WSL），成功进入终端。
2. 敲 `whoami`、`pwd`、`ls`，理解每条输出的含义。
3. 用 `ls --help` 查看帮助，找出 `-l` 和 `-a` 选项的作用。
4. 用 `man ls` 打开手册页，练习按空格翻页、按 `q` 退出。
5. 敲 `df -h` 和 `free -h`，看看你的磁盘和内存有多少。
6. 思考：为什么日常不推荐用 root 用户直接操作？
