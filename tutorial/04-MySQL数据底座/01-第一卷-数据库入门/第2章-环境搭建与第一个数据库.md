# 第 2 章 环境搭建与第一个数据库

## 本章目标

读完这一章，你将能够：

- 在自己电脑上装好 MySQL 并能登录
- 创建数据库、创建表、插入数据、查询数据
- 理解 `mysql` 命令行的基本用法
- 知道图形化工具怎么选

> 如果你已经装好了 MySQL，可以跳过安装部分，直接从 2.3 节开始。

---

## 2.1 选择哪个版本

MySQL 目前主流版本：

| 版本 | 状态 | 建议 |
|------|------|------|
| MySQL 8.0 | 当前主流 | ✅ 推荐，功能全、性能好 |
| MySQL 5.7 | 仍大量在用 | 可用，但已进入维护期 |
| MariaDB 10.x | MySQL 的开源分支 | 完全兼容，可替代 |
| MySQL 9.x | 创新版 | 尝鲜用，生产暂不推荐 |

**本教程基于 MySQL 8.0**，但讲的知识在 5.7 / MariaDB 上基本都适用。遇到版本差异会特别标注。

## 2.2 安装 MySQL

### Windows 安装

**方式一：官方安装包（推荐新手）**

1. 打开 MySQL 官网下载页：`https://dev.mysql.com/downloads/mysql/`
2. 选择 "MySQL Installer for Windows"，下载后运行
3. 选择 "Developer Default"（开发者默认）或 "Server only"
4. 一路下一步，到 "Authentication Method" 时选 **"Use Strong Password Encryption"**
5. 设置 root 密码（务必记住！比如 `Root@123456`）
6. 安装完成后，MySQL 服务会自动启动

**方式二：用 Docker（如果你装了 Docker）**

```bash
docker run -d --name mysql8 \
  -e MYSQL_ROOT_PASSWORD=Root@123456 \
  -p 3306:3306 \
  mysql:8.0
```

一行命令搞定，最适合安全实验——随时可以删掉重来。

### macOS 安装

用 Homebrew 最简单：

```bash
brew install mysql
brew services start mysql
mysql_secure_installation   # 安全初始化，设置密码等
```

### Linux（Ubuntu）安装

```bash
sudo apt update
sudo apt install mysql-server
sudo systemctl start mysql
sudo mysql_secure_installation
```

> **小白问**：`root` 是什么？
> MySQL 里的 `root` 是最高权限的管理员账号（和系统 Linux 的 root 是两个概念，虽然名字一样）。第一次登录就用它。生产环境千万别用 root 跑应用，第 18 章会讲怎么建最小权限账号。

### 验证安装

打开终端，输入：

```bash
mysql -u root -p
```

系统会提示输入密码，输入你设置的密码（输入时不显示，正常现象），回车。如果看到：

```
mysql>
```

说明登录成功！你现在已经进入 MySQL 的命令行了。

> **常见报错**：`ERROR 2002 (HY000): Can't connect to local MySQL server`
> 说明 MySQL 服务没启动。Windows 去"服务"里找 MySQL 启动；Linux 用 `sudo systemctl start mysql`；macOS 用 `brew services start mysql`。

## 2.3 你的第一条 SQL

进入 `mysql>` 后，先做几个最简单的操作。

**查看所有数据库：**

```sql
SHOW DATABASES;
```

你会看到系统自带的几个库：`information_schema`、`mysql`、`performance_schema`、`sys`。这些是 MySQL 自己的，先别动。

**创建一个数据库：**

```sql
CREATE DATABASE security_lab;
```

`security_lab` 是我们这次实验用的库名，意思是"安全实验室"。

**使用这个数据库：**

```sql
USE security_lab;
```

**创建一张表：**

```sql
CREATE TABLE hosts (
    id INT AUTO_INCREMENT PRIMARY KEY,
    ip VARCHAR(64) NOT NULL,
    os VARCHAR(64),
    status VARCHAR(16)
);
```

逐行解释：

| 代码 | 含义 |
|------|------|
| `CREATE TABLE hosts` | 创建一张叫 hosts（主机）的表 |
| `id INT AUTO_INCREMENT PRIMARY KEY` | id 是整数、自动递增、主键（唯一标识） |
| `ip VARCHAR(64) NOT NULL` | ip 是最多 64 字符的字符串，不能为空 |
| `os VARCHAR(64)` | 操作系统，可为空 |
| `status VARCHAR(16)` | 状态，可为空 |

**插入数据：**

```sql
INSERT INTO hosts (ip, os, status) VALUES
('192.168.1.10', 'Ubuntu 22.04', 'UP'),
('192.168.1.11', 'Windows 11', 'UP'),
('10.0.0.5', 'CentOS 7', 'DOWN');
```

**查询数据：**

```sql
SELECT * FROM hosts;
```

你会看到：

```
+----+---------------+--------------+--------+
| id | ip            | os           | status |
+----+---------------+--------------+--------+
|  1 | 192.168.1.10  | Ubuntu 22.04 | UP     |
|  2 | 192.168.1.11  | Windows 11   | UP     |
|  3 | 10.0.0.5      | CentOS 7     | DOWN   |
+----+---------------+--------------+--------+
3 rows in set (0.00 sec)
```

恭喜，你已经完成了数据库操作的完整闭环：**建库 → 建表 → 插入 → 查询**。

> **小白问**：每条 SQL 后面的分号 `;` 能省吗？
> 在命令行里不能省——分号表示"这条语句结束了，可以执行了"。在图形化工具里有些可以省，但养成写分号的习惯准没错。

## 2.4 图形化工具（可选）

命令行是基本功，但图形化工具更直观。推荐：

| 工具 | 特点 | 平台 | 费用 |
|------|------|------|------|
| MySQL Workbench | 官方出品，功能全 | 全平台 | 免费 |
| DBeaver | 支持多种数据库，强大 | 全平台 | 免费/付费 |
| Navicat | 界面精美，好用 | 全平台 | 付费 |
| DataGrip | JetBrains 出品，智能 | 全平台 | 付费 |

新手推荐 **MySQL Workbench** 或 **DBeaver**。它们能让你用鼠标建库建表、写 SQL、看结果，还能画 ER 图（表关系图）。

不过要注意：**命令行必须会**。很多服务器没有图形界面，运维和应急时只能靠命令行。而且面试和实战中，SQL 都是直接写的。

## 2.5 常用的 mysql 命令行操作

```sql
SHOW DATABASES;              -- 查看所有数据库
USE security_lab;            -- 使用某个数据库
SHOW TABLES;                 -- 查看当前库的所有表
DESC hosts;                  -- 查看表结构（DESCRIBE 的缩写）
SHOW CREATE TABLE hosts;     -- 查看建表语句
SELECT DATABASE();           -- 查看当前在哪个库
EXIT;                        -- 退出（或 QUIT）
```

`DESC hosts` 的输出：

```
+--------+-------------+------+-----+---------+----------------+
| Field  | Type        | Null | Key | Default | Extra          |
+--------+-------------+------+-----+---------+----------------+
| id     | int         | NO   | PRI | NULL    | auto_increment |
| ip     | varchar(64) | NO   |     | NULL    |                |
| os     | varchar(64) | YES  |     | NULL    |                |
| status | varchar(16) | YES  |     | NULL    |                |
+--------+-------------+------+-----+---------+----------------+
```

这张表就是表的"身份证"，字段、类型、能否为空、键、默认值、额外属性一目了然。以后排查问题经常用它。

## 2.6 常见报错与排查

| 报错 | 原因 | 解决 |
|------|------|------|
| `ERROR 1045 Access denied` | 密码错误 | 确认密码；忘了密码可重置 |
| `ERROR 2002 Can't connect` | 服务没启动 | 启动 MySQL 服务 |
| `ERROR 1046 No database selected` | 没 USE 数据库 | 先执行 `USE 库名;` |
| `ERROR 1064 syntax error` | SQL 语法错 | 检查拼写、分号、引号 |
| `ERROR 1050 Table already exists` | 表已存在 | 改表名或先 DROP |

> **小白问**：我密码忘了怎么办？
> 本地实验环境可以重置：停止 MySQL 服务，用 `--skip-grant-tables` 模式启动，登录后 `ALTER USER 'root'@'localhost' IDENTIFIED BY '新密码';`。生产环境要走正规流程，别乱来。

| 知识点 | 内容 |
