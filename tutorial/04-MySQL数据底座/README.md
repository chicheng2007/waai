# MySQL 从零到实战：AI + 网络安全数据底座

> 一套写给零基础学习者的 MySQL 完整教程。不止教你写 SQL，更教你用 MySQL 搭建 **AI 与网络安全系统的数据底座**。

---

## 为什么是这套教程

你可能用过 Excel 存数据，也可能写过 Python 把数据存进列表。但当数据多到几万条、几十万条，当多个程序要同时读写，当需要"找出过去 30 天所有来自可疑 IP 的登录记录"——你就需要一个**数据库**。

MySQL 是世界上最流行的开源关系型数据库。它免费、稳定、快，几乎所有后端系统都在用它。而在 **AI + 网络安全** 领域，MySQL 更是无处不在：

- **安全日志系统**：把几百万条登录、流量、告警日志存进去，秒级查询
- **威胁情报平台**：存储 IP 黑名单、恶意域名、攻击特征库
- **用户与权限**：堡垒机、扫描平台、AI 服务的账号体系都靠数据库
- **AI 数据管道**：特征数据、标注数据、模型元数据、实验结果都落在 MySQL
- **SQL 注入攻防**：想做好 Web 安全，必须懂 SQL——这既是攻击者的武器，也是防守者的必修课

这套教程延续了前面《Python 通关 AI+安全》《系统语言通关 AI+安全》《混合编程通关 AI+安全》的风格：**零基础友好、代码驱动、场景贯穿、合规底线**。它既是独立的一套 MySQL 教程，也是整个系列的"数据篇"。

## 学习路线

### 路线 A：零基础系统学（推荐）

按章节顺序从头学到尾。适合完全没接触过数据库的人。约 8–12 周。

### 路线 B：快速上手 SQL

只读第一卷 + 第二卷（第 1–10 章），掌握增删改查。约 2 周。适合马上要用数据库的人。

### 路线 C：安全方向专精

重点读第 18–21 章（安全）+ 第 9–10 章（联查子查询）+ 第 31–33 章（实战）。适合做 Web 安全、渗透测试的人。

### 路线 D：AI 工程方向

重点读第 6–10 章（查询）+ 第 13 章（索引）+ 第 26、30 章（编程与 AI 应用）。适合做 AI 平台、数据工程的人。

## 环境要求

- **MySQL 8.0**（推荐）或 MySQL 5.7 / MariaDB
- 命令行客户端 `mysql`，或图形化工具（MySQL Workbench / DBeaver / Navicat）
- 编程语言环境（第六卷需要）：Python 3 / GCC 或 Clang / Rust / Go
- 所有示例在 Windows / macOS / Linux 均可运行，系统差异会特别标注
