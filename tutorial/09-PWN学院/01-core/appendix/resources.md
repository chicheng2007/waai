# 附录 D：推荐资源

## 靶场与题目平台

| 平台 | 网址 | 说明 |
| --- | --- | --- |
| BUUCTF | https://buuoj.cn | 国内最流行的 CTF 靶场，PWN 题目丰富 |
| NSSCTF | https://www.nssctf.cn | 新生赛平台，难度梯度合理 |
| CTFtime | https://ctftime.org | 国际 CTF 赛事日历与排名 |
| pwn.college | https://pwn.college | 亚利桑那州立大学的免费 PWN 课程 |
| Hack The Box | https://www.hackthebox.com | 综合渗透平台 |

## 推荐书籍

- 《CTF 竞赛权威指南（PWN 篇）》—— 系统介绍 PWN 技术
- 《0day 安全：软件漏洞分析技术》—— 经典漏洞利用书籍
- 《二进制安全之旅》—— 适合新手的入门读物
- 《程序员的自我修养——链接、装载与库》—— 深入理解 ELF 和链接

## 在线教程与博客

- **ctf-wiki**：https://ctf-wiki.org —— 国内最全面的 CTF 知识库
- **Linux 源码**：https://sourceware.org/git/?p=glibc.git —— glibc 官方源码
- **pwntools 文档**：https://docs.pwntools.com
- **how2heap**：https://github.com/shellphish/how2heap —— glibc 堆利用示例代码（强烈推荐！）

## 学习建议

1. **先刷题再看书**：做题时发现问题，带着问题查资料，效率最高
2. **复现经典题目**：how2heap 的每个示例都值得亲手调试
3. **读 writeup**：看别人的解题思路，学习不同的利用角度
4. **加入社区**：CTF 战队、论坛、Discord 群组，和其他选手交流
