# 第一篇 · 筑基篇：新手村

> 万丈高楼平地起。这一篇我们不讲任何漏洞利用，只把以后要用到的基础知识一次性铺好。

**适合谁读**：完全零基础，没写过 C，没看过汇编，不知道 ELF 是什么也没关系。

**学完你将**：能读懂简单的 C 程序和对应的汇编，理解内存、栈、函数调用、保护机制这些「黑话」。
