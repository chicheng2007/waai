## 🎬 这一季的游戏设定

在基础篇里，我们学会了怎么利用游戏的 Bug。但有个问题一直没回答：

> **游戏为什么会出这个 Bug？后台到底是怎么管理的？**

这一季，我们切换视角：

| 基础篇（玩家视角） | 进阶篇（后台视角） |
| --- | --- |
| 储物柜租赁系统（堆） | 系统的**后台管理日志**（malloc/free 源码） |
| 快速回收筐（tcache） | 筐上的**防伪印章**（key）和**地址打码**（safe-linking） |
| 回收站（bin） | 后台的**分类账本**（bins 链表维护） |
| 城堡警报（保护机制） | 反作弊系统的**军备竞赛**（检查机制演化史） |
| 存档系统（IO_FILE） | 存档的**每一个格子**（FILE 结构体）和**技能表**（vtable） |
| 手动翻地图 | 请 **AI 代打**（angr）和**机器人试错工厂**（AFL） |

一句话：**基础篇教你利用 Bug，进阶篇教你看懂 Bug 从哪里来，以及反作弊升级后怎么继续玩。**
