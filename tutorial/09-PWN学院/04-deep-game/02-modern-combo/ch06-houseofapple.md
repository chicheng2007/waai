# 第 6 关 · House of Apple：存档系统的终极连招

## 🎬 游戏开场

glibc 2.34 把 `__free_hook`、`__malloc_hook` 这些"钩子按钮"全拆了(第 4 关)。老套路一夜失效,玩家陷入恐慌:没钩子了,怎么拿 shell?

然后,一位高手放出一套神级连招——**House of Apple**。它不依赖任何 hook,而是把目标转向"存档系统"(IO_FILE),通过一连串精巧操作,最终让程序在执行 `exit` 或 `puts` 时乖乖执行 `system("/bin/sh")`。

这套连招成了 glibc 2.35 时代的"标准答案"。这一关,我们用游戏比喻把它的逻辑讲清楚。

---

## 🧠 核心概念（游戏版）

### 1. House of Apple 的三大变体

House of Apple 不是一个招式,是一系列,常见的有:

| 变体 | 触发方式 | 游戏比喻 |
| --- | --- | --- |
| **Apple 1** | 程序 `exit()` 时 | 游戏退出时刷卡触发 |
| **Apple 2** | 调用 `puts`/`printf` 时 | 打印文字时刷卡触发 |
| **Apple 3** | IO 流操作(如 `puts` 的缓冲刷新) | 写日志时刷卡触发 |

核心思想都一样:伪造 FILE 结构,让某个 IO 操作触发我们布置的攻击链。

### 2. 前置条件(需要什么)

House of Apple 通常需要:

1. **任意地址写一个堆地址**:用 largebin attack(第 5 关)实现。
2. **控制一个 fake FILE 结构**:通常放在堆上,内容由我们构造。
3. **知道 libc 基址**和**堆地址**。

游戏翻译:你得先能用"分类架攻击"往指定地址写一个值,然后准备一张"假存档卡",最后知道城市和储物柜的坐标。

### 3. 攻击链条(游戏化拆解)

```
① largebin attack → 把 _IO_list_all(存档链表头)改成指向我们的fake FILE
                     (或改写某个_IO_FILE的关键字段)
② 伪造FILE结构   → 在堆上造一张假存档卡:
                     - flags 设置成特殊值
                     - vtable 指向合法的 _IO_wfile_jumps(绕过检查)
                     - 某些字段指向我们的"攻击指令"(wide data)
③ 触发           → 程序exit或puts时,遍历FILE链表,刷卡
④ vtable调用     → 因为vtable指向合法区域但偏移被利用,
                     最终调用到我们构造的函数指针 → system("/bin/sh")
```

游戏翻译:

- 第一步:用"分类架攻击"把存档链表头改成指向我们的假存档卡。
- 第二步:假存档卡的"技能清单"指向合法清单的一个特殊偏移——这个偏移上的"按钮",恰好会去读卡片上我们写好的"指令"。
- 第三步:游戏退出/打印时刷卡。
- 第四步:按到那个特殊按钮,按钮读我们写的指令 → 执行 system。

### 4. 为什么能绕过 vtable 检查?

glibc 检查 vtable 必须在合法区域内(`__libc_IO_vtables`)。House of Apple 的巧思:

> **不伪造 vtable,而是把 vtable 指针指向一个合法的 vtable 表的中间位置**(如 `_IO_wfile_jumps` 加上某个偏移),这样检查能过,但被调用的函数变成了 `_IO_wfile_seekoff` 之类的"跳板",再配合 FILE 结构里的 `wide data` 字段,最终劫持控制流。

游戏翻译:我不造假技能清单,我把"技能清单指针"指向**真清单的中间某个按钮**——这个按钮本身是合法的,但它会去读卡片上的"备注栏",而备注栏被我写成了 system。检查一看"技能清单是真的",放行;结果按下去执行了我的指令。

### 5. 难度说明

House of Apple 是进阶篇最复杂的连招,真正的 exp 需要精确构造 FILE 结构的几十个字段。本关目标是**理解思路**;具体字段构造,留给硬核版和实战。

游戏比喻:你现在理解了这套连招的"战术意图",具体"每个键按几下"需要大量练习。

## 🔧 真实世界对照

| 游戏说法 | 真实术语 |
| --- | --- |

| 假存档卡 | fake `_IO_FILE` (堆上) |

| 分类架攻击前置 | largebin attack |

## 🎯 本关任务:理解流程图

把 House of Apple 的攻击链画成流程图:

```
largebin attack → 改_IO_list_all → 伪造FILE → exit/exit触发 → 合法vtable偏移 → system
```

对每一步,用一句话解释"为什么这一步能达成、系统为什么会上当"。能讲清楚,就掌握了核心逻辑。
