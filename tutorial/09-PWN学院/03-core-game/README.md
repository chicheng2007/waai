> 把 PWN 当成一款游戏来玩。你不需要一开始就懂汇编、懂 glibc，你只需要——**想通关**。

这是一本**完全用游戏比喻**讲清楚 PWN 漏洞利用的入门教程。它对应的"硬核版"是 [01-core 基础·硬核版](../01-core/README.md)，本版把每个概念都翻译成了《内存城》这款游戏里的场景。

## 🕹️ 欢迎来到《内存城》

想象你正在玩一款开放世界游戏——**《内存城》(Memory City)**：

- **你**，是玩家，也叫 **Pwner**（通关者）。
- **程序**，是城里的一栋栋建筑。有的建筑会给你任务（输入），有的会给你奖励（输出）。
- **内存**，是整座城市。城里每一间小屋都有门牌号，那就是**地址**。
- **CPU**，是游戏引擎，它一刻不停地读指令、做动作。
- **漏洞**，是游戏里的 **Bug**。普通玩家看到 Bug 会绕开，而你——你要**利用它通关**。

游戏的目标只有一个：拿到 **shell**（管理员权限）。拿到它，你就能在这座城里为所欲为。

> ⚠️ **合法声明**：本教程所有技术仅用于 CTF 竞赛和你自己搭建的授权实验环境。未经授权攻击他人系统是违法的。我们只做"游戏里的好人"。

## 🧭 为什么要游戏化？

因为 PWN 的知识体系对新手太不友好了。你一上来就会遇到这些黑话：

```
栈溢出、ret2libc、ROP 链、Canary、GOT 表、PLT、UAF、double free、
fastbin attack、tcache poisoning、FSOP、House of Apple……
```

这些词就像游戏里突然蹦出来的英文技能名，看不懂就没法玩。但如果你换一种方式理解：

| 黑话 | 游戏里的东西 |
| --- | --- |
| 内存 | 一座城市，每间屋子都有门牌号（地址） |
| 指针 | 藏宝图上的坐标 |
| 栈 | 一摞叠起来的盘子，函数调用时往上叠，返回时从顶上拿走 |
| 堆 | 城市储物柜中心，租柜子（malloc）、退柜子（free） |
| 栈溢出 | 往盘子里堆太多菜，把桌边的"回城卷轴"（返回地址）挤掉了 |
| 返回地址 | 告诉程序"干完这票该回哪儿"的回城卷轴 |
| ret2text | 把回城卷轴改成"隐藏关卡入口"的坐标 |
| ROP | 游戏里散落着很多"乐高小零件"（gadget），拼起来就能遥控程序 |
| Canary | 餐桌上的警报器，一碰就响，你得先偷到它的口令 |
| UAF | 你退了储物柜，却偷偷留了钥匙，还往里塞东西 |
| double free | 同一个柜子退租两次，骗系统把它租给你两遍 |
| 堆风水 | 提前把储物柜摆好位置，让目标柜子刚好落在你要的地方 |

是不是瞬间就亲切多了？**这本教程就是带你一路打怪、一路捡装备、一路把黑话翻译成游戏语言。**
