# 第 25 关 · 内核 PWN：管理员模式初探

## 🎬 游戏开场

到目前为止,你都是在"普通玩家模式"(用户态)里闯关。现在,游戏给你开了个隐藏区域——**管理员模式(内核态)**。

这里权力更大:

- 普通玩家(User)→ 管理员(Root / uid 0)
- 能读取任何文件、绕过很多限制
- 但规则完全不同,出错会直接让整个游戏崩溃(kernel panic)

内核 PWN 的目标很直接:**从普通玩家提权成 root**。方法通常是利用内核里的漏洞(内核 UAF、越界写等),改写进程的权限凭证(cred 结构),或者执行提权的 shellcode。

---

## 🧠 核心概念（游戏版）

### 1. 用户态 vs 内核态

```
用户态 (ring 3)  ← 你之前玩的所有关卡
  ↓ 系统调用 (syscall)
内核态 (ring 0)  ← 管理员模式,权限最高
```

- 程序通过 **syscall** 从用户态"呼叫"内核,请求服务(读文件、开设备等)。
- 内核态代码运行在最高权限,能访问所有内存和硬件。

游戏比喻:普通玩家只能在大厅活动,通过"服务窗口"(syscall)请管理员帮忙;内核态是管理员办公区,进去就能直接改游戏规则。

### 2. 内核里的"储物柜":slab/slub

用户态用 malloc,内核用 **slab 分配器**管理小对象。它也有"回收筐"的概念(freelist),也有 UAF、double free 类漏洞——只是对象变成了内核结构体。

游戏比喻:内核世界也有储物柜中心,只是柜子里放的是"管理员的装备"(内核对象)。

### 3. 提权的靶子:cred 结构

每个进程有个 `cred`(凭证)结构,记录它的 uid/gid(身份)。root 的 uid=0。

内核提权的经典操作:

- 找到当前进程的 cred 结构。
- 利用漏洞把 cred 里的 uid 改成 0(或者用一个假的 cred 替换)。
- 此后进程就是 root——**提权成功**。

游戏比喻:你把自己的"玩家身份卡"上的等级从"普通"涂成"管理员",游戏就认你是 root 了。

### 4. 常见内核漏洞类型

| 漏洞 | 游戏说法 | 效果 |
| --- | --- | --- |
| 内核 UAF | 退租管理员装备后继续用 | 篡改内核对象 |
| 越界写(OOB) | 往隔壁柜子塞东西 | 改相邻数据 |
| 栈溢出 | 内核栈上堆菜 | 劫持内核控制流 |
| 条件竞争 | 趁管理员转身时动手 | 竞态利用 |

### 5. 环境准备

内核 PWN 需要专门的实验环境,通常用 **QEMU 启动的虚拟机** + 给定的内核镜像和驱动模块(.ko):

```bash
# 典型题目文件
bzImage          # 内核镜像
rootfs.cpio      # 文件系统
vmlinux          # 带符号的内核(方便调试)
```

启动:

```bash
qemu-system-x86_64 -kernel bzImage -initrd rootfs.cpio \
    -append "console=ttyS0" -nographic
```

## 🎯 闯关任务:认识你的第一个内核题

由于内核 PWN 需要专门的 QEMU 环境,这里给出"认知任务":

1. 找一个入门内核题(如 `CTFWiki` 的 kernel-ctf 题目),启动 QEMU,进去执行 `id` 看当前身份。
2. 用 `cat /proc/kallsyms | grep commit_creds` 观察内核符号(如果没禁)。
3. 理解目标:通过漏洞调用 `commit_creds(prepare_kernel_cred(0))` 把自己变成 root。

记住这个经典提权组合:

```c
commit_creds(prepare_kernel_cred(0));  // 内核里执行 → 当前进程变root
```
