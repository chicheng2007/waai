# 第 14 关 · printf 嘴瓢：格式化字符串漏洞

## 🎬 游戏开场

游戏里有个**传话 NPC**。你跟它说话，它会把你的话重复给大家听。正常玩法是：

```
你说："你好"
NPC 喊："你好"
```

但有一天你发现，NPC 有个坏习惯：**它会把你话里的 `%` 开头的符号，当成"特殊指令"来执行**，而不是原样喊出来。

比如你说：

```
NPC，喊出" %p "
```

它不去喊 "%p" 这两个字符，而是把**旁边某个玩家的私密信息**（内存里的一个值）喊了出来！

你说："喊出第 8 个 %p"——它真的去翻栈上第 8 个位置的值。

你说："把数字写到我指的地方（%n）"——它居然真的改了那个地方的数据！

这就是 **格式化字符串漏洞**：**程序把用户输入直接当成 `printf` 的格式串，导致玩家能用特殊的 `%` 指令读取和改写内存。**

---

## 🧠 核心概念（游戏版）

### 1. 漏洞长什么样？

**错误写法**（有漏洞）：

```c
void echo(char *user_input) {
    printf(user_input);     // ← 用户的话直接当格式串！嘴瓢了
}
```

**正确写法**：

```c
void echo(char *user_input) {
    printf("%s", user_input);   // ← 把用户的话当"普通字符串"打印
}
```

区别在哪？在错误写法里，你输入 `%p`、`%x`、`%n` 这些符号会被 `printf` 当成"命令"解释。

### 2. printf 的"指令集"

`printf` 支持一堆以 `%` 开头的格式符，其中几个是玩家的"作弊指令"：

| 格式符 | 游戏效果 | 用途 |
| --- | --- | --- |
| `%p` | 打印一个指针（地址） | 泄露地址 |
| `%x` | 打印十六进制数 | 泄露栈上数据 |
| `%s` | 把某个地址当字符串打印 | 读取任意地址内容 |
| `%n` | **把已打印的字符数写入指定地址** | 任意地址写（大杀器） |
| `%<数字>$p` | 直接打印第 N 个参数 | 精确定位 |
| `%<数字>c` | 打印指定宽度的字符 | 控制 `%n` 写入的数值 |

### 3. 为什么能读到"别人的信息"？

这里要理解一个 C 语言的坑：`printf` 怎么知道该打印几个参数？

```c
printf("数字是 %d\n", x);   // 格式串说要1个参数，你提供了1个 ✓
printf(user_input);         // 格式串是用户给的，但没提供任何参数 ✗
```

当格式串里有 `%p` 但程序没传对应参数时，`printf` 会**去栈/寄存器里随便抓一个值**当参数。

游戏比喻：NPC 收到指令"喊出第3个玩家的信息"，但没第三个玩家——它不管，直接从旁边的队伍里随便抓一个人喊出来。而这个"队伍"就是栈上的数据。

所以：

```
输入 %p  → 打印栈上一个随机的值（可能是返回地址、Canary...）
输入 %p%p%p...  → 把栈上一串值全打印出来
```

### 4. 定位参数：$ 语法

`printf` 的参数按顺序存在寄存器和栈里。64 位下：

- 前 6 个"参数"从寄存器 `rsi, rdx, rcx, r8, r9`取（rdi 被格式串占了）。
- 第 7 个开始从栈上取。

用 `%N$p` 可以直接指定"第 N 个参数"，不用一路 `%p` 数过去。

**关键**：你的输入本身也在栈上！所以存在一个偏移 N，使得 `%N$p` 打印的是**你自己输入的开头几个字节**。找到这个 N，你就能把"想要的地址"放进输入里，再用 `%N$s` 读取那个地址的内容——**任意地址读**。

> 🎮 找偏移的技巧：输入 `AAAA` + 一串 `%p`，看看第几个 `%p` 打印出 `0x41414141`（A 的十六进制），那个位置就是你的输入起点。

## 🔧 真实世界对照

| 游戏说法 | 真实术语 |
| --- | --- |
| 传话 NPC | printf 函数 |
| 特殊指令 | 格式符 %p/%s/%n 等 |
| 乱抓参数 | 读取栈/寄存器上的非预期数据 |
| 定位第N个 | `%N$` 位置参数语法 |

**识别漏洞**：看到 `printf(x)`、`sprintf(buf, x)`、`fprintf(..., x)` 且 x 是用户可控的，就是格式化字符串漏洞。

## 🎯 闯关任务：让 NPC 泄密

写程序：

```c
// fmt.c
#include <stdio.h>
void echo() {
    char buf[100];
    read(0, buf, 100);
    printf(buf);      // 有漏洞！
}
int main(){ echo(); return 0; }
```

```bash
gcc -g -O0 -no-pie -fno-stack-protector fmt.c -o fmt
```

任务：

1. 运行，输入 `%p.%p.%p.%p.%p.%p.%p.%p`，观察打印出的地址串。
2. 找到哪个位置开始出现你的输入（用 `AAAA%p.%p...` 测试，找 `0x41414141`）。
3. 试试 `%7$s`（把第7个参数当字符串打印），看看会不会读到有趣的东西。

## 📌 本关小结

| 你学会了 | 一句话记忆 |
| --- | --- |
| 格式化字符串漏洞 | 用户输入被当成 printf 格式串 |
| 成因 | `printf(user_input)` 而不是 `printf("%s", user_input)` |
| 利用 | `%p` 泄露、`%s` 读内存、`%n` 写内存 |
| 定位 | `%N$` 指定第 N 个参数 |
| 找偏移 | 输入 AAAA，找到 0x41414141 出现的位置 |
