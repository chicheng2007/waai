# 第 2 章 搭建 Python 开发环境

## 本章目标

读完并做完这一章，你将拥有：

- 一个可以正常运行的 Python 环境
- 一个趁手的代码编辑器（VS Code）
- 能安装和管理第三方库的能力
- 独立解决"装不上库"这类常见问题的能力

> **重要提醒**：这一章请务必**动手操作**，只看不练等于没学。遇到和教程不一样的地方，先按教程走完，再回头研究差异。

## 2.1 先搞懂几个名词

新手最容易被一堆名词搞晕。先花五分钟搞清楚它们，后面就顺畅了。

| 名词 | 通俗解释 | 类比 |
|------|---------|------|
| Python | 一门编程语言 | 一种"语言"，比如汉语 |
| 解释器 | 执行 Python 代码的程序 | 一个"翻译官"，把 Python 翻译成计算机能懂的指令 |
| Python 环境 | 解释器 + 一堆配套工具 | 一整套"汉语教学设备" |
| pip | Python 的包管理工具 | 一个"应用商店"，用来安装别人写好的代码库 |
| 库/包/模块 | 别人写好的、可复用的代码 | "工具箱"，比如专门做数学的工具箱 |
| IDE / 编辑器 | 写代码的软件 | "高级记事本"，带语法高亮、自动补全 |
| 虚拟环境 | 隔离的项目环境 | "独立的工具间"，不同项目互不干扰 |

### 2.1.1 为什么会有 Python 2 和 Python 3

Python 有两个大版本：Python 2 和 Python 3。它们语法不兼容。Python 2 已经停止维护多年，**本教程全部使用 Python 3**，请务必安装 3.10 或更高版本。

> **注意**：如果你看到网上老教程里写 `print "hello"`（没有括号），那是 Python 2 的写法，在 Python 3 里会报错。Python 3 要写成 `print("hello")`。

## 2.2 安装 Python

### 2.2.1 Windows 系统

**第一步：下载安装包**

1. 打开 Python 官网：<https://www.python.org/downloads/>
2. 点击页面上醒目的 "Download Python 3.x.x" 按钮（会自动推荐最新版）
3. 下载得到一个 `.exe` 文件，类似 `python-3.12.0-amd64.exe`

**第二步：安装**

1. 双击安装包
2. **极其重要**：勾选底部的 **"Add python.exe to PATH"**（把 Python 加入系统路径）
   - 这一步如果不勾选，后面在命令行里敲 `python` 会提示"不是内部或外部命令"
   - 如果你是中文系统，这一项显示为"将 Python 添加到 PATH"
3. 选择 "Install Now"（默认安装）即可
4. 等待安装完成，出现 "Setup was successful" 就成功了

**第三步：验证**

1. 按 `Win + R`，输入 `cmd`，回车，打开命令提示符
2. 在黑色窗口里输入：

```cmd
python --version
```

3. 如果显示类似 `Python 3.12.0`，说明安装成功

> 如果你的电脑上 `python` 命令没反应，试试 `python3 --version` 或 `py --version`。Windows 上这几种命令都可能有效。

### 2.2.2 macOS 系统

macOS 系统自带了 Python 2，但我们需要 Python 3。

**方法一：官网安装包（推荐新手）**

1. 打开 <https://www.python.org/downloads/>
2. 下载 macOS 版本的安装包（`.pkg` 文件）
3. 双击安装，一路点"继续"

**方法二：使用 Homebrew（如果你已经装了）**

```bash
brew install python
```

**验证**：打开"终端"（Terminal），输入：

```bash
python3 --version
```

显示 `Python 3.x.x` 即成功。注意 macOS 上通常用 `python3` 而不是 `python`（因为 `python` 可能指向系统自带的 Python 2）。

### 2.2.3 Linux 系统（以 Ubuntu 为例）

大部分 Linux 发行版自带 Python 3，先检查：

```bash
python3 --version
```

如果版本低于 3.10 或没安装：

```bash
sudo apt update
sudo apt install python3 python3-pip
```

## 2.3 安装代码编辑器 VS Code

虽然 Python 自带一个叫 IDLE 的简单编辑器，但 Professionals 都用 VS Code。它免费、强大、插件丰富。

**安装步骤**：

1. 打开官网：<https://code.visualstudio.com/>
2. 下载对应系统的版本
3. 安装（Windows 一路下一步即可；macOS 拖进应用程序文件夹）

**必装插件**：

打开 VS Code，点击左侧的扩展图标（四个方块），搜索并安装：

1. **Python**（Microsoft 官方出品）——提供语法高亮、代码补全、运行调试
2. **Pylance**——更强的智能提示（装 Python 时通常会提示一起装）

> **小白问**：VS Code、PyCharm、Jupyter 用哪个？
>
> **答**：本教程推荐 VS Code，因为它轻量、通用、免费。PyCharm 是专业 Python IDE， heavier；Jupyter 是做数据分析的利器，第四卷会用到。初学阶段先把 VS Code 用熟就够了。

## 2.4 你的第一个程序：Hello World

按照国际惯例，学任何语言的第一件事都是让程序输出 "Hello, World!"。

### 2.4.1 用 VS Code 运行

1. 在电脑上新建一个文件夹，比如 `python_learning`，专门放你的练习代码
2. 用 VS Code 打开这个文件夹（文件 → 打开文件夹）
3. 在文件夹里新建一个文件，命名为 `hello.py`（注意后缀必须是 `.py`）
4. 在文件里输入以下代码：

```python
print("Hello, World!")
```

5. 运行方式：在代码区域点右键 → "Run Python File in Terminal"，或者点右上角的播放按钮 ▶

如果终端里显示 `Hello, World!`，恭喜你，你已经是程序员了！

### 2.4.2 逐行解释

```python
print("Hello, World!")
```

- `print`：Python 内置的函数，作用是"把括号里的内容打印到屏幕上"
- `()`：圆括号表示"调用函数"，括号里放的是要打印的内容
- `"Hello, World!"`：用双引号括起来的文字，叫做"字符串"。Python 会把引号里的内容原样输出
- 整行意思：**调用 print 函数，让它把 "Hello, World!" 显示出来**

### 2.4.3 动手试试

把代码改成下面这样，看看会发生什么：

```python
print("你好，世界！")
print(2026)
print(3 + 5)
print("我叫", "小明")
```

运行结果应该是：

```
你好，世界！
2026
8
我叫 小明
```

观察到什么了吗？`print` 不仅能打印文字，还能打印数字、做计算、一次打印多个东西（用逗号隔开）。

> **注意**：中文输出在有些 Windows 命令行里可能显示乱码。如果乱码，在 VS Code 内置的终端里运行一般没问题，因为 VS Code 默认用 UTF-8 编码。

## 2.5 用命令行运行 Python

除了在编辑器里点按钮，你还应该学会用命令行运行，这是基本功。

1. 打开命令行（Windows 用 cmd 或 PowerShell，macOS/Linux 用终端）
2. 用 `cd` 命令切换到你的代码文件夹：

```cmd
cd 你的文件夹路径
```

例如：

```cmd
cd C:\Users\你的用户名\python_learning
```

3. 输入：

```cmd
python hello.py
```

（macOS/Linux 用 `python3 hello.py`）

4. 看到 `Hello, World!` 即成功

> **小白问**：`cd` 是什么？
>
> **答**：`cd` 是 "change directory" 的缩写，意思是"切换目录/进入文件夹"。命令行里你需要先"走到"文件所在的文件夹，才能直接运行里面的文件。

## 2.6 安装第三方库：pip 的使用

Python 之所以强大，是因为有海量免费的第三方库。安装它们用 `pip` 命令。

### 2.6.1 基本用法

打开命令行，输入：

```bash
pip install 库名
```

例如安装后面要用的 NumPy：

```bash
pip install numpy
```

macOS/Linux 上如果提示权限问题，用：

```bash
pip3 install numpy
```

### 2.6.2 常用 pip 命令

```bash
# 安装库
pip install numpy

# 安装指定版本
pip install numpy==1.24.0

# 卸载库
pip uninstall numpy

# 查看已安装的库
pip list

# 升级库
pip install --upgrade numpy

# 导出当前环境所有库（后面做项目很有用）
pip freeze > requirements.txt

# 根据 requirements.txt 批量安装
pip install -r requirements.txt
```

### 2.6.3 国内镜像加速（很重要）

默认情况下，pip 从国外服务器下载库，速度可能很慢甚至失败。使用国内镜像可以大幅提升速度：

```bash
pip install numpy -i https://pypi.tuna.tsinghua.edu.cn/simple
```

常用的国内镜像源：

- 清华：<https://pypi.tuna.tsinghua.edu.cn/simple>
- 阿里云：<https://mirrors.aliyun.com/pypi/simple/>
- 豆瓣：<https://pypi.douban.com/simple/>

**永久配置镜像源**（一劳永逸）：

在命令行执行：

```bash
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

之后再安装包就默认走清华源了。

> **注意**：如果你在公司/学校网络，可能需要配置代理。遇到 `Connection timed out` 错误，多半是网络问题，换镜像源或检查网络。

### 2.6.4 常见的安装报错

**报错 1：`'pip' 不是内部或外部命令`**

原因：Python 没加到 PATH，或者 pip 没装好。
解决：重新安装 Python，务必勾选 "Add python.exe to PATH"。

**报错 2：`Could not find a version that satisfies the requirement xxx`**

原因：库名拼错了，或者该库不支持你的 Python 版本。
解决：检查拼写；尝试 `pip install --upgrade pip` 升级 pip。

**报错 3：`Microsoft Visual C++ 14.0 is required`**（Windows）

原因：某些库需要编译，缺少 C++ 编译环境。
解决：去微软官网下载 "Visual Studio Build Tools"，或者安装 Anaconda（自带编译好的库）。

## 2.7 关于 Anaconda（可选但推荐）

Anaconda 是一个 Python 发行版，预装了数据分析和 AI 常用的几乎所有库，还带一个强大的环境管理工具 `conda`。

**优点**：
- 一次安装，NumPy、Pandas、Matplotlib、scikit-learn 全都有
- 环境管理方便，避免库版本冲突
- Windows 上无需单独配置编译环境

**缺点**：
- 安装包较大（约 500MB–1GB）
- 占用磁盘空间较多

**建议**：
- 如果你只是想快速开始，装 Anaconda 最省心
- 如果你喜欢轻量、可控，用官方 Python + pip 也完全没问题
- 本教程后续会讲虚拟环境（第 12 章），用哪种方式都能配合

**安装 Anaconda**：

1. 打开官网：<https://www.anaconda.com/download>
2. 下载对应系统的安装包
3. Windows 安装时，在 "Advanced Installation Options" 界面勾选 **"Add Anaconda to PATH"** 和 **"Register Anaconda as default Python"**（虽然 installer 不推荐勾选，但新手勾上更省事）
4. 安装完成后，打开 "Anaconda Prompt"，输入 `python --version` 验证

> 如果你装了 Anaconda，后续安装包可以改用 `conda install 库名` 或继续用 `pip install`，两者可以混用（但建议一个环境里优先用一种）。

## 2.8 虚拟环境初体验（先有个印象）

不同项目可能需要不同版本的库。比如项目 A 需要 NumPy 1.20，项目 B 需要 NumPy 1.24。如果都装在系统 Python 里，就会打架。

**虚拟环境**就是给每个项目一个独立的"工具间"，互不干扰。

Python 3 自带 `venv` 模块，创建虚拟环境很简单：

```bash
# 创建名为 myenv 的虚拟环境
python -m venv myenv

# 激活（Windows）
myenv\Scripts\activate

# 激活（macOS/Linux）
source myenv/bin/activate
```

激活后，命令行前面会出现 `(myenv)` 字样，表示你在虚拟环境里。此时用 `pip install` 安装的库只在这个环境里生效。

退出虚拟环境：

```bash
deactivate
```

第 12 章会详细讲虚拟环境和包管理。这里你只需要知道：**做项目时先建虚拟环境，是个好习惯**。
