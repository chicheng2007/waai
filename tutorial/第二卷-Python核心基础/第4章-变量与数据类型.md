## 4.1 变量：数据的"容器"

### 4.1.1 重新认识变量

第 3 章我们已经初步接触了变量。这里做一个更精确的比喻：

**变量 = 一个贴了标签的盒子**。

- 盒子本身叫"变量名"
- 盒子里装的东西叫"值"
- 往盒子里放东西的动作叫"赋值"，用 `=` 表示

```python
ip = "192.168.1.1"
```

这行代码的意思是：创建一个叫 `ip` 的盒子，把字符串 `"192.168.1.1"` 放进去。

之后你只要喊 `ip`，Python 就知道你要用这个盒子里的东西：

```python
print(ip)   # 输出: 192.168.1.1
```

### 4.1.2 赋值的多种写法

**基本赋值**：

```python
x = 10
y = 20
```

**链式赋值**（多个变量同一个值）：

```python
a = b = c = 100
print(a, b, c)   # 100 100 100
```

**同时赋值**（一一对应，非常 Pythonic）：

```python
name, age = "小明", 18
print(name, age)   # 小明 18

# 经典应用：交换两个变量的值
a, b = 1, 2
a, b = b, a        # 一行搞定交换
print(a, b)        # 2 1
```

在其他语言里交换两个变量需要临时变量，Python 一行就够了，这是它优雅的体现。

**增强赋值**（后面运算符部分详讲）：

```python
x = 10
x += 5    # 等价于 x = x + 5
print(x)  # 15
```

### 4.1.3 变量的命名规范

技术上，变量名要遵守：

1. 只能包含字母、数字、下划线
2. 不能以数字开头
3. 不能是 Python 关键字
4. 区分大小写

**但"能写"不等于"该写"**。Python 社区有一套公认的命名规范（PEP 8），专业开发者都遵守：

| 场景 | 规范 | 示例 |
|------|------|------|
| 普通变量/函数 | 小写 + 下划线 | `user_name`, `learning_rate` |
| 常量 | 全大写 + 下划线 | `MAX_RETRY = 3` |
| 类名 | 大驼峰 | `NetworkScanner` |
| 私有变量 | 下划线开头 | `_internal_var` |
| 避免 | 单字母（循环除外）、拼音混英文 | 少用 `a`, `b`，除非是临时变量 |

查看 Python 所有关键字：

```python
import keyword
print(keyword.kwlist)
```

> **注意**：不要用 `list`、`str`、`dict`、`id` 等内置名词当变量名，会覆盖掉 Python 自带的功能，导致奇怪的 bug。

## 4.2 六种基本数据类型

Python 有六种基本数据类型，我们先认识前四种，后两种在第 7 章讲。

### 4.2.1 数字（Number）

Python 的数字主要分三种：

**整数（int）**：没有小数部分的数

```python
age = 18
count = -5
big = 12345678901234567890   # Python 的 int 可以是任意大，不会溢出
print(type(age))   # <class 'int'>
```

**浮点数（float）**：带小数点的数

```python
pi = 3.14159
temperature = -0.5
scientific = 1.5e3    # 科学计数法，等于 1500.0
print(type(pi))       # <class 'float'>
```

> **注意**：浮点数有精度问题。这是计算机用二进制表示小数的固有缺陷：
> ```python
> print(0.1 + 0.2)   # 0.30000000000000004，而不是 0.3
> ```
> 涉及精确计算（如金额）时，用 `decimal` 模块或先转成整数再算。

**复数（complex）**：形如 `a + bj`，AI 的傅里叶变换等场景会用到，初学阶段了解即可

```python
z = 3 + 4j
print(z.real)   # 3.0  实部
print(z.imag)   # 4.0  虚部
```

### 4.2.2 字符串（String，str）

字符串是**用引号包起来的一串文字**。引号可以是单引号、双引号或三引号：

```python
s1 = "hello"
s2 = '你好'
s3 = """这是一个
多行字符串"""
```

字符串的核心操作（第 8 章详解，这里先混个脸熟）：

```python
ip = "192.168.1.1"
print(ip[0])       # '1'  取第一个字符（下标从 0 开始）
print(len(ip))     # 12   字符串长度
print("192" in ip) # True 判断子串是否存在
```

### 4.2.3 布尔值（Boolean，bool）

布尔值只有两个：`True` 和 `False`。它是所有逻辑判断的基础。

```python
is_admin = True
is_banned = False
print(type(is_admin))   # <class 'bool'>
```

**布尔值其实是特殊的整数**：`True == 1`，`False == 0`。这在某些场景下很有用：

```python
print(True + True)   # 2  （1+1）
print(False * 100)   # 0
```

**真值测试**：在 Python 中，很多东西都能当"真假"用。记住这条规则：

> 以下值在布尔上下文中被视为 **False**（假值）：
> `False`、`0`、`0.0`、`""`（空字符串）、`[]`（空列表）、`{}`（空字典）、`()`（空元组）、`None`
>
> 其他一切通常都被视为 True。

```python
if "":
    print("这行不会执行")
else:
    print("空字符串是假值")   # 输出这句
```

这个规则在安全脚本里非常常用，比如判断配置是否为空：

```python
config = ""
if not config:
    print("配置为空，使用默认值")
```

### 4.2.4 空值（None）

`None` 表示"什么都没有"，是 Python 的空值。它和 `False`、`0`、空字符串都不一样。

```python
result = None
print(result is None)   # True  —— 判断是否为空用 is
```

`None` 常用来表示"函数没有返回值"或"尚未初始化的状态"。

### 4.2.5 如何查看数据类型：type()

```python
print(type(18))        # <class 'int'>
print(type(3.14))      # <class 'float'>
print(type("hello"))   # <class 'str'>
print(type(True))      # <class 'bool'>
print(type(None))      # <class 'NoneType'>
```

### 4.2.6 数据类型转换

不同数据类型之间可以互相转换：

```python
# 转成整数
int("100")      # 100
int(3.9)        # 3  注意：直接截断小数，不是四舍五入
int("1010", 2)  # 10  把二进制字符串转成整数

# 转成浮点数
float("3.14")   # 3.14
float(10)       # 10.0

# 转成字符串
str(100)        # '100'
str(3.14)       # '3.14'

# 转成布尔值
bool(0)         # False
bool(1)         # True
bool("")        # False
bool("hello")   # True
```

**转换失败的后果**：

```python
int("abc")   # ValueError: invalid literal for int()
```

所以处理用户输入或外部数据时，最好做异常保护（第 10 章会讲 `try-except`）：

```python
user_input = "abc"
try:
    num = int(user_input)
    print("转换成功:", num)
except ValueError:
    print("输入不是合法的数字!")
```

## 4.3 运算符

### 4.3.1 算术运算符

假设 `a = 10`, `b = 3`：

| 运算符 | 含义 | 示例 | 结果 |
|--------|------|------|------|
| `+` | 加 | `a + b` | 13 |
| `-` | 减 | `a - b` | 7 |
| `*` | 乘 | `a * b` | 30 |
| `/` | 除 | `a / b` | 3.3333...（永远是 float） |
| `//` | 整除（地板除） | `a // b` | 3（向下取整） |
| `%` | 取余（模） | `a % b` | 1 |
| `**` | 幂 | `a ** b` | 1000 |

**整除的细节**：

```python
print(10 // 3)     # 3
print(-10 // 3)    # -4  （向下取整，不是 -3！）
```

**取余的经典用途**（安全/算法里高频）：

```python
# 判断奇偶
num = 7
if num % 2 == 0:
    print("偶数")
else:
    print("奇数")

# 循环使用端口列表（取余实现"绕回"）
ports = [80, 443, 22]
for i in range(5):
    print(ports[i % len(ports)])
# 80 443 22 80 443
```

**字符串和列表也能用 `+` 和 `*`**：

```python
print("hello" + " " + "world")   # hello world
print("ha" * 3)                  # hahaha
print([1, 2] + [3, 4])           # [1, 2, 3, 4]
print([0] * 5)                   # [0, 0, 0, 0, 0]
```

### 4.3.2 比较运算符

比较的结果永远是布尔值 `True` 或 `False`：

假设 `a = 10`, `b = 3`：

| 运算符 | 含义 | 示例 | 结果 |
|--------|------|------|------|
| `==` | 等于 | `a == b` | False |
| `!=` | 不等于 | `a != b` | True |
| `>` | 大于 | `a > b` | True |
| `<` | 小于 | `a < b` | False |
| `>=` | 大于等于 | `a >= b` | True |
| `<=` | 小于等于 | `a <= b` | False |

> **超级常见的坑**：`=` 是赋值，`==` 才是比较！
> ```python
> x = 5        # 赋值：把 5 放进 x
> print(x == 5)  # 比较：x 里装的是不是 5？输出 True
> ```

**链式比较**（Python 特色，很优雅）：

```python
age = 20
print(18 <= age < 60)   # True，等价于 18 <= age and age < 60

# 判断 IP 是否在某段（简单示意）
port = 8080
print(1024 < port < 65535)   # True
```

### 4.3.3 逻辑运算符

| 运算符 | 含义 | 示例 | 说明 |
|--------|------|------|------|
| `and` | 与 | `a and b` | 两边都为 True 才返回 True |
| `or` | 或 | `a or b` | 一边为 True 就返回 True |
| `not` | 非 | `not a` | 取反 |

**短路求值**（重要）：

- `A and B`：如果 A 为 False，B 根本不会执行（因为结果已定为 False）
- `A or B`：如果 A 为 True，B 根本不会执行（因为结果已定为 True）

```python
# 利用短路避免除零错误
x = 0
if x != 0 and 10 / x > 2:   # x != 0 为 False，后面的 10/x 不会执行
    print("ok")
else:
    print("避免了除零错误")
```

**逻辑运算符返回的是"值"而不只是布尔值**：

```python
print(0 or "默认值")       # 默认值  （0 是假值，返回后面的）
print("hello" and "world") # world   （都是真值，返回最后一个）
print("" or [1, 2])        # [1, 2]
```

这个特性常用于设置默认值：

```python
def connect(host=None):
    host = host or "127.0.0.1"   # host 为空时用默认值
    print("连接到", host)
```

### 4.3.4 赋值运算符

| 运算符 | 等价于 | 示例 |
|--------|--------|------|
| `=` | — | `x = 10` |
| `+=` | `x = x + 10` | `x += 10` |
| `-=` | `x = x - 10` | `x -= 10` |
| `*=` | `x = x * 10` | `x *= 10` |
| `/=` | `x = x / 10` | `x /= 10` |
| `//=` | `x = x // 10` | `x //= 10` |
| `%=` | `x = x % 10` | `x %= 10` |
| `**=` | `x = x ** 10` | `x **= 10` |

### 4.3.5 成员运算符

判断一个元素是否在某个容器（字符串、列表、字典、集合）里：

| 运算符 | 含义 | 示例 |
|--------|------|------|
| `in` | 在...里面 | `"192" in ip` |
| `not in` | 不在...里面 | `"admin" not in username` |

```python
ip = "192.168.1.1"
print("192" in ip)        # True
print("admin" not in "administrator")  # False

# 在列表里查找（安全场景：判断 IP 是否在黑名单）
blacklist = ["10.0.0.1", "192.168.1.100"]
ip = "10.0.0.1"
if ip in blacklist:
    print("该 IP 在黑名单中，拒绝访问!")
```

### 4.3.6 身份运算符

| 运算符 | 含义 |
|--------|------|
| `is` | 两个变量是否指向同一个对象 |
| `is not` | 是否指向不同对象 |

`is` 和 `==` 的区别是新手必考知识点：

- `==` 比较的是**值**是否相等
- `is` 比较的是**内存地址**（是不是同一个对象）

```python
a = [1, 2, 3]
b = [1, 2, 3]
print(a == b)    # True  —— 值一样
print(a is b)    # False —— 是两个不同的列表对象

c = a
print(a is c)    # True  —— c 和 a 指向同一个对象
```

**判断 None 时永远用 `is`**：

```python
x = None
print(x is None)   # True  ✓ 推荐
print(x == None)   # True  能工作，但不推荐
```

> **注意**：Python 对小整数（-5 到 256）和某些字符串做了缓存（叫"驻留"），所以 `a = 100; b = 100; a is b` 可能是 True。但这是实现细节，不要依赖它做业务逻辑判断。

### 4.3.7 位运算符（了解即可）

直接操作二进制位，在底层优化、加密、权限标志等场景会用到：

| 运算符 | 含义 | 示例（a=6, b=3） | 结果 |
|--------|------|-----------------|------|
| `&` | 按位与 | `a & b` | 2（110 & 011 = 010） |
| `\|` | 按位或 | `a \| b` | 7（110 \| 011 = 111） |
| `^` | 按位异或 | `a ^ b` | 5（110 ^ 011 = 101） |
| `~` | 按位取反 | `~a` | -7 |
| `<<` | 左移 | `a << 1` | 12（相当于 ×2） |
| `>>` | 右移 | `a >> 1` | 3（相当于 ÷2） |

**权限标志的经典用法**：

```python
READ = 4    # 二进制 100
WRITE = 2   # 二进制 010
EXEC = 1    # 二进制 001

# 用 | 组合权限
perm = READ | WRITE   # 6，二进制 110，表示可读写
print(perm)

# 用 & 检查权限
if perm & EXEC:
    print("有执行权限")
else:
    print("无执行权限")   # 输出这句
```

### 4.3.8 运算符优先级

当一个表达式里有多个运算符时，Python 按优先级计算。从高到低（常用部分）：

```
**                    幂（最高）
~ + -                 取反、正负号
* / // %              乘除整除取余
+ -                   加减
<< >>                 移位
&                     按位与
^                     按位异或
|                     按位或
== != > < >= <=       比较
is / is not           身份
in / not in           成员
not                   逻辑非
and                   逻辑与
or                    逻辑或（最低）
```

**示例**：

```python
result = 2 + 3 * 4 ** 2   # 2 + 3 * 16 = 2 + 48 = 50
print(result)              # 50
```

> **黄金法则**：**不确定就加括号**。括号的优先级最高，而且能让代码更易读。别为了省几个字符牺牲可读性。
>
> ```python
> result = 2 + (3 * (4 ** 2))   # 更清晰
> ```

## 4.4 综合实战：写一个端口状态判断小程序

把本章学到的知识串起来：

```python
# 端口状态分析小程序
# 综合应用：变量、数据类型、运算符、成员判断

# 常量（全大写表示不该被修改）
COMMON_PORTS = {
    "HTTP": 80,
    "HTTPS": 443,
    "SSH": 22,
    "FTP": 21,
    "MySQL": 3306,
}

# 高危险端口列表
DANGEROUS_PORTS = [23, 445, 3389]  # Telnet, SMB, RDP

# 模拟检测到的开放端口
open_ports = [22, 80, 3389, 8080]

print("=== 端口安全分析报告 ===\n")
for port in open_ports:
    # 判断是否是常见服务
    service = "未知服务"
    for name, p in COMMON_PORTS.items():
        if port == p:
            service = name
            break
    
    # 判断是否危险
    if port in DANGEROUS_PORTS:
        level = "[高危]"
    elif 1024 <= port <= 65535:
        level = "[普通]"
    else:
        level = "[需关注]"
    
    print(f"端口 {port}: {service} {level}")

print("\n=== 统计 ===")
print(f"共发现 {len(open_ports)} 个开放端口")
print(f"其中高危端口 {len([p for p in open_ports if p in DANGEROUS_PORTS])} 个")
```

运行结果：

```
=== 端口安全分析报告 ===

端口 22: SSH [普通]
端口 80: HTTP [普通]
端口 3389: 未知服务 [高危]
端口 8080: 未知服务 [普通]

=== 统计 ===
共发现 4 个开放端口
其中高危端口 1 个
```

> **说明**：这个程序用了字典、列表、for 循环等还没系统讲的知识。看不懂没关系，先运行看效果，等学完第 5、7 章再回来看，你会发现自己已经能完全理解它了。这就是"先见森林，再见树木"的学习方法。
