# 第 5 章 条件判断与循环

## 本章目标

- 熟练使用 `if / elif / else` 做条件判断
- 掌握 `for` 循环和 `while` 循环
- 理解 `break`、`continue`、`pass` 的作用
- 掌握 `range()` 的各种用法

程序的三大基本结构：**顺序、分支、循环**。前面学的代码都是从上到下顺序执行，这一章我们给程序加上"判断"和"重复"的能力。

## 5.1 条件判断：if 语句

### 5.1.1 最基本的 if

```python
score = 85
if score >= 60:
    print("恭喜，及格了!")
```

语法要点：

1. `if` 后面跟一个条件表达式
2. 条件后面加**冒号** `:`
3. 条件成立时要执行的代码必须**缩进**（通常 4 个空格）
4. 缩进是 Python 用来划分代码块的唯一方式（其他语言用 `{}`）

> **注意**：缩进错误是初学者最常犯的错误。同一代码块内的语句必须缩进相同的空格数。混用 Tab 和空格会导致 `TabError`。强烈建议统一用 4 个空格（VS Code 默认就是）。

### 5.1.2 if-else：二选一

```python
age = 16
if age >= 18:
    print("你已成年，可以进入")
else:
    print("抱歉，未成年人禁止入内")
```

`else` 后面也加冒号，代码同样缩进。`else` 在 `if` 条件为 False 时执行。

### 5.1.3 if-elif-else：多选一

```python
score = 75

if score >= 90:
    grade = "优秀"
elif score >= 80:
    grade = "良好"
elif score >= 70:
    grade = "中等"
elif score >= 60:
    grade = "及格"
else:
    grade = "不及格"

print(f"你的等级是: {grade}")   # 中等
```

要点：

- `elif` 是 "else if" 的缩写，可以有任意多个
- Python 从上到下依次判断，**第一个满足的条件被执行，后面的全部跳过**
- `else` 是可选的，且只能有一个，必须放在最后

**关键：条件的顺序很重要！**

```python
# 错误示例：顺序反了，所有分数都会落到第一个分支
if score >= 60:
    grade = "及格"
elif score >= 90:
    grade = "优秀"   # 永远执行不到
```

### 5.1.4 嵌套 if

if 里面还能套 if：

```python
username = "admin"
password = "123456"

if username == "admin":
    if password == "123456":
        print("登录成功!")
    else:
        print("密码错误")
else:
    print("用户名不存在")
```

> **建议**：嵌套别超过 2–3 层，否则代码会变成"箭头代码"（一层层缩进像箭头），难以阅读。深层嵌套通常可以用逻辑运算符或提前返回来简化（第 6 章讲函数时会介绍）。

### 5.1.5 条件表达式（三元运算符）

简单的二选一可以写成一行：

```python
age = 20
status = "成年" if age >= 18 else "未成年"
print(status)   # 成年
```

语法：`值1 if 条件 else 值2`。条件为 True 取值1，否则取值2。

**安全场景示例**：

```python
failed_attempts = 5
action = "锁定账户" if failed_attempts >= 5 else "允许重试"
print(action)   # 锁定账户
```

### 5.1.6 多个条件的组合

用 `and`、`or`、`not` 组合条件：

```python
# 登录验证：用户名正确 且 密码正确
username = "admin"
password = "wrong"
if username == "admin" and password == "123456":
    print("登录成功")
else:
    print("登录失败")

# 判断是否是工作日
day = "周六"
if day == "周六" or day == "周日":
    print("周末，休息")
else:
    print("工作日，上班")

# 判断 IP 是否不在内网段
ip = "8.8.8.8"
if not ip.startswith("192.168"):
    print("这是外网 IP")
```

## 5.2 for 循环：遍历容器

### 5.2.1 遍历列表

`for` 循环用来"依次取出容器里的每个元素"：

```python
fruits = ["苹果", "香蕉", "橘子"]
for fruit in fruits:
    print(fruit)
```

输出：

```
苹果
香蕉
橘子
```

执行过程：第一次循环，`fruit` = "苹果"；第二次，`fruit` = "香蕉"；第三次，`fruit` = "橘子"。循环体内用 `fruit` 就能拿到当前元素。

**循环变量命名**：`fruit` 是我们自己起的名字，可以叫任何合法名字。但建议用有意义的复数/单数对应，比如 `for ip in ip_list`。

### 5.2.2 遍历字符串

```python
for char in "AI安全":
    print(char)
```

输出：

```
A
I
安
全
```

### 5.2.3 遍历字典

字典的遍历有三种方式：

```python
user = {"name": "admin", "age": 30, "role": "admin"}

# 1. 默认遍历键（key）
for key in user:
    print(key)
# name age role

# 2. 遍历值（value）
for value in user.values():
    print(value)
# admin 30 admin

# 3. 同时遍历键和值（最常用）
for key, value in user.items():
    print(f"{key}: {value}")
# name: admin
# age: 30
# role: admin
```

### 5.2.4 range()：生成数字序列

`range()` 常和 `for` 配合，用来循环固定次数：

```python
# range(5) 生成 0,1,2,3,4（不含 5）
for i in range(5):
    print(i)

# range(2, 6) 生成 2,3,4,5
for i in range(2, 6):
    print(i)

# range(0, 10, 2) 生成 0,2,4,6,8（步长 2）
for i in range(0, 10, 2):
    print(i)
```

**记忆口诀**：`range(起点, 终点, 步长)`，**含起点，不含终点**。

**用 range 遍历列表下标**：

```python
ports = [22, 80, 443]
for i in range(len(ports)):
    print(f"第 {i+1} 个端口: {ports[i]}")
```

> **更 Pythonic 的写法**：用 `enumerate()` 同时拿到下标和值：
> ```python
> for i, port in enumerate(ports):
>     print(f"第 {i+1} 个端口: {port}")
> ```

### 5.2.5 循环中的 break / continue / pass

**break：立即跳出整个循环**

```python
# 在列表里找某个 IP，找到就停止
ip_list = ["10.0.0.1", "10.0.0.2", "192.168.1.1"]
target = "192.168.1.1"
for ip in ip_list:
    if ip == target:
        print("找到了!", ip)
        break
    print("检查:", ip)
```

**continue：跳过本次循环，进入下一次**

```python
# 只打印偶数端口
for port in [21, 22, 80, 443, 8080]:
    if port % 2 != 0:   # 奇数
        continue
    print("偶数端口:", port)
```

**pass：什么都不做（占位符）**

```python
for i in range(5):
    if i == 2:
        pass   # 暂时跳过，以后再补逻辑
    else:
        print(i)
```

`pass` 常用于"先搭好结构，逻辑以后再写"的场景。

### 5.2.6 循环的 else 子句（冷门但有用）

`for` 和 `while` 都可以带 `else`，**循环正常结束后执行 else；如果是被 break 跳出的，则不执行**：

```python
# 搜索目标，找不到时执行 else
for ip in ["10.0.0.1", "10.0.0.2"]:
    if ip == "8.8.8.8":
        print("找到了")
        break
else:
    print("没找到目标 IP")   # 输出这句
```

这个特性在"搜索失败时给提示"的场景很方便，可以省掉一个标志变量。

## 5.3 while 循环：条件成立就重复

### 5.3.1 基本用法

```python
count = 0
while count < 5:
    print("当前计数:", count)
    count += 1   # 别忘了更新条件，否则死循环!
```

输出：

```
当前计数: 0
当前计数: 1
当前计数: 2
当前计数: 3
当前计数: 4
```

> **超级重要的坑**：`while` 循环必须有让条件最终变为 False 的语句（比如 `count += 1`），否则会**死循环**，程序永远停不下来。如果不小心写了死循环，按 `Ctrl + C` 强制停止。

### 5.3.2 for vs while 怎么选

| 场景 | 用哪个 |
|------|--------|
| 已知循环次数 / 遍历容器 | `for` |
| 不知道要循环几次，靠条件控制 | `while` |
| 用户输入直到满足条件 | `while` |
| 游戏主循环、服务监听 | `while True` |

**示例：猜数字游戏**

```python
import random

secret = random.randint(1, 100)
attempts = 0

while True:
    guess = int(input("猜一个 1-100 的数字: "))
    attempts += 1
    
    if guess < secret:
        print("太小了，再大点")
    elif guess > secret:
        print("太大了，再小点")
    else:
        print(f"恭喜你，猜对了! 用了 {attempts} 次")
        break
```

### 5.3.3 循环里的输入验证

```python
# 直到用户输入合法端口号才继续
while True:
    port_str = input("请输入端口号(1-65535): ")
    if port_str.isdigit():
        port = int(port_str)
        if 1 <= port <= 65535:
            print("合法端口:", port)
            break
    print("输入无效，请重新输入")
```

## 5.4 嵌套循环

循环里面可以套循环：

```python
# 打印 3x3 乘法表
for i in range(1, 4):
    for j in range(1, 4):
        print(f"{i}x{j}={i*j}", end="  ")
    print()   # 换行
```

输出：

```
1x1=1  1x2=2  1x3=3
2x1=2  2x2=4  2x3=6
3x1=3  3x2=6  3x3=9
```

外层循环走一次，内层循环走完一整轮。

**性能注意**：嵌套循环的次数是相乘关系。外层 1000 次 × 内层 1000 次 = 100 万次。数据量大时要小心性能，这也是后面学 NumPy 的原因（向量化替代循环）。

## 5.5 综合实战：简单日志分析器

把条件判断和循环用起来，写一个分析安全日志的小程序：

```python
# 简易日志分析器
# 假设有一批登录日志，每条是 (用户名, 状态) 的元组

logs = [
    ("admin", "SUCCESS"),
    ("root", "FAILED"),
    ("admin", "FAILED"),
    ("guest", "FAILED"),
    ("admin", "SUCCESS"),
    ("root", "FAILED"),
]

failed_count = {}   # 记录每个用户的失败次数

for username, status in logs:
    if status == "FAILED":
        # 累加失败次数
        if username in failed_count:
            failed_count[username] += 1
        else:
            failed_count[username] = 1

print("=== 登录失败统计 ===")
for username, count in failed_count.items():
    if count >= 2:
        print(f"[警告] {username} 失败 {count} 次，可能存在暴力破解!")
    else:
        print(f"{username} 失败 {count} 次")

print("\n=== 可疑账户 ===")
suspects = [u for u, c in failed_count.items() if c >= 2]
if suspects:
    print("需要重点关注:", ", ".join(suspects))
else:
    print("暂无可疑账户")
```

运行结果：

```
=== 登录失败统计 ===
[警告] root 失败 2 次，可能存在暴力破解!
admin 失败 1 次
[警告] guest 失败 1 次... 

（guest 只有 1 次，实际输出以代码逻辑为准）

=== 可疑账户 ===
需要重点关注: root
```

> **动手试试**：修改代码，增加"统计每个用户的成功率"功能。提示：成功次数 / 总次数。

## 5.6 常见错误

**错误 1：忘记冒号**

```python
if age >= 18     # 少了冒号
    print("ok")
```
报错：`SyntaxError: expected ':'`

**错误 2：忘记缩进**

```python
if age >= 18:
print("ok")      # 没缩进
```
报错：`IndentationError: expected an indented block`

**错误 3：while 死循环**

```python
x = 0
while x < 5:
    print(x)     # 忘了 x += 1，永远循环
```
解决：按 `Ctrl+C` 停止，加上更新语句。

**错误 4：混淆 = 和 ==**

```python
if x = 5:        # 写成了赋值
    print("ok")
```
报错：`SyntaxError: invalid syntax`

## 5.7 本章总结

| 知识点 | 核心内容 |
|--------|---------|
| if / elif / else | 条件判断；冒号+缩进；条件顺序影响结果 |
| 三元表达式 | `值1 if 条件 else 值2` |
| 条件组合 | `and` / `or` / `not` |
| for 循环 | 遍历列表/字符串/字典；`range(起,止,步)` 含起不含止 |
| 字典遍历 | `keys()` / `values()` / `items()` |
| 循环控制 | `break` 跳出、`continue` 跳过、`pass` 占位 |
| 循环 else | 正常结束执行，break 跳出不执行 |
| while 循环 | 条件成立就重复；务必更新条件防死循环 |
| 嵌套循环 | 次数相乘，注意性能 |
