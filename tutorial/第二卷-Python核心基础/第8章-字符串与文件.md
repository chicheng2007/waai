## 8.1 字符串基础

### 8.1.1 创建字符串

```python
s1 = "hello"          # 双引号
s2 = 'hello'          # 单引号
s3 = """多行
字符串"""             # 三引号，可跨行

# 引号嵌套
print("他说: '你好'")
print('她说: "再见"')
```

### 8.1.2 转义字符

在字符串里，某些特殊字符需要用反斜杠 `\` 转义：

| 转义序列 | 含义 |
|---------|------|
| `\n` | 换行 |
| `\t` | 制表符（Tab） |
| `\\` | 反斜杠本身 |
| `\"` | 双引号 |
| `\'` | 单引号 |
| `\r` | 回车 |

```python
print("第一行\n第二行")
print("列1\t列2\t列3")
print("路径: C:\\Users\\test")
```

**原始字符串**：如果不想让 `\` 被当成转义符，在字符串前加 `r`：

```python
path = r"C:\Users\test\new"   # \n 不会被当成换行
print(path)   # C:\Users\test\new
```

> **注意**：处理 Windows 文件路径时，用原始字符串或正斜杠 `/` 能避免转义困扰。

### 8.1.3 字符串的索引和切片

字符串本质上是字符序列，操作和列表类似：

```python
ip = "192.168.1.1"

print(ip[0])      # '1'
print(ip[-1])     # '1'
print(ip[0:3])    # '192'
print(ip[:3])     # '192'
print(ip[-3:])    # '1.1'
print(ip[::-1])   # '1.1.861.291'  反转
```

### 8.1.4 字符串的不可变性

字符串一旦创建就不能修改：

```python
s = "hello"
# s[0] = "H"   # 报错！TypeError: 'str' object does not support item assignment

# 想"修改"，只能创建新字符串
s = "H" + s[1:]
print(s)   # Hello
```

## 8.2 字符串常用方法

### 8.2.1 大小写转换

```python
s = "Hello World"
print(s.upper())     # HELLO WORLD  全大写
print(s.lower())     # hello world  全小写
print(s.title())     # Hello World  每个单词首字母大写
print(s.capitalize())# Hello world  整个字符串首字母大写
print(s.swapcase())  # hELLO wORLD  大小写互换
```

**应用**：不区分大小写的比较

```python
user_input = "Admin"
if user_input.lower() == "admin":
    print("匹配成功")
```

### 8.2.2 查找和判断

```python
s = "192.168.1.1"

print(s.find("168"))       # 4  找到，返回位置；找不到返回 -1
print(s.index("168"))      # 4  找到返回位置；找不到报错
print(s.count("1"))        # 5  统计出现次数
print(s.startswith("192")) # True  是否以...开头
print(s.endswith(".1"))    # True  是否以...结尾
print("192" in s)          # True  是否包含
```

**安全场景**：

```python
# 判断文件类型
filename = "malware.exe"
if filename.endswith((".exe", ".bat", ".scr")):
    print("可执行文件，需重点检查")

# 判断是否为内网 IP
ip = "192.168.1.1"
if ip.startswith("192.168."):
    print("内网 IP")
```

### 8.2.3 分割和连接

```python
ip = "192.168.1.1"
parts = ip.split(".")
print(parts)   # ['192', '168', '1', '1']

# 不传参数时按空白字符分割
text = "hello   world  python"
print(text.split())   # ['hello', 'world', 'python']

# splitlines：按行分割
log = "line1\nline2\nline3"
print(log.splitlines())   # ['line1', 'line2', 'line3']

# join：用指定字符串连接列表
parts = ["192", "168", "1", "1"]
print(".".join(parts))   # 192.168.1.1
print("-".join(["a", "b", "c"]))   # a-b-c
```

### 8.2.4 去除空白

```python
s = "  hello  "
print(s.strip())    # 'hello'  去除两端空白
print(s.lstrip())   # 'hello  '  去除左侧
print(s.rstrip())   # '  hello'  去除右侧

# 指定要去除的字符
s = "###hello###"
print(s.strip("#"))   # 'hello'
```

> **应用**：处理用户输入或读取文件时，`strip()` 几乎必用，能去掉不小心多敲的空格和换行符。

### 8.2.5 替换

```python
s = "hello world"
print(s.replace("world", "Python"))   # hello Python

# 指定替换次数
print(s.replace("l", "L", 1))   # heLlo world（只替换第一个）
```

### 8.2.6 对齐和填充

```python
s = "AI"
print(s.center(10, "-"))   # '----AI----'  居中
print(s.ljust(10, "*"))    # 'AI********'  左对齐
print(s.rjust(10, "0"))    # '00000000AI'  右对齐
print("42".zfill(5))       # '00042'  用 0 填充
```

### 8.2.7 字符判断

```python
print("123".isdigit())       # True  全是数字
print("abc".isalpha())       # True  全是字母
print("abc123".isalnum())    # True  全是字母或数字
print("   ".isspace())       # True  全是空白字符
print("Hello".isupper())     # False
print("hello".islower())     # True
```

**应用**：输入验证

```python
port = "8080"
if port.isdigit() and 1 <= int(port) <= 65535:
    print("合法端口")
```

## 8.3 字符串格式化

### 8.3.1 % 格式化（老式）

```python
name = "小明"
age = 18
print("我叫 %s，今年 %d 岁" % (name, age))
```

### 8.3.2 str.format()（较新）

```python
print("我叫 {}，今年 {} 岁".format("小明", 18))
print("我叫 {name}，今年 {age} 岁".format(name="小明", age=18))
```

### 8.3.3 f-string（推荐，Python 3.6+）

在字符串前加 `f`，用 `{变量名}` 直接嵌入变量：

```python
name = "小明"
age = 18
print(f"我叫 {name}，今年 {age} 岁")
```

**f-string 的强大之处**：

```python
# 可以直接写表达式
a, b = 3, 5
print(f"{a} + {b} = {a + b}")   # 3 + 5 = 8

# 格式化数字
pi = 3.1415926
print(f"pi ≈ {pi:.2f}")         # pi ≈ 3.14  保留 2 位小数
print(f"{1000000:,}")           # 1,000,000  千位分隔符

# 对齐
print(f"{'AI':>10}")            # 右对齐，宽度 10
print(f"{'AI':^10}")            # 居中

# 调用方法
name = "hello"
print(f"{name.upper()}")        # HELLO
```

> **强烈推荐**：日常开发一律用 f-string，简洁、直观、性能最好。

## 8.4 编码问题（UTF-8）

### 8.4.1 什么是编码

计算机只能存数字（0 和 1），文字要变成数字才能存，这个"翻译规则"就是编码。

- **ASCII**：最早的编码，只能表示英文字符（1 字节）
- **GBK**：中文编码（中国国标）
- **UTF-8**：国际通用编码，能表示世界上所有语言，是当今互联网的主流

> **黄金法则**：**永远用 UTF-8**。它能避免 99% 的中文乱码问题。

### 8.4.2 encode 和 decode

```python
s = "你好"
b = s.encode("utf-8")     # 字符串 → 字节（编码）
print(b)                  # b'\xe4\xbd\xa0\xe5\xa5\xbd'
print(b.decode("utf-8"))  # 字节 → 字符串（解码）→ 你好
```

### 8.4.3 常见乱码问题

**问题**：打开文件看到"æ±½è½¦"这样的乱码。

**原因**：文件的编码和读取时用的编码不一致（比如文件是 UTF-8，却用 GBK 读取）。

**解决**：读写文件时明确指定 `encoding="utf-8"`（下一节会讲）。

## 8.5 文件操作

### 8.5.1 打开文件：open()

```python
f = open("test.txt", "r", encoding="utf-8")
content = f.read()
print(content)
f.close()   # 用完记得关闭
```

**打开模式**：

| 模式 | 含义 |
|------|------|
| `r` | 读取（默认） |
| `w` | 写入（覆盖原内容） |
| `a` | 追加（在末尾添加） |
| `r+` | 读写 |
| `b` | 二进制模式（如 `rb`、`wb`，用于图片、可执行文件） |

**重要**：加 `b` 模式时不能指定 `encoding`（因为操作的是字节）。

### 8.5.2 推荐写法：with 语句

手动 `close()` 容易忘记，而且中途出错时可能执行不到。用 `with` 语句自动管理：

```python
with open("test.txt", "r", encoding="utf-8") as f:
    content = f.read()
    print(content)
# 离开 with 代码块，文件自动关闭
```

> **强烈推荐**：所有文件操作都用 `with` 语句。这是 Python 的最佳实践。

### 8.5.3 读取文件的几种方式

```python
with open("log.txt", "r", encoding="utf-8") as f:
    # 1. 读取全部内容
    content = f.read()

with open("log.txt", "r", encoding="utf-8") as f:
    # 2. 读取一行
    line = f.readline()

with open("log.txt", "r", encoding="utf-8") as f:
    # 3. 读取所有行（返回列表，每行是元素）
    lines = f.readlines()

with open("log.txt", "r", encoding="utf-8") as f:
    # 4. 逐行迭代（最常用，省内存）
    for line in f:
        print(line.strip())   # strip() 去掉行尾的换行符
```

**性能提示**：大文件（几百 MB）不要一次性 `read()`，用 `for line in f` 逐行处理，节省内存。

### 8.5.4 写入文件

```python
# 写入（覆盖）
with open("output.txt", "w", encoding="utf-8") as f:
    f.write("第一行\n")
    f.write("第二行\n")

# 追加
with open("output.txt", "a", encoding="utf-8") as f:
    f.write("第三行\n")

# 写入多行
lines = ["line1", "line2", "line3"]
with open("output.txt", "w", encoding="utf-8") as f:
    f.writelines(line + "\n" for line in lines)
```

> **注意**：`w` 模式会**清空**原文件！如果不想清空，用 `a` 模式。

### 8.5.5 文件路径

```python
# 相对路径（相对于当前工作目录）
"data/log.txt"

# 绝对路径
"/home/user/data/log.txt"          # Linux/macOS
r"C:\Users\user\data\log.txt"     # Windows

# 用 os.path 拼接路径（跨平台推荐）
import os
path = os.path.join("data", "log.txt")
```

### 8.5.6 处理文件不存在

```python
import os

if os.path.exists("log.txt"):
    with open("log.txt", "r", encoding="utf-8") as f:
        content = f.read()
else:
    print("文件不存在")
```

或用异常处理（第 10 章详讲）：

```python
try:
    with open("log.txt", "r", encoding="utf-8") as f:
        content = f.read()
except FileNotFoundError:
    print("文件不存在")
```

## 8.6 CSV 文件处理

CSV（逗号分隔值）是最常见的数据交换格式，Excel 能直接打开。

### 8.6.1 用 csv 模块读取

```python
import csv

with open("users.csv", "r", encoding="utf-8") as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)   # row 是一个列表
```

### 8.6.2 用 csv 模块写入

```python
import csv

data = [
    ["username", "status"],
    ["admin", "success"],
    ["root", "failed"],
]

with open("result.csv", "w", encoding="utf-8", newline="") as f:
    writer = csv.writer(f)
    writer.writerows(data)
```

> **注意**：Windows 上加 `newline=""` 能避免多出空行的问题。

### 8.6.3 DictReader / DictWriter（更方便）

```python
import csv

# 读取为字典
with open("users.csv", "r", encoding="utf-8") as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(row["username"], row["status"])
```

> **剧透**：第四卷的 Pandas 有更强大的 CSV 读取能力（`pd.read_csv()`），一行代码就能读入并转成数据表。但理解底层原理很重要。

## 8.7 综合实战：日志文件分析器

把本章知识综合起来，写一个读取真实日志文件并分析的程序：

```python
# 日志分析器
# 假设有一条条日志，格式: "时间 | 用户名 | 事件 | IP"

log_content = """2026-11-25 10:00:01 | admin | LOGIN_SUCCESS | 192.168.1.10
2026-11-25 10:01:15 | root | LOGIN_FAILED | 10.0.0.5
2026-11-25 10:02:30 | admin | LOGIN_FAILED | 192.168.1.10
2026-11-25 10:03:45 | guest | LOGIN_FAILED | 8.8.8.8
2026-11-25 10:05:00 | root | LOGIN_FAILED | 10.0.0.5
"""

# 1. 解析日志
def parse_log(content):
    records = []
    for line in content.strip().splitlines():
        parts = [p.strip() for p in line.split("|")]
        if len(parts) == 4:
            records.append({
                "time": parts[0],
                "user": parts[1],
                "event": parts[2],
                "ip": parts[3],
            })
    return records

# 2. 统计失败登录
def analyze(records):
    failed_users = {}
    suspicious_ips = set()
    
    for r in records:
        if r["event"] == "LOGIN_FAILED":
            failed_users[r["user"]] = failed_users.get(r["user"], 0) + 1
            suspicious_ips.add(r["ip"])
    
    return failed_users, suspicious_ips

# 3. 生成报告
def write_report(failed_users, suspicious_ips, output_file):
    with open(output_file, "w", encoding="utf-8") as f:
        f.write("=== 登录安全分析报告 ===\n\n")
        f.write("失败登录统计:\n")
        for user, count in failed_users.items():
            level = " [可疑]" if count >= 2 else ""
            f.write(f"  {user}: {count} 次{level}\n")
        f.write(f"\n可疑 IP 列表 ({len(suspicious_ips)}个):\n")
        for ip in sorted(suspicious_ips):
            f.write(f"  {ip}\n")
    print(f"报告已写入: {output_file}")

# 执行
records = parse_log(log_content)
failed_users, suspicious_ips = analyze(records)
write_report(failed_users, suspicious_ips, "security_report.txt")

# 查看报告
with open("security_report.txt", "r", encoding="utf-8") as f:
    print(f.read())
```

## 8.8 本章总结

| 知识点 | 核心内容 |
|--------|---------|
| 字符串索引切片 | 和列表类似；`[::-1]` 反转 |
| 字符串不可变 | 不能直接改字符，只能创建新字符串 |
| 常用方法 | `upper/lower`、`split/join`、`strip`、`find`、`replace`、`startswith/endswith` |
| f-string | `f"{变量}"`；支持表达式、格式控制 |
| 编码 | 永远用 UTF-8；`encode()`/`decode()` |
| 文件读取 | `with open(..., "r", encoding="utf-8")` |
| 文件写入 | `"w"` 覆盖、`"a"` 追加 |
| 逐行处理 | `for line in f`（大文件必用） |
| CSV | `csv.reader` / `csv.DictReader` |
| 路径 | `os.path.join()` 跨平台 |
