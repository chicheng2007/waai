## 16.1 项目背景

1. 找出访问量异常的 IP（可能是扫描器或攻击者）

## 16.2 第一步：生成模拟日志数据

实际项目中你会读真实日志，这里我们先生成一份模拟数据，方便你运行和理解。

```python
import numpy as np
import pandas as pd

np.random.seed(42)

# 模拟 5000 条访问日志
n = 5000

# 正常用户 IP（访问次数少）
normal_ips = [f"192.168.1.{i}" for i in range(10, 50)]
# 攻击者 IP（访问次数多）
attacker_ips = ["45.33.22.11", "103.21.58.90"]

# 大部分是正常 IP，少部分是攻击者
all_ips = np.random.choice(normal_ips, size=n-200, replace=True) + \
          np.random.choice(attacker_ips, size=200, replace=True)
np.random.shuffle(all_ips)

# HTTP 状态码：正常 200 居多，攻击者多 404
status_codes = []
for ip in all_ips:
    if ip in attacker_ips:
        status_codes.append(np.random.choice([200, 404, 403], p=[0.2, 0.7, 0.1]))
    else:
        status_codes.append(np.random.choice([200, 404, 301, 500], p=[0.85, 0.08, 0.05, 0.02]))

# 请求路径
paths = np.random.choice(
    ["/", "/index.html", "/login", "/admin", "/wp-admin", "/.env", "/api/user"],
    size=n, p=[0.3, 0.2, 0.15, 0.1, 0.1, 0.05, 0.1]
)

# 时间戳
timestamps = pd.date_range("2026-11-25 00:00", periods=n, freq="17s")

# 构建 DataFrame
df = pd.DataFrame({
    "timestamp": timestamps,
    "ip": all_ips,
    "status": status_codes,
    "path": paths,
})

print("数据概况:")
print(df.head())
print(f"\n总记录数: {len(df)}")
```

---

## 16.3 第二步：探索性数据分析（EDA）

```python
# 1. 基本统计
print("=== 基本信息 ===")
df.info()

print("\n=== 状态码分布 ===")
print(df["status"].value_counts())

print("\n=== 访问最多的 IP（Top 10）===")
ip_counts = df["ip"].value_counts().head(10)
print(ip_counts)
```

**发现**：两个攻击者 IP（45.33.22.11、103.21.58.90）的访问次数远超正常 IP，这就是明显的异常信号。

---

## 16.4 第三步：找出异常 IP

用 NumPy 的统计方法设定阈值：

```python
# 每个 IP 的访问次数
ip_counts_full = df["ip"].value_counts()

# 用 3σ 原则找异常
mean = ip_counts_full.mean()
std = ip_counts_full.std()
threshold = mean + 3 * std

print(f"平均访问次数: {mean:.1f}")
print(f"标准差: {std:.1f}")
print(f"异常阈值: {threshold:.1f}")

# 找出超过阈值的 IP
anomalous_ips = ip_counts_full[ip_counts_full > threshold]
print("\n=== 异常 IP ===")
print(anomalous_ips)
```

---

## 16.5 第四步：深入分析攻击者行为

```python
# 分析异常 IP 的状态码分布
for ip in anomalous_ips.index:
    print(f"\n=== 分析 IP: {ip} ===")
    ip_data = df[df["ip"] == ip]
    print(f"访问次数: {len(ip_data)}")
    print("状态码分布:")
    print(ip_data["status"].value_counts())
    print("访问路径 Top 5:")
    print(ip_data["path"].value_counts().head(5))
```

**发现**：攻击者的 404 比例极高（约 70%），且频繁访问 `/admin`、`/wp-admin`、`.env` 等敏感路径——典型的**目录扫描/漏洞探测**行为。

---

## 16.6 第五步：时间规律分析

```python
# 按小时统计访问量
df["hour"] = df["timestamp"].dt.hour
hourly = df.groupby("hour").size()

print("=== 每小时访问量 ===")
print(hourly)

# 攻击者 vs 正常用户的时间分布对比
attacker_data = df[df["ip"].isin(anomalous_ips.index)]
normal_data = df[~df["ip"].isin(anomalous_ips.index)]

print("\n=== 攻击者每小时访问量 ===")
print(attacker_data.groupby(attacker_data["timestamp"].dt.hour).size())
```

## 16.7 第六步：可视化报告

```python
import matplotlib.pyplot as plt

plt.rcParams["font.sans-serif"] = ["SimHei"]
plt.rcParams["axes.unicode_minus"] = False

fig, axes = plt.subplots(2, 2, figsize=(14, 10))
fig.suptitle("Web 访问日志安全分析报告", fontsize=18, fontweight="bold")

# 1. 状态码分布（饼图）
status_counts = df["status"].value_counts()
axes[0, 0].pie(status_counts.values, labels=status_counts.index, autopct="%1.1f%%", startangle=90)
axes[0, 0].set_title("HTTP 状态码分布")

# 2. Top 10 IP 访问量（柱状图）
ip_counts.head(10).plot(kind="bar", ax=axes[0, 1], color="steelblue")
axes[0, 1].set_title("访问量 Top 10 IP")
axes[0, 1].set_xlabel("IP")
axes[0, 1].set_ylabel("访问次数")
axes[0, 1].tick_params(axis="x", rotation=45)

# 3. 每小时访问趋势（折线图）
axes[1, 0].plot(hourly.index, hourly.values, marker="o", color="green")
axes[1, 0].set_title("每小时访问量趋势")
axes[1, 0].set_xlabel("小时")
axes[1, 0].set_ylabel("访问次数")
axes[1, 0].grid(True, alpha=0.3)

# 4. 攻击者状态码分布（堆叠柱状图）
attacker_status = attacker_data["status"].value_counts()
attacker_status.plot(kind="bar", ax=axes[1, 1], color="red", alpha=0.7)
axes[1, 1].set_title("异常 IP 的状态码分布（404 居多）")
axes[1, 1].set_xlabel("状态码")
axes[1, 1].set_ylabel("次数")

plt.tight_layout()
plt.savefig("web_security_report.png", dpi=150, bbox_inches="tight")
plt.show()
```
