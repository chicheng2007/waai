# 零基础 Python 通关 AI + 网络安全：从第一行代码到智能安全实战

> 一套为**纯零基础**学习者写的 super 详细教程。不讲空话，每一章都有可运行的代码、逐行解释、常见报错和配套练习。学完之后，你将具备用 Python 做数据处理、机器学习、深度学习、大模型应用，以及把它们用于**网络安全**（威胁检测、恶意软件分析、入侵检测、漏洞挖掘、AI 攻防）的完整能力。

---

## 关于这套教程

### 它适合谁

- 完全没有编程经验，但想进入 **AI + 网络安全** 领域的人
- 学过一点 Python，但知识零散、不成体系的人
- 想从传统安全行业（运维、等保、安全服务）转型 AI 安全的人
- 想从 AI 方向拓展到网络安全，做"既懂 AI 又懂攻击与防御"的复合型人才
- 需要一份可以边学边查、长期陪伴的"工具书"的人

### 它不适合谁

- 已经能熟练用 PyTorch 写模型、又精通攻防的人（你可以直接跳到第九卷查漏补缺）
- 想三天速成的人（AI + 安全没有捷径，但这条路是弯路最少的）

### 这套教程的特点

1. **零基础友好**：假设你连"变量"是什么都不知道，所有概念都从生活中的例子讲起。
2. **代码驱动**：超过 600 个可运行代码示例，每一个都逐行解释。
3. **双主线融合**：以 Python 为地基，AI 为主线，网络安全为落点——所有例子尽量贴近 AI 与安全场景。
4. **循序渐进**：九卷 30 章，从环境搭建到大模型安全实战，环环相扣。
5. **重视实战**：每卷都有项目实战，尤其第九卷包含多个完整的 AI 安全项目。
6. **合法合规**：所有安全示例均基于公开数据集、自建靶场和授权测试环境，强调白帽伦理与法律边界。

> **伦理声明**：网络安全知识是一把双刃剑。本教程所有技术仅用于**合法授权**的安全测试、防御研究和学习。未经授权对他人系统进行扫描、渗透或攻击在《中华人民共和国网络安全法》《刑法》等法律法规下属违法行为。请始终在"自己的靶场 / 明确授权 / CTF 竞赛"环境下练习。做个守护网络世界的白帽，而不是破坏者。

## 如何使用这套教程

1. **按顺序读**：前四卷是地基，不要跳。
2. **边读边敲**：不要只看不练，代码一定要亲手敲一遍。
3. **允许卡住**：报错是常态，把报错信息复制到搜索引擎，你已经不是第一个遇到的人。
4. **做练习**：每章末尾的练习题是检验理解程度的最好方式。
5. **合法练习**：所有攻击性技术只在自己的靶场或授权环境下练习。
6. **用 GitHub 管版本**：把你的代码提交到 GitHub，既是备份也是作品集。
