## 17.1 向量：带方向的箭头

### 17.1.1 什么是向量

向量就是一串有序的数字，比如 `[3, 4]`。

它有两层理解：

- **代数角度**：一组数字
- **几何角度**：一个从原点出发的箭头，指向坐标 (3, 4)

```
    y
    |
  4 |     ↗ (3,4)
    |    /
  3 |   /
    |  /
  0 +--------- x
      3
```

向量在 AI 里无处不在：

- 一张图片可以表示成一个向量（所有像素值排成一列）
- 一个用户的行为可以表示成一个向量（年龄、消费、点击次数...）
- 一个词可以表示成一个向量（词嵌入 word2vec）

### 17.1.2 向量的创建和运算

```python
import numpy as np

v = np.array([3, 4])      # 二维向量
w = np.array([1, 2])

print(v + w)   # [4 6]  向量加法：对应分量相加
print(v - w)   # [2 2]
print(v * 2)   # [6 8]  数乘：拉伸箭头
print(np.linalg.norm(v))  # 5.0  向量的长度（模）
```

### 17.1.3 点积（Dot Product）

点积是两个向量对应元素相乘再求和：

```python
v = np.array([1, 2, 3])
w = np.array([4, 5, 6])

dot = np.dot(v, w)   # 1*4 + 2*5 + 3*6 = 32
print(dot)           # 32

# 或
print(v @ w)         # 32
```

**点积的几何意义**：衡量两个向量的"相似程度"和"方向关系"。

- 点积 > 0：方向大致相同
- 点积 = 0：互相垂直（正交）
- 点积 < 0：方向大致相反

**余弦相似度**（AI 里判断文本/向量相似度的核心）：

```python
def cosine_similarity(a, b):
    return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))

v1 = np.array([1, 2, 3])
v2 = np.array([1, 2, 3])   # 完全相同
v3 = np.array([3, 2, 1])   # 不同

print(cosine_similarity(v1, v2))  # 1.0  完全相似
print(cosine_similarity(v1, v3))  # 0.71  部分相似
```

> **AI 应用**：推荐系统里判断用户兴趣相似度、NLP 里判断语义相似度、人脸识别里比对特征向量，底层都是余弦相似度。

## 17.2 矩阵：变换的配方

### 17.2.1 什么是矩阵

矩阵就是一个二维的数字表格：

```python
A = np.array([[1, 2],
              [3, 4]])
```

**几何意义**：矩阵代表一种**空间变换**（旋转、缩放、拉伸等）。一个向量乘以矩阵，就被"变换"成了另一个向量。

### 17.2.2 矩阵的基本运算

```python
A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])

print(A + B)      # 对应元素相加
print(A * 2)      # 每个元素乘 2
print(A.T)        # 转置：行列互换 → [[1,3],[2,4]]
```

### 17.2.3 矩阵乘法（核心！）

```python
A = np.array([[1, 2], [3, 4]])   # 2x2
B = np.array([[5, 6], [7, 8]])   # 2x2

C = A @ B
print(C)
# [[19 22]
#  [43 50]]
```

**计算规则**：结果 C 的第 i 行第 j 列 = A 的第 i 行与 B 的第 j 列的点积。

```
C[0,0] = A[0,:] · B[:,0] = 1*5 + 2*7 = 19
C[0,1] = A[0,:] · B[:,1] = 1*6 + 2*8 = 22
...
```

**维度规则**：`(m×n) @ (n×p) = (m×p)`，左边矩阵的列数必须等于右边矩阵的行数。

> **这是神经网络的数学核心**：`输出 = 输入 @ 权重矩阵 + 偏置`。每一层神经网络本质上就是一次矩阵乘法。理解了这个，你就理解了深度学习的"骨架"。

### 17.2.4 矩阵乘法的几何意义

矩阵乘法可以理解为"对空间做变换"：

```python
import numpy as np

# 一个向量
v = np.array([1, 0])   # 指向右边

# 旋转矩阵（旋转 90 度）
theta = np.pi / 2
R = np.array([[np.cos(theta), -np.sin(theta)],
              [np.sin(theta),  np.cos(theta)]])

result = R @ v
print(result)   # [6.1e-17 1.] ≈ [0, 1]  向上，正好旋转了 90 度
```

这就是为什么计算机图形学、3D 游戏、机器人、AI 都重度依赖矩阵——**矩阵是描述空间变换的通用语言**。

## 17.3 特征值与特征向量

### 17.3.1 直觉理解

当一个矩阵 A 作用于某些特殊向量 v 时，结果只是把 v 拉伸或压缩，不改变方向：

```
A · v = λ · v
```

- `v` 是**特征向量**（方向不变的那个特殊方向）
- `λ` 是**特征值**（拉伸的倍数）

```python
A = np.array([[2, 0], [0, 3]])

eigenvalues, eigenvectors = np.linalg.eig(A)
print("特征值:", eigenvalues)   # [2. 3.]
print("特征向量:\n", eigenvectors)
```

这个矩阵代表"x 方向拉伸 2 倍，y 方向拉伸 3 倍"，特征值就是拉伸倍数 2 和 3。

### 17.3.2 AI 中的应用：PCA 降维

PCA（主成分分析）是一种降维算法，核心就是找数据协方差矩阵的特征向量——那些"数据变化最大的方向"。

```python
# PCA 的简化演示
X = np.random.randn(100, 5)   # 100 个样本，每个 5 维

# 计算协方差矩阵
cov = np.cov(X, rowvar=False)

# 求特征值和特征向量
eigenvalues, eigenvectors = np.linalg.eig(cov)

# 按特征值排序，取最大的几个方向
idx = np.argsort(eigenvalues)[::-1]
print("各方向的重要性（特征值）:", eigenvalues[idx])
```

> **安全应用**：PCA 可用于异常检测——把高维数据投影到主要方向，在低维空间里偏离正常模式的点就是异常。也可用于数据可视化（把 100 维数据降到 2 维画出来）。

## 17.4 线性代数在 AI 与安全中的意义

| 概念 | AI 中的作用 | 安全中的作用 |
|------|-----------|-------------|
| 向量 | 表示数据样本、词嵌入、图像 | 表示流量特征、文件特征 |
| 点积/余弦相似度 | 相似度计算、注意力机制 | 恶意样本相似度比对 |
| 矩阵乘法 | 神经网络的核心运算 | 特征变换、降维 |
| 特征值/PCA | 降维、数据压缩 | 异常检测、可视化 |

**一句话总结**：线性代数让计算机能"批量"处理数据。AI 之所以能处理海量数据，全靠矩阵运算的并行性和高效性。
