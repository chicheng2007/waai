## 19.1 项目设计：一个混合架构的安全扫描器

我们要做一个「资产发现与风险检测工具」，架构如下：

```
┌────────────────────────────────────────┐
│  Python 编排层（CLI / API）              │
│  - 目标解析、任务调度                    │
│  - 规则管理（YAML 配置）                 │
│  - 报告生成（JSON/HTML）                 │
│  - AI 辅助分析（可选）                   │
├────────────────────────────────────────┤
│  Rust 引擎（PyO3 扩展）                  │
│  - 并发端口扫描                         │
│  - 服务指纹识别                         │
│  - 输入验证（内存安全）                  │
│  - 超时/限速控制                        │
└────────────────────────────────────────┘
```

**为什么这样分**：
- Rust 处理网络包和并发（快、安全）——这是核心
- Python 处理配置和报告（灵活、生态好）——这是胶水
- 窄接口：Python 只调「扫描」几个函数

### 19.2.2 核心扫描逻辑

```rust
use pyo3::prelude::*;
use std::net::{IpAddr, TcpStream};
use std::time::Duration;
use std::sync::Mutex;

/// 扫描结果
#[pyclass]
#[derive(Clone)]
struct ScanResult {
    #[pyo3(get)]
    port: u16,
    #[pyo3(get)]
    open: bool,
}

#[pymethods]
impl ScanResult {
    fn __repr__(&self) -> String {
        format!("<Port {} {}>", self.port, if self.open {"open"} else {"closed"})
    }
}

/// 验证并解析目标 IP（防恶意输入）
fn validate_target(target: &str) -> PyResult<IpAddr> {
    target.parse::<IpAddr>().map_err(|_| {
        pyo3::exceptions::PyValueError::new_err("无效的 IP 地址")
    })
}

/// 检查单个端口
fn check_port(ip: IpAddr, port: u16, timeout_ms: u64) -> ScanResult {
    let timeout = Duration::from_millis(timeout_ms);
    let open = TcpStream::connect_timeout(
        &std::net::SocketAddr::new(ip, port), timeout
    ).is_ok();
    ScanResult { port, open }
}

/// 并发扫描（释放 GIL）
#[pyfunction]
fn scan_ports(target: &str, ports: Vec<u16>, timeout_ms: u64, concurrency: usize)
    -> PyResult<Vec<ScanResult>>
{
    let ip = validate_target(target)?;

    pyo3::Python::with_gil(|py| {
        py.allow_threads(|| {
            use std::sync::mpsc;
            use std::thread;

            let (tx, rx) = mpsc::channel();
            let ports = std::sync::Arc::new(ports);
            let mut handles = Vec::new();

            // 分片并发
            let chunk_size = (ports.len() + concurrency - 1) / concurrency;
            for chunk in ports.chunks(chunk_size) {
                let chunk = chunk.to_vec();
                let tx = tx.clone();
                handles.push(thread::spawn(move || {
                    for port in chunk {
                        let result = check_port(ip, port, timeout_ms);
                        tx.send(result).ok();
                    }
                }));
            }
            drop(tx);

            let mut results = Vec::new();
            for r in rx { results.push(r); }
            for h in handles { h.join().ok(); }
            results.sort_by_key(|r| r.port);
            results
        })
    })
}

#[pymodule]
fn scanengine(_py: Python, m: &PyModule) -> PyResult<()> {
    m.add_function(wrap_pyfunction!(scan_ports, m)?)?;
    m.add_class::<ScanResult>()?;
    Ok(())
}
```

**安全设计要点**：
- `validate_target` 防止无效/恶意输入
- 超时控制（`timeout_ms`）避免无限等待
- 并发限制（`concurrency`）避免对目标造成 DoS
- 释放 GIL，让 Python 侧不阻塞

## 19.3 Python 编排层

### 19.3.1 目标解析与规则管理

```python
# scanner.py
import yaml
import json
from datetime import datetime
from typing import List, Dict
import scanengine

class ScanConfig:
    def __init__(self, config_path: str):
        with open(config_path) as f:
            self.data = yaml.safe_load(f)

    @property
    def targets(self) -> List[str]:
        return self.data.get("targets", [])

    @property
    def port_ranges(self) -> List[str]:
        return self.data.get("ports", ["1-1000"])

    @property
    def timeout_ms(self) -> int:
        return self.data.get("timeout_ms", 500)

    @property
    def concurrency(self) -> int:
        return self.data.get("concurrency", 50)


def parse_ports(ranges: List[str]) -> List[int]:
    """解析端口范围，如 '80,443,8000-8080'"""
    ports = set()
    for r in ranges:
        for part in r.split(','):
            part = part.strip()
            if '-' in part:
                start, end = map(int, part.split('-'))
                ports.update(range(start, min(end, 65535) + 1))
            else:
                p = int(part)
                if 1 <= p <= 65535:
                    ports.add(p)
    return sorted(ports)


class SecurityScanner:
    def __init__(self, config: ScanConfig):
        self.config = config

    def scan(self) -> Dict:
        ports = parse_ports(self.config.port_ranges)
        all_results = {}

        for target in self.config.targets:
            results = scanengine.scan_ports(
                target,
                ports,
                self.config.timeout_ms,
                self.config.concurrency,
            )
            open_ports = [r.port for r in results if r.open]
            all_results[target] = {
                "open_ports": open_ports,
                "scan_time": datetime.now().isoformat(),
                "risk_level": self._assess_risk(open_ports),
            }
        return all_results

    def _assess_risk(self, open_ports: List[int]) -> str:
        """基于开放端口评估风险（可接 AI 模型）"""
        high_risk = {23, 445, 3389, 1433, 3306}  # telnet, smb, rdp, mssql, mysql
        if high_risk & set(open_ports):
            return "HIGH"
        if len(open_ports) > 10:
            return "MEDIUM"
        return "LOW"


def generate_report(results: Dict, output: str):
    """生成 JSON 报告"""
    with open(output, 'w') as f:
        json.dump(results, f, indent=2, ensure_ascii=False)
```

### 19.3.2 CLI 入口

```python
# cli.py
import argparse
from scanner import ScanConfig, SecurityScanner, generate_report

def main():
    parser = argparse.ArgumentParser(description="混合架构安全扫描器")
    parser.add_argument("-c", "--config", required=True, help="配置文件路径")
    parser.add_argument("-o", "--output", default="report.json", help="报告输出")
    args = parser.parse_args()

    # 合规确认
    confirm = input("确认已获得目标授权？(yes/no): ")
    if confirm.lower() != "yes":
        print("已取消。请仅在授权环境下使用。")
        return

    config = ScanConfig(args.config)
    scanner = SecurityScanner(config)
    results = scanner.scan()
    generate_report(results, args.output)
    print(f"扫描完成，报告已保存到 {args.output}")

if __name__ == "__main__":
    main()
```

## 19.5 安全工具的特殊考量

### 19.5.1 不可信输入

安全工具处理的数据来自攻击者，必须假设输入是恶意的：

- **输入验证**：IP、端口、文件路径都要严格验证（Rust 的 `Result` 很好用）
- **长度限制**：防止超长输入导致内存耗尽
- **解析健壮性**：网络协议解析要能处理畸形包（Rust/Safe Rust 防止内存错误）

### 19.5.2 超时与资源控制

- 网络操作必须设超时（防止挂死）
- 并发要有上限（防止耗尽资源，也避免对目标 DoS）
- 大文件处理要流式（不要一次读入内存）

### 19.5.3 合规与审计

- 记录谁、何时、扫描了什么（审计日志）
- 明确授权检查（CLI 里加了确认步骤）
- 限速（避免对目标造成压力）
