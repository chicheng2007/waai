# 第九章 首选项与配置文件

Wireshark 高度可定制。合理的配置能显著提升分析效率，而配置文件（Profile）功能让你在不同场景下快速切换整套设置。

## 9.1 首选项对话框概览

通过菜单 `Edit → Preferences`（快捷键 `Ctrl + Shift + P`）打开首选项对话框。左侧是分类树，右侧是对应设置。主要分类包括：

- **Appearance**：界面外观（字体、颜色、主题、布局）。
- **Layout**：窗格布局方式。
- **Columns**：数据包列表的列配置。
- **Capture**：捕获相关默认设置。
- **Name Resolution**：名称解析（IP→域名、MAC→厂商、端口→服务名）。
- **Protocols**：各协议的专用设置（非常庞杂，按需调整）。
- **Statistics**：统计相关设置。
- **Filter Expressions**：保存常用过滤器表达式。
- **Shortcuts**：键盘快捷键自定义。

## 9.2 实用的界面配置

### 9.2.1 添加常用列

默认列之外，建议添加以下列（在 `Columns` 分类中点击 `+`）：

| 列名 | 类型 | 字段 | 用途 |
| --- | --- | --- | --- |
| Src Port | Src Port (unresolved) | tcp.srcport / udp.srcport | 快速看源端口 |
| Dst Port | Dst Port (unresolved) | tcp.dstport / udp.dstport | 快速看目的端口 |
| TTL | IPv4 TTL | ip.ttl | 判断跳数、识别操作系统 |
| TCP Seq | TCP Seq | tcp.seq | 分析 TCP 序号 |
| Time (Delta) | Delta time displayed | — | 与上一包的时间差 |

添加列时，类型选择「Custom」，在 Fields 栏输入对应的显示过滤器字段名。

### 9.2.2 名称解析

`Name Resolution` 分类下有三个开关：

- **Resolve physical (MAC) addresses**：把 MAC 前缀解析为厂商名（如 `00:11:22:...` → `Cisco`）。
- **Resolve network (IP) addresses**：反向 DNS 查询，把 IP 解析为主机名。
- **Resolve transport (port) names**：把端口解析为服务名（如 80 → http）。

> **注意**：启用 IP 反向解析会触发额外的 DNS 查询，可能污染你的抓包，并在离线分析时引入延迟。抓包分析时通常**关闭** IP 名称解析，或仅在需要时开启。MAC 和端口解析一般无害，可以保持开启。

### 9.2.3 时间显示格式

在 `Appearance → Columns` 中可设置时间列的默认格式。推荐把「Seconds Since Previous Displayed Packet」作为一列常驻，分析网络时延非常方便。

## 9.3 配置文件（Profile）

配置文件是 Wireshark 的一项强大功能。它把一整套设置（列、过滤器、着色规则、首选项等）打包，方便在不同场景下切换。

### 9.3.1 典型使用场景

- **网络排障 Profile**：显示 TTL、重传标志、时间差列，开启专家信息着色。
- **安全分析 Profile**：显示完整 IP/端口，自定义可疑流量着色规则，预置常用过滤表达式。
- **Web 开发 Profile**：重点显示 HTTP 相关列，预置 HTTP 过滤表达式。

### 9.3.2 创建配置文件

1. 点击状态栏右侧的配置文件名称（默认 `Default`），弹出菜单。
2. 选择 `New`，输入名称（如 `Security`）。
3. 在新 Profile 下调整各种设置。
4. 以后点击状态栏的 Profile 名称即可切换。

### 9.3.3 导入导出

配置文件可以导出为 `.zip` 文件，方便备份和分享：

- 菜单 `Edit → Configuration Profiles → Export`。
- 同事之间交换配置文件，可以统一团队的分析环境。

## 9.4 保存常用过滤器表达式

`Filter Expressions` 分类允许你保存常用的显示过滤器，并给它一个名字。保存后，在过滤器输入框的下拉箭头中可以直接选择。

把高频使用的过滤器（如 `tcp.flags.reset == 1`、`dns`、`http.request`）保存起来，能省去反复输入的麻烦。

## 9.5 快捷键自定义

`Shortcuts` 分类中可以为几乎所有操作绑定快捷键。默认的常用快捷键包括：

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + E` | 开始/停止捕获 |
| `Ctrl + O` / `Ctrl + S` | 打开 / 保存文件 |
| `Ctrl + F` | 查找包 |
| `Ctrl + M` | 标记/取消标记 |
| `Ctrl + G` | 跳转到指定包 |
| `Ctrl + Shift + P` | 打开首选项 |
| `+` / `-` | 放大 / 缩小字体 |

完整的快捷键表见附录（第四十一章）。

## 9.6 配置备份

Wireshark 的配置存放在用户目录：

- Windows：`%APPDATA%\Wireshark\`
- Linux：`~/.config/wireshark/`
- macOS：`~/.config/wireshark/`

定期备份这个目录，可以避免重装系统后丢失精心配置的环境。

## 9.7 小结

- 首选项对话框涵盖外观、布局、列、名称解析、协议设置等。
- 建议添加源/目的端口、TTL、时间差等实用列。
- 抓包分析时通常关闭 IP 反向名称解析，避免干扰和延迟。
- 配置文件（Profile）可以打包整套设置，按场景快速切换。
- 常用过滤器可保存为表达式，提高效率。
- 配置目录记得备份。
