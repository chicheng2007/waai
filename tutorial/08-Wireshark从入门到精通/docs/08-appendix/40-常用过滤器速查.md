# 附录 A：常用过滤器速查表

本附录汇总高频使用的显示过滤器和捕获过滤器，方便随时查阅。

## A.1 显示过滤器——按协议

| 需求 | 表达式 |
| --- | --- |
| 所有 TCP | `tcp` |
| 所有 UDP | `udp` |
| 所有 ARP | `arp` |
| 所有 ICMP | `icmp` |
| 所有 DNS | `dns` |
| 所有 HTTP | `http` |
| 所有 TLS | `tls` |
| 所有 IPv6 | `ipv6` |
| 所有 ICMPv6 | `icmpv6` |
| DHCP | `dhcp` |
| 非某协议 | `!arp` |

## A.2 显示过滤器——按地址/端口

| 需求 | 表达式 |
| --- | --- |
| 源 IP | `ip.src == 192.168.1.10` |
| 目的 IP | `ip.dst == 192.168.1.10` |
| 源或目的 IP | `ip.addr == 192.168.1.10` |
| IP 网段 | `ip.addr == 192.168.1.0/24` |
| 多个 IP | `ip.addr in {10.0.0.1, 10.0.0.2}` |
| TCP 端口 | `tcp.port == 80` |
| 源端口 | `tcp.srcport == 80` |
| 目的端口 | `tcp.dstport == 443` |
| 端口范围 | `tcp.port in {8000..8080}` |
| UDP 端口 | `udp.port == 53` |
| MAC 地址 | `eth.addr == 00:11:22:33:44:55` |
| 广播帧 | `eth.dst == ff:ff:ff:ff:ff:ff` |

## A.3 显示过滤器——TCP 分析

| 需求 | 表达式 |
| --- | --- |
| SYN 包 | `tcp.flags.syn == 1` |
| 纯 SYN（扫描） | `tcp.flags.syn == 1 && tcp.flags.ack == 0` |
| RST 包 | `tcp.flags.reset == 1` |
| FIN 包 | `tcp.flags.fin == 1` |
| 重传 | `tcp.analysis.retransmission` |
| 快速重传 | `tcp.analysis.fast_retransmission` |
| 重复 ACK | `tcp.analysis.duplicate_ack` |
| 乱序 | `tcp.analysis.out_of_order` |
| 零窗口 | `tcp.analysis.zero_window` |
| 所有 TCP 分析标记 | `tcp.analysis.flags` |
| 有数据的段 | `tcp.len > 0` |
| 指定流 | `tcp.stream eq 0` |
| RTT | `tcp.analysis.ack_rtt > 0.1` |

## A.4 显示过滤器——HTTP/DNS

| 需求 | 表达式 |
| --- | --- |
| HTTP 请求 | `http.request` |
| GET 请求 | `http.request.method == "GET"` |
| POST 请求 | `http.request.method == "POST"` |
| 特定主机 | `http.host == "www.example.com"` |
| URI 包含 | `http.request.uri contains "admin"` |
| 错误响应 | `http.response.code >= 400` |
| 404 | `http.response.code == 404` |
| User-Agent | `http.user_agent contains "curl"` |
| DNS 查询 | `dns.flags.response == 0` |
| DNS 响应 | `dns.flags.response == 1` |
| 查询特定域名 | `dns.qry.name == "example.com"` |
| NXDOMAIN | `dns.resp.code == 3` |
| 超长域名（隧道） | `len(dns.qry.name) > 50` |

## A.5 显示过滤器——安全分析

| 需求 | 表达式 |
| --- | --- |
| 包含关键字 | `frame contains "password"` |
| 十六进制特征 | `frame contains 47:45:54` |
| SQL 注入 | `http.request.uri contains "SELECT"` |
| XSS | `http contains "<script"` |
| 目录遍历 | `http.request.uri contains "../"` |
| 大包 | `frame.len > 1400` |
| 小包（扫描） | `frame.len < 64` |
| TTL 异常 | `ip.ttl < 16` |
| TLS ClientHello | `tls.handshake.type == 1` |
| TLS 告警 | `tls.alert` |

## A.6 捕获过滤器（BPF）速查

| 需求 | 表达式 |
| --- | --- |
| 主机 | `host 192.168.1.10` |
| 源主机 | `src host 192.168.1.10` |
| 目的主机 | `dst host 192.168.1.10` |
| 网段 | `net 192.168.1.0/24` |
| 端口 | `port 80` |
| TCP 端口 | `tcp port 80` |
| 端口范围 | `portrange 1000-2000` |
| 协议 | `tcp` / `udp` / `icmp` / `arp` |
| 排除 | `not arp` |
| 组合 | `host 10.0.0.1 && tcp port 80` |
| MAC | `ether host 00:11:22:33:44:55` |
| 长度 | `greater 1000` / `less 64` |
| SYN 包 | `tcp[tcpflags] & tcp-syn != 0` |

## A.7 逻辑运算符

| 运算符 | 别名 | 含义 |
| --- | --- | --- |
| `&&` | `and` | 与 |
| `\|\|` | `or` | 或 |
| `!` | `not` | 非 |
| `in` | — | 成员判断 |
| `contains` | — | 包含子串 |
| `matches` | — | 正则匹配 |

## A.8 常用字段函数

| 函数 | 用途 | 示例 |
| --- | --- | --- |
| `len()` | 长度 | `len(dns.qry.name) > 50` |
| `upper()` | 转大写 | `upper(http.host) contains "EXAMPLE"` |
| `lower()` | 转小写 | `lower(http.request.uri) contains "admin"` |
