# 第十三章 显示过滤器进阶

本章深入显示过滤器的高级特性：成员运算、字符串处理、正则匹配、字段切片，以及一批高频实战范例。掌握这些，你几乎可以表达任何筛选逻辑。

## 13.1 成员运算 `in`

`in` 运算符用于判断一个值是否属于某个集合，语法：`值 in {元素1, 元素2, ...}`。

```
tcp.port in {80, 443, 8080}          # 端口是 80/443/8080 之一
ip.addr in {10.0.0.1, 10.0.0.2}      # IP 是其中之一
http.request.method in {"GET", "POST"}  # GET 或 POST 请求
eth.type in {0x0800, 0x0806}         # IPv4 或 ARP
```

集合也可以表示范围：

```
tcp.port in {80..90}                 # 端口 80 到 90
ip.addr in {192.168.1.1..192.168.1.10}   # IP 范围
```

`in` 比多个 `or` 更简洁清晰，是首选写法。

## 13.2 字符串处理函数

### 13.2.1 `contains` 与 `matches`

- `contains`：子串匹配（区分大小写）。
- `matches`：正则匹配（区分大小写，默认使用 PCRE 语法）。

```
http.request.uri contains "login"        # URI 含 "login"
http.host matches "example\\.com"        # 正则匹配域名
dns.qry.name contains "ad"               # 查询名含 "ad"（找广告域名）
http.user_agent contains "curl"          # UA 含 curl
```

### 13.2.2 `upper()` 与 `lower()`

用于大小写转换，常配合 `contains` 实现忽略大小写的匹配：

```
upper(http.host) contains "EXAMPLE"      # 把域名转为大写再匹配
lower(http.request.uri) contains "admin" # 转为小写再匹配
```

### 13.2.3 `len()`

返回字符串或字节字段的长度：

```
len(dns.qry.name) > 30                   # 超长域名（可能是 DNS 隧道）
len(http.request.uri) > 100              # 超长 URI
```

**安全分析技巧**：DNS 隧道攻击常用超长子域名外传数据，`len(dns.qry.name) > 50` 是简单的检测思路。

## 13.3 字段切片

可以使用方括号对字节字段或字符串进行切片：

```
ip.addr[0] == 192                        # IP 地址第一个字节（需注意实际字段类型）
tcp.payload[0:4] == 47:45:54:20          # TCP 载荷前 4 字节是 "GET "
dns.qry.name[0:5] contains "www"         # 域名前 5 字节
```

切片语法 `[起始:长度]`，常用于检查载荷特征（魔数、协议头）。

## 13.4 协议字段层次

Wireshark 的字段名是层级化的，用点号分隔。例如：

```
ip.src                  # IP 层 → 源地址
tcp.srcport             # TCP 层 → 源端口
tcp.flags.syn           # TCP 层 → 标志 → SYN 位
http.request.method     # HTTP 层 → 请求 → 方法
dns.qry.name            # DNS 层 → 查询 → 名称
```

在协议树中选中字段，右键 `Prepare as Filter`，Wireshark 会显示完整的层级字段名。学会从协议树推断字段名，就不需要死记硬背。

**抽象字段 vs 具体字段**：有些字段是「抽象」的，如 `ip.addr` 同时匹配源和目的；有些是「具体」的，如 `ip.src`。`tcp.port` 同时匹配源和目的，`tcp.srcport` 只匹配源。

## 13.5 特殊运算符

### 13.5.1 位运算

```
tcp.flags & 0x02 != 0                    # SYN 位置位（位与）
ip.flags & 0x04                          # DF 位
```

### 13.5.2 协议存在性

```
tcp contains "password"                  # TCP 流中包含 "password" 字样
frame contains "admin"                   # 整个帧中包含 "admin" 字符串
```

`frame contains` 是万能搜索：它在整个帧的字节中搜索字符串或十六进制序列，当你不知道具体字段时非常有用。

```
frame contains "GET /admin"              # 帧中包含该字符串
frame contains 47:45:54                  # 帧中包含十六进制 "GET"
```

## 13.6 高频实战过滤器范例

### 13.6.1 网络排障类

```
tcp.flags.reset == 1                     # 所有 RST 包（连接被重置）
tcp.analysis.retransmission              # TCP 重传
tcp.analysis.duplicate_ack               # 重复 ACK
tcp.analysis.zero_window                 # 零窗口（接收方处理不过来）
tcp.analysis.flags                       # 所有 TCP 分析标记（重传、乱序等）
icmp.type == 3                           # ICMP 目的不可达
ip.ttl < 16                              # TTL 过小（可能路由异常）
```

### 13.6.2 安全分析类

```
tcp.flags.syn == 1 && tcp.flags.ack == 0 # 纯 SYN（可能是扫描）
tcp.port == 22 && tcp.len > 0            # SSH 数据（暴力破解分析）
dns.qry.name contains ".xyz"             # 查询可疑顶级域
http.request.method == "POST"            # POST 请求（可能提交数据）
ip.src == 192.168.1.0/24 && tcp.flags.syn == 1 && tcp.flags.ack == 0  # 内网主机发起的扫描
```

### 13.6.3 Web 分析类

```
http.request                             # 所有 HTTP 请求
http.response.code >= 400                # 错误响应
http.request.method == "GET" && http.request.uri contains ".js"   # JS 文件请求
http.host == "www.example.com"           # 特定站点
http.content_type contains "json"        # JSON 响应
tls.handshake.type == 1                  # TLS Client Hello
```

### 13.6.4 性能分析类

```
tcp.window_size < 1000                   # 小窗口
frame.len > 1400                         # 大包
tcp.time_delta > 1                       # TCP 包间隔超过 1 秒（需开启 TCP 时间戳首选项）
```

## 13.7 组合表达式的最佳实践

1. **先宽后窄**：先用协议过滤缩小范围，再加字段条件。如 `tcp && tcp.flags.syn == 1`。
2. **善用括号**：复杂逻辑一定要用括号明确优先级，避免歧义。
3. **用 `in` 代替多个 `or`**：更简洁。
4. **保存常用表达式**：通过 `Edit → Preferences → Filter Expressions` 保存，一键调用。
5. **验证表达式**：应用前看输入框颜色，绿色才正确。黄色警告要留意。

## 13.8 小结

- `in` 运算符用于集合成员判断，比多个 `or` 更简洁。
- `contains`（子串）、`matches`（正则）、`upper()`/`lower()`、`len()` 是常用的字符串/函数工具。
- 字段切片 `[起始:长度]` 可检查载荷特征。
- 字段名层级化，从协议树右键 `Prepare as Filter` 可快速获取。
- `frame contains` 是全帧万能搜索，不知道字段时很好用。
- 掌握排障、安全、Web、性能四类常用过滤器，能覆盖绝大多数场景。
