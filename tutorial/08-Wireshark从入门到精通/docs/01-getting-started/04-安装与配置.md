# 第四章 安装与配置

本章介绍在三大主流操作系统上安装 Wireshark 的方法，以及抓包所需的权限配置。安装本身不难，但很多初学者会卡在「抓不到包」这个环节，原因往往是网卡驱动或权限没配置好。

## 4.1 安装前的准备

- 建议从官网 <https://www.wireshark.org/download.html> 下载最新稳定版。
- 安装过程需要管理员/root 权限。
- 确保网卡驱动正常，且网络接口处于可用状态。

## 4.2 Windows 安装

### 4.2.1 安装步骤

1. 下载 Windows 安装包（`.exe`，64 位系统选 x64）。
2. 双击运行安装程序，按提示点击「Next」。
3. **关键一步**：安装组件选择界面，务必勾选 **Npcap**（或 WinPcap，旧版）。Npcap 是 Windows 下抓包的核心驱动，不装它 Wireshark 无法捕获流量。
   - Npcap 安装时会询问是否以「WinPcap 兼容模式」安装，一般保持默认即可。
   - 如需捕获本地回环（loopback）流量，确保勾选「Support loopback traffic」（Npcap 默认支持）。
4. 选择安装路径，完成安装。
5. 首次启动时，如果提示「以管理员身份运行」，按提示操作即可。不过现代版本通过 Npcap 服务，普通用户也能抓包。

### 4.2.2 常见问题

- **看不到网卡列表**：通常是 Npcap 没装好。重新运行安装程序，修复安装 Npcap；或在 Npcap 官网单独下载重装。
- **抓不到包**：检查是否选对了网卡（WLAN 还是以太网）；关闭可能冲突的 VPN/虚拟网卡软件再试。
- **无法捕获 loopback**：确认 Npcap 安装时启用了 loopback 支持，或在 Wireshark 中选择 `Npcap Loopback Adapter` 接口。

## 4.3 Linux 安装

Linux 发行版众多，包管理器不同，安装方式也不同。

### 4.3.1 Debian / Ubuntu

```bash
sudo apt update
sudo apt install wireshark
```

安装过程中会弹出一个配置对话框，询问「是否允许非超级用户捕获数据包？」建议选择 **Yes**（允许普通用户抓包）。如果安装时选了 No，可以事后调整：

```bash
sudo dpkg-reconfigure wireshark-common
# 选择 Yes
sudo usermod -aG wireshark $USER
# 注销并重新登录，使组权限生效
```

### 4.3.2 RHEL / CentOS / Fedora

```bash
# Fedora
sudo dnf install wireshark

# RHEL/CentOS 需先启用 EPEL 仓库
sudo yum install epel-release
sudo yum install wireshark
```

### 4.3.3 权限说明

Linux 下抓包需要访问网络接口的原始套接字，通常需要 root 权限或 `CAP_NET_RAW` capability。Wireshark 的安装包通过给 `dumpcap` 设置 capability（而非让整个 Wireshark 以 root 运行）来平衡安全与便利：

```bash
# 查看 dumpcap 的权限设置
getcap /usr/bin/dumpcap
# 正常应显示：cap_net_admin,cap_net_raw+eip
```

> **安全提示**：千万不要用 root 直接运行 Wireshark 图形界面。Wireshark 解析的是不可信的网络数据，以 root 运行会带来安全风险。正确做法是给 `dumpcap` 授权，让主程序以普通用户运行。

### 4.3.4 无图形界面的服务器

如果只有命令行环境，可以只安装 `tshark`：

```bash
sudo apt install tshark
```

然后用 `tshark -i eth0 -w capture.pcap` 抓包，再把文件传到本地用图形界面分析。

## 4.4 macOS 安装

### 4.4.1 方法一：Homebrew（推荐）

```bash
brew install --cask wireshark
```

### 4.4.2 方法二：DMG 安装包

从官网下载 `.dmg` 文件，双击把 Wireshark 拖入应用程序文件夹。

### 4.4.3 权限配置

macOS 下普通用户默认不能抓包。安装时如果勾选了「Install ChmodBPF」，系统会自动配置权限；否则需要手动设置：

```bash
sudo chmod 644 /dev/bpf*
```

更持久的做法是安装时允许 `ChmodBPF` 启动项。首次启动时如果提示权限不足，按照系统提示到「系统偏好设置 → 安全性与隐私」中允许即可。

## 4.5 首次启动与基本配置

安装完成后首次启动 Wireshark，建议做如下配置：

1. **选择主题与字体**：菜单 `Edit → Preferences → Appearance`，调整配色和字体大小，让长时间分析更舒适。
2. **设置列**：在 `Preferences → Columns` 中，建议添加「源端口」「目的端口」列，方便快速查看（详见第九章）。
3. **关闭不需要的协议**：如果某些协议解析影响性能，可在 `Analyze → Enabled Protocols` 中禁用。
4. **设置时间格式**：在视图菜单中把时间显示为「日期时间」或「自第一个包起的秒数」，按分析习惯选择。

## 4.6 验证安装是否成功

最简单的验证方法：

1. 启动 Wireshark，在主界面的接口列表中应该能看到至少一个网卡（如 `Wi-Fi`、`eth0`、`en0`）。
2. 点击某个网卡旁边的「开始捕获」按钮（蓝色鲨鱼鳍图标）。
3. 打开浏览器访问任意网站，稍等片刻，应该能看到数据包不断滚动。
4. 点击红色方块「停止捕获」，界面上会显示捕获到的数据包列表。

如果能看到数据包，说明安装成功。如果列表为空或提示错误，回到前面的权限/驱动部分排查。

## 4.7 小结

- Windows：必须安装 Npcap 驱动，注意 loopback 支持。
- Linux：安装后需配置普通用户抓包权限（`wireshark` 用户组 + dumpcap capability），切勿用 root 运行图形界面。
- macOS：推荐 Homebrew 安装，注意 ChmodBPF 权限配置。
- 无图形界面环境：只装 tshark，抓包后传到本地分析。
- 验证方法：启动捕获，访问网站，看是否有包滚动。
