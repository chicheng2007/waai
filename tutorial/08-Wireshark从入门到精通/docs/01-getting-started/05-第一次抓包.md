# 第五章 第一次抓包

本章带你完成一次完整的抓包流程：选择网卡、开始捕获、产生流量、停止捕获、保存文件。这是后续所有分析的基础。

## 5.1 启动 Wireshark 与接口选择

启动 Wireshark 后，你会看到欢迎界面，其中列出了本机可用的网络接口（Network Interfaces），例如：

- `Wi-Fi` 或 `wlan0`：无线网卡
- `Ethernet` 或 `eth0`：有线网卡
- `Npcap Loopback Adapter`（Windows）或 `lo`（Linux）：本地回环接口
- `VMware Network Adapter` 等虚拟网卡

**选择哪个接口？** 取决于你想抓什么流量：

- 想抓上网流量：选正在使用的 `Wi-Fi` 或 `Ethernet`。
- 想抓本机访问本机服务的流量：选 loopback 接口。
- 想抓虚拟机流量：选对应的虚拟网卡。

接口列表中通常会显示每个接口的实时流量小图表，帮你判断哪个接口有活动。

## 5.2 开始捕获

选中接口后，有三种方式开始：

1. 双击接口名称，立即开始捕获。
2. 单击选中接口，然后点击工具栏上的**蓝色鲨鱼鳍**图标（Start Capturing Packets）。
3. 使用快捷键 `Ctrl + E` 快速开始/停止捕获。

开始后，主窗口会实时滚动显示捕获到的数据包。每一行就是一个数据包（更准确说是「帧」）。

## 5.3 制造一些流量

如果刚开始界面是空的（或只有零星几个包），你需要制造一些网络活动。最简单的方法：

1. 打开浏览器，访问一个网站，例如 `http://example.com`。
2. 或者在命令行执行 `ping 8.8.8.8`（Linux/macOS 用 `ping -c 4 8.8.8.8`）。

你会看到数据包列表迅速增长。每行包含编号、时间、源地址、目的地址、协议、长度和简要信息。

> **小提示**：如果只想看自己产生的流量，避免被后台程序的流量干扰，可以在捕获前先设置捕获过滤器（见第十一章），或在分析时用显示过滤器筛选。

## 5.4 停止捕获

当你捕获了足够的数据包后，点击工具栏上的**红色方块**图标（Stop Capturing Packets），或再次按 `Ctrl + E` 停止。

停止后，数据包不再增加，你可以从容地进行分析。

## 5.5 观察数据包列表

停止捕获后，随便点击列表中的一行，观察下面两个窗格：

- **协议详情窗格**：以树状结构展示这一层层的协议首部信息，比如 Ethernet → IP → TCP → HTTP。
- **字节窗格**：以十六进制和 ASCII 形式显示数据包的原始字节。

点击协议树中的某个字段（如 `Source: 192.168.1.10`），字节窗格中对应的字节会高亮显示。这个联动功能在后续分析中非常有用（详见第八章）。

## 5.6 保存抓包文件

如果不保存，关闭 Wireshark 后捕获的数据就丢失了。保存方法：

1. 菜单 `File → Save`（快捷键 `Ctrl + S`），弹出保存对话框。
2. 选择保存位置，输入文件名，如 `first-capture.pcapng`。
3. 点击保存。

**文件格式说明**：

- **pcapng**：Wireshark 4.x 默认格式，功能更强，支持多接口、注释、增强信息。推荐用它。
- **pcap（经典格式）**：兼容性最好，几乎所有网络工具都支持。如果需要和其他工具交互，可以选择此格式。

「Save As」还可以选择只保存筛选后的包、指定范围等，详见第十五章。

## 5.7 打开已有抓包文件

除了实时抓包，Wireshark 更能打开已有的抓包文件：

1. 菜单 `File → Open`（快捷键 `Ctrl + O`）。
2. 选择 `.pcap` 或 `.pcapng` 文件。

你也可以使用命令行直接打开：

```bash
wireshark first-capture.pcapng
```

Wireshark 官网的[样本抓包库](https://wiki.wireshark.org/SampleCaptures)提供了大量真实场景的抓包文件，非常适合练习。

## 5.8 几个实用技巧

- **相对时间**：默认时间列显示的是「自捕获开始经过的秒数」，便于观察包之间的时间间隔。
- **标记包**：右键数据包 → `Mark Packet`（快捷键 `Ctrl + M`），可以给关注的包打标记，方便回顾。
- **注释**：右键 → `Edit Packet Comment`，可以给包添加文字注释（需保存在 pcapng 中）。
- **查找**：`Ctrl + F` 打开查找框，可按显示过滤器、十六进制值或字符串查找包。
- **回到顶部/底部**：`Ctrl + Home` / `Ctrl + End` 快速跳转。

## 5.9 小结

- 启动后先选对接口，双击或点鲨鱼鳍图标开始捕获，`Ctrl + E` 快速开关。
- 通过访问网站或 ping 制造流量，观察数据包列表滚动。
- 点击数据包可以在协议树和字节窗格查看细节，三者联动。
- 用 `Ctrl + S` 保存为 pcapng（推荐）或 pcap 格式。
- 用 `Ctrl + O` 打开已有抓包文件，善用标记、注释、查找等辅助功能。
