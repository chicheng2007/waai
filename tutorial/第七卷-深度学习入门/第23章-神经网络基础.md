## 23.1 从神经元说起

### 23.1.1 模仿大脑

人脑有约 860 亿个神经元，每个神经元接收信号、处理后传给下一个。神经网络就是模仿这个结构：

```
输入 → [神经元] → [神经元] → ... → 输出
```

### 23.1.2 一个人工神经元

一个神经元做三件事：

1. **接收输入**：x1, x2, x3...
2. **加权求和**：`z = w1*x1 + w2*x2 + w3*x3 + b`（w 是权重，b 是偏置）
3. **激活**：`a = 激活函数(z)`，输出结果

```
x1 ──w1──┐
x2 ──w2──┼──→ Σ ──→ 激活函数 ──→ 输出
x3 ──w3──┘    +b
```

**类比**：神经元像一个"投票器"——每个输入投一票（权重代表票数大小），汇总后如果超过某个门槛（激活），就输出结果。

```python
import numpy as np

# 一个神经元的计算
x = np.array([0.5, 0.8, 0.2])       # 输入
w = np.array([1.0, -0.5, 0.3])      # 权重
b = 0.1                              # 偏置

z = np.dot(w, x) + b   # 加权求和
print(z)   # 0.34
```

### 23.1.3 激活函数

激活函数给网络引入"非线性"，让它能学复杂规律。没有激活函数，再多层的网络也等价于一层（都是线性变换）。

常见激活函数：

```python
# Sigmoid：把任意值压到 0-1（早期常用，输出概率）
sigmoid = lambda z: 1 / (1 + np.exp(-z))

# ReLU：负值变 0，正值不变（现代最常用，简单高效）
relu = lambda z: np.maximum(0, z)

# Tanh：压到 -1 到 1
tanh = lambda z: np.tanh(z)

z = np.array([-1, 0, 1, 2])
print("Sigmoid:", sigmoid(z))   # [0.27 0.5 0.73 0.88]
print("ReLU:", relu(z))         # [0 0 1 2]
print("Tanh:", tanh(z))         # [-0.76 0 0.76 0.96]
```

> **现代默认**：隐藏层用 ReLU，二分类输出用 Sigmoid，多分类输出用 Softmax。

## 23.2 神经网络

### 23.2.1 多层网络

把很多神经元按层组织：

```
输入层     隐藏层1     隐藏层2     输出层
  x1  ──→   ○  ──→    ○  ──→    ŷ
  x2  ──→   ○  ──→    ○  
  x3  ──→   ○  ──→    ○  
```

- **输入层**：接收数据（特征）
- **隐藏层**：中间的层，做特征提取（"黑盒"的核心）
- **输出层**：给出预测

**"深度"学习**：隐藏层多（深）的神经网络，就叫"深度学习"。

### 23.2.2 前向传播（Forward Propagation）

数据从输入层流向输出层的过程：

```python
import numpy as np

np.random.seed(42)

# 一个两层网络
# 输入: 3个特征；隐藏层: 4个神经元；输出: 1个值
W1 = np.random.randn(3, 4)   # 输入层→隐藏层的权重
b1 = np.random.randn(4)
W2 = np.random.randn(4, 1)   # 隐藏层→输出层的权重
b2 = np.random.randn(1)

def forward(X):
    # 第一层
    z1 = X @ W1 + b1
    a1 = np.maximum(0, z1)   # ReLU 激活
    # 输出层
    z2 = a1 @ W2 + b2
    return z2

X = np.array([[0.5, 0.8, 0.2]])   # 一个样本
output = forward(X)
print(output)
```

**关键洞察**：前向传播就是一连串的 `矩阵乘法 + 激活`。第 17 章学的矩阵乘法，这里直接用上了。

### 23.2.3 反向传播（Backpropagation）——训练的核心

网络刚开始的权重是随机的，预测是乱的。怎么学出好的权重？

**反向传播**的思路（结合第 19 章的梯度下降）：

1. **前向传播**：用当前权重做预测
2. **计算损失**：预测和真实值的差距（损失函数）
3. **反向传播**：从输出层往输入层，计算每个权重对损失的影响（梯度）
4. **更新权重**：用梯度下降调整权重
5. **重复**：数万次后，权重越来越好

```
前向：输入 → ... → 输出 → 损失
反向：损失 → 梯度 → 更新权重（从后往前）
```

> **反传的数学本质**：链式法则（求复合函数的导数）。你不需要手推，PyTorch 会自动帮你算（叫"自动微分"）。但理解这个流程，能让你明白训练到底在干什么。

## 23.3 常见的网络结构

### 23.3.1 全连接网络（MLP）

每个神经元和上一层所有神经元相连。适合表格数据（就是前面机器学习处理的数据）。

```
安全应用：基于文件特征（大小、熵值等）的恶意软件检测
```

### 23.3.2 卷积神经网络（CNN）

用"卷积核"扫描输入，擅长处理图像（保留空间结构）。

```
安全应用：恶意软件字节图像识别（把二进制文件转成图片，用CNN分类）
```

### 23.3.3 循环神经网络（RNN） / Transformer

擅长处理序列数据（文本、时间序列）。

```
安全应用：日志序列异常检测、恶意代码序列分析
```

> **大模型的基础**：现在的大语言模型（GPT、DeepSeek）都基于 Transformer 架构，它是 RNN 的升级版，能更好处理长序列和并行计算。

## 23.4 深度学习 vs 传统机器学习

| 对比项 | 传统机器学习 | 深度学习 |
|--------|------------|---------|
| 特征工程 | 需要人工提取特征 | 自动学特征（端到端） |
| 数据需求 | 小数据也能work | 需要大量数据 |
| 算力需求 | CPU 够用 | 通常需要 GPU |
| 可解释性 | 较强 | 较弱（黑盒） |
| 适合场景 | 结构化表格数据 | 图像、文本、语音等非结构化数据 |

**选择建议**：

- 数据量小、是表格数据 → 用 scikit-learn（简单高效）
- 数据是图像/文本/语音、数据量大 → 用深度学习
- 安全场景：文件特征检测用传统 ML 就很好；恶意代码字节分析、日志序列分析用深度学习

> **小白问**：深度学习一定比传统机器学习好吗？
>
> **答**：不一定。数据少时，深度学习反而容易过拟合，效果不如传统方法。工具没有好坏，关键是匹配场景。真正的高手是"能用简单方法解决就不复杂化"。

## 23.5 本章总结

| 概念 | 核心要点 |
|------|---------|
| 神经元 | 加权求和 + 激活函数 |
| 激活函数 | ReLU（隐藏层）、Sigmoid（二分类）、Softmax（多分类） |
| 前向传播 | 矩阵乘法 + 激活，数据从输入到输出 |
| 反向传播 | 从损失反推梯度，更新权重 |
| 训练循环 | 前向→损失→反向→更新，重复多次 |
| 网络结构 | MLP（表格）、CNN（图像）、RNN/Transformer（序列） |
| 深度学习 vs ML | 自动特征、需大数据和GPU、可解释性弱 |
