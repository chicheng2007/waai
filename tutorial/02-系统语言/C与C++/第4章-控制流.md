# 第 4 章 控制流：分支与循环

## 本章目标

- 掌握 `if-else`、`switch-case`
- 掌握 `for`、`while`、`do-while` 循环
- 理解 `break`、`continue`、`goto`
- 注意 C 语言控制流的常见坑

C 的控制流语法和 Python / Java 类似，但更底层、更灵活（也更危险）。

---

## 4.1 条件判断

### 4.1.1 if-else

```c
#include <stdio.h>

int main() {
    int score = 75;
    if (score >= 90) {
        printf("优秀\n");
    } else if (score >= 60) {
        printf("及格\n");
    } else {
        printf("不及格\n");
    }
    return 0;
}
```

### 4.1.2 真假值

C 语言里：

- **0 是假**
- **非 0 都是真**（包括负数！）

```c
int x = -1;
if (x) {
    printf("x 为真\n");   // 会执行！-1 是非零
}
```

> **和 Python 的区别**：Python 里很多东西（空串、空列表）是假值，C 里只有 0 是假。

### 4.1.3 常见错误：= 与 ==

```c
int x = 5;
if (x = 10) {   // 错误！这是赋值，不是比较
    printf("永远成立\n");  // 因为赋值后 x=10，非零为真
}
```

> **技巧**：把常量写在左边可以避免这类错误：
> ```c
> if (10 == x) { ... }   // 如果写成 10 = x，编译器会报错
> ```

### 4.1.4 switch-case

```c
int port = 80;
switch (port) {
    case 80:
        printf("HTTP\n");
        break;
    case 443:
        printf("HTTPS\n");
        break;
    case 22:
        printf("SSH\n");
        break;
    default:
        printf("未知端口\n");
}
```

> **必须写 break**：如果漏掉 `break`，会"贯穿"（fall-through）到下一个 case。这有时是特性，但常常是 bug。编译器用 `-Wall` 会警告。

## 4.2 循环

### 4.2.1 for 循环

```c
// 经典写法
for (int i = 0; i < 10; i++) {
    printf("%d ", i);
}

// 等价的 while
int i = 0;
while (i < 10) {
    printf("%d ", i);
    i++;
}
```

### 4.2.2 while 与 do-while

```c
// while：先判断后执行
while (condition) {
    ...
}

// do-while：先执行后判断（至少执行一次）
do {
    ...
} while (condition);
```

### 4.2.3 break 与 continue

```c
for (int i = 0; i < 10; i++) {
    if (i == 3) continue;   // 跳过本次
    if (i == 8) break;      // 跳出整个循环
    printf("%d ", i);
}
// 输出: 0 1 2 4 5 6 7
```

---

## 4.3 goto（C 特有的危险工具）

```c
int main() {
    int x = 0;
    if (x == 0) {
        goto error;   // 跳转到标签
    }
    printf("正常流程\n");
    return 0;

error:
    printf("错误！\n");
    return 1;
}
```

> **建议**：尽量避免 `goto`，它会让代码难以理解（"面条代码"）。但在某些场景（如统一错误处理、内核代码）它很有用。Linux 内核里大量使用 goto 做错误清理。

## 4.4 实战：暴力破解检测逻辑

```c
#include <stdio.h>
#include <string.h>

// 模拟登录验证（教学用途）
int try_login(const char *username, const char *password) {
    // 假设正确密码是 "admin123"
    if (strcmp(username, "admin") == 0 && strcmp(password, "admin123") == 0) {
        return 1;  // 成功
    }
    return 0;  // 失败
}

int main() {
    int failed = 0;
    char password[50];
    
    for (int attempt = 1; attempt <= 5; attempt++) {
        printf("第 %d 次尝试，输入密码: ", attempt);
        scanf("%s", password);
        
        if (try_login("admin", password)) {
            printf("登录成功!\n");
            return 0;
        } else {
            failed++;
            printf("密码错误，已失败 %d 次\n", failed);
        }
        
        if (failed >= 3) {
            printf("失败次数过多，账户锁定!\n");
            break;
        }
    }
    return 0;
}
```

这个例子用了 `for`、`if`、`break`、`strcmp`，展示了控制流在实际安全逻辑中的应用。

## 4.5 控制流中的安全陷阱

### 4.5.1 switch 贯穿漏洞

```c
int role = 1;  // 1 代表普通用户
switch (role) {
    case 1:
        printf("普通用户\n");
        // 忘了 break！
    case 0:
        printf("管理员权限\n");   // 普通用户也执行了！权限提升漏洞
        break;
}
```

> **真实漏洞**：这类"漏写 break"的贯穿 bug 在权限判断代码中可能导致严重的越权漏洞。编译器用 `-Wall` 会警告，务必重视。

### 4.5.2 循环边界错误

```c
// 经典错误：<= 导致多执行一次
for (int i = 0; i <= 10; i++) {
    arr[i] = i;   // arr[10] 越界！数组只有 10 个元素（0-9）
}

// 经典错误：size_t 下溢
size_t size = get_size();
for (size_t i = size - 1; i >= 0; i--) {
    // 如果 size 是 0，size-1 变成巨大值，无限循环！
}
```

> **安全关联**：循环边界错误导致数组越界，是缓冲区溢出的常见来源。记住 C 的惯例：**用 `< size` 而不是 `<= size-1`**。

### 4.5.3 悬空 else

```c
if (a)
    if (b)
        printf("A");
else              // 这个 else 属于哪个 if？
    printf("B");
// else 属于最近的 if（即 if(b)）！
```

> **建议**：永远用花括号 `{}` 明确代码块，即使只有一行。这能避免悬空 else 和维护时的 bug。

## 4.6 本章总结

| 知识点 | 内容 |
|--------|------|
| if-else | 0 是假，非 0 都真；注意 = 与 == |
| switch-case | 必须写 break 防止贯穿（越权漏洞） |
| for/while/do-while | 三种循环；do-while 至少执行一次 |
| break/continue | 跳出/跳过 |
| goto | 危险但有时有用，尽量少用 |
| 安全陷阱 | switch 贯穿、循环边界、`<=` 越界、悬空 else |
