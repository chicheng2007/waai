## 12.1 高性能端口扫描器

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <thread>
#include <mutex>
#include <atomic>
#include <chrono>
#include <sys/socket.h>
#include <netinet/in.h>
#include <arpa/inet.h>
#include <unistd.h>

// Windows 需要用 winsock2.h，这里以 Linux/macOS 为例

std::atomic<int> scanned(0);
std::mutex cout_mutex;

bool scan_port(const std::string &ip, int port, int timeout_ms = 200) {
    int sock = socket(AF_INET, SOCK_STREAM, 0);
    if (sock < 0) return false;
    
    // 设置超时
    struct timeval timeout;
    timeout.tv_sec = 0;
    timeout.tv_usec = timeout_ms * 1000;
    setsockopt(sock, SOL_SOCKET, SO_RCVTIMEO, &timeout, sizeof(timeout));
    setsockopt(sock, SOL_SOCKET, SO_SNDTIMEO, &timeout, sizeof(timeout));
    
    struct sockaddr_in addr;
    addr.sin_family = AF_INET;
    addr.sin_port = htons(port);
    inet_pton(AF_INET, ip.c_str(), &addr.sin_addr);
    
    bool open = false;
    if (connect(sock, (struct sockaddr*)&addr, sizeof(addr)) == 0) {
        open = true;
    }
    close(sock);
    scanned++;
    return open;
}

void scan_range(const std::string &ip, int start, int end, 
                std::vector<int> &results, std::mutex &result_mutex) {
    for (int port = start; port <= end; port++) {
        if (scan_port(ip, port)) {
            std::lock_guard<std::mutex> lock(result_mutex);
            results.push_back(port);
            std::lock_guard<std::mutex> cl(cout_mutex);
            std::cout << "[+] " << ip << ":" << port << " 开放\n";
        }
    }
}

int main(int argc, char **argv) {
    std::string ip = "127.0.0.1";
    int start = 1, end = 1024, threads = 50;
    
    if (argc > 1) ip = argv[1];
    if (argc > 2) start = std::stoi(argv[2]);
    if (argc > 3) end = std::stoi(argv[3]);
    
    auto begin = std::chrono::high_resolution_clock::now();
    
    std::vector<int> results;
    std::mutex result_mutex;
    std::vector<std::thread> pool;
    
    int range = (end - start + 1) / threads;
    for (int t = 0; t < threads; t++) {
        int s = start + t * range;
        int e = (t == threads - 1) ? end : s + range - 1;
        pool.emplace_back(scan_range, ip, s, e, std::ref(results), std::ref(result_mutex));
    }
    
    for (auto &t : pool) t.join();
    
    auto elapsed = std::chrono::high_resolution_clock::now() - begin;
    auto ms = std::chrono::duration_cast<std::chrono::milliseconds>(elapsed).count();
    
    std::cout << "\n=== 扫描完成 ===\n";
    std::cout << "开放端口数: " << results.size() << "\n";
    std::cout << "耗时: " << ms << " ms\n";
    
    return 0;
}
```

编译：

```bash
g++ -std=c++17 -O2 -pthread scanner.cpp -o scanner
./scanner 127.0.0.1 1 1024
```

> **C++ 优势体现**：标准库线程（`std::thread`）、原子操作、互斥锁让多线程编程变得相对简单，性能远好于脚本语言。这也是为什么高性能扫描工具常用 C/C++ 或 Go。

## 12.2 文件哈希计算工具

```cpp
#include <iostream>
#include <fstream>
#include <iomanip>
#include <sstream>

// 简化版：演示原理（实际项目用 OpenSSL）
// 编译: g++ hash.cpp -lcrypto -o hash

#include <openssl/md5.h>
#include <openssl/sha.h>

std::string file_md5(const std::string &path) {
    unsigned char hash[MD5_DIGEST_LENGTH];
    MD5_CTX ctx;
    MD5_Init(&ctx);
    
    std::ifstream file(path, std::ios::binary);
    char buffer[4096];
    while (file.read(buffer, sizeof(buffer))) {
        MD5_Update(&ctx, buffer, file.gcount());
    }
    MD5_Update(&ctx, buffer, file.gcount());  // 最后一批
    MD5_Final(hash, &ctx);
    
    std::stringstream ss;
    for (int i = 0; i < MD5_DIGEST_LENGTH; i++) {
        ss << std::hex << std::setw(2) << std::setfill('0') << (int)hash[i];
    }
    return ss.str();
}

int main(int argc, char **argv) {
    if (argc < 2) {
        std::cout << "用法: " << argv[0] << " <文件>\n";
        return 1;
    }
    std::cout << argv[1] << " 的 MD5: " << file_md5(argv[1]) << std::endl;
    return 0;
}
```

**安全用途**：计算可疑文件的 MD5，与威胁情报库比对，判断是否已知恶意样本。

## 12.3 内存安全检测示例

用 AddressSanitizer 检测各种内存错误：

```cpp
// mem_errors.cpp
#include <cstdlib>
#include <cstring>

void uaf() {
    int *p = (int*)malloc(sizeof(int));
    free(p);
    *p = 42;   // UAF
}

void overflow() {
    char *buf = (char*)malloc(8);
    strcpy(buf, "这是一个超长的字符串");   // 堆溢出
    free(buf);
}

void double_free() {
    int *p = (int*)malloc(sizeof(int));
    free(p);
    free(p);   // Double Free
}

int main() {
    uaf();
    // overflow();
    // double_free();
    return 0;
}
```

```bash
g++ -fsanitize=address -g mem_errors.cpp -o mem_errors
./mem_errors
```

ASan 会给出详细报告，精确指出错误位置和类型。这是开发安全 C/C++ 程序的必备工具。

## 12.5 线程安全与工具优化

### 12.5.1 C++ 线程安全注意事项

多线程扫描器里的共享数据要加锁保护：

```cpp
#include <mutex>
#include <vector>

std::mutex mtx;
std::vector<int> results;

void worker(int start, int end) {
    for (int port = start; port <= end; port++) {
        if (scan(port)) {
            std::lock_guard<std::mutex> lock(mtx);   // RAII 自动加锁/解锁
            results.push_back(port);
        }
    }
}
```

> `std::lock_guard` 利用 RAII：构造时加锁，析构时自动解锁。即使中间抛异常也不会忘记解锁——这正是 C++ 相比手动 pthread_mutex 的优势。

### 12.5.2 原子操作

简单的计数器用原子变量更高效（无需锁）：

```cpp
#include <atomic>
std::atomic<int> counter{0};

counter++;   // 原子操作，线程安全
int val = counter.load();
```

### 12.5.3 常见并发 bug

```cpp
// 数据竞争：两个线程同时写
int shared = 0;   // 无保护 → 未定义行为

// 死锁：两个线程互相等待对方释放锁
std::mutex m1, m2;
// 线程A: lock(m1); lock(m2);
// 线程B: lock(m2); lock(m1);   // 死锁！
// 解决：用 std::scoped_lock(m1, m2) 一次性加锁
```

> **安全关联**：并发 bug（数据竞争、死锁）不仅影响稳定性，也可能被攻击者利用来制造 DoS 或状态混乱。写多线程安全工具时要格外小心。
