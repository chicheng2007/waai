## 三个区怎么分

本仓库按"用途"分成几个平级区，别找错地方：

- **guides/** —— 语法不会，学语法
- **tools/** —— 某门语言 / 工具怎么用
- **reference/**（本区）—— 书、链接、硬件配置资料
- **roadmap/** —— 全局学习路线与时间线
- **tutorial/** —— 六套完整系统教程

## 关于硬件文档

[hardware-setup.md](hardware-setup.md) 是针对你的具体设备写的（R9000P 2025 / RTX 5060 8GB / 32GB DDR5）。8GB 显存能做什么、不能做什么都标清楚了——本地跑 9B 量化模型可以，训练大模型不现实。这份是实战记录，不是通用教程。
