# 书籍推荐（按阶段 × 优先级）

> 原则：**一次只读一本，读懂再开下一本**。书不在多，读懂的才是你的。标注"必读"的先啃，"选读"的按需查。

**导航**：[00 总览](../roadmap/00-overview.md) · **书单** · [链接速查表](links.md) · [打卡](../checkin-log.md)

各阶段详情见 [学习路线](../roadmap/00-overview.md)。可点击的直达链接见 [链接速查表](links.md#十书籍购买)。

---

## 阶段 A：现在（大二上，软考期）
| 书 | 用途 | 优先级 |
|---|---|---|
| 《网络工程师教程》第 5 版（雷震甲） | 软考官方教材，主线 | **必读** |
| 《Python 编程：从入门到实践》（Eric Matthes） | Python 入门，只看基础篇 | **必读** |

## 阶段 B：软考后（AI 入门）
| 书 | 用途 | 优先级 |
|---|---|---|
| 《机器学习实战》（Peter Harrington） | 代码驱动入门，跟着敲 | **必读** |
| 《利用 Python 进行数据分析》（Wes McKinney） | pandas 数据处理，AI + 取证都用得上 | **必读** |
| 《机器学习》（周志华，西瓜书） | 建立理论框架，前几章精读即可 | 选读 |

## 阶段 C：大二下 ~ 大三（深度学习 + 网安）
| 书 | 用途 | 优先级 |
|---|---|---|
| 《动手学深度学习》（李沐） | 配套课程，边看边敲代码 | **必读** |
| 《白帽子讲 Web 安全》（吴翰清） | Web 安全经典，攻防必读 | **必读** |
| 《Web 安全深度剖析》（张炳帅） | Web 安全实操补充 | 选读 |
| 《文件系统取证分析》（Brian Carrier） | 讲 NTFS/FAT 底层原理，配合火眼理解"为什么" | 选读 |
| 《深度学习》（Goodfellow，花书） | 大部头，当字典查，别通读 | 选读 |

## 阶段 D：大三以后按需（走哪个方向读哪本）
- 《逆向工程核心原理》—— 走逆向 / PWN 方向
- 《Metasploit 渗透测试指南》—— 做渗透实操
- 《CTF 竞赛权威指南》—— 系统打 CTF
- AI+安全交叉类书籍 —— 大三有基础后再看，现在读了也吸收不了

---

> **提醒**：零基础阶段别买一堆书囤着。先买阶段 A 两本，读完再买 B。每一本都要动手敲书里的代码/做书里的实验，光看不练等于没读。

> 《动手学深度学习》官网 https://zh.d2l.ai 有免费完整在线版和 Jupyter 代码，可以先在线读，再决定是否买纸质书。纸质书在京东 / 当当 / 天猫搜书名即可。
