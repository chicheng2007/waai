## 二、你的真实定位（请重新记住这一条）

不要因为"攻防取证也零基础"就觉得自己没优势。你的定位应该是：

```
起点：网安专业在读（有课程/实验室/老师资源）+ 正在考软考（网络地基）+ 三线刚起步
目标：网安基础 + AI 能力双修的复合人才
```

**核心洞察：AI 不用等网安学好了再学，它应该是你学攻防和取证的工具。**

- 学攻防时，让大模型用大白话给你讲"SQL 注入原理"、"攻击链每一步在干嘛"
- 写渗透脚本时，让 AI 帮你写代码、改报错
- 做取证时，用 AI 帮你从海量日志/文档里自动提取关键证据
- 这样你学网安的速度会比纯手工学的同学快，而且**自然就有了"AI+网安"的实战感觉**

**记住：三线不是竞争关系，是互相加速的关系。** 软考打网络地基 → 网安基础给 AI 提供场景 → AI 反过来加速网安学习。

> **AI Agent 的两个身份**：① 现在就是你的学习工具——编码 Agent（Cursor / Claude Code / Copilot）帮你写 Python、改报错、写 CTF 和取证脚本；② 大三以后深入的方向——Agent 开发本身是 AI+网安最有前景的赛道（自动化渗透、威胁情报、告警研判）。详见 [04 大模型/Agent](04-llm-agent.md)。

## 九、编程语言取舍（大二先把 Python 练熟，别急着加语言）

- **Python（绝对主力，现在死磕）**：AI 全栈 + 网安脚本 + 取证分析 + CTF，三线全靠它
- **C++（保持，别丢）**：AI 领域用于模型部署/性能优化；网安用于逆向/PWN；大二不用猛练，保持手感即可
- **Go（大三后按需）**：网安里用于写高并发扫描器、代理、云安全工具（如 fscan 等）；AI 领域用得少。做安全开发/护网时再学
- **Rust（更靠后，按需）**：内存安全 + 高性能，用于底层工具、恶意代码分析、重构安全组件；学习曲线陡，大三下以后有兴趣再碰
- **原则**：现在只专精 Python + 保持 C++。语言是工具，先把一条线走通再扩展，不要为了学语言而学语言
- **怎么学 Python**：见 [Python 学习路线](../resources/python-roadmap.md)——从会语法到能写网安/AI 脚本的七个台阶

## 十、执行纪律（这几条比计划本身更重要）

1. **软考优先**：现在别因为学 CTF 和 AI 把软考挂了，主次分清。
2. **AI 当工具用**：学攻防取证时，遇到不懂的就问大模型，从第一天就养成习惯。
3. **CTF 驱动网安**：不要啃完书再实战，边做题边查漏补缺，这是最快的路径。
4. **每天敲代码**：哪怕只有 20 分钟，手不能停。看懂 ≠ 会写。
5. **一个项目做透**：贪多做一堆半吊子项目，不如把一个做到能讲清楚。
6. **用输出倒逼输入**：写博客、传 GitHub、给同学讲，教别人是最好的学习。
7. **语言先专精 Python**：Go / Rust 大三后按方向再学，现在加语言只会分散精力；C++ 保持手感即可。见上面"编程语言取舍"。
8. **从第一天就用编码 Agent**：Cursor / Copilot 帮你写代码，但每一行你都要看懂，抄不懂等于白学。
9. **守住法律底线**：渗透、扫描类操作只在靶场或书面授权环境进行，未授权碰真实系统违法，这是网安专业学生的红线。
10. **别和别人比进度**：每个人的节奏不同，你只需要比昨天的自己强。
