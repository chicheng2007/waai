## 怎么用这套路线

- **00 是入口**，先读它建立全局观，再跳到对应阶段的细篇。
- **软考是当前唯一硬主线**（01），AI 三线从第一天起就是加速器，不是"等网安学完再说"。
- **用"结束标志"驱动**，不用"学了多久"驱动——每篇都标了这一阶段做到什么算完成。
- 时间分配、完整大学时间线、三线如何互相加速，都在 [00 总览](00-overview.md) 里。
