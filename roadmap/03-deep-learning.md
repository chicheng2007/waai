## 6.1 深度学习基础
- **框架**：PyTorch（装 CPU 版即可：`pip install torch`，不用显卡）
- **课程**：李沐《动手学深度学习》（B 站视频 + 配套电子书 d2l.ai）
- **重点章节**：
  - 多层感知机（MLP）—— 基础
  - RNN / LSTM —— **重点！** 日志分析、流量序列都靠它
  - CNN —— 图像分类，网安用得少，可快速过
  - Attention / Transformer —— 先了解概念，阶段 3 深入

**目标**：能用 PyTorch 搭一个简单网络，把数据塞进去训练，看懂 loss 曲线。

## 6.2 网安实战项目（挑 1~2 个做透，不要贪多）

| 方向 | 技术栈 | 数据集 / 工具 | 难度 |
|---|---|---|---|
| 恶意流量检测 | 随机森林 / XGBoost | CIC-IDS2017（Kaggle） | ★★ |
| 钓鱼邮件识别 | TF-IDF + 逻辑回归 | 自己收集正常/钓鱼邮件各 1000 条 | ★★ |
| 日志异常检测 | LSTM AutoEncoder | 自己电脑的系统日志 / HDFS 日志数据集 | ★★★ |
| 恶意代码分类 | PE 文件特征提取 + XGBoost | Kaggle `Malware Detection` | ★★★ |

**做项目的正确姿势**（写进简历的要点）：
1. 明确业务问题：要解决网安里的什么痛点
2. 数据怎么来的、怎么预处理的（特征提取是关键，这里用到你的网安知识）
3. 用了什么模型、为什么选它
4. 评估指标：准确率之外，重点看**召回率**（网安里漏报代价高）
5. 写成 GitHub README + 一篇博客，这就是你的作品集
